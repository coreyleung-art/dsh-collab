## 2 · 工具面（宿主级，任何会话可调）

| 工具 | 用途 | 关键参数 |
|---|---|---|
| `plugin_standard` | 规范台：N1–N8 / R006 十项 / P1–P5 / 门型 A–F；`action=selfproof` 跑门自证矩阵 | `action=norms\|r006\|patterns\|gates\|all\|selfproof`（**取判据一律用 `all`**） |
| `plugin_name_gate` | 命名门：check / allocate / audit / explain | `name`、`tools[]`、`selfTools[]`（见下）、`base` |
| `plugin_review` | R006 十项审查（单插件或全量） | `target`、`all`、`deep`（真跑挂载冒烟）、`limit` |
| `plugin_pattern_list` | P1–P5 模式目录 | `detail` |
| `plugin_pattern_scaffold` | 模式化交付生成 | `pattern`、`slug`、`purpose`、`tools[]`、`outRoot`、`dryRun`（默认 true）、`confirm` |

**`selfTools` 的用法（容易误判）**：`check`/`allocate` 会把「已在活体工具表里的名字」报为 N4 冲突。若那个名字是**该插件自己已挂载的工具**，它是正常状态、不是冲突——此时把它列进 `selfTools[]`，判定即转 advisory 而不导致 `ok=false`。`audit`（只判形式）不需要它。

**语义纪律**：
- 真挂载冒烟有**四态**：`pass` / `fail` / `skipped`（**该次执行**的环境问题：缺 node、peer 解析不到、当次无 shell 服务——**这是示例清单，不是对审查方环境的预判**）/ `timeout`（apply 阶段阻塞）。四态**不得合并**，`skipped` 绝不可当 `pass`。
- 审查结果 `partial` = 有待证项，不是失败，也不等于通过。
- 退出码语义（CLI 侧）：`0` 成功 · `1` 失败/门失效 · `2` 用法或 IO 错误。

11. **★ 声明面代替实测面**：把描述里的数字当实测报出（作者犯过：工具描述写「16 条负例」，实测 15，账本照抄）。
12. **★ 代理量代替实测量**（作者犯过，**同一病已在两个域复现**）：
    ① 用「deps 只 +1」推出「5 项 bundle 无 deps 条目」并当实测报出，逐项实测为假。
    ② **（2026-10-08 复现）** 用 `size=0` 与 `pushed==created` 推出「仓为空壳」并与真判据**并列**写进证据链。裁判给同账号反例证伪二者：`corey-i9` **size=0 恒 8 个月却有 commit**；`created 10:29:38 → pushed 10:29:41` 仅差 **3 秒**仍有 commit。真判据只有**内容级**三条：`commits` 409 / `contents` 404 / `git/refs` 409。
    ⇒ 教训：元数据字段（size / 时间戳）是**代理**，内容级端点才是**测量**；**代理量不得与实测量并列进入同一条证据链**，否则链被自身的伪判据污染。
13. **★ 会撒谎的检查（三条实证）**：① CLI 的 `process.exit` 会**连带杀掉**后台未完成的异步递归链，于是 `--selfcheck` 显示 pass，掩盖了真实的无界递归；② peer 解析失败会让真挂载冒烟静默走 `skipped`，看上去「没报错」；③ 指纹等价只能证明「移植忠实」，**不能证明被移植的东西本身正确**（忠实移植了一个忠实移植的缺陷）。

> **判据座右铭**：凡「检查通过」，先问一句——**它是怎么通过的？有没有一条路径让它必然通过？**

14. **判据形态盲区**：R6 只识别 `VERSION = "x.y.z"` 形态，认不出 `STD_ID = 'PSTD/1.0.1'` 这种命名 —— 这类第二处版本声明会漏检。发现新命名形态时，**扩判据而不是放过**。

15. **★ 不可复现的读数（真读数 + 缩名 = 等于没测）**（作者犯过，2026-10-08）：证据卡写「pstd 66KB」，数字**对**（真名 `dsh-plugin-pstd` size=66），但 `repos/coreyleung-art/pstd` 实测 **404** ⇒ 引用方**无法原样重跑**，这条读数的证据价值归零。

    **现测 = 自包含命令 + 全名（不缩写）+ 输出摘要 + 时刻**，缺一即不得作为他人不可逆决策的输入。
    ⇒ 配套纪律（因删仓不可逆）：**不可逆决策须在决策时现测**——旧读数即便仍为真，也可能已陈旧（曾据此误报「另 5 个空仓」，实测各 1 commit）。
    ⇒ **操作性门（裁判归纳、作者落盘）「引用自检三问」**，引任何版本/名字/数之前先过一遍：
