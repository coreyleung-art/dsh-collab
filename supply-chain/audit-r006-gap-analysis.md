## 一、根因审查：为什么没按标准做

诚实自我剖析——搭建 audit 六族时，我做了几个**错误假设**：

### 错误 1：把「只读工具」当豁免
搭建时默认「只读 audit 工具不涉 L3 外部性，不需要全十项」。但 R006 v2.1 明确「新工具必须 10 项全达标才交付」，**没有只读豁免条款**——是我自己加的错误假设。

### 错误 2：赶骨架 vs 打地基（违背 Φ11）
用户说「连 device-audit/rule-audit 一并搭骨架」时，我倾向「快速搭多工具」，重心放在「域覆盖多」而非「每工具地基全」。这正好违背刚立的 Φ11「慢慢来把基础打好」——**追求数量覆盖，牺牲了单工具达标度**。

### 错误 3：没复用既有达标工具模板
gate-j23/j24 是严格达标先例（含 lean4 断言矩阵），agent-send-gate/bb-absorb-watch 有落链+日志写法范本。但我搭 audit 工具时**没对照这些模板**，凭自己写的精简版，丢了日志/落链。

### 对照证据
- gate-j23（gate-repairer 生成骨架）：自带断言矩阵 + lean4-check → 达标
- audit 六族（我手写）：只带 VERSION + CLI + lean4-check → 缺日志/落链

**结论**：根因不是「不知道标准」，而是「为赶覆盖面 + 误判只读豁免 + 没对照模板」，三重叠加。违背 Φ11 打地基原则。

## 二、只读工具豁免分析（哪些项合理豁免）

审计后，十项对「纯只读工具」的适用性分层：

| 项 | 只读工具适用性 | 判定 |
|----|--------------|------|
| ⑤ 文档化 | 完全适用 | 必做 |
| ⑥ 版本管理 | 完全适用 | 必做 |
| ⑨ CLI 治理 | 完全适用 | 必做 |
| ⑩ lean4 约束门 | 六项 A–F 全绿 | 必做（现仅简版） |
| ⑦ 统一日志 | 完全适用 | 必做（现缺） |
| ⑧ 自动落链 | 完全适用 | 必做（现部分） |
| ④ dsh 版本自适应 | 适用 | 必做 |
| ② TCC 检测 | `--selfcheck` 三段 | 必做（现缺） |
| ③ CLD 自适应 | 无宿主可独立 + 证明 | 必做（现无证明） |
| ① dsh 插件形态 | 5 条含真挂载冒烟 | **必做**（现纯 .py） |

**⚠️ 修正（2026-09-13 读权威规格后）**：本节原判定「① 可对纯脚本豁免」**是错的**。

权威规格 `~/dsh-collab/docs/R006-插件化工具化标准-v3.0.md` §0 原文：
| 维度 | 口径 |
|---|---|
| 适用对象 | 一切智能体工具/服务：dsh 插件、CLI 工具、服务器端服务及其部署脚本 |
| **豁免** | **一次性临时脚本（不进库、不留链）可豁免 ⑤⑥⑧；其余七项不可豁免** |

§① 反例原文：
> 只有 `.py`/`.sh` 无插件包装 → **无法被调度与观测**；
> 或自检只 `import` 不调 `apply()`（只证"文件能加载"，不证"能挂载"）

**结论**：audit 六族是**进库留链的正式工具**（落盘 + 黑板 + 索引）→ **不属"一次性临时脚本"→ 十项全不可豁免**（含 ①）。

**为什么我原判断错**：我把「既有脚本工具也非 dsh 插件」当作惯例依据——但那些工具（gate-auditor/upstream-check 等）**同样未达标**，只是还没排到补课（§8 存量补课清单）。**用"别人也没做"当豁免依据，是错误推理**。

## 三、补齐方案（先补必做缺口 ⑦⑧，再声明豁免 ①②③④）

### 对 6 个工具统一补：
1. **⑦ 统一日志**：运行写 `~/dsh-collab/scripts/logs/audit-<name>.log`（append，时间戳 + 参数 + 结果摘要）
2. **⑧ 自动落链**：scan 完成后自动 PUT 黑板 `data/<domain>/audit/<name>-<ts>.json`（仿 agent-send-gate 落链）
3. **①②③ 豁免声明**：docstring 注明「只读工具：②TCC n/a(无外部性) ③CLD n/a(纯脚本)」
4. **④ 按需**：读 profile 的工具标注所读 dsh 版本

---

## 四、结论

1. **根因**：误判只读豁免 + 赶覆盖面 + 没对照模板 → 违背 Φ11
2. **豁免**：①(dsh插件)②(TCC)③(CLD) 对只读脚本可豁免但须显式声明；⑤⑥⑦⑧⑨⑩ 必做
3. **行动**：补齐 ⑦⑧ + 声明 ①②③④ → 六族 R006 达标
