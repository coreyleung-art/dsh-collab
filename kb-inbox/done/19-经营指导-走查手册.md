## 各模块数据点（指标清单）

### 1. 商家等级（/shopGrade#/level）
- 日常等级 / 大促等级
- 今日体验分（含趋势）
- 综合体验分说明：履约、服务、商品三维度加权（综合体验分 = 服务分×权重 + 商品分×权重 + 履约分×权重）
- 今日更新数据｜更新日期（每日上午 10 点前更新）
- 指标明细表：分类 / 指标详情 / 指标表现 / 提分指南 / 优化建议
- 关键规则（FAQ）：
  - 周期订单量 <30 单时指标分数最高 80 分
  - 售后判商责率 = 下单时间 T-17~T-3 近 15 天数据
  - 等级越高流量曝光/活动提报权益越多；低等级管控次日生效

### 2. 营业分析（/manageAnalysis/pc#/business）
- 财务分析 / 成交分析
- 今日实时数据：预计收入、营业额、有效订单（均含「比昨日同时段」）
- 预计收入 = 今日已完单 + 今日下单进行中
- 历史营业数据（时间范围：今日/昨日/近7日/近30日/自定义 + 下载表格）：
  - 收入（比前日）、营业额（比前日）、支出（比前日）、有效订单（比前日）

### 3. 流量分析（traffic.js 已实现）
- 曝光人数、曝光-入店率、曝光-下单率、下单人数
- 贡献最大渠道 + 占比（如搜索渠道）
- 整体表现（较上周期同时段 %）

### 4. 商品分析（/page/analysis/productAnalysis）
- 三个入口：新品培育 / 全部商品分析 / 异常品预警
- 时间范围：昨日/近7日/近30日/自定义 + 对比日期（7日前）
- 数据总览（统计周期 vs 对比周期）：
  - 动销商品数（较7日前 / 商圈同行）
  - 商品动销率（较7日前 / 商圈同行）
  - 在售商品数（较7日前 / 商圈同行）
  - 商品销量（较7日前 / 商圈同行）
- 类目明细 / 商品明细（可导出全部数据）

### 5. 服务分析（/manageAnalysis/pc#/service）
- 时间范围：昨日/近7日/近30日/自定义
- 服务整体 8 项指标（均含「比前7日」+ 商圈同行对比）：
  1. 服务问题导致的营业额损失（元）
  2. 非顾客原因异常订单数（单）
  3. 接单问题订单数（单）
  4. 顾客投诉订单数（单）
  5. 超时拣货订单数（单）
  6. 超时配送订单数（单）
  7. 配送信息闭环率（%）
  8. 送前返图率（%）+ 未返图订单数（可下载订单）

### 6. 营销分析（/manageAnalysis/pc#/market）
- 时间范围：昨日/近7日/近30日/自定义
- 营销活动总览 6 指标（均含「比前7日」+「商圈同行均值」）：
  1. 活动营业总额
  2. 活动订单数
  3. 活动成本
  4. 商家补贴金额
  5. 平台补贴金额
  6. 投入产出比（ROI）
- 趋势图（各指标）
- 营销活动类型表（按活动类型聚合同 6 指标）

### 7. 顾客分析（/manageAnalysis/pc-vue#/customerAnalysis/single）
- 新老客看板：时间范围（每日数据/每周累计/每月累计 + 自定义）
- 成交顾客数（较前一日 / 较上周日）
- 新客人数（较前一日 / 较上周日）
- 老客人数（较前一日 / 较上周日）
- 新客占比 vs 老客占比（我的 vs 商圈同行均值）
- 日期序列趋势（按日）

### 8. 评价分析（/page/customer#/frontweb/userComment/commentAnalysis）
- 注意：仅统计有效评价（已过滤无责/屏蔽）
- 时间范围：昨日/近7天/近30天/自定义 + 导出数据
- 总览：差评数、中评数、好评数、评价数、中差评率（均含「较上周期」）
- 智能评价分析（AI 分析评价内容）：
  - 分类：中差评（1-3 星）/ 好评
  - 评价数、商品相关中差评数（占比）、服务相关中差评数（占比）

### 9. 报表下载（/manageAnalysis/pc#/report）
- 下载列表分类：交易数据 / 订单数据 / 流量数据 / 商品数据 / 服务数据
- 数据类型：门店财务明细 / 门店成交明细 / 配送费用数据
- 日期范围：按日（营业数据日期为账单日期）
- 数据指标（门店财务明细示例）：
  - 商家ID / 名称 / 省份 / 城市
  - 收入、商品原价、包装费、顾客配送费、营业支出、商家补贴金额、公益捐款、其他费用
  - 营业额、实付交易额、有效订单数、实付单均价
  - 佣金、配送服务费
  - 已取消订单数 + 取消损失金额（用户/商家/配送/其他原因分列）
- 报表预览 + 下载

### 10. 经营诊断（/manageAnalysis/pc#/diagnose）
- 总分（如 71 分）+ 待提升指标数
- 三大维度评分：基础运营 / 服务履约 / 营销活动
- 诊断指标：待提升指标（n 项）/ 满分指标（n 项）
- 每项指标明细：指标 / 指标数据 / 指标得分 / 阶段目标 / 优化建议 / 立即学习（课程链接）
  - 如：配送收入占比（近7日日均0%，60分）、配送超时率、不接单率（节日汇总/近7日汇总）

## 汇总能力设计

`lib/business.js` 提取函数：
- `fetchBusiness(page)` — 营业分析（今日实时 + 历史）
- `fetchProduct(page)` — 商品分析总览
- `fetchService(page)` — 服务分析 8 指标
- `fetchMarket(page)` — 营销分析 6 指标
- `fetchCustomer(page)` — 顾客分析新老客
- `fetchComment(page)` — 评价分析
- `fetchDiagnose(page)` — 经营诊断总分 + 维度 + 待提升项
- `fetchGrade(page)` — 商家等级/体验分
- `buildPanorama(storeId)` — 经营全景汇总（聚合以上 + 流量/关键字）
