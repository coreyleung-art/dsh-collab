# 外卖运营合规护栏（红线规则）

> 适用范围：美团闪购/京东秒送/抖店即时零售 多平台外卖门店运营
> 关键决策前必须交叉验证当前页面/平台规则（本页为运营护栏汇总，具体细则以平台现行规则为准）

## 1. 拒单率周红线（>10% 起管控）
- 平台按周统计拒单率（拒单/接单总量），**超过 10% 进入管控**，触发流量降权、活动资格收紧等处罚。
- 运营动作：自动操作（拒单）触发红线前必须先警告；拒单必须记录原因并留审计。
- 参考：美团闪购商户违规管理规则（2026-06-29，违规红线）。

## 2. 鲜花「花图不符包赔」（花店类目生死线）
- 美团闪购鲜花「花图不符包赔」服务标签说明（2026-08-12）：**商品展示图与实物不符需包赔**。
- 运营要求：商品图必须真实（颜色/花材/数量/包装）；正常偏差有豁免，但刻意差异属违规。
- 影响：包赔产生营业损失 + 合规扣分 → 花店类目（如守白鲜花）商品上架前务必核对实拍图。

## 3. 顾客消息 3 分钟回复率考核
- 平台考核顾客消息回复时效（1 分钟人工回复率，达标率 80%），近 7 日滚动统计。
- 考核口径：无咨询不考核；未开通 IM 人工回复则指标计入且得分为 0。
- 运营动作：IM 工作台待回复会话须优先处理；自动回复/话术库覆盖常见场景。

## 4. 合规信用分
- 美团闪购商户合规信用分管理规范（2026-08-11）：平台按规范扣分，分低影响流量/活动资格。
- 运营要求：关注信用分变化，违规记录可在后台「违规管理」查询。

## 5. 其他红线
- 实拍发货治理：高价商品（生鲜/珠宝）需实拍发货。
- 假冒伪劣商品：严禁，违规公示处罚。
- 写操作通用护栏：接单/拒单/上下架/改价/评价回复/删除必须先 dry-run 或人工确认，全程留审计；店铺密码绝不存取，登录由用户在对应窗口完成。
