# 订单管理模块（闪购商家端）
> 走查自：守白鲜花（wmmqsb348890）· 营业中

## 入口与页面
- 导航：侧边栏「订单管理」→ 子项（今日待办 / 预订单 / 全部订单 / 进行中订单管理）
- 全部订单 URL：`https://shangoue.meituan.com/#/page/orderbusiness#/order/history`
- 页面组成（自上而下）：
  1. **IM 客服消息栏**：今日未回复 / 顾客消息 / 平台消息 计数（有 60s 倒计时提示）
  2. **常用回复 / 本店话术**：快捷回复模板区
  3. **客服指标表**：指标 / 目标值 / 当前值 / 状态（回复率考核指标）
  4. **客服账号表**：客服账号 / 正在接待用户数 / 操作
  5. **订单列表区**：无订单时显示「暂无数据」

## 关键运营规则（沉淀为知识）
- **回复率考核**：顾客消息需在 3 分钟内回复，超时影响回复率考核；「今日未回复」有 60s 倒计时
- 营业中时订单列表在订单产生后出现；当前无订单 → 订单卡选择器待营业后补充

## 动作原语（后续录制）
- 待订单产生后录制：查看待接单 / 接单 / 拒单 / 订单详情（选择器同监控层 selectors.orders）

# 营销活动模块 + 平台 UI 覆盖层特性

## 营销活动模块
- 入口：侧边栏「营销活动」→ 店铺活动 / 报名活动 / 我的活动 / 活动日历 / 活动助手
- 店铺活动 URL：`https://shangoue.meituan.com/#/marketing/shangou/activity/pc/merchant/entry`
- 用途：满减/折扣/优惠券等店铺活动配置（待抽屉关闭后补充表单结构）

## 平台 UI 覆盖层（重要·影响动作执行器）
实测发现闪购商家端存在两个常驻覆盖层：
1. **小闪 AI 助手抽屉**（`.ai-drawer` / `.assistant-chat-*`）：整层覆盖主内容区，
   重载页面后仍自动打开；点击 backdrop 与 header 关闭按钮均未能收起——待进一步研究收起方式。
2. **IM 会话框**（`.wm-im-dialog`）：常驻打开，可通过容器内 close 图标关闭（已实测可行）。

**执行器规则**：任何自动化动作前，必须先检测并处理覆盖层（至少收起 IM 会话框），
否则动作元素可能被遮挡不可点击；AI 抽屉收起方式待解锁（可能需定位其折叠控件）。

### 监督规则（建议）
- 回复率红线：近7日 1 分钟人工回复率 ≥ 80%（平台考核，未达标影响权益解锁）
- 今日未回复：IM 工作台「今日未回复」内消息须 3 分钟内回复，60s 倒计时内处理
- 首响率目标：≥ 80%（60 秒内响应）
- 员工交接班时处理「待办消息」（保留 30 天）

### 店铺欢迎语
- 亲，您的订单已经送达，不知您对小店的服务是否满意，创业不易，如果有问题请随时联系我们，万分感谢！

### 订单类自动回复
- 【用户下单成功】(空)（33未审核 条未审核）

- 【订单已完成】(空)（11未审核 条未审核）

### 范本使用规范
- 范本按场景组织（欢迎语/下单/配送/送达/售后），员工可直接套用再个性化
- 新增话术先「批量设置」→ 保存；未审核话术需复核后再启用
- 回复须在 60 秒内完成，话术宜简短明确（首句说明已收到/正在处理）

## 三、管理流程建议
1. 每日：查看「今日未回复」清空待办；检查 60秒首响率/服务率
2. 每周：查看服务数据近7日趋势（首响率/解决率/不满意率/咨询量）
3. 异常处置：首响率 <80% → 检查员工在线时段/自动回复覆盖；不满意率上升 → 复盘差评话术
4. 范本迭代：每月根据咨询高频问题增补快捷回复，统计「客服询单转化率」评估销售能力
