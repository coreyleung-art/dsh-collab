## 一、平台机制精确化（原文比摘要更细）

### 1.1 服务商权利真相
- 淘闪给服务商 **12 个点**（月销售额抽12点），拉新期平台一点不留全返成果（ch11）
- **平台公开政策、非只对成果**（Speaker7 纠正"不是拉新政策，是平台政策"）（ch11）
- 阶梯性返佣（不会永远返）+ **商圈流量倾斜→单店曝光78%** + 城市级运营活动发起权（ch15）
- 履约**必须有品牌**（繁花非必备路径——用哪个品牌可以自选）（ch15）

### 1.2 授权周期与"阶段性命门"（ch11+ch08 合证）
- 一年一年签，**7月24号到期**（2026-09-05 会议时点）
- 命门逻辑：淘闪花店仅 **5万家** vs 美团 **25万家** → 服务商任务=把美团花店搬到淘闪
- 若任务完成（拉到10万/25万），平台可能**不再需要服务商**（外卖服务商已名存实亡=前车之鉴）
- → 一切必须在窗口期内积累，且要用繁花/自有资产沉淀防翻脸

### 1.3 平台宽松边界（supply 蓝图最大背书）
- 平台**不管服务商额外变现**：可在成都750新签服务商里开**招商会拉加盟**(繁花森林)——不管
- 可给成都生鲜1500+店**供蔬菜供肉**——只要供应链有优势，平台不管，反而认为是**加分项(粘性)**（ch16）
- 只卡控两指标：**新签 + GMV**（ch16）

## 三、城市战打法（原文级细节）

### 3.1 "偷袭美团"战役论（ch08+ch16 振宇提出）
- "把钟总拉进来，我们发起**城市的遭遇战，去偷袭他**（美团）"（ch08）
- "帮淘闪在美团上面撬开一个口，这才叫打仗"（ch05）
- 城市合伙人(存量+强建联) + 服务商(流量权+活动权) = **两张牌组合拳**才打得透
  - 只有流量权 → 平台规则倾斜不持久，反效果，**天怒人怨/商家会死**
  - 只有运营权 → 整体区域失衡，为卖代理权倾斜自家商家=废

### 3.2 卖地图=卖"希望"
- 单城没跑通前**只卖地图没价值**："商家对你没信心，你没证明拿下地图能给商家出业绩"
- 卖的其实是"**平台渠道代理权的希望/未来的价值**"（ch18）
- 佛山已卖 **40万** 做城市客户；他再拆区县卖(5-10万/区)（ch11）

### 3.3 财散人聚=理财产品逻辑（ch18）
- 点数分配权让度给代理商 → 代理商**提前支付未来现值**(代理费) → 覆盖运营研发
- "你的点数不是你的点数，是运营全国服务商资质的分配权"

### 3.4 战役化节奏（ch17 确认无限制）
- 打一个城市赢一个再拿一个；多点开发；广告型串联(城市战果可叠加)
- 每城用不同主体=合规正常（中恒天雅模式）
