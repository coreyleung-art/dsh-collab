## §0 为什么要停

**本线已产出 16 条判据、5 个门、5 个真缺陷、1 条新规则。而原目标在【第 3 轮】就已达成。**

**判据**（引自本线）：「**判据一旦不再服务于任何具体判定，它就在贬值。**」
**⇒ 应用到本线自身**：**新增判据的【边际交付量】= 0 时，即应停止新增。**
**⇒ 实测**：最近三轮判据（绕过须失败 / 消除 vs 使可见 / 可检测不可判定）**仍改变了判定**（如"是否抽公共模块"），**但不再产生任何新的交付物需求** ⇒ **边际交付量 = 0** ⇒ **收口。**

## §6 收敛判据（本线自身的停止条件）

> **新增判据的【边际交付量】= 0 时，停止新增。**

**三个层级**（本线实际经历）：
| 层级 | 症状 | 正确动作 |
|---|---|---|
| **L1** | 产出判据，不产出缺陷 | **把判据做成门**（门会自动抓缺陷） |
| **L2** | 产出更精细的判据，不收敛到交付 | **聚合落文档 + 设沟通门槛** |
| **L3（本轮）** | **判据仍在增加，而交付物不再增加** | ★ **收口**：固化 + 停止新增 + 留存未闭合项 |

**⇒ 本线现位于 L3。已收口。**
