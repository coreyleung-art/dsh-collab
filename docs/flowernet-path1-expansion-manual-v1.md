# Flowernet 路径1 · 地区→全国 扩张执行手册 v1

> 明鉴 · 2026-09-09 · 深化《垄断地位战略推演》路径1（借身份地位, 优势从地区扩展到全国）
> 目标: 把"成都单城优势"扩张成"全国服务商身份"的可执行细节——选城/复制节奏/单城SOP/里程碑/风险
> 锚点: 成都15%份额/750动销 · 单城复制180-220万(轻装100-130万) · 5城2000-3000万/10城5000-7000万/30城1.5-2亿 · 双牌身份 · IP样本11月

---

## 〇、路径1核心逻辑

```
成都(地区霸主, 15%份额) → 借身份外溢 → 全国(5城→10城→30城 → 服务商身份)
         ↑                    ↑                       ↑
    IP首场11月+平台增量数据   向淘宝闪购提案换管道       每城复制180-220万
```

**一句话**：用成都战功（IP首场+平台增量数据）向平台证明"双牌=能带来增量"，换取全国管道/更多城资格，然后逐城复制。

---

## 一、选城策略（复制哪座城）

| 优先级 | 城市 | 依据 | 成本 |
|---|---|---|---|
| P0 样板 | **成都** | 已锁15%/750动销 | — |
| P1 首扩 | **杭州** | 平台大盘+述标≤50万先行(low-cost验证) | 轻装100-130万 |
| P1 首扩 | **广州** | 初蘅(振宇背景)门店作 dogfooding 验证, 不并表不算 Flowernet 资产 | 轻装100-130万 |
| P2 批量 | 合肥/南京/上海/北京 | 单城模型跑通后复制 | 180-220万/城 |
| P3 铺开 | 30城 | 10城月净1200万回血滚动, 不全融 | 45-60万/城轻装 |

**选城三原则**：
1. **先验证再铺**——每城先做"轻装版"（亚城述标/1-2店打样）验证模型，跑通才上"满配"
2. **优先有盘口的城**——杭州/上海盘口大；成都已验证，不重复
3. **IP样本先行**——每城用 IP 首场(3-5店)做冷启动，带外部新用户换平台好感

## 二、复制节奏（三级跳）

```
阶段A 成都样板(月0-6)   →  阶段B 第二城验证(月6-9)  →  阶段C 批量复制(月9-24)
  75动销→1200            杭州/广州各1城              5城→10城→30城
  打平36万/月            亚城述标50万                 单城180-220万
  四条线跑通             复制成都SOP                 月净1200万回血
```

| 阶段 | 时点 | 目标 | 关键动作 |
|---|---|---|---|
| A 成都样板 | 0-6月 | 打平36万/月, 动销1200 | IP首场11月, 数据端口P1 |
| B 第二城验证 | 6-9月 | 亚城轻装跑通模型 | 杭州述标≤50万, 复制成都SOP |
| C 批量复制 | 9-24月 | 5城→10城→30城 | 单城180-220万, 基建复用 |

## 三、单城操作SOP（每城复制同一套）

| # | 步骤 | 动作 | 投入 |
|---|---|---|---|
| 1 | 立项 | 选城定位/平台接口确认 | 1-2周 |
| 2 | 打样 | 1-2店跑通单店模型 | 轻装(如述标) |
| 3 | 团队 | 本地运营督导+BD(平台发薪) | 0-2万/月 |
| 4 | IP冷启动 | 首场3-5店售罄, 带外部新用户 | IP零成本+路演30万级 |
| 5 | 爬坡 | 动销爬坡至城市份额 | 平台发薪BD+代运营 |
| 6 | 复制 | 满配(180-220万), 进入城市矩阵 | 单城满配 |
| 7 | 数据 | 接入数据端口P1, 订单级回流 | 声通省硬件后置 |

> **每城铁律**：先打样验证(成本低) → 再满配复制(成本高) → 数据接入(可持续)。不烧钱铺规模，每城模型先自证。

## 五、扩张风险与对策

| 风险 | 对策 |
|---|---|
| 平台不批新城市管道 | 用成都战功+IP增量数据换, 提案而非索取 |
| 单城复制失败 | 先轻装打样验证, 不一步满配 |
| 跨城管理半径 | 本部4人+城市总, 30城用基建/系统复用 |
| 第二城抢下就被截胡 | 述标锁定期+快速落地(苏州教训不要重) |
| 复制烧钱超支 | 每城满配前打样, 声通省硬件, 代运营现金流反哺 |

## 六、与垄断三必然性的咬合（扩张的底气）

```
路径1(地区→全国) 每扩一城, 都在强化垄断身份:
  ① 双牌身份 → 每城有资格入驻(平台授予)
  ② 数据底座 → 每城数据回流量 → 底座更厚
  ③ IP定价权 → 每城粉丝消费 → 品类上游更稳
  = 扩张不是单纯复制门店, 是"身份+数据+IP"三必然性的逐城累积
```
