## 第一部分 · 规范本体(分类+约束+决策树)

### G 分类(4 类)
| 类型 | 用途 | 规模 | 生命周期 |
|---|---|---|---|
| G1 全员广播 | 制度/重启/重大事件(J34) | 可全员 17+ | 一次性(月≤5) |
| G2 任务协作 | 真需 B/C 互见的共同任务 | ≤5 人 | 完成即归档 |
| G3 评审讨论 | 临时共识/方案评审 | ≤8 人 | 48h 收敛即散 |
| G4 状态同步 | 多角色共享状态面 | ≤6 人 | 状态结束归档 |

### C 硬约束(6 条)
C1 规模闸(>5 人须论证) · C2 用途闸(仅 G1-G4) · C3 黑板闸(>50 字走黑板) ·
C4 生命周期闸(禁永久群) · C5 放大预算(消息×参与者) · C6 存量清理(40+ 大群归档)

### 决策树(工具将实现)
开群前 4 问 → 输出推荐通道: 点对点 / 新会话 / G1-G4 群聊 / 黑板

## 第三部分 · 工具规格(group-gate.py · R006 十项对照)

| 项 | 实现 |
|---|---|
| ① dsh 插件形态 | 可挂 dsh-plugin-group-gate(P2) |
| ② TCC 检测 | --selfcheck |
| ③ CLD 自适应 | --cld-check |
| ④ dsh 版本自适应 | --version-check |
| ⑤ 文档化 | group-gate-README.md |
| ⑥ 版本管理 | --version |
| ⑦ 统一日志 | ~/.dsh/group-gate.log |
| ⑧ 自动落链 | 审计结果落 data/groups/ |
| ⑨ CLI 治理 | argparse 子命令 |
| ⑩ Lean4 约束门 | --lean4-check: 违规群(>5人无论证/永久群)应被识别 |

### check 子命令决策逻辑(输入→建议)
```
group-gate.py check --desc "<开群场景描述>" [--participants N] [--need-mutual yes/no] [--duration temp/long/once]
→ 输出: 推荐通道 + G 类 + 理由 + 成本估算(消息×N vs 点对点)
```

### audit 子命令存量扫描
```
group-gate.py audit [--json]
→ 输出: 存量群聊健康报告(G1-G4 分类/超大群/长驻群/建议)
```
