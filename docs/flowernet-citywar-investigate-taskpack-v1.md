## 一、调查任务分配

### Task-1 · 淘闪城市合伙人制度公开面（A1/A3/A4）
- 检索: 淘宝闪购 城市合伙人 招商 / 淘宝买菜/闪购 区域代理 / 淘闪 服务商 招募
- 关注: 制度是否真实存在、哪些城市开放、资质门槛是否与妙记吻合(实缴200万/存款400万/流水800万/社保)
- 产出: 制度存在性结论(真/伪/查无) + 公开资质清单 + 与妙记差异表

### Task-2 · 即时零售鲜花大盘与弃用先例（A2/B2/B3）
- 检索: 即时零售 鲜花 市场规模 / 淘宝闪购 美团 鲜花 门店数 / 外卖 服务商 取消 / 美团 代运营 城市代理
- 关注: 5万vs25万门店数可否验证; 平台"任务完成弃服务商"先例
- 产出: 数据对照表 + 先例时间线

### Task-3 · 供应链/IP/工具行业基础（B4/C1/C2）
- 检索: 鲜花供应链 贸易 公司 / 花店 资材 包材 批发 / 鲜花 IP 联名 花束 / 花店 SaaS 管理软件 / 鲜花 自动包装设备
- 关注: supply trade/ip-license 线的行业玩家与毛利结构; 花店工具竞品
- 产出: 行业玩家清单 + 毛利/门槛判断 + IP 联名案例

### Task-4 · 城市合伙人模式先例（B1）
- 检索: 城市合伙人 区域代理 即时零售 / 闪购 城市服务商 / 京东到家 区域代理 模式
- 关注: 其他平台是否有同类"卖区域代理权"模式及运营方式
- 产出: 模式对标表

## 二、方法纪律
- web_search 多角度(≥2 查询/问) + 信源分级(官方 > 行业媒体 > 自媒体), 标注可信度
- 查无结果=明确写"查无公开信息", 不脑补
- D2 组(合作方人名/内部股权)一律不查, 涉合作隐私
- 原始检索结果落 research/investigate-20260907-*/ 供回溯
