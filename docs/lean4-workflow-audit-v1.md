## 二、Lean4 型改造目标(每工作流)
把"文档写了要注意" → 数据层/入口不可绕过:
1. **schema 门**: 写蓝图/规则/关系前, 结构校验器拦截(字段缺失/非法引用/重复)
2. **幂等+原子**: 写入幂等(重复拒)+ 可回滚
3. **审计留痕**: 每次结构性写操作带 auth(谁/何时/依据)
4. **引用完整**: 写入的 id 必须存在(蓝图/规则/agent 注册表校验)
