## 四、这段时间真正值钱的部分：23 条纪律

★★★ **它们不是设计出来的，是被错误逼出来的。按层列：**

### 4.1 读数层

| 纪律 | 由来 |
|---|---|
| ★ **「空 ≠ 无」** | ★ 分母为 0 时必须报**不可判**，不得报 0 或通过 |
| ★ **「不可判 ≠ 不成立」** | ★ 读不到时不得说「不存在」 |
| ★★ **「报 0 须附扫过的面」**（D-053） | ★ 报「0 条」时必须写出**扫了哪些面** |
| ★★★ **「全局量词须附枚举面 + 命中数」**（D-149） | ★ 说「所有/整个/没人」必须写 **N 与 M** |
| ★★★★ **「不可判须附【缺什么手段】」**（D-150） | ★★ **「不可判」常常是【我手上手段】的属性，不是【对象】的属性** |
| ★★★★★ **「执行噪声 ≠ 读数错误」**（同族第四条） | ★ 超时/中断时须说**返回了几条** |

### 4.2 判据层

| 纪律 | 由来 |
|---|---|
| ★ **「信号免疫」** | ★ 判据应选**污染者不产生的信号**，而非受害者身上的残留 |
| ★★ **「鉴别力不足」**（上位通则） | ★★ **判据的区分力 < 你要判的区分** —— 三实例：**粒度 / 语义 / 层面** |
| ★★★ **「从未红过即不是判据」** | ★★ **空转族**：D-133（常量）、D-147（阈值）—— 断言必须见过红 |
| ★★★★ **「负控须验【被消费的值】」** | ★ 只验「取数成功」不够（★ 我因此差点漏掉一个真缺陷） |

### 4.3 规则层（★ 这段最集中）

| 纪律 | 由来 |
|---|---|
| ★ **「禁令 ⇒ 假阴性」** | ★「不许报」会**压制真东西** —— 改成**升级项** |
| ★★ **「要求 ⇒ 假阳性」** | ★★「必先跑 X」会**自认合规**（跑过 ≠ 搜全）—— 须附**搜索面**与**不完全性声明** |
| ★★★ **「规则 + 修复路径 优于 规则 + 完备性要求」** | ★ 前者可执行，后者不可达（★ 实证：不可达的那条，**十分钟内就被打破**） |
| ★★★★ **「不要立完备的规则，要立可修的规则」** | ★ 本区间 6 次修法的**同一句** |

### 4.4 跨方层（★ 最深的一支）

| 纪律 | 由来 |
|---|---|
| ★ **「报对方问题前，先换一种提取法重算」** | ★ 提取出错时**没有内部矛盾**，症状与「对方真错了」无法区分 |
| ★★ **「换法的前提：两法【失效模式独立】」** | ★ 若共享盲点 —— 一致**什么也证明不了** |
| ★★★ **「独立性取决于【假设】，不取决于【层次】」** | ★ 自检：**放宽一支的假设，看另一支结论变不变** |
| ★★★★ **「自升格 与 报对方错 同构」** | ★★ 两边都**只有一个来源** —— 一致都不带信息 |
| ★★★★★ **「S3 机制化：n = 独立假设类数」** | ★★ **n=1 即不得记作证据**（★ 已实作成 `evidence-sources.py`） |
