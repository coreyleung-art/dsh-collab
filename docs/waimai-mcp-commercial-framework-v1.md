## 二、栈3 merchant(商家向) 评估卡

### 价值假设(妙记1 输入)
- AI 自动改价/上下架/竞品监控/库存联动, 单运营 20→50 店/人, 24h, 错误率≈0
- 千店边际递减; 单店月营收 5-15 万(花店)

### 定价候选(待调研数据填入)
| 模型 | 逻辑 | 月费候选 | 待验证 |
|------|------|---------|--------|
| A 固定订阅 | 工具价值 | ¥99-499/月(分档) | 商家付费意愿(LTV) |
| B 效果分成 | 多赚部分分成 | 增量营收 5-10% | 可归因性 |
| C 混合 | 基础费+效果 | ¥99 + 增量 5% | 复杂度 vs 接受度 |

### 判断标准
- 商家 ARPU > 服务成本 → 可规模化
- 留存(12月) > 60% 才健康
- 竞争: 美团服务市场同类工具价格带对比

## 三、栈4 ops(服务商向) 评估卡

### 价值假设(妙记2 输入)
- 军团式代运营: 标准化 SOP + 公域私域 + 全平台
- 现收费: 营业额 8%(双方觉不公平) → 探索阶梯/月费+提点
- 淘闪返佣: 阶梯单量最高全单 6% 归服务商; 收入 = 8% 服务 + 6% 返佣
- 目标: 2 万月利润倒推; 轻资产起盘(借力白云区团队)

### 收费模型候选(妙记2 已讨论 + 待调研)
| 模型 | 说明 | 妙记2 佐证 | 待验证 |
|------|------|-----------|--------|
| A 固定抽成 8% | 现行业通用 | 已用, 双方觉不公平 | 替代需求 |
| B 阶梯收点 | 按营业额反向阶梯 | ✅ 认可思路 | 阶梯档位设计 |
| C 月费+低提点 | 基础 2000-5000/月 + 低提成 | ✅ 提出组合 | 平衡风险 |
| D 预收大笔无月费 | 一次性预收 | ✅ 提及 | 现金流 vs 流失 |

### 判断标准
- 服务商毛利(服务费+返佣 - 运营成本) > 40%
- 单店代运营净利 2 万目标(妙记2)可达性
- 多店规模效益(边际成本下降曲线)
