## 补丁清单(G-C11 起, 延续公约编号)

### G-C11 · 跨设备「看黑板」短指引(内容分级)
- 断言: envelope-content-scoped
- 内容: 跨设备信封 payload.text > 50 字 → 内容先落黑板 notes/<target>/<key>, 信封只带「看黑板 <key>」短指引
- 理由: 本地 R002/R003 已防(R033 入账), 跨设备黑卡片 content 带全文 = 同类浪费跨设备版(接收端全文注入上下文)
- 校验: 守护转写黑卡片时检查 content 长度, >50 字且无黑板 key → GATE FAIL

### G-C12 · 跨设备噪音上报(R018 泛化)
- 断言: noise-reportable
- 内容: 收到无关跨设备消息 → noise 上报(黑板 data/audit/noise-reports/ 带 node+from 字段)
- 理由: R018 已治设备内噪音; 跨设备(服务器总线)噪音无上报, 污染源难追溯
- 校验: 信封 from=<device>:<role> 可溯源; noise 报告含 device 维度

### G-C13 · 跨设备风暴熔断(R034 延伸)
- 断言: storm-fuse
- 内容: 服务器统计同 from+target+action 10 分钟 >5 次 → 熔断转死信 + 告警
- 理由: S3 重试×2 已防单条失败, 但发送方重复发同内容(风暴)未防——风暴是上下文爆炸主因
- 校验: 服务器 bus/status 统计频率, 超阈 GATE FAIL

### G-C14 · 发送方黄灯义务(探照灯补全)
- 断言: sender-yellow-duty
- 内容: 目标离线(黄灯)时, 发送方必须转黑板(notes/<target>/), 不得重复塞 bus 队列
- 理由: 公约 G-C4 已管服务器侧队列零积压; 发送方侧义务缺失——不转黑板则积压循环
- 校验: bus/send 返回 offline 后, 发送方 30s 内应写黑板对应 key(可审计)

### G-C15 · 跨设备去重(本地 10min 同内容去重泛化)
- 断言: cross-device-dedup
- 内容: 服务器全局去重——同 from+target+内容 hash 10 分钟重复 → 只投 1 次, 返回 duplicate
- 理由: 本地 agent-bus 已去重; 跨设备多端可能重复发同一消息(如 relay 兜底+直发双路径)
- 校验: 服务器存 hash, 重复即拦

### G-C16 · 纯确认不回(跨设备版)
- 断言: ack-suppression
- 内容: 跨设备收「看黑板/收到/✅」类纯确认 → 不回(防跨设备确认风暴)
- 理由: 本地 R018/R033 已防; 跨设备 ack 经服务器往返更贵(每 ack 一次服务器 IO)
- 校验: 内容匹配确认模式且无新信息 → 发送方不应再回

### G-C17 · 群聊跨设备约束(R033 G1-G4 泛化)
- 断言: cross-device-group-bounded
- 内容: 跨设备群聊(多设备多角色)同样受 G1-G4 约束(规模 ≤5-8/收敛即散/内容走黑板)
- 理由: 跨设备群聊放大更严重(每消息经服务器→多设备注入), 应比本地更严
- 校验: 服务器群聊参与者数与生命周期审计(复用 group-gate.py 逻辑扩展)

### G-C18 · 大 payload 拒绝(信封容量门)
- 断言: envelope-size-limit
- 内容: 信封 payload > 阈值(建议 4KB 或 configurable) → 拒绝, 提示落黑板引用
- 理由: bus 信封是投递通道非存储; 大 payload 塞 bus = 服务器带宽+每端注入成本
- 校验: 守护/bus/send 检查 payload 大小, 超限 GATE FAIL
