# 2026-08-30-binary-version-overwrite 升级时把新版本内容写进旧版本文件名（版本文件覆盖错误）

> 级别: P3 · 日期: 2026-08-30

## 现象
node-bridge v1.3.2→v1.3.3 升级时，先用 cp v1.3.3 → v1.3.2 覆盖同名文件（plist 仍指向 v1.3.2），导致文件名 v1.3.2 内容 v1.3.3 的版本混乱

## 根因
升级操作直接覆盖旧版本文件而非让 plist 指向独立新版本文件

## 修复
恢复 v1.3.2 原文件（.bak-v133 备份），sed 更新 plist 指向 node-bridge-macos-arm64-v1.3.3 独立文件

## 教训（→ SOP 更新点）
版本升级应保持文件名=版本内容一致（plist 指向新版本独立文件），不覆盖旧文件；备份先于任何替换

## SOP 更新
版本管理 SOP：升级 = 备份旧版 → plist 改指向新版独立文件 → 重启 → 心跳验证，禁止覆盖同名
