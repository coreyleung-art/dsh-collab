## 一、鱼骨图 · 影响"成都单城打透"的因素（因果分析）

```mermaid
flowchart LR
    R[🏆成都单城打透<br>第一阶段核心目标] --> A[\人/]
    R --> B[\钱/]
    R --> C[\平台/]
    R --> D[\数据/]
    R --> E[\IP商品/]
    R --> F[\组织/]
    subgraph 人
    A1[平台发薪BD军团<br>20新签+10运营] --> A
    end
    subgraph 钱
    B1[种子1000万<br>只花400-500万] --> B
    B2[代运营毛利≥36万/月打平] --> B
    end
    subgraph 平台
    C1[双牌资格+城市合伙人] --> C
    C2[帮淘闪增量→换管道] --> C
    end
    subgraph 数据
    D1[端口P1白名单<br>订单级回流] --> D
    D2[单店订单级=底座主位] --> D
    end
    subgraph IP商品
    E1[IP首场11月<br>授权零成本] --> E
    E2[预售制+3-5店<br>零库存风险] --> E
    end
    subgraph 组织
    F1[本部4人+吸收代运营团队] --> F
    F2[平台发薪·小精干不扩] --> F
    end
```

**鱼骨读法**：六大因（人/钱/平台/数据/IP/组织）共同决定"成都单城打透"能否成。核心：
- **钱**：种子只花400-500万，打平线36万/月（不烧钱）
- **平台**：双牌是入场券，"帮平台增量"换管道（护城河④）
- **数据**：单店订单级=底座主位（真空缺口）

## 二、力导向关系图 · 战略要素关系网络

```mermaid
flowchart TD
    subgraph 根
    A[行业地图know-how<br>怎么切蛋糕] 
    end
    subgraph 入场券
    B[双牌·先发优势]
    end
    subgraph 真护城河4能力
    C1[①服务能力] --- C2[②行业洞察]
    C2 --- C3[③调拨流量]
    C3 --- C4[④帮平台增量战绩]
    C4 --- C1
    end
    A --> B
    B --> C1
    A --> D[平台左右逢源<br>A建B优势B建C优势]
    C4 --> D
    D --> E[垂类重要玩家]
    E --> F[往头部挤<br>差异化+竞争+现金流+估值]
    subgraph 经营主轴
    G[现金流自转<br>每级建下一级]
    end
    C2 & C4 --> G
    G --> F
```

**关系读法**：
- 根(行业know-how) → 入场券(双牌) → 真护城河(4能力循环)
- 4能力(尤其④帮平台战绩) → 平台左右逢源 → 垂类重要玩家 → 头部
- 经营主轴(现金流自转) 贯穿，每级盈利建下一级 → 最终头部

## 三、两图配合使用（推演演示流程）

