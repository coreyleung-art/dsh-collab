## 一、存量处理：唯一性目录登记 + 本地清理

### 1.1 唯一性登记（保留，防丢失）
- 建 **images_manifest.json**（i9 交付包 1971 张 + 本地 385 张合并）——字段：文件名/SHA256/门店/批次/路径/i9已收(Y/N)
- 存黑板 data/return-photos/manifest + 本地 docs/return-photos-manifest.md
- 目的：i9 数据资产安全凭证——「这些图 i9 有了，哈希可核」

### 1.2 本地清理（确认后）
- 与 i9 确认：标注完成/已核哈希 → 本地原始图可清理（保留 MANIFEST 即可，图可 i9 重取）
- 清理范围：learning/return-photos/images 49 张 + meituan-multi 采集原始（约 385 张/100MB）
- 按删前考古：返图是 i9 有副本的资产 → archive_meta（清单留档）后删本体

## 二、每日自动化：采完→验收→直传 i9

### 2.1 流程（老登自动化任务）

1. **采集**：老登每日任务采新返图（返图提取技能）→ 本地暂存 ~/dsh-collab/return-photos/inbox/
2. **验收**：验金石 QA 冒烟（图片完整性/数量/命名）+ R030 verify 证据（采集成功率）
3. **传输门**：pre-transfer-check（余量检查）→ 通过后传输
4. **直传 i9**：scp/HTTP 推送到 i9 标注目录（或 genebank /shared/）——每日批次
5. **落链登记**：新增批次追加 MANIFEST + 黑板 data/return-photos/daily-<date>
6. **本地清理**：传输+确认后，本地仅留 3 天缓存（保留最近 3 批，更早删）

### 2.2 本地 3 天缓存（用户建议采纳）
- 保留最近 3 天批次（防 i9 未及时拉取重传）；第 4 天起自动清理（保留 MANIFEST）
- 清理走删前考古（safe_delete——i9 有副本）
