## 一、赛道格局（三层无交集 = 相对蓝海）

```

 ├─ 通用AI SaaS层: 外卖大师 10万+商家 无鲜花纵深 —— 降维威胁
 ├─ 数据工具层: 富泰科 499-1099/月 只采不执行 —— 付费意愿验证
```

## 二、关键决策输入（并入蓝图/商业评估）

### 1. 栈3(商家SaaS)差异化 = 垂类 know-how（非通用改价）
- 节日日历节奏 / 花材时效 / 区域价格弹性 / RFID 履约联动 / 跨平台聚合+送前返图
- 竞品监控模块对标富泰科 499-1099/月 自助定价

### 2. 栈4(服务商平台) = 花递是现成 B 端入口
- 花递 10% 抽佣需覆盖人工 → 人效痛点 = 我方 20→50 店/人能力变现入口
- 客户池: 花递类抽佣玩家(第一层) + 长尾代运营公司(第二层)

### 3. 合规护栏(写入工具设计)
- 商家知情授权 + 操作留痕（监管点名"代运营授权非侵害经营权挡箭牌"）
- "模拟真人防反作弊"表述 → "符合平台规范的真人级操作节奏"
- 美团一店一服务商 → 走 ISV/授权路径(123.meituan.com)

### 4. 窗口关闭信号(监控)
- 美团官方鲜花工具迭代 / 外卖大师发布鲜花行业版 → 信号触发即调整窗口策略
