### 1.1 设计要点（逐字摘要）

| 项 | 内容 |
|---|---|
| **定位** | 「任意支持 MCP 的客户端（Claude Desktop / IDE / 第三方 agent / 手机）经 **E2 注册 + 授权**接入 comm 通讯架构，**成为外部节点**」 |
| **目标** | 「任意 MCP 客户端**零开发接入**：经标准 MCP 协议**读黑板 / 发消息 / 订阅事件 / 查节点**，成为分布式协作节点（24h 服务器可达）」 |
| **非目标（明确不做）** | ❌ 不做消息路由中枢（**评估已否决 SPOF 方案**）· ❌ 不迁移 `mcp-station`（留本机作管理面）· ❌ 不迁移 `feature-mcp` |
| **分阶段** | **P0** 只读骨架（JSON-RPC + `bb_read`/`node_list`）→ **P1** 鉴权 + `bb_write`(域白名单) → **P2** `bb_subscribe` + `bus_send` → **P3** 自助注册 → **P4** 迁服务器 |
| ★ **依赖现状** | ★ **P1 依赖 E2 ✅ · P2 依赖 bus-bridge 8791 ✅ · P3 依赖 R-ERR4 ✅** ⇒ **技术前置【全部已就绪】** |
| **风险与门** | 域白名单 + **写审计（黑板留痕）** · **每设备独立 token + 可单吊销 + 0600** · 断线重连（复用 SSE）· **P0 只读先行防范围膨胀** · 锁 **JSON-RPC 2.0** + `tools/list` 动态发现 |
