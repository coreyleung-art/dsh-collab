# 连接实验室 · 孤岛组合探索 v1(Island Connect Lab)

> 作者: 明鉴 v2 · 2026-09-05 · 用户提出
> 一句话: 不只"看见孤岛", 而是穷举孤岛×候选的组合, 用多特征打分潜在可连接性, 探索→确认→建边 = 蓝图自进化
> 延续: docs/self-evolution-island-connectivity.md(自进化探索); 本方案是其"实验室化"落地

## 一、目标
把孤岛探测从"报告 24 个孤岛"升级为:
1. **穷举**: 每个孤岛 × 每个非孤岛节点(或全节点) → 全部候选组合
2. **打分**: 多特征计算"潜在可连接性"(不只共享资源, 而是职责语义相似度)
3. **排序**: 高分组合 = "值得探索的潜在连接"
4. **建议-确认**: 候选边供人/相关 agent 确认, 确认后真正建边(入图谱)

## 二、连接特征(可连接性评分维度)
| # | 特征 | 说明 | 权重 |
|---|------|------|------|
| F1 | 同域 | agent 职能域相同(ops/dev/data/biz…) | 0.25 |
| F2 | 能力语义 | abilities 文本余弦相似(向量) | 0.30 |
| F3 | 资源共享 | 已有同资源键(未达边阈值的弱共享) | 0.20 |
| F4 | 资源互补 | 一方资源=另一方能力产出(消费关系) | 0.15 |
| F5 | 同设备 | 同 mac-mini/同项目 | 0.10 |
> 分数 = Σ(Fi×Wi); >0.6 高潜 / 0.4-0.6 中潜 / <0.4 弱

## 三、形态
- **后端**: /api/connect-lab → 穷举孤岛×候选, 返回 top 候选带分
- **呈现**: 管理器新视图或并入智能体 Tab(副视图「🧪连接实验室」)
- **工具**: bb-connect-lab.py(R006 合规: --scan/--selfcheck)可选
- **数据**: 候选结果落 data/connect-lab/candidates.json(待确认池)

## 四、真实原则(用户一贯要求)
- ⚠️ 候选 ≠ 真实连接: 打分只给"值得探索"信号
- 建立边必须人工/相关 agent 确认(呼应 Φ1 用户主权/Φ9 约束前置)
- 已确认边入图谱(agent-network 关系)并回写

## 五、验收
| # | 标准 |
|---|------|
| A1 | 穷举: 24 孤岛 × 全部节点 → 组合清单 |
| A2 | 打分: 5 特征加权, 分档(高/中/弱) |
| A3 | 排序: top N 候选可看可确认 |
| A4 | 确认后能建真实边(更新图谱) |
| A5 | 结果落 data/connect-lab/candidates.json |
| A6 | 门禁 bb-gallery-gate 全绿 |

## 六、里程碑
- M1 后端穷举+打分(5 特征)→ /api/connect-lab
- M2 呈现(智能体 Tab 副视图)+ 候选落盘
- M3 确认闭环(确认→建边→图谱更新)
- M4 文档+工具化(R006)
