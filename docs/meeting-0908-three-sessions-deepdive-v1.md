## 一、垂类行业布局与资本架构（obcnwhp3 · 25章）

### 1.1 平台节奏逻辑（全文级, 摘要未及）
- **阿里财报驱动**: 开城进度与"我们"无关——阿里所有业务(本地生活/云/钉钉/团购)都服务于 **3·31 财报**(阿里财年)，业务分解随财报走(亏损业务也为财报叙事存在——团购仅3城年亏1亿多仍做, 因"2万亿市值财报好看不止1亿")
- **→ 对 citywar 含义**: 平台授权/开城节奏不可控于我方, 政策窗口判断应锚定阿里财年节点(3·31/9·30)

### 1.2 成都当日新签实证（数据鲜活）
- 当日新签 **25 家**(便利店1/生鲜6/水果4/鲜花3/垂直11)——成都城市合伙人全品类身份日签量级
- **双体系 1+1 打通**: 阿里大零售下两个体系(鲜花全国服务商 + 城市合伙人全品类), 打通=战略价值(两张牌组合)

### 1.3 战略共识（数据端口=护城河）
- **数据节点/端口 = 未来最大护城河**——建立统一价值看法, 防路径依赖(像消防员救火式做商家服务=失去北极星)
- 关键手: 全平台服务端口 → 获取盘上数据接入份额 → 成为行业底座
- 数据软硬件采集端口**战略亏损也要做**
- 平台间数据不通 → 我方做"所有平台服务端口"成行业底座(全渠道)

### 1.4 控制权与资本架构（最密集部分）
- 创始人(振宇/Speaker3=用户?)诉求: 资本**服务架构**——不被干扰/不被绑架/资源核心团队不被架空
- 有限合伙 vs 有限公司: LP 核心诉求=安全(怎么进怎么退/对赌到阶段/体量/份额); GP=控制权+业务方向+操盘
- 曾总(读法律)可能出更好架构; 广州橙果体系内阿凯=做法务/招商角色, 顶层=振宇控盘
- 路径依赖反思: 不做"灭火式"商家服务, 要指南针/北极星
- 繁花定位澄清: 品牌名(繁花/初蘅/喜花)不重要——大方向=自建垂直鲜花全国 KA 连锁 + 服务90%市场的供应链/代运营/品牌

### 1.5 AI+上市路径（摘要完全没提）

## 二、淘闪鲜花城市站业务规划（obcnwjk9 · 11章）

### 2.1 成都现状（全文精确数据）
- 市场份额 **15%** ≈ 淘闪内 **700-800 存量鲜花商家**, **有效动销 750**(有订单)
- 未动销两因: ①做美团不做淘闪(如初蘅/楚恒——美团订单量大拿不到淘闪结果) ②门店质量差
- **→ 获取商家通道**: 电话 + BD 跑街——**20 PD 做新签 + 10 BD 做运营**(平台发工资, =平台工作人员)

### 2.2 运营权限盘点（旗子/抓手）
- 城市合伙人(鲜花全国)可: 门店分级(青铜→铂金/钻石快速升档) · 上活动 banner · 上鲜花专栏 banner(花严选上方/下方插 IP 联名) · 发全局商家信 · 指挥 BD 宣传
- 双角色权限重叠区: 全国鲜花合伙人=鲜花类目评级; 城市合伙人=零售类目评级(例: 送水晶球也浮现鲜花店)
- **明星同款**: 小阿狸案例选中红玫瑰款, 所有门店可上

### 2.3 IP 联名打法（造节逻辑）
- IP(尤其二次元) = **造节工具**: 27/23个节日框架打破 → "应援月"(非一天) → 粉丝消费习惯移植
- 活动发起方=淘宝闪购, 邀约全国花店参与(例"张庭鹤"指代某IP)
- 地推: 商场大屏/中庭(成都=自己地盘搞快闪地推, 其他城市不投)

### 2.4 IP 授权贸易线闭环（supply 直接落地版, 最重磅）
- **定制包材=正版锁**: 不买资材包→不可能有正版花束(包材 IP 定制+监修)
- 授权链完整: IP 指定工厂生产(例: 喜得利) → **IP 指定贸易公司销售** → 完整授权链路
- IP 方要求全渠道可售(阿里/淘宝/京东); 我方自建管道=**贸易线逻辑**——获授权后自建销售网络, 卖定向 IP 入口
- **IP 聚合平台**: 拢进多个 IP → IP 公司下挂(不能外挂)——服务我方门店家族设计/IP联动元素; IP 公司下挂未来主体

## 三、自营花店合作模式及供应链（obcnwk6q · 15章）

### 3.1 初蘅品牌合作（粤语为主）
- 未来花店投资构成多样(全投/与股东合投); 关键=**品牌归属**: 用初蘅品牌则合作模式不同, 品牌是关键
- 若由振宇方管理→用初蘅; 万百品牌节奏: 兴国路/番禺/东莞装修门店独立夹合作意向, 初版合同=**招商投资规则**
- 初蘅定位: 广州鲜花行业"奇葩头部"——**全直营全自管**(对比: 月恋/花仙女=加盟但各店自己拿货=散)

### 3.2 供应链公司逻辑（supply 蓝图强化）
- 市场为什么没人做供应链? 因为没有这么多自营门店(散)
- **触达 B 端**: 通过上半场的事触达 B 端 → 供应链从"幻想"变"现实"(不再需要爬虫, 本身有数据)
- 例: 美团内部模式(考虑非即时供应链)
- **BD 复用三件事**: 一个 BD 走出去=帮供应链找客户 + 帮淘闪上新 + 卖硬件软件——一鱼三吃
- 流量权+活动权放给自投门店 → 评级王者级 → "拿牌接水"

### 3.3 门店仓/合资供应链（新机制）
- **每区一个细仓**: 服务自己 8-10 店 + 服务周边 ABCD 商家(扫街顺带)
- 开仓逻辑: 区仓非冷链为主(鲜花前置仓=垂直细分仓, 库存低/无需冷链/全平台可发/商家找代发)
- 前置仓投资: 30/20/25㎡+三匹机, 冷库模型(to B 非小象山姆 to C)
- 前置仓位=稀缺资源(每个城市)——部分观点认为不算稀缺

### 3.4 礼品与业态延伸
- 精油香薰类: 方所式体验台(一群人闻/买)——银行网点 showroom 思路(展厅不生产)
- 供应链线索运营: 触达 B 端后供应链不再幻想(云端盘/数据已在手)
