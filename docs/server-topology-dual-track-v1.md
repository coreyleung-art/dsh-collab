# 服务器拓扑双轨纪律 · D1 定稿成文

> 版本 v1.0 · 2026-10-03 星桥成文 · 依据：2026-10-02 用户实践裁决 = 方案 A（明示双轨）
> 决策材料见 `agent-comm-substrate-v3-20261002.md` §4；本文是**成文的双轨纪律**（RULES 口径，可核验）。

## 1. 定稿结论（一句话）

**Tailscale 直连是主用通道；服务器（xingqiao）是「跨网兜底中继 + 注册 + 信封 + 镜像」，不再是「唯一中继」。**

裁决依据（2026-10-02 实测，全部可复跑）：
- 「只连服务器」联合验收四通道可用：bus 0.13s / 黑板 1.04s / 镜像 34s / SSE 数秒 ⇒ 兜底能力成立；
- 用户指示「测完即恢复旧通道」⇒ Tailscale 直连主用是既定事实；
- funnel 根治与通道规则 v2 均在双轨框架下落地。

## 2. 双轨拓扑（各通道职责，一条通道一件事）

| 轨道 | 通道 | 职责 | 失效时 |
|---|---|---|---|
| 主轨（Tailscale 直连） | tailscale-direct | 跨设备直连会话、funnel 公网入口 | 自动退向兜底轨 |
| 兜底轨（服务器） | board-central（106.53.214.108:8792） | 黑板镜像 / E2 注册表 / 发现层 | 本机板照常（R031 通讯永续） |
| 兜底轨 | bus-8791 | 跨设备信封收发（唤醒/通知） | 信封排队，恢复后投递 |
| 兜底轨 | sse-8803 | 订阅端事件流 | central-inbox 重连（catch-up 待补） |

## 3. 双轨纪律（可核验条目）

1. **不制造单点**：任何组件不得只连服务器（判据：服务器挂、本机板与直连照常——server-only-e2e 实测）。
2. **写板必双板**：跨设备卡双写本机板+中枢板并逐板回读（bb-card-send 断言；agent-way 1.5.9 起 deliverViaBlackboard 同规）。
3. **信封带凭据**：bus-8791 发送必须带 token（0600 文件/环境变量）；401 是可观测失败，不得静默吞（1.5.9 起读状态码）。
4. **注册随心跳**：E2 注册表 services 字段随心跳写时变更；缺位组件键在位值 "absent"（R038）。
5. **降级有退路**：主轨失效时兜底轨可独立闭环（验收判据=server-only-e2e 四通道 PASS）。
