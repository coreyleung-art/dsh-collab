### 1.4 一条贯穿两章的判法（本件共用）

> **复发/解除谓词 `REC(X)`** ≝ 存在一条命令 `C`，其输出 `O` 在**「X 存在」时**与**「X 不存在」时**取值不同；**且两个取值都已被观测到过**（至少红过一次）。
>
> ⇒ **给不出 `C` 的 = `不可判`；给得出 `C` 但从未红过的 = `unverified`（不计入分子，也不计入分母）。**

★ 这条判法直接落地本项目纪律：**「一个断言若从未红过，它就不是判据。」**

## 二、格式条款：解除条件一律写成 `RCP-6`（本件产出，可直接抄进 v7）

> **一条解除条件 E 可判 ⟺ E 写成下面六元的合取，六元逐字贴出；缺一即 E 只能记 `待补判据`。**

| 元 | 名称 | 必填内容 |
|---|---|---|
| **1** | **谓词 P** | 一个布尔式，**取值域三态**：`成立` / `不成立` / **`不可判`** |
| **2** | **复跑命令 C** | 一条可直接粘贴的命令（含 `cd`），**不改盘、不留副作用** |
| **3** | **读数三元** | **未编辑输出 O** + **退出码 E** + **取值时刻 T**（`date` 实读） |
| **4** | **分母断言 D** | 明写**分母是什么**，并给**分母为 0 时的期望行为**（**必须是「不可判」**） |
| **5** | **负控 N** | **造红输入的构造方法** + **该输入下的期望输出（必须红）** + **首次实红的存档** |
| **6** | **观测窗 W** | 窗口长度 + 复跑间隔 + **样本下限**（窗口内至少跑 N 次，少于 N 次 ⇒ 不可判） |

### 2.1 缺元判定表

| 缺哪一元 | 只能记 | 典型错写（本件现测到的实例） |
|---|---|---|
| 缺 **4** 分母 | `待补判据` | 「`total=0` ⇒ 无问题」（**分母 0 的绿不是绿**） |
| 缺 **5** 负控 | `待补判据` | 「门全绿 ⇒ 零复发」（本仓 **`gcr-gate` 的 11 个判据函数有 0 个真负控**，见 §四.3） |
| 缺 **6** 观测窗 | `待补判据` | 「零复发」「持续 100%」（无窗口即无样本） |
| 缺 **1** 三态 | `待补判据` | 二值谓词遇空分母自动落 `不成立` 或 `成立` |
| 缺 **3** 时刻 | `读数无效`（**不得入表**） | 引用 v6.1 的 10-11 读数当现状 |
| 缺 **2** 命令 | `读数无效` | 「实测支持率 96.7%」而不给命令 |

### 2.2 两条硬纪律（本件沿用并追加一条）

1. **退出码必须在管道之前取。** `cmd | tail` 取到的是 `tail` 的 `$?`。正确形：`cmd > /tmp/x 2>&1; rc=$?; tail /tmp/x; echo "exit=$rc"`。
2. **负控必须「造世界」而非「改期望」。**
3. ★★ **（本件追加）报「未搜到 / 0 命中 / 空」之前，必须先给一个必定命中的阳性对照。** —— 本仓已有先例：`zstdcat` 未安装而某代理用了 `2>/dev/null` ⇒ **解压字节 0 ⇒ grep 恒 0** ⇒ 报「469 个文件全 0 命中」，是**假的**（一手记录：`~/.dsh/inbox/w1-the-verbatim-i-passed-down-was-not-verbatim.json`）。**本件本轮复现了该先例**：

```
$ which zstdcat
(zstdcat 不存在 ⇒ 用它做的 0 命中是假绿)
$ /opt/homebrew/bin/zstd -dc ~/.dsh/sessions/--Users-coreyleung--/*/session.jsonl.zstd | wc -c
 3624650925          ← ★ 阳性对照：换对探针后，同一批数据可读 3.6 GB
```

⇒ ★ **「空 ≠ 无」的机器化形式 = 「0 命中必须附正控」。**
