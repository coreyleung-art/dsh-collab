# 规范效力档位标准 v1（Spec Effectivity Levels · SEL）

> **出件**：2026-10-11 · 星桥第二任 `session-e317d6ab`（mac-mini）
> **性质**：★ **可独立引用的评价标准** —— 用于评价「一条规范/锚/纪律**到底有没有效力**」，**不限于本机、不限于本线**
> **用途**：① 给既有规范**定档** ② 给新建规范**设目标档** ③ 判断某条规范**为何没起作用**
> **纪律**：★ 定档判据**须可执行**；★ **定档权不在被评对象本人**（见 §六）

---

## 〇、一句话

**「写进文件」与「被遵守」是两件事。** 本档位用**四个可检验的门槛**回答一个问题：
**这条规范，在没人主动记得它的时候，还起作用吗？**

---

## 一、要解决的问题（为什么需要这个标准）

**通例**：团队常把「规则已入册」当成「问题已解决」。**但入册只完成了一件事：它可被检索。**

**当一条规范只写到这一层时，会出现一类固定形态**：
- **新成员读不到它**（它不在他们实际会读的那份东西里）
- **读到了也不影响流程**（不遵守没有任何后果）
- **立它的人自己也会违**（因为没有机制在违的当场把行为拦住）
- ★★ **最坏的一种**：**它让人以为问题已经解决** —— 这比没有规则更坏

⇒ **本标准的用途就是**：**把「以为有效」与「确实有效」分开，并给出可检验的分界。**

---

## 二、★ 四级档位（L1–L4）

### L1 · 已记录（Recorded）

| 项 | 内容 |
|---|---|
| **定义** | 该规范**已写在某个可检索的载体**里（规则账本 / 文档 / 注释 / 归档件） |
| **保证了什么** | **可追溯、可引用、可复跑入口** —— ★ **这是必要条件，不是充分条件** |
| **★ 判据（可执行）** | 能被 `grep` 命中，且有稳定路径 |
| **★ 失效形态** | ① **不在读者实际会读的载体里** ② **无后果** ③ **立规者可自违** |
| **典型反例** | 规则明明写在账本里，但**没人执行过它**；或它写在 A 文档，而所有人只读 B 文档 |

### L2 · 有提示（Prompted）

| 项 | 内容 |
|---|---|
| **定义** | 除 L1 外，**存在一个【触发时会被送到眼前】的提示**（技能 / 清单 / 检查表 / 启动注入） |
| **比 L1 多了什么** | ★ **时机**：它会在**该用的那一刻**出现，而不是等你去检索 |
| **★ 判据（可执行）** | 存在明确的**触发条件**，且触发后**有可观察的产物**（提示文本 / 清单项） |
| **★ 失效形态** | **依赖「被调用」** —— ★ **若触发条件是「人记得去调用它」，则等于没触发** |
| **典型反例** | 一份「开工前请检查 X」的技能文档，★ 而它的 §边界 自己写着「**这是手动的**」 |

### L3 · 进门（Gated）

| 项 | 内容 |
|---|---|
| **定义** | 除 L2 外，该规范被做成**可执行的门**，且**位于某条流程的必经点** —— ★ **不过门就进不了下一步** |
| **比 L2 多了什么** | ★★ **强制**：不是「提醒你」，而是「**不做就过不去**」 |
| **★★ 判据（三个都要，缺一即降档）** | ① **可执行**：有命令、有**退出码**，能被流程判<br>② **进必经点**：它挂在某条**有明确入口/出口的流程**上（不是「建议在提交前跑一下」）<br>③ **有负控**：**造断 ⇒ 必红**（能证明它真的会拦） |
| **★ 失效形态** | ①**能跑但没人跑**（不在必经点）②**能红但没负控**（红可能是偶然，也可能恒绿）③**只判形式不判内容**（见 L4 的边界） |
| **典型正例** | 一个带退出码的校验器，挂在「升版发布」流程的固定一步 |

### L4 · 有对抗与闭合分离（Adversarial + Closure-separated）

| 项 | 内容 |
|---|---|
| **定义** | 除 L3 外，再加两条：<br>**① 该门自带负控并经过对抗性验证**（找错立场，而非确认立场）<br>**② 闭合权与执行权分离** —— ★ **执行者不能宣布「已闭合」，只能报「候选闭合 + 证据」，由异体宣布** |
| **比 L3 多了什么** | ★★ **抗自证**：堵住「**自己写门 + 自己跑 + 自己宣布通过**」这条路径 |
| **★ 判据（可执行）** | ① 存在**独立的负控**（造断必红），且**由非作者设计或复核**<br>② **闭合记录须带异体标识**（verifier 字段非空、且不是执行者）<br>③ **门明确声明自己【只判什么】**（例：只判声明完整性，**不判语义真假**） |
| **★ 失效形态** | **自审**：门存在、也有效，**但判通过的人就是写门/执行的人** ⇒ ★ 该门**不能用于宣布闭合**（它退化成一个自检工具） |
| **★ 为什么这级最重要** | ★ 因为**前三级的失效都还是「没起作用」，而这一级的失效是「起了反作用」** —— 它给出**虚假的完成感** |

## 三、★ 升降档：怎么知道现在在哪一档

★ **一条可复跑的判定路径**（从上往下问，**第一个答「否」的地方就是当前档位**）：

```
Q4: 闭合权与执行权分离了没有？且负控由异体设计/复核过？
    否 ↓
Q3: 该门是否位于某条流程的必经点？不跑就过不去？
    否 ↓
Q2: 触发时它会不会自己送到眼前？（还是等你去调用）
    否 ↓
Q1: 它写在可检索的载体里吗？
    是 ⇒ L1 · 否 ⇒ L0（未记录）
```

★ **注意**：**这四问必须按序** —— ★ **跳过 Q3 直接问 Q4 会把「有异体签名的文档」误判成 L4**（签名不产生强制力）。

## 四、★ 档位对目标的含义（不是越高越好）

| 目标 | 建议档位 | 理由 |
|---|---|---|
| **参考资料**（知识、先例、术语） | **L1 足够** | 它本来就不需要强制 |
| **作业规范**（该怎么做、别怎么做） | ★ **至少 L2** | 需要在该用的时刻被想起 |
| **安全/合规红线** | ★★ **至少 L3** | 必须「不做就过不去」 |
| **「已完成」的宣布权**（谁有权说这件事通过了） | ★★★ **必须 L4** | ★ **否则「通过」这个结论本身不可信** |

⇒ ★★ **一句话**：**档位应与【失败的代价】匹配** —— **代价越低越不需要强制，代价越高越不能只靠自觉。**

---

## 五、★ 使用方式（三步）

1. **定档**：对目标规范跑 §三 的四问 ⇒ 得到**当前档位**
2. **设目标档**：按 §四 的表，依**失败代价**选**目标档**
3. **补差**：**逐级补** —— ★ **不要从 L1 直接跳 L4**（L4 的门必须先存在，才谈得上闭合分离）

★ **补差的顺序（按代价升序）**：
```
L1 → L2：加一个【触发条件】（什么情况下它该出现）
L2 → L3：把它做成【有退出码的命令】并【挂到必经点】
L3 → L4：加【负控】+ 把【闭合权】从执行者手里拿走
```

---

## 六、★ 边界与纪律（★ 本标准的自指问题）

1. ★★ **定档权不在被评对象本人** —— ★ 若你**自己给自己的规范定档**，那你做的是**自评**，不是定档。
   ⇒ ★ **本档位标准【自己的定档】也必须由异体做。**
2. ★ **L3 的门【只判它们声明要判的东西】** —— ★ **不得用「门绿了」替代「内容为真」**。
   ⇒ 一条门即使到了 L3，**它也可能只判形式**；★ **语义真假始终需要异体。**
3. ★ **本标准不主张「L1 无价值」** —— ★ 它是**必要条件**：追溯、审计、复跑入口都靠它。
   ⇒ ★ 它只主张：**它不充分。**
4. ★ **本标准自身目前处于 L1**（已记录）。★ **其升档须由异体执行** —— ★ 本文件**不宣布自己有效**。

## 七、本机实例对照（可复跑的样本，供校准档位）

| 对象 | 档位 | 依据 |
|---|---|---|
| **一条写在规则账本里、从未被执行的规则** | **L1** | 可检索；但无触发、无门 ⇒ ★ 立规者可自违 |
| **一份「开工前请检查 X」的技能文档，且其 §边界 写明「这是手动的」** | **L2** | 有触发条件（开工）；★ 但触发条件是「人记得调用」 |
| **一个带退出码、挂在升版流程固定一步的校验器** | **L3** | ① 可执行 ② 进必经点 ③ 有负控（其 `--accept-*` 类开关反证它会红） |
| **一个由非作者设计负控、且闭合须带异体标识的门** | **L4** | 抗自证 |
| ★ **一条「自己写门 + 自己跑 + 自己宣布通过」的流程** | ★ **不是 L4** | ★ 门可能有效，但**闭合权未分离** ⇒ 它退化成自检工具，**不能宣布闭合** |

---

## 八、最小可用的自检（给使用者的三个问题）

1. **如果我今天忘了这条规范，谁会拦我？** —— 答「没人」⇒ 最高 L2
2. **它不通过的时候，流程会停吗？** —— 答「不会」⇒ 不是 L3
3. **说「这条通过了」的人，和做这件事的人，是不是同一个？** —— 答「是」⇒ ★ **不是 L4**，★ **该结论不可信**
