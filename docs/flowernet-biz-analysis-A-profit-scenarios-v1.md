# Flowernet 盈利假设双情景商业分析（情景A / 情景B）

版本 v1 · 明鉴体系商业分析 · 分析对象：Flowernet（垂直鲜花全国第一目标）

> **分析纪律**：「已确认背景」一律视为事实基线直接推演，不做质疑；「估算/假设」字段为分析师输入，已显式标注，待真实数据回填。

## 二、盈亏平衡点测算（总闸门，先于双情景）

### 2.1 成都站月度固定成本估算【估算】

| 科目 | 月成本（估算） |
|---|---|
| 团队34人全成本（工资+五险一金+少量保底） | ≈30万 |
| 办公/行政/差旅 | ≈3万 |
| 系统运维与杂费 | ≈3万 |
| **合计固定成本 FC** | **≈36万/月**（敏感区间 30-40万） |

注【口径】：新签激励1200元/店为平台结算项（垫付-回款浮差，非固定成本）；数据端口150万、合规50万为资本性一次性投入；买回预留200万战略封存，不参与运营现金流。

### 2.2 算式与结论

**打平条件：`月实收现金毛利 ≥ FC`；拆开即 `全池GMV × 实际入管道比例 × 现金抽成率 ≥ 36万`**

- 店均GMV = 2000万 ÷ 750 ≈ **2.67万/店/月**
- 打平所需GMV = 36万 ÷ 抽成率；打平所需动销 = 打平GMV ÷ 2.67万

| 现金抽成实现率 | 打平所需GMV | 打平所需动销 | 占当前池比例 ||---|---|---|---|
| 10点 | 360万/月 | ≈135店 | 18% |
| 8点 | 450万/月 | ≈169店 | 22.5% |
| 6点（返佣现金口径下限） | 600万/月 | ≈225店 | 30% |

**结论：**
1. **打平门槛极低**：存量动销的 18%-30% 真实参与抽成即打平，结构性冗余 ≈ 3.3-5.6 倍（135-225店 vs 存量750）。
2. **盈亏平衡是"实现率"问题而非"量"的问题**：返佣结构（6现金+6CPC）下 CPC 不能变现则现金抽成率天然打折，故统一仪表盘指标应为 **月度现金毛利（打平线36万）** 而非 GMV。
3. **充分条件**：成都站月现金毛利 ≥ 36万（≈ 全池GMV的1.8%，或 6点现金 × 入管道比例 ≥ 30%）。

## 三、情景A：我们盈利了会怎样（按模型跑正：160-200万/月毛利）

### 3.1 融资与估值：叙事切换带来 2-3 倍估值差
- **亏损叙事**锚：GMV×PS 2-4x，再扣烧钱速度与窗口不确定性，敏感于「还能烧多久」。
- **盈利叙事**锚：月净利 ≈ 100-150万（毛利160-200 − 固定36 − 激励浮支10-15）→ 年化 1200-1800万；P/E 10-15x → pre 1.2-2.7亿，叠加全国服务商资格+数据端口先发资产溢价 → **合理 pre-money 1.5-3亿**。
- 同企业同资产，两种叙事估值可差 2-3 倍；盈利数据 = Pre-A 2000-3000万 只需出让 10-20%（而非 30%+）的底气。**现金为正 = 能等 = 议价权在创始团队**。

### 3.2 窗口期动作：有现金 = 窗口资产全可执行

| 动作 | 亏损态 | 盈利态 |
|---|---|---|
| 买回预留200万 | 等融资或缩水执行 | **即刻执行**，零稀释 |
| 数据端口150万（R11 20.7 / R27 20.7） | 与工资抢现金 | 一季度内投完，抢占半年先发窗 |
| 第二城复制 | 无资本 | 300-500万自筹复制已验证模型（R05地图支撑） |
| 双牌齐推（R02 21.0，路线最高分） | 看政策脸色 | 全国服务商返佣 + 城市合伙人1200/店 双收，盈利放大器 |

### 3.3 股东关系：双刃剑，靠 GP 制度驯服
资源方（持牌方/本地资源）看到盈利会出现两种行为：**①更愿追加**（以资源换股、跟投第二城）；**②想分钱**（推动分红/套现）。对策：以51%投票权+GP结构定**分红政策**——M4前 0-20% 分红、80-100% 再投入，设「分红触发线 = M4后/第二城稳定」；用盈利现金执行买回 = 给早期资源方确定性退出通道，防其推动过早分红或贱卖。

### 3.4 M1-M4 里程碑加速效应

| 里程碑 | 加速表现 |
|---|---|
| M1（成都盈利模型验证） | 提前达成 → Pre-A 前置且溢价，或**选择不融**、用利润直接推进 |
| M2（数据端口/中台落地） | 现金支持一季度落地 → A轮前置条件早熟 |
| M3（第二城复制） | 自筹+小轮，稀释最小 |
| M4（全国扩张：双牌+服务商地图） | 叙事升级为「全国鲜花服务商集团」，A轮按全国体量融资 |

**综合：M1→A轮全程可压缩 30-50%**，融资从「生存动作」变为「增长选项」。

## 四、情景B：我们不盈利会怎样（月现金毛利持续 < 36万）

### 4.1 现金跑道测算
种子1000万拆解：买回预留200万 + 合规50万 视为**不可动用** → 可用运营现金 ≈ **750万**（数据端口150万可停/缓）。

| B情形 | 月现金毛利 | 月净烧 | 跑道（保命模式） | 备注 |
|---|---|---|---|---|
| B-轻度（爬坡慢，毛利25-35万） | 打平线下 | 1-11万 | 自持2年以上 | 不致命；缺的是增长/窗口资本 |
| B-重度（返佣缩水×GMV下滑，毛利0-10万） | 断裂级 | 26-36万 | ≈18-24个月 | 前提：砍扩张、进保命模式 |
| B-急性（毛利归零 **且** 仍维持A计划投入） | 0 | 70-100万 | **≈8-12个月** | 唯一会"饿死"的组合 |

**关键判断：纯运营烧钱 18 个月内烧不死成都站（固定成本仅36万/月，不足模型毛利1/4）；真正致命的是「毛利不足 × 仍按盈利计划花钱」的错配。**

### 4.2 什么会先断（按实际依赖顺序）
1. **新签激励垫付**先收缩——1200元/店拉满依赖平台回款，返佣缩水时垫付即变浮亏；增速受损但存量不损。
2. **数据端口/中台投入**停摆——但先发窗仅半年，暂停=战略性放弃 R11/R27（须显式决策，不能默认滑过）。
3. **买回预留200万**——不动（最后防线）。
4. **团队工资**——团队150万预算 ≈ 4-5个月工资池，零毛利超5个月即触碰；此前必须已融资或已收缩（新签20→10-12人）。
5. 最坏：现金流倒计时 <6个月仍无融资 → 动买回预留/贱卖资产。

### 4.3 提前启动融资的信号与最迟时点
**启动信号（任一命中即启动，不等 M1）：**
- 硬财务：连续2个月现金毛利 <36万 且无回升趋势；
- 政策（命脉）：3·31续签谈判中现金返点 <6点 或 CPC 继续缩水，见信号即动；
- 增长：在管商家池连续2个月<750 或 日净增<10家(警讯);
- 现金：可用现金 <450万（≈保命12个月）必须启动；<250万 必须已 close 或已全面收缩。

**最迟时点：** 融资交割需 3-6 个月 → 保命模式（18-24月跑道）下最迟**第12-14个月**启动 Pre-A；若须维持窗口投入（急性跑道8-12个月）→ **最迟第4-6个月启动，即 M1 之前一个季度**，以「成都盈利拐点 + 全国窗口资产」双叙事去融，而非等盈利实锤。

### 4.4 保命优先级（砍什么保什么）

| 优先级 | 对象 | 理由 |
|---|---|---|
| ① 保 | 持牌资格与合规（橙果/中恒天仰/合规50） | 一切收入之源，丢牌=归零 |
| ② 保 | 成都存量750店动销与现金毛利（运营10人全保） | 唯一确定性现金流 |
| ③ 保 | 买回预留200万 | 战略期权；仅跑道<6月且融资无望才可动 |
| ④ 缓 | 数据端口最小可用版 | 窗口资产，优先于第二城、后于存量运营 |
| ⑤ 降 | 新签激励垫付：拉满 → 跟平台回款 | 增量让位于存量 |
| ⑥ 砍 | 第二城/扩张预算 → 0 | 非生存项 |
| ⑦ 最后 | 团队收缩（新签20 → 10-12人） | 触底信号；此前必须已启动融资 |

## 五、双情景对比表

| 维度 | 情景A：盈利（毛利160-200万/月跑正） | 情景B：不盈利（现金毛利<36万/月） |
|---|---|---|
| 财务面 | 月净利100-150万，现金自持 | 保命净烧25-40万/月，跑道18-24个月；急性组合8-12个月 |
| 估值叙事 | 利润P/E 10-15x+窗口资产溢价：pre 1.5-3亿 | GMV/资产折价叙事：估值或腰斩至 1/2-1/3 |
| 融资姿态 | 选择权：可融可不融，出让10-20% | 必融：提前启动、出让放大、条款被动 |
| 窗口动作 | 买回即刻 + 数据端口全投 + 第二城自筹 | 砍至保存量 + 数据端口最小版，买回封存 |
| 股东关系 | 追加 vs 分钱双刃，GP分红政策驯服 | 资源方观望/施压控制权，以保牌+存量数据维稳 |
| 里程碑 | M1-M4 压缩30-50% | M1延期；Pre-A 前置至 M1前一季度 |
| 头号风险 | 盈利后自满、内部争利 | 政策断裂 × GMV 下滑双缩叠加 |

## 六、决策建议：按盈利情景设计打法，按不盈利情景铺安全垫（双轨制）

**结论先行：打法按 A 设计（盈利是基准而非激进假设），安全垫按 B 铺设。** 理由来自第二节测算：打平只需 18-30% 实现率、135-225 店，A 的达成门槛远低于直觉，「默认不盈利」才是过度保守；真正要防御的是 B 的**急性变体**（毛利归零×仍按A花钱）。

**双轨落地五条：**
1. **主线 = 盈利打法（A）**：锚定沙盘高分路线——R02双牌齐推(21.0) + R11数据端口(20.7)/R27数据中台(20.7) 作盈利放大器优先执行；R01成都堡垒(20.6) 既是 A 的基座也是 B 的保命核心，永远第一投入。
2. **预算红线（B）**：固定成本锁定 ≤36万/月（上限40万），超支须 GP 决议——这是盈亏平衡公式的全部分母，管住它，B 就死不了。
3. **资金封存**：买回预留200万 + 合规50万 独立账户，经营性缺口不得挪用（极端条款：跑道<6个月方可动）。
4. **统一仪表盘 + 触发器**：核心指标 = 月度现金毛利（打平线36万）；双触发——①连续2个月 <36万 → 自动执行保命清单（§4.4）；②任一融资信号（§4.3）→ 立即启动 Pre-A 接触。触发即执行，不依赖「再观察一个月」。
5. **融资节奏前置**：无论 A/B，M1 前一个季度即开始 Pre-A 接触——盈利数据是最好的筹码，未盈利也留有 3-6 个月交割缓冲。两条情景的最大公约数动作收敛为同一件事：**把「成都月度现金毛利」仪表盘做亮**。
