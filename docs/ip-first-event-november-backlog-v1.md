## 六、成功标准与红线

| 成功标准 | 红线(违反=暂停) |
|---|---|
| 成都 3-5 店参与且售罄 | 不搞定制化物料(起订量风险) |
| 平台正向数据(新增用户/流量) | 不自担库存(预售制+强制采购链接) |
| 筛选出 3-5 家"指哪打哪"核心商家 | 不做盲盒/立体物(7.5-9月周期) |
| 商家信任度建立(下一大促跟随) | 不选中性/低狂热 IP(美团教训) |
| 首场数据显眼(淡季出亮眼) | 不垫资超支(IP 当零成本推进) |
