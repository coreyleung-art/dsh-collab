## §3 优化方案（五期，每期可独立验收）

### P1 · 补洞（**不是重建响应式 —— 断点已在**）
- ~~新增 `@media (max-width: 768px)` 与 `(max-width: 430px)` 两档断点~~ → ★ **更正：两档断点（768/480）已在，只需在其中补缺项**
- `viewport-fit=cover`（改 `bb-blueprint-gallery.py:1644`）+ 四边 `env(safe-area-inset-*)` 内边距
- ★ **扩展已有的全宽化规则**：现有 `[style*="width:360px"]` → 改为覆盖 `width:400px|420px|440px|620px`（或抽成统一类名）
- 补 `touch-action: manipulation`（去掉 300ms 点击延迟）
- 验收：**每页 `documentElement.scrollWidth <= innerWidth`**

### P2 · 交互从 hover 迁到 tap（**功能补全，不是美化**）
- 所有 `hover 看 X` 增补 **tap 等价**（点击展开 / 长按看详情）
- 提示语改写：**滚轮缩放 → 双指缩放**；**hover 高亮 → 轻点选中**
- 引入 `pointerdown` 事件（统一鼠标/触摸），替换纯 `mouseover/mouseenter`
- ★ 判据：**页面上不再出现「hover / 滚轮 / 右键」字样**（可机械扫描）

### P3 · 图谱页专门重建（最差的一页）
- 画布：宽度 `100%`；高度由视口计算（`calc(100vh - 头部 - tab栏 - 底部)`），**不写死 500px**
- 节点标签：手机上**只画 `short`**；**轻点节点 → 底部抽屉弹详情**（替代 hover 弹层）
- ★★ **新增「列表模式」**：小屏上图谱本质难用 ⇒ 提供 **关系列表（父→子 + 类型）** 视图，一键切换
- 验收：画布无横向溢出；任一节点可**只靠轻点**看到完整信息

### P4 · 移动专属易用性
- **下拉刷新**（`overscroll-behavior-y` + 手势）
- **返回手势 / hash 前进后退**（页面已支持 `#hash`，补 history 语义）
- 触摸目标 **≥ 44×44 px**
- 首屏**骨架屏**（避免白屏等 200 KB）
- 子tab 行加**可滚动提示**（渐变遮罩或箭头），或改成**两行自动换行**
- ★ 「**数据截至时间**」按我已裁的方案显示（每件 mtime + 页面刷新时间双戳）

### P5 · 蜂窝网络优化
- 大载荷**按需/分页**（`cap-perm` 202 KB、`biz-assets` 171 KB）
- ★ **复用 A 组 SSE**：页面订阅模型版本号，**变了才重取**（A 组已给版本号）
- 离线态 UI：明确显示「**缓存数据 · 截至 xx:xx**」（`__dataState.mode` 已有，补 UI）
