## 三、投资计划(钱从哪来 × 何时要)

### 资金节奏(对应 C 分析三情形)
| 时点 | 事件 | 钱 |
|---|---|---|
| 现在(M0) | 种子1000万(自己人) | 51%+期权结构, 外部资本0 |
| M1达标(6-9月) | 动销1200+/买回落地/毛利账成型 | **Pre-A 2000-3000万**(里程碑触发非现金枯竭) |
| M2(9-15月) | 第二城(杭州述标≤50万先行) | Pre-A 到账后上海/北京立项 |
| M3(15-24月) | 10城满配 | A轮 3000-3700万 |
| 30城 | 10城月净1200万回血滚动 | 不再外部大额融资 |

### 三种情形预案(不赌单一剧本)
| 情形 | 信号 | 动作 |
|---|---|---|
| A 盈利跑正 | 毛利>支出自造血 | 可晚融至12-15月(少稀释) |
| B 持平 | 毛利≈支出 | 按计划 11-12月 Pre-A |
| C 亏损 | 毛利<36万 | 7-8月可转债过桥(动用弹性250万缓冲) |

### 投资纪律(100轮P0收敛)
1. **授权买回 = 最高优先级**: 200万封存专用, 30天谈判门→不成转三年长约
2. **现金毛利 = 唯一口径**: CPC按70%折价, 打平线36万/月仪表盘, 回款率<70%降速
3. **数据合规先行**: 50万保命钱先立规矩, 白名单>60%接受才投管线
4. **钱只投"买授权+数据端口+团队"**: 空手套白狼清单(算力白嫖/平台发薪/激励回款)省30-40%
5. **前6个月只承诺两件事**: 成都打透+数据端口P1(design-02纪律)
