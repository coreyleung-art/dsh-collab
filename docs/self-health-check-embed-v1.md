# 系统架构管理器 · 自健康检查内嵌(自免疫系统) v1

> 作者: 明鉴 v2 · 2026-09-05 · 用户提出
> 一句话: 审查器不只是命令行工具, 而是管理器的"自免疫系统"——运行时自检 + 问题沉淀报告 + 讨论前自动扫描

## 一、目标
1. **内嵌自检**: 管理器页面内可看"自身健康状态"(像体检报告)
2. **问题沉淀**: 每次自检发现问题 → 自动沉淀为报告(黑板 + docs)
3. **讨论前自扫**: 每次会话讨论架构管理器前, 明鉴先跑一遍健康扫描

## 二、架构

```
┌─ 内嵌健康检查(gallery 后端) ──────────────┐
│ build_health_report():                     │
│  H1 JS 语法(node --check 外部文件)          │
│  H2 Python 语法(py_compile)                │
│  H3 Tab-View 结构(bb-gallery-audit 复用)    │
│  H4 API smoke(关键端点可达)                 │
│  H5 版本一致性(引擎/壳/台账)                │
│  H6 数据完整性(关键 JSON 可读)              │
│  → JSON 报告 {healthy, checks[], ts}       │
└────────────────────────────────────────────┘
        ↓ /api/health              ↓ 沉淀
┌─ 页面呈现 ─────────┐    ┌─ 报告落档 ──────────┐
│ 🩺健康 Tab/徽标     │    │ docs/health-<ts>.md  │
│ 绿=全过 红=有问题    │    │ 黑板 notes/health/   │
└────────────────────┘    └─────────────────────┘

┌─ 讨论前自扫(明鉴习惯) ─────────────────────┐
│ 每次讨论管理器前: bash bb-gallery-gate.sh   │
│ + 若变化大: bb-gallery-audit --selfcheck    │
└────────────────────────────────────────────┘
```

## 三、实现
| 件 | 内容 | owner |
|----|------|-------|
| 后端 | gallery 加 build_health_report() + /api/health | 明鉴 |
| 数据 | 健康报告含时间戳/6 检查项/建议 | 明鉴 |
| 呈现 | 总览页顶部健康徽标(绿/黄/红) + 点开看明细 | 明鉴 |
| 报告 | 不健康时自动落 docs/health-<ts>.md + 黑板 | 明鉴 |
| 习惯 | 每次讨论前跑 bb-gallery-gate.sh(明鉴纪律) | 明鉴 |

## 四、验收
| # | 标准 |
|---|------|
| A1 | /api/health 返回 6 检查项 JSON(全绿/问题) |
| A2 | 总览页健康徽标实时反映(绿/红) |
| A3 | 发现问题时自动沉淀报告(docs+黑板, 带 ts) |
| A4 | 讨论前自扫成习惯(每轮先 gate) |
| A5 | 门禁 bb-gallery-gate.sh 仍全绿 |

## 五、风险
- 健康检查本身不打断服务(独立子进程 node --check)
- 报告落档低频(仅问题/每日)
