## 一、盈利假设双情景(分析A)

**盈亏平衡总闸门**: 成都站固定成本 ≈36万/月(30-40万敏感) → 打平条件=月实收现金毛利≥36万
→ 按 GMV2000万×抽成率: 现金抽成率需≥1.8%(全池进入假设) 或按动销口径 需 ≥13-14家有效动销店净贡献

| 维度 | 情景A 盈利(160-200万毛利跑正) | 情景B 不盈利(毛利<36万) |
|---|---|---|
| 融资 | 可晚融至12-15月(盈利叙事估值高) | 提前至M1中段, 可转债过桥 |
| 窗口动作 | 有现金→买断授权/投数据端口/扩第二城 | 砍投入→保授权买回+团队, 数据端口降速 |
| 股东关系 | 资源方看到盈利→愿意追加/续投 | 需经营权分成给资源方保参与感 |
| 里程碑 | M1-M4 加速 | 保命优先(砍数据端口/区仓, 保牌照+团队) |
| 决策 | **双轨制**: 按盈利情景设计打法(抢窗口), 按不盈利情景铺安全垫(6个月成本缓冲) |

## 三、融资时点规划(分析C)

- **Pre-A 由里程碑触发, 非现金枯竭**: 三硬信号(动销1200+/授权买回落地/月毛利账成型2-3月) + 一预警(账上<6月成本→提前3-6月路演)
- **最优窗口**: M1后1-2月(3·31返佣关账+成都SOP成型+第二城决策 三线汇聚), 最迟第15月M2前
- **三情形**: A盈利→晚融12-15月 / B持平→按计划11-12月 / C亏损→提前可转债过渡
- **不融资的真实代价**: 丢四个时间窗(3·31返佣红利/声通授权窗口/杭州上海盘口/2029递表日历)

## 四、股东与权责(分析C+D)

**四层结构**: 权(层①章程表决≥51%)/钱(层②财务LP)/参与感(层③资源方)/事(层④子公司) 四权分离

| 股东类型 | 权 | 责 | 利 |
|---|---|---|---|
| **GP(用户)** | 经营决策/业务方向/51%投票权 | 业绩对赌(公司层)/定期报告/信义义务 | carry 20-30%/管理费1.5-2%/里程碑期权 |
| **资源方**(于总/吴总/紫阳) | 顶层控股股东/董事席位/清单式否决(增资担保并购) | 出资/不干预日常 | 按股分红(可动态)/资源作价 |
| **财务LP**(外部基金) | 知情权/审计权/清单否决/退出权 | 出资/不干预经营 | 优先回本/门槛收益/里程碑解锁 |

- **紫阳铁序**: 先工商确证股东身份 → 再资源作价入股(独立评估+防火墙), 确证前仅候补
- **第二轮四件套**: 外部LP只进层②(物理隔离) + 资源方优先认购/加权反稀释/30天跟投窗口 + 51%章程兜底 + 期权池与身份治理分离
- **对赌**: 一律公司层(2025执复27号, 个人不兜底), 里程碑同款锁LP对赌+创始人期权(利益同向)
- **退出**: LP回购/转让/IPO三选; 资源方可回售; 创始人反稀释+投票权不稀释

## 六、必要要素提醒(按R-A11主动职责)

1. **授权买回 = 一切的地基**: 不落地则 R01-R32 全部是"替平台打工"叙事, 融资无从谈起——建议下周内启动谈判
2. **36万/月打平线 = 运营总闸门**: 每月盯这个数, 低于即触发降速预案(砍数据端口/区仓, 保牌照团队)
3. **紫阳身份确证 = 声通协同路线开关**: 确证前 R06/R07/R28 等声通系路线全部冻结
4. **3·31 返佣红利 = 第一次现金窗口**: 错过则现金抽成腰斩(12→6点), 前6个月动作应赶在此前
5. **数据合规红线**: 端口采集只走平台白名单(design-06), 这是刑事级风险不是商誉问题
