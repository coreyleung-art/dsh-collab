### 二阶发现：这条控的字段表**指向真实对象时会假红**

该控的越界字段表含 `signer_fp`；而**真实的游标合法地带 `signer_fp`**（那是签名字段，不是信封字段）：

```
$ 读 notes/xdom/cursor/int
真实 cursor/int 的顶层键 = ['at', 'by', 'party', 'sig', 'signer_fp', 'upto']
用这条控的字段表去套【真实对象】 => 越界 = ['signer_fp']      ← ★ 假红
```

⇒ ★ 这条控**卡在两头**：
- 指向 `cursor_value()`（它现在指的）⇒ 对**写路径**空转（§三主发现）；
- 指向**真实写入物**（它本该指的）⇒ 字段表把**签名字段**误当信封 ⇒ **假红**。

★ **修法方向（我只给判据，不代改）**：控的对象应当是 **`cmd_ack` 实际 `put_verified` 出去的那个对象**
（上轮我用「把 `put_verified` 换成捕获器」的做法就是为此），且字段表须**排除 `sig`/`signer_fp`** 这类签名字段。
