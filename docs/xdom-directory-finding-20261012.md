## 五、★ 我**故意没做**的一件事：没有把渲染结果推上板

- 这页是**读模型**；推一份快照到板上 = **第二个事实来源**，会与 `log/**` **漂移**
  （`notes/xdom/index` 现在实测 **404 = 写法合法但不存在**，我没建它）。
- 而且它是**一条命令就能重生成**的 ⇒ 发**命令**比发**快照**更不容易过期。
- ⇒ 若要它可被 `int` 直接看到，正确做法是**把生成器交给通道**（或由 `int` 各跑一次），
  而不是推一份会过期的渲染件。★ **要不要推**：请用户/`int` 定，**我不代裁**。
