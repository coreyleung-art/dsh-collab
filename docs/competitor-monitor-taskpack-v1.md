## 〇、为什么持续(背景)

竞品调研基线已确认赛道"相对蓝海但有平台天窗", 定义了**窗口关闭信号**:
- 美团官方鲜花工具迭代(鲜花数据大模型/返图下沉)
- 外卖大师等通用 AI SaaS 发布鲜花行业版
持续调研 = 盯住这些信号, 窗口关闭前最大化先发优势。

| 蓝图/产品 | 监控对象 | 关注点 |

## 二、持续机制(三层)

### L1 · 月度深度扫描(主任务)
- 频率: 每月 1 次(固定月初)
- 内容: 全范围重扫(web_search 多组 + 官方价目/公告核验)
- 产出: research/competitor-monitor/YYYY-MM-competitor-scan.md
  - 新玩家清单(增量) / 存量变化 / 融资动态 / 定价变化
  - 窗口信号检查表(每项: 触发/未触发 + 证据)
- 执行: 数据调查员(可派子代理), ~2h/次

### L2 · 周度轻扫(信号盯梢)
- 频率: 每周 1 次
- 内容: 关键词快速检索(美团鲜花/花店AI运营/鲜花代运营/外卖大师鲜花), 只记信号
- 产出: 黑板 data/ops/competitor-weekly/ + 无实质变化不落长报告
- 执行: sysops 定时触发调查员轻扫

### L3 · 事件触发(窗口信号即时)
- 触发条件(发现即报):
  1. 美团发布鲜花行业新工具/大模型能力下沉
  2. 外卖大师/再惠发布鲜花行业版
  3. 新玩家融资曝光(鲜花×AI运营)
  4. 花递等代运营玩家出现工具化/规模化大动作
- 动作: 即时产出深研小报告 + 通知明鉴(蓝图/战略更新)

## 四、产出规范(对齐 R012 完整体 + 数据调查员标准)

每份扫描报告须含:
1. 增量竞对清单(名称/模式/规模/技术/融资/强弱) — 与基线表 diff
2. 存量变化(定价/功能/范围) — 时间线
3. 窗口信号检查表(触发状态 + 证据链接)
4. 对我方蓝图/战略的启示(建议动作)
5. 证据分级(一手/二手/营销) + 局限声明
