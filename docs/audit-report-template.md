# 审计报告模板（强制项）

> **本文件是「哈希口径声明」与「实跑验证」两条纪律的承载物。**
> 由来：星桥审查线 2026-10-09 的 F44 / F57 / F60 / F67 / F69 + 模式库 M7–M10。
> **用法**：新建审计报告时复制本骨架；**带 ★ 的段落是强制项，缺一即该报告不合格**。
> 本模板自身口径声明（示范）：**SHA-256 全量摘要的前 16 位小写 hex**。

---

## ★ 强制项 0 · 哈希口径声明行（F44）

**每份含哈希的报告，必须在头部或就近处声明算法与截断长度。**

```
> **★ 哈希口径**：本次全部 16 位 hex = SHA-256 全量摘要的前 16 位小写 hex。
> 用 md5 核会得到不同值，那不是篡改。
```

**理由（F44 实测）**：16 位 hex 在 `md5`/`sha1`/`sha256`/`sha512` 四种算法下**都合法** ⇒ 不声明算法时，
**第三方用错算法会得到「不匹配」** —— 我方实测误判率 **5/5 = 100%**。
⇒ **「引用的规格未被写出」与「引用的事实是假的」输出相同**（M8 的变体）。

**可选机械核**：`shasum -a 256 <file> | cut -c1-16`

每个数字必须带**观测时刻**；若对象仍在增长，须写「该数字附时点，重跑更大是预期」。

| 对象 | 值 | 观测时刻 | 是否仍在增长 |
|---|---|---|---|
| | | | |

**理由（Q2-d 实测）**：某信息包发布后 **49 秒**，其所描述的产物即被重建 ⇒ **任何按该 sha 核验的审查员都会得到「不符」**。

## ★ 强制项 2 · 实跑验证（模式库 M9）

**凡以「检查通过」作结论处，须写明该检查是否【执行过被测对象】。**

| 声称 | 检查类型 | 实跑命令 | 实跑时刻 | rc | 自测标识 |
|---|---|---|---|---|---|
| | 静态 / 实跑 | | | | |

**判据**：`exit=0` 对「真通过」与「静默跑默认动作」**同痕** ⇒ **看输出里的自测标识行，不看退出码**（出处：`scripts/selftest-inventory.py`）。
**理由（M9 三次实证）**：X19（语法全绿后实跑暴露 3 个运行期错误）· `c7-delta-exact.py` 空输入 rc=1 · 本库维护者写 `gate-canfail` 时 `--selftest` 连崩两次。

## ★ 强制项 3 · 按归属分列（F61 / F69）

**凡统计类读数（失误数 / 截断数 / 覆盖率…），若涉及多方，必须按归属分列。**

**★ 且须自证「归属无交集」**：否则宽模式在前会把窄模式**静默吞掉**，得到的是假分列。

```
# 分列自检（silent-truncation-lint v1.0.2 起内置）
#   --by-owner 多模式时，工具会检出「多归属」并告警；
#   报告须写明：本次分列是【真分列】（各模式两两无交集）还是【有歧义】。
```

**理由（F61 实测）**：我方统计对方截断时把「我的」单列一栏，**结果暴露我自己的 61 处 vs 对方 12 处**。
⇒ **若只统计对方，这个数字永不出现。**
**理由（F69 实测）**：`--by-owner repro --by-owner stage-review`（宽在前）⇒ 只得到一组、被吞者不出现在任何一栏，且工具不报错。

## 报告骨架（非强制，但建议照此五段）

1. **立案卡** —— 对象 / 范围 / 判据来源
2. **声称对账表** —— `C编号 | 声称 | 判据 | 复现命令 | 实测结果 | 判定 | 严重级`
3. **无法判定清单** —— 逐条附**缺失的观测面**
4. **命中的故障模式** —— 引模式库编号（M1–M10 / P / X / F）
5. **未覆盖范围** —— 明确写下没审什么

---

## 强制项 5 · 判定纪律（零新建，直接引用）

- **不裁**自己参与建构的对象（S3 自审无效）；
- **否定性结论**必附观测面（`absence-claim-lint.py`）；
- **引用**必附内容指纹（哈希 + 时点）；
- **按归属分列**的自查（强制项 3）—— **审别人时注意什么，就用同一判据审自己**；
- **报告只增不改**：修订另出 `v<n+1>`，旧版保留。
