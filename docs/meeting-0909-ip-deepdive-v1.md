## 一、核心定调(全文级, 最重要)

1. **IP 变现靠"物料/包材", 不是靠卖花本身**——"IP 嘅最终变现如果喺物料"。授权金 100-200万 靠包材赚回, 周期结束必正现金流(「哪怕我一百万两百万嘅授权金, 呢个包材就赚得返嚟」)。
2. **"两张牌"认知修正**: 城市合伙人=官方运营方角色(能线下落地/活动/触达商家); **全国流量牌照≠代运营**——"代运营同呢件事半分钱都冇关系"。代运营=纯劳动力生意想象空间小; 全国牌本身冇用, "签咗客先有用"。
3. **IP 授权成本 ≈ 零/正**(钟总口径, 用户确认): 「当你冇成本, 有钱赚添」——IP方倒贴求渠道(「唔收 IP 费都得」), 我方只要出全国渠道+帮角色庆生/升量, 游戏公司抢着合作。**→ 直接支持: 授权金不必在第一阶段预留大额成本!**
4. **第一阶段唯一目标 = 建商家信任 + 平台正向数据**, 非成交/非盈利: 「城市战役嘅达到嘅目标, 它成交多少其实我唔太在意」「第一轮其实系赚商家信任度」。
5. **平台最大外部威胁 = 达摩克利斯之剑**: 若平台(淘宝闪购)财报长期无我方正向反馈 → 可能被列为策略调整对象。城市战役=重中之重(用最少资源打最靓仗)。

## 二、IP 筛选方法论(十字坐标)

- **横轴**: IP受众性别(左男→右女) · **纵轴**: 狂热程度(下冷→上热)
- **只选右上象限**: 女性向 × 高狂热 (价格敏感度极低)
- **排除**: 男性向/中性/低狂热(美团选迪士尼=中性低狂热→倒逼商家刷单→法律纠纷=前车之鉴); 真人IP暂不纳入(授权贵/不可控/「唔好做」)
- **先例教训**: 美团同类活动选"最大不犯错"头部IP(中性低狂热) → 销售压力→误导商家刷单→法律纠纷。我方策略=剑走偏锋, 靠 IP 粉丝狂热为平台带**外部新增用户**(非存量转化)
- 优先: 少女游戏(恋与制作人/永远制造人类)多角色; 张凌赫=精准代言案例(但真人IP贵)

## 三、落地模型(防库存/现金流波动)

- **报名-备货-交付博弈是核心**: 怕 ①发不起货(报多备少) ②库存积压(备多报少)。两端都不该我方承担。
- **解法=预售制/强制采购链接**: 「预设(预售)交畀平台, 强制买——呢个系 IP 方要求, 任何大 IP 公司都唔接受报名唔用我耗材」。美团已有**指定采购端口先例**→链路已跑通, 放心。
- **第一期小样板**: 每城只 3-5 家店(饥饿营销/稀缺), 单场备货 ≤200-1000 束; 头粉(KOL/高氪)圈内集资3档套餐(2888/888/288)预估大盘→按大盘配货→略多留散客。
- **物料选型**: 现成通用资材优先(硬卡盒/贺卡/缎带/包装袋), 不搞定制化(起订量高/周期长/商家难还原); 主花约束(品种/数量), 配花枝材不约束。
- **不做盲盒/立体物**(周期7.5-9月/开模复杂): 毛绒/棉花娃娃可作标准品。
- **时间表**: 10月中授权合同签好 → 10月底公告/报名/套餐/购买链接 → **11月首场落地**(赶11.24-25圣诞预热前) → 圣诞同步推进第二波 → 214前冲1000店服务商。
- **城市策略**: 对外谈"全国级"谈判口径(平台全矩阵流量=淘宝8亿+支付宝+千问≈16-18亿入口), 实际资源全倾斜成都(样板城) + 广州低成本执行几场(本地验证)。
