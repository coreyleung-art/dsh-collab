## 〇、与通讯层 MCP 的区别(明鉴分层判断)

| 维度 | 通讯层 MCP(comm-mcp-server) | 业务能力 MCP(waimai-mcp-server) |
|------|---------------------------|-------------------------------|
| 层 | 底座/接入层 | 应用/能力层 |
| 对象 | 黑板/E2/bus 基础设施 | 8787 面板外卖运营能力 |
| 消费方 | 外部 agent/设备(接入协作) | 用户/商家/第三方(调用能力) |
| 本质 | 接口标准化 | 能力服务化/产品化 |
| 蓝图 | agent-network(mcp-access) | mtm(mcp-export) |

## 一、目标与范围

### 目标
把 8787 面板已验证的外卖运营能力封装为标准 MCP 服务, 使:
1. 任何 MCP 客户端(AI 助手/商家工具/第三方系统)可调用外卖能力(查/分析/操作)
2. 能力与数据源解耦(消费方不知面板细节)
3. 为"服务封装溢价"(8787 SaaS 化模式 A)预留产品通道

### 非目标
- ❌ 不做多店写权限开放(动作类强制 R027 人类开关锁)
- ❌ 不暴露凭据/面板内部
- ❌ 不做计费系统(模式 A 验证价值后再议商业化)

## 二、能力盘点(工具面草案)

| `waimai_alerts` | /api/alerts | 订单告警 |

### 2.2 动作操作类(L3 需确认)
| MCP 工具 | 动作 | 门 |
|---------|------|-----|
| `waimai_accept` | 接单 | R027 开关锁 + R026 用户确认 |

| `waimai_price` | 改价 | 同上 + 决策六问(R028) |

> 动作类默认 dry-run, 需 confirmed + 人类授权(R027 生产区默认 OFF)

## 三、架构设计

```
┌───────────────────────────────────────────┐
│ MCP 客户端(AI 助手/商家工具/第三方)        │
└──────────────┬────────────────────────────┘
               │ MCP JSON-RPC 2.0 (streamable HTTP/SSE)
┌──────────────▼────────────────────────────┐
│ waimai-mcp-server (新组件)                │
│ ├ 鉴权: API Key/设备 token(R-ERR4 复用)  │
│ ├ 工具面: waimai_* (映射下)              │
│ ├ 动作门: R027 开关锁 + R026 确认         │
│ └ 审计: 全部调用留痕黑板                  │
└──────────────┬────────────────────────────┘
               │ 内部 API (本机, 不对外暴露)
┌──────────────▼────────────────────────────┐
│ 8787 面板 (127.0.0.1:8787)                │
│ state/alerts/report/analyze/action APIs   │
└───────────────────────────────────────────┘
```

### 部署
- 首版: mac-mini 本机(8787 同机, 数据不出门) → MCP SSE/HTTP 端点
- 访问: 本机/Tailscale(自用) → 若 SaaS 化再评估公网/服务器(B 方案, 需备案)
- 复用: waimai_* 宿主工具面逻辑 + external-link SSE 8910 先例

## 四、安全与护栏(动作类是重点)

| 层 | 约束 |
|----|------|
| 只读分析 | token 即可(L0/L2 自动) |
| 动作操作 | R027 人类开关锁(生产区默认 OFF) + R026 用户确认 + 演练优先 |
| 数据 | 只读不暴露面板凭据/配置 |
| 审计 | 每调用留痕(data/mcp-audit/ 或黑板) |
| 隔离 | J29: 测试仅守白 8 店 |

### 越权拒绝(Lean4 门)
| 不该发生 | 门 |
|---------|-----|
| 无 token 调动作 | 401 |
| 未授权店操作 | store 白名单 403 |
| 无人类确认执行 | R027 Unlocked(Authorization) 拒 |
| 测试店外批量 | J29 隔离 |
