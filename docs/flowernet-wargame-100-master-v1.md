## 三、逐主题 Top 裁决洞察

### T01-授权与持牌
- **授权买回谈判: 如何给声通/平台一个无法拒绝的买断报价(现金+业绩对赌可回售结构)?** → 反方胜点成立: '彻底买断所有权'在平台侧不现实，声通能卖运营权难卖接口权。修正为'锁定性买断'——三年长约+费率锁死+优先续约权+单方断供违约赔偿，效果近买断而现金成本砍半，预算余量留作他城复制与对赌履约储备。
- **声通30天落地门到期未成的PlanB: 换持牌主体的完整切换方案与成本?** → 正方流程可行、反方政策风险属实。裁决: 切换必须与'政策平移'捆绑谈判——先拿到平台书面确认'主体变更不重谈政策'再启动，谈不拢宁可双轨拖延也不裸切; 30万预备金从合规预算划拨，未动用年底回填买回预算，防政策风险二次放大。
- **一年期授权续签谈判: 拿什么筹码换续签+更优政策(抽成/接口/排他)?** → 正方方向对但'绝对保底'危险: 保底一旦未达即授平台反手涨抽成的把柄。裁决: 硬条款只争可量化项——抽成阶梯挂钩达成率区间而非单点保底，保底线设85%; 排他降级为'成都鲜花类目优先试点权'书面化; 接口SLA附违约赔偿才签。

### T02-成都单城
- **动销750→1200+爬坡：三个月每月的激活目标与手段分解？** → 正方漏斗成立但前提是真激活；反方点中考核失真与淡旺季回吐两大翻车点。裁决：动销口径须为30天内≥3单且无自购，反刷单规则先行；M1以存量促活与质量验证为主，M2-M3再放量，禁止为冲量签空壳店，宁慢勿假。
- **现金/CPC分账模型：6点现金+6点CPC如何分别跟踪与变现CPC？** → 正方对区分真实现金与平台信用判断正确；反方点破CPC=或有收入，存在过期回收与商家意愿双重风险。裁决：现金毛利是打平线与激励的唯一口径，CPC按70%变现率折价预估并单列跟踪，变现以商家自愿+ROI可证为前提，不强制代投。
- **真实抽成率验证：抽样N家店实测现金抽成率的方法与达标线？** → 反方点中选样偏差与双口径失真最有价值。裁决：抽成率统一用平台结算口径（实收佣金÷计佣GMV），抽样由运营组长加密随机执行、BD不碰取样防自证虚高，基数每月复核，跌破达标线即触发议价清退。

### T03-城市扩张
- **第二城选择: 杭州(70%+潜力) vs 苏州(老商复议) vs 广州(橙果主场)排序?** → 反方胜在提醒防御成本须重估，正方战略排序成立。裁决：杭州第一但分段投入——述标(≤50万)先行、资格落定才投重金；广州第二作低成本并行（牌照复用、轻团队）；苏州仅测试不立项。
- **第二城复制节奏: 成都SOP到什么程度才可复制(动销?毛利?团队?)?** → 反方胜点=窗口不等人，但门槛降到单店验证又太松。裁决：双门槛——现金毛利≥40万连续3周（不设动销绝对数，看周环比为正）+城市经理成建制可外派；SOP四模块先行文档化并随城迭代；杭州述标与门槛验证并行推进、互不等候。
- **杭州15号述标: 投标材料的差异化叙事(成都战果+双牌+数据端口)?** → 反方胜在筹码管理与口径风险。裁决：战果数据全换平台同源口径并由于总签字复核；双牌叙事改为全国持牌+城市本地合规运营；端口演示放会后、正文仅一句；主线定位品类增量，给平台看GMV翻倍路径而非抢份额话术。

### T04-数据端口
- **1. 端口产品定义：L1自有/L2服务商权限/L3商家工具/L4城市盘口，先做哪层？** → 反方合规与接入动机质疑成立，但正方分层正确。修正：权属先行——L2只采『持牌授权范围内自有+签约授权店』，L3数据回报走白名单与知情同意，L4仅在聚合指数形态下启动。
- **2. 合规边界：平台数据不得披露第三方——白名单内采集什么合法？** → 反方风险真实但过度——服务商为本店履约对账本就触达经营数据，关键是把『履约采集』与『数据变现』两件事物理切割。裁决：采集只走官方授权通道，变现只用自营+自愿授权数据的脱敏聚合，中间加留痕审计。
- **3. 半年先发窗口：数据端口分阶段（design-06 P1-P3）的加速路径？** → 加速方向对但顺序须调：先证『授权可得性』再投管线，防止管线建在沙地上。裁决：以3·31续约为强制节点，半年拆四段（授权验证1月→管线与100店2月→工具与指数2月→资产化1月），每段设放弃/转向触发器。

### T05-供应链
- **区仓网络: 1:8拓扑(芳村总仓→区仓)在第二城的复制条件?** → 反方胜：1:8是密度成熟后的形态，不是开城起点。修正：第二城以当地产区直采+单城心仓起步，芳村总仓只做SOP输出与集采谈判；区仓严格按签约店数≥20家与预测日单≥80单逐开，禁止按图铺满8仓；冷库先租后建、仓配首3月外包按单付费，验证盈亏后转自营，把单城180-220万投入压在最小化。
- **花材直采 vs 芳村批发: 到多少店规模自建直采才划算?** → 反方在节奏上胜、正方在方向上对：直采该做，但要等规模。修正：设硬门槛——单城签约店≥300家或单品月采购≥15万才立项，试点只切2-3个高频爆款；首年外包昆明产地服务商按吨付费，不自建产地仓与买手编制；芳村批发保留≥40%份额做长尾与应急双通道；按季做同SKU直采vs批发全成本对比，不划算即回撤。
- **IP贸易线: 定制包材正版锁的供应链(监修/指定工厂/指定贸易)怎么跑?** → 反方账算得实：IP线是差异化点缀，不是利润主干。修正：IP包材一律预售+限量，日常现货零库存；IP准入卡授权金<15万且可阶梯付费、监修承诺≤3轮；指定工厂一主一备，贸易走持牌主体内部化防行商抽点；3个月3000套试单不过动销线即砍线，资金不与主线混池。

### T06-IP与品牌
- **双旦(圣诞+元旦)部署: 2026-09起的倒排时间表与节点动作?** → 正方时间轴成立，但须以柔性供应链为前提：预售定金锁单≥40%再放大备货，把库存风险前置转移；反方损耗与人力瓶颈攻击成立，故每节点设熔断复核，过会才进下一段。裁决：按正方节奏执行，叠加预售锁单、A/B档投放、损耗红线三层修正。

- **小阿狸模式复制: 红玫瑰款全门店打同款→下一单IP选什么?** → 正方复制方法论提法正确，反方单城样本不足+热度时点攻击成立。裁决：不直接赌下一单，先双IP小样本A/B（池内分组各试2周），用售罄率/复购率替代拍板选IP；热度指标入例行周报，触发即撤。方法论固化选IP-试销-放量-撤场四步SOP，并标注成都样本局限。

### T10-风险合规
- **1. 数据合规体系: 采集/存储/使用的合规框架(平台规则+个保法)?** → 正方方案胜，但须把数据当业务生命线而非合规负担：合规50万是保命钱不是成本。反方点出的端口断供与个保法天价罚单成立，防御重心应放在端口数据权属锁定与最小化接触面上——让每个能碰到数据的人都可追溯，让平台审计随时查得清、说得明，合规建设进度要作为Pre-A路演材料主动展示。
- **2. 反诈红线: 服务商地图销售话术如何避开'招商骗局'同构?** → 反方击中要害：红线不在收费本身，而在承诺与兑现的匹配度，话术合规优先级高于签约速度。裁决采纳双轨——对内话术铁律管住销售动作，对外合同与退款机制管住事后救济；同时把服务效果做成可对账的交付物（周报/数据看板），用真实履约证明收费正当性，让报案失去事实基础，比任何话术规避都更根本。
- **3. 平台规则: 服务商管理规范逐条合规自查清单?** → 正方方向正确但执行必须工具化防漏，反方指出的规则扩散性与版本失控是真实威胁。裁决采纳清单制+责任人制，但补上两道闸：一是红线条款（代操作账号/转包/私下返佣）单独列示、零容忍宣贯，防漏一条毁全局；二是把投诉率、拒单率等考核指标纳入周报监控，让违规在处罚前先被数据暴露。
