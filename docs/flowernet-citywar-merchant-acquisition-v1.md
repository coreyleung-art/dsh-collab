## 〇、一句话结论

**「帮淘闪打城市战」= 用"全国鲜花服务商 + 城市合伙人"双牌，战役化逐城拿商家、跑 GMV、换返佣/授权/代理费；「获取商家信息」= 城市合伙人以强建联平移存量店 + 服务商以新签考核持续拉新，两条通道把本地商家纳入体系。**

## 一、平台授权结构（谁手里有什么牌）

| 牌 | 归属/事实 | 出处 |
|----|----------|------|
| 全国鲜花类目服务商资格 | 成果持有（淘宝闪购全国鲜花类目），**一年期合同** | ch11, ch14 |
| 唯一性 | 当前无同类竞争对手；合同未标"唯一"但**平台倾向单服务商** | ch14 |

## 二、城市合伙人机制（区域代理权）

### 2.1 定位与关系
- 城市合伙人 = 淘闪**非餐饮全品类城市代理**（不止鲜花），与全国鲜花服务商**相互独立无绑定**（ch12）
- 已拿下的成都城市合伙人：可依托**既有门店运营管理权**，把存量鲜花店**平移对接**至成果鲜花服务商体系（ch12）

### 2.2 遴选投标机制（ch13/ch16）
- 评委 6 人：鲜花/水果生鲜/便利店/其他类目 4 位总部负责人 + 西南大区总 + 成都城市经理
- 环节：一面 → 二面 → 三面；**终面赴杭州阿里全球总部**，标注分高者入选（兼客观+主观）
- 资质：无需自有门店；需 **23 个品类商家管理服务能力**；老商经验加分
- 硬性门槛：**实缴 200 万注册资金 + 400 万存款证明**（年流水 800 万、固定社保人数另见 summary）
- 进展：成都已拿下；苏州因老商历史运营加分未中；后续推进杭州/北京/上海

### 2.3 管控与考核（ch14）
- 平台核心管控指标：**开店数量 + GMV**（成都目前完成不佳）
- 城市合伙人考核：新签门店量 + 运营内容（商家活动报名、店铺装修、投流意愿）

## 三、「获取商家信息」机制（核心问题答案）

两条通道，均以平台授权为基础、运营动作落地：

### 通道 A：存量平移（城市合伙人强建联）
- 成都 8000+ 即时零售门店，其中**鲜花店约 750 家**，由城市合伙人团队**强建联掌握**，可直接平移至服务体系（summary）
- 机制：城市合伙人凭运营管理权 → 逐店平移对接 → 商家进入鲜花服务商体系 → **商家信息（名单/经营/需求）随之进入我方体系**
- 这是**当前最大的存量池**：750 家 ≈ flowernet-supply 的初始目标客户基数

### 通道 B：新签拉新（服务商考核驱动）
- 平台考核 = 新签门店量 → 服务商/城市合伙人必须持续拉新（多元活动拉新提量被认可，ch16）
- 拉新返点（ch11）+ 12 点返佣分配权：新签商家进入体系的同时获得运营触点（装修/报名/投流=持续信息回传）

### 通道 C：消费者迁移（外部增量，用户注入）
- 他平台无授权商家有需求 → 导流当地淘闪（supply 蓝图 acquire 线已有）

### 信息沉淀为资产
- ch8：核心方向 = **借城市合伙人资质做代运营积累商家数据**，开发软硬结合的行业工具，逐步蚕食美团份额
- ch19：依托城市合伙人代运营资格，单渠道 → 全渠道代运营，叠加物料/软硬件订阅现金流

## 四、「帮淘闪打城市战」打法（逐城扩张模型）

### 4.1 单城跑通模型（ch18 核心）
1. 仅售卖城市服务商地图无价值 → 需**先单城跑通模型**
2. 组合拳：**流量倾斜权 + 运营活动权** → 盘活本地存量商家 → 跑出商家增量业绩
3. 商家信任建立 → 支撑代理权销售（后续城市可售）

### 4.2 双牌推进（summary）
- 必须同时持有：**全国鲜花服务商 + 对应城市合伙人**两张牌，才能打透单城市模型（单一资源有短板）
- 落地顺序：城市合伙人强建联触达存量 → 服务商流量政策给商家实际业绩 → 完成平台考核

### 4.3 节奏（ch17 + summary）
- 战役化、逐城突破、**打一个成一个**的叠加节奏
- 多点开发并行；广告型串联（城市战果可叠加）
- 不同城市合作主体不同属合规正常安排
- 单城模型跑通后，中标概率随案例积累提升 → 售卖「城市服务商地图/代理权」

### 4.4 现金流（ch19 + summary）
- **让度点数分配权**聚拢商家/代理商：出让区域代理返佣分配权，换代理商提前支付代理费（财散人聚）
- 覆盖前期运营与研发成本；长期叠加物料/软硬件服务订阅现金流

### 4.5 硬件工具远期（summary）
- 商家信任积累后推出**行业软硬件工具订阅制**（如花店枝材粉碎压缩工作台等非标硬件）
- 最终泛化为全行业工具服务商

### 5.1 边界提醒（明鉴判断）
- 城市合伙人投标/服务商授权均挂在**成果/合资体系**，非 flowernet-supply 自身牌照
- flowernet-supply 的角色 = 在商家池之上做**供货 + IP + 锁店**（贸易侧），**不直接打城市战**
- 「打城市战/拿商家」主体 = 成果/淘闪服务商项目（可能属 flowernet-ops 或合资资本化面）——**归属需用户定夺**，勿擅自并入 supply
