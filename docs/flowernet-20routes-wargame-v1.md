## 三、收敛分析: 主路线 + 副翼组合(非单条)

**沙盘结论: 无单一路线可独立成立, 20 条收敛为 3 簇 + 1 北极星**

```
┌─ 簇1 现金流引擎(立即跑正) ──────────────┐
│  主: R04 代运营军团(160-200万/月毛利)    │ ← 养活体系
│  翼: R02 双牌齐推(城市合伙人+服务商)      │ ← 窗口内抢资格
│  → 组合=「代运营回血 × 双牌抢窗口」      │
├─ 簇2 护城河沉淀(窗口内铺) ──────────────┤
│  主: R11 数据端口堡垒(分阶段, 合规前置)   │ ← 北极星
│  翼: R06 声通算力白嫖(省现金) + R13 区仓  │ ← 数据/供应链资产
│  → 组合=「数据端口 × 算力白嫖 × 区仓」   │
├─ 簇3 资本架构(随时可接) ────────────────┤
│  主: R10 混合资本分层(资源方+财务LP)      │ ← 回应于总/紫阳
│  翼: R03 自营KA(品牌底盘)               │ ← 增信+平台风险对冲
│  → 组合=「分层架构 × 自营底盘」          │
└─ 北极星(终局): R20 底座+连锁双引擎 ────┘
    = 簇1×簇2×簇3 收敛(数据底座服务90% + KA连锁自营10%)
```

**收敛逻辑**: R04/R03/R09/R18/R19 的高分来自"控盘+现金流", 但对抗修正剥掉虚高——纯滚动(R09)/纯防守(R19)降级; R04/R03 因现金流实留榜但必须挂副翼(数据端口), 否则窗口浪费。**真实打法=簇1先活+簇2窗口内铺资产+簇3随时接资本, 三簇同时起(对应 01/02 交付底稿)**。

## 五、沙盘关键洞察

1. **窗口期是最大变量**(一年授权+半年先发)——所有"稳健/滚动"路线对抗后降级, 窗口内必须抢资格+铺数据端口
2. **R04 现金流最实但护城河最弱**——纯服务不沉淀数据=被替代风险(redteam 第4轮打穿)
3. **组合拳优于单路线**: 20条=10条有效组合素材, 真实战略是 簇1×簇2×簇3 三线并发
4. **R05 地图销售红线**: 单城未跑通前禁售(反诈同构), 与 citywar gate③一致
5. **数据端口须合规前置**(R11 对抗)——design-06 转律师意见是沙盘硬约束
