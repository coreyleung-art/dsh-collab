## 二、提案 A：J44 门（`scripts/j44-reuse-gate.py`）

### A.1 三处缺陷（★ 均为本线亲验，可复跑）

| # | 缺陷 | 复跑 |
|---|---|---|
| A1 | ★ **措辞决定结论** —— 同一件事，换说法即变 | `--intent "给 expired 接告警卡"` ⇒命中 **1** （拒）；`--intent "新建一个告警写入器用于总线过期消息"` ⇒命中 **0**（放行） |
| A2 | ★ **候选不可裁** —— 命中项的 `name` 是**日期结尾的滚动 id** | 命中项显示 `[S5] hr-ruling-bind-object-state-and-retraction-expired-20260914` ⇒ **人无法据此判「是不是同一个东西」** |
| A3 | ★★ **它对自己的旗舰反例不敏感** | `--intent "新建一个沉淀链扫描器"` ⇒命中 **0** ⇒ 门输出「本机无命中 ⇒ 允许新建」。★★ 而 J44 文档逐字记着「当天差点新建一个**已存在**的沉淀链扫描器（`sedimentation-chain-scan.py`，2026-08-22 建）」 |

### A.2 根机制（★ 由 `session-int-mbp` / 明鉴查清）

★★★ **上游已声明局限，下游把它升格了**：

```python
# 上游 scripts/local-registry.py:400-401 逐字
print("⇒ ★ 无命中【不等于不存在】—— 本索引用【词面匹配】…")

# 下游 scripts/j44-reuse-gate.py:305 / :313 逐字
· 无命中 ⇒ 过（本机确实没有 ⇒ J44 允许新建）
return True, "本机无命中 ⇒ J44 允许新建"
```

★ 两句相距 **不到 100 行代码**，★★ **直接对撞**。

### A.3 提案修法（★ 三条，★ 不代裁）

1. ★★ **判据改为【语义检索】**，不再只做字面命中。★ 本机已有 **`local-registry` 2301 条目** + **`knowledge_search`**（★ 向量检索）可用。
2. ★★ **候选表改为显示【人可读标题 + 一行摘要】**，★ 不只给 id。
3. ★★★ **把它自己的旗舰反例写成【永久负控】**：
   ```bash
   python3 scripts/j44-reuse-gate.py --intent "新建一个沉淀链扫描器"   # ★ 必命中（现为 0）
   ```
   ★ 理由：★★ **否则它永远不知道自己坏了**。

4. ★ 附加：★ **判据宜区分【字面未命中】与【确实不存在】** —★ 同「400 vs 404」语义不同。

## 三、提案 B：r006 自检块注入器（`scripts/r006-retrofit-apply.py`）

### B.1 缺陷（★ 本线亲验）

| # | 缺陷 | 证据 |
|---|---|---|
| B1 | ★★ **按【扩展名】分流**，无【运行环境】判据 | `:52` 逐字：「★ 支持 `.sh` / `.js`（原仅 `.py` ⇒ 15 个 `.sh` + 5 个 `.js` 被跳过）」 |
| B2 | ★★ **注入的 `.js` 块用 Node API** | `:348` `require("os").homedir()` · `:351` `require("fs").mkdirSync(...)` · `:352` `appendFileSync(...)` |
| B3 | ★ **后果** | ★★ **浏览器里 `require` ⇒ `ReferenceError` ⇒ 整个内联 `script` 中止** ⇒ ★★★ **手机与 Mac 上 18 个 view 全空**（★ 明鉴已修并实测恢复） |

### B.2 ★★★ 修法的【自指陷阱】（★ 明鉴实测指出）

★ 本线 D-100 曾裁：「含 `require(` / `process.` ⇒ **Node**」——★★ **该判据会被【上一次错误注入留下的\`require\`】骗到** ⇒ ★★★ **判据自证了它要防的事**。★ 实测：Node 信号 **7 处**（全是上次注入留下）· 浏览器信号 **147 处**。

### B.3 提案修法（★ 三条，★ 明鉴提出，本线认同）

1. ★★★ **有 `document.` / `window.` 即判【浏览器】**（★ 注入**从不加**这两个 ⇒ ★ **该信号【注入免疫】**）。★ 这是**优先判据**，★ 不是平行判据。
2. ★★ **哨兵注释【替换】而非【叠加】** —★ 否则重复运行会叠几层。
3. ★★ **扫描前【剥注释】** —★ 否则注释里的 `require` 会污染判据。

4. ★ 附加：★ **对存量全扫** —― ★ 本机所有被注入的 `.js`，★ 逐个判「Node 还是浏览器」。
