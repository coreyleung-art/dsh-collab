### ① 产出方定义冲突

| ★ | ★ |
|---|---|
| **冲突** | ★ A 段：「**产出方** = **不声明自身身份**的一方」；★ B 段：「**产出方** = **消息的内容来源**，★ 可与写入方不同」 |
| **合并者的处置** | ★ 取 **B**（★ 理由：★ 与 §3.1「有身份的写入方」自洽） |
| **为什么严重** | ★★ **它是【§3 参与者类别】的基础定义** —— ★ A 的说法会让「有身份的写入方」与「产出方」成为**互斥**概念，★ 而 §3.1 要求**有身份的写入方也有产出方身份** |
| **我的建议** | ★★ **取 B**。★ 理由：★ **A 的定义让 §3.1 自相矛盾**（★ 一个「有身份」的写入方按 A 就不是「产出方」了） |

### ⑤ 身份状态「三种」的内部不可能 ★ 已被修正

| ★ | ★ |
|---|---|
| **原文** | ★ D 段：「写入方 **MUST** 在每条产出上声明其**身份状态**（上述**三种**之一）」 |
| **为什么不可能** | ★★ **「未声明」不能被【声明】** —— ★ 若「未声明」是一个可选值，★ 那么**选了它本身就是一种声明**，★ 它就不是「未声明」了 |
| **合并者的处置** | ★ 改写为：「★ **MUST** 声明身份状态；★ **合法取值只有前两种**（★ 有身份 / 声明无身份）；★ **未声明是【取值缺失】**」 |
| **我的建议** | ★★ **采纳该修正**。★ 而它**不改变 D 的本意** —— ★ D 的原意正是「**未声明是缺陷，不是类别**」 |
