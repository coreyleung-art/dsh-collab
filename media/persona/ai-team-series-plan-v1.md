## 一、总纲（方案 C 生意主线）

**每集从一个生意痛点切入，AI 是解题工具而非主角——「用 AI 运营多盘生意的创业者」人设最贴，非技术读者友好；先痛后解，天然「慢慢变强」。**

四季度结构：
```
第一季·痛点   （生意的难：对账/差评/客户）    —— 让读者共情「我懂你的痛」
第二季·破局   （第1个AI/替回消息/快照）      —— 痛点开始被 AI 接住
第三季·翻车   （写冲突/心跳/内存）          —— 真实挫折，不完美才可信
第四季·成果   （验收/外发/企微/流量）        —— 慢慢变强的成果兑现
月度复盘       （方法论沉淀）
```

## 三、生产规格（每集）

| 项 | 规格 |
|---|---|
| 字数 | 600-1000（细分档，短平快） |
| 结构 | 起点（痛点场景）→ 做了什么 → 遇到什么 → 变化（脱敏）→ 下一站悬念 |
| 标题 | 每集 5 个候选（成长钩/痛点钩，技能树 A1） |
| 去 AI 味 | 每集过 20 条清单（模板库 〇·七） |
| 数据 | 量级可引营收不引（管线 §5.4） |
| 节奏 | 每周 2-3 集；甜（破局/成果）苦（痛点/翻车）交替 |
| 发布 | 用户审核 → QA 验收 → 企微（source=media level=P1）→ 公众号/知乎母稿 |
