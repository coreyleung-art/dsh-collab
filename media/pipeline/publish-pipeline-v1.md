## 一、管线总览（五段式）

```
[素材采集] → [稿件生产] → [用户审核] → [外链发布] → [数据回收]
   ↓              ↓            ↓            ↓             ↓
 事件源/迭代报告 模板+选题库   人工把关      企微先行      平台数据接口
 用户生意素材    分级（短中长）  决策权在用户   扩展多平台    阅读/涨粉/转化
```

| 阶段 | 负责 | 输入 | 输出 | 门槛 |
|---|---|---|---|---|
| ① 素材采集 | 媒体专员 | 登记表更新日志/迭代报告/广播/用户素材 | 素材卡片（事件+数据+来源） | 有据可查，不虚构 |
| ② 稿件生产 | 媒体专员 | 素材卡片+模板库+选题库 | 结构化稿件（多标题/正文/摘要/标签） | 分级匹配平台 |
| ③ 用户审核 | **用户** | 稿件成品 | 通过/修改/驳回 | **发布前必经**（硬性） |
| ④ 外链发布 | 外链通讯员 92623479 | 审核通过稿件 | 平台发布成功回执 | P1 级推送 |
| ⑤ 数据回收 | 媒体专员+外链通讯员 | 平台数据接口 | 阅读/涨粉/转化台账 | 周度复盘→选题优化 |

## 二、平台定位（首期策略）

### 2.1 平台评估矩阵（候选 7 平台）

| 平台 | 内容形态 | 人设契合度 | 流量红利 | 变现路径 | 接入成本 | 首期结论 |
|---|---|---|---|---|---|---|
| **微信公众号** | 长文/图文 | ★★★★★ | 中（私域沉淀强） | 知识付费/咨询 | 中（需公众号） | ✅ **主平台 A** |
| **知乎** | 长文/问答 | ★★★★★ | 中（搜索长尾强） | 咨询/课程 | 低（开放 API） | ✅ **主平台 B** |
| 掘金 | 技术长文 | ★★★★ | 中（技术垂直） | 工具/插件引流 | 低 | ⏳ 二期（技术拆解稿） |
| 小红书 | 图文/短笔记 | ★★★ | 高（种草） | 带货/咨询 | 中（需账号） | ⏳ 二期（视觉素材需配齐） |

| 抖音 | 短视频 | ★★★ | 高 | 带货/直播 | 高（需视频制作） | ⏳ 三期 |

**首期结论（用户 2026-08-17 决策）：平台暂不锁定——先出首篇稿件双平台试水（公众号+知乎为候选主平台），看数据回收效果再定主阵地**。图文长文人设契合度最高、接入成本可控；视频平台（B站/抖音/视频号）待视觉素材能力配齐后二期切入（PC-i9 GPU 渲染 + 模板化可补）。

### 2.2 平台差异化适配（v2 增强：技能树 A4 调性数据）

| 维度 | 公众号 | 知乎 |
|---|---|---|
| 标题风格 | 情绪钩子+悬念（13-20 字，括号补充点击+20%，数字前置） | 问题导向+干货承诺（前 5% 标题吃掉 80% 流量） |
| 正文结构 | 故事式/干货论证式（清单式 P0 主力） | 问答式/干货论证式（结论先行→分点→案例→清单） |
| 字数 | 1000-3000（1500 字完读率 47% vs 2000+ 仅 18%） | 2000-4000 |
| 标签 | 3-5 个 | 3-5 个话题 |
| 变现锚点 | 私域引导（企微/社群） | 咨询/课程 |
| **最佳发布时段** | **晚 20-22（官方定时群发）** | 午 12-13 / 晚 20-23 |

**母稿一稿多发流程（技能树 A3/A4）**：母稿（事实一致）→ 公众号版（故事式/干货论证式，换开头与节奏）→ 知乎版（问答式，换标题与开头）——核心证据与承诺不变。

## 五、发布链路契约（与外链通讯员 92623479 对齐）

### 5.1 稿件交接格式（v1 约定，92623479 确认 2026-08-17）
```json
{
  "channel": "wecom",
  "level": "P1",
  "source": "media",
  "text": "【标题】\n摘要……\n（亮点列表）\n（本地路径链接）",
  "dedup": "media-<稿号>-<日期>"
}
```

**发布格式细则（92623479 确认）**：
- `source` 用 **"media"**（P1 白名单含 media 直接推送；"media-correspondent" 未在白名单会默认 P2 入汇总）——显式 level=P1 两种都行，source=media 最稳
- 正文 ≤ **4000 字符**（企微 markdown 上限）
- 结构：`【标题】+ 2-3 行摘要 + 亮点列表 + 链接/路径`
- 超长稿件：发摘要 + 本地文件路径（~/dsh-collab/media/），用户点击查看全文
- dedup 指纹 `media-<稿号>-<日期>`（10 分钟去重）

### 5.2 流转规则
1. 媒体专员产出稿件 → 落盘 `drafts/` → 提交用户审核（本会话呈现）
2. 用户通过 → 转外链通讯员（agent_send）+ 稿件全文/链接
3. 外链通讯员 channel.send 发布 → 回执（ok/success）
4. 数据回收 → 周复盘

### 5.3 边界
- **未审核稿件绝不进入发布通道**（与外链凭据同原则）
- 涉商业数据（订单量/营收等）发布前用户把关
- **数据红线（用户 2026-08-17 确认）：量级可引（如「10 家店/高峰期 700+ 单/降本 X 小时」），具体营收/利润等财务数据不引**——稿件统一脱敏
- 不虚构事实：稿件标注来源（事件源/迭代报告编号）

### 5.4 数据引用许可清单（素材源 2fe61625 授权 · 2026-08-17）

**✅ 可引用（标注来源+时点）**
- 行业/市场数据：竞品扫描 28 来源（美团 100 亿+/行业复购 14%/节日脉冲 +139% 等——来源可溯）
- 方法论类：节日四段式运营/定价三层/降本 ROI 框架/调研优先制度（模式输出，不涉具体经营）
- 模式验证类（脱敏表述）：「10 店矩阵 + 全自动化」「节日事件量脉冲约 10 倍」「自动化降本 8-12h/周人力」——不点具体店名/金额
- 供应链数据：斗南/云花苑/TWFood 公开批发价 + 规格解析（台北花語官方源）

**🚫 需脱敏/不公开**
- 具体营收/利润/订单金额/客单价明细
- 门店名单+具体经营指标配对（如「天河3号 37 事件」）
- 成本结构/平台扣点/供应商协议细节
- 未公开融资/扩张计划细节（五山店可用「拟开新店」表述）
- 用户个人信息（梁振宇/Corey/银行资源等）

**通用原则**：涉经营数据一律「脱敏表述 + 公开来源支撑」；拿不准标「待用户审核」。
