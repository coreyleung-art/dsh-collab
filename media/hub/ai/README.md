## 数据文件（AI 直接消费）

| 文件 | 内容 | 何时用 |
|---|---|---|
| `roster.json` | 角色档案（角色/能力/资源/状态/里程碑） | 找人协作、查能力、查资源归属 |
| `timeline.json` | 事件流（日期/类型/标题/来源/状态） | 查历史里程碑、做大事记、写战报 |

| `lessons.json` | 经验沉淀（方法论/踩坑/成功模式） | 复用 SOP、避开已知坑 |

## 消费方式

1. **检索**：read 对应 JSON → 按需筛选（如 `roster.json` 查某角色资源）
2. **上下文注入**：会话启动/接任务时，read `roster.json` + `timeline.json` 即可获得网络全景
3. **写战报/稿件**：媒体专员从 `timeline.json` 取事件流 → 标注来源 → 出稿
4. **一致性**：本目录与 `human/` 网页同源（同一数据源双写）——改数据时同步两处
