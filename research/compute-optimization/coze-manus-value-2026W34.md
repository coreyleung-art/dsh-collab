## 结论摘要

**一句话结论：扣子按「月积分实际消耗 + 专属功能使用」决定留档/降档（¥159 为 ¥199 旗舰档活动价，用户已自查确认）；Manus 当前性价比与公司运营风险都不支持续费，建议月付观察或停用；两者合计 ¥374/月 对轻量/中等用量用户明显偏贵，可降为 ¥40–100/月 档 + API/本地算力替代。**

- 扣子（Coze 国内版）：官方个人版五档 = 免费 0 元 / 进阶 39.9 元（3万积分）/ 高阶 99 元（9.9万）/ 旗舰 199 元（19.9万）/ 尊享 999 元（99.9万）。**用户实付 ¥159 已确认为旗舰版 ¥199 档的活动价**（用户自查账单确认，如 818 活动价）。积分体系 1000 积分 ≈ ¥1，即会员费本质是「¥199 等值算力 + 平台权益」。
- 「增长方案日更项目」：**公开检索未能独立验证该具体项目**（无法确认其形态/价格/更新内容）。需用户提供名称或链接后复核；但可以确定：**付费模板/付费技能/第三方付费插件不能用积分抵扣（现金支付）**，即它在会员费之外另算一笔钱，是评估「值不值」时最容易漏掉的部分。
- Manus：2026 年多方交叉的现行标价为 Free $0 / Standard（Pro 基础）$20（4000 积分/月）/ Customizable $40（8000）/ Extended $200（40000）/ Team 共享池。**用户实付 $20/月已确认与 Standard 档标价相符**（用户自查账单确认）。积分消耗：中等复杂任务 500–1000+ 积分，简单任务约 200，复杂任务可到 2000；月度积分不结转，任务中途耗尽即中断且不退。
- 替代算力成本（2026-08-17 DeepSeek 调价后）：V4-Flash 高峰输出 ¥9/百万 tokens、闲时 ¥4.5/百万；V4-Pro 高峰输出 ¥27/百万、闲时 ¥13.5/百万；通义 Qwen3.6-Plus 输出约 ¥12/百万。**轻量日更任务（每日 1 次、输出 3 千 tokens）自建 API 月成本仅约 ¥1.3–2.6**——会员费买的是「平台能力/托管/专属功能」，不是 tokens。

### 2. 积分经济与口碑

- 积分按任务复杂度消耗：简单任务约 200，中等复杂任务 500–1,000+（有用户报告单任务 900），复杂任务可到 2,000。$20 档 4,000 积分 ≈ **每月约 4–8 个中等任务**。
- 槽点（多来源一致）：执行前无成本估算（扣了才知道）；月度积分不结转；任务中途积分耗尽即中断、已消耗不退；高峰期服务器 busy/排队；输出通常「原型级」，需人工清理；不能用自己的 API Key。
- 知乎实测帖「花了30刀的积分后，我对Manus祛魅了」、Reddit r/ManusOfficial 多条积分耗尽抱怨：独立来源佐证上述问题。
- **公司/产品运营风险（2026 新增，重要）**：Manus 2026 年被 Meta 收购后遭中国监管否决，2026-08-12 宣布「即将恢复独立运营」，腾讯据报拟以 20 亿美元购入 Meta 持股。**产品路线、计费、数据政策均可能在未来 1–2 个季度变动**；叠加高峰时段服务不稳，不建议年付锁定。

## 额度利用率自查方法

### 扣子 Coze（网页/桌面端）
1. 左下角**积分卡片** → 打开订阅管理，查看**当前档位、剩余积分、到期日、购买记录**（确认 ¥159 是什么档位）；
2. 进入**积分消耗页面**：按时间范围筛选，查看**累计消耗**；按项目类别筛选（Agent 项目/编程项目/视频项目/云设备/其他）；单击「··· → 查看明细」看每个项目逐日消耗；可按累计积分消耗排序找出最耗积分的项目；
3. 设置**积分预警**（余量告警），避免 0 积分停服；
4. 移动端：我的 → 积分 → 积分消耗页面，同网页。
5. **利用率判断标准**：月消耗 ÷ 档位月积分（旗舰版 19.9 万）。≥60%（≈12 万）算「用满」；30–60% 建议降一档；<30% 基本是浪费。注意 818 活动赠送积分会虚高「余额」，判断消耗时看「消耗量」而非「剩余」。

### Manus
1. 官方仪表板：**当前余额**（剩余积分）、**使用历史**（过去任务及各自积分消耗）、**支出洞察**（哪类任务最耗积分）、**余额告警**；
2. 任务开始前仪表板会给**积分估算**，参考过往同类任务；复杂多阶段任务先看执行计划再放行；
3. 判断标准：$20 档 4,000 积分 ≈ 4–8 个中等任务；若每月实际完成的任务数不足 4 个，或单任务均耗 >800 积分且产出需大量返工，则不划算。
4. 停用/降档前：确认免费档能否读取历史任务产出；不能则先导出所有项目文件。
