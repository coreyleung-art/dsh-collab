# 鲜花花材批发价格 — 数据采集规范与价格波动因子体系

> 目标时间范围：2023年1月至今 | 主力数据源：昆明市农业农村局（nyncj.km.gov.cn）

---

## 一、数据采集方案

### 1.1 采集目标

| 维度 | 说明 |
|------|------|
| 数据源 | 昆明市农业农村局价格行情页 https://nyncj.km.gov.cn/nygz/jgxq/ |
| 时间范围 | 2023年1月1日 ~ 至今 |
| 采集频率 | 历史数据：一次性回爬；增量数据：每日1次 |
| 数据格式 | 2023年起统一为"品名×最高/最低/均价"每日发布格式 |

### 1.2 采集技术方案

```
阶段一：历史回爬（2023-01 ~ 上月末）
  └─ 按月分页遍历，每页解析日期+品类+三价
  └─ 按月存储为独立文件，便于断点续爬
  └─ 预估：约1277天 × 30-50品类/天 ≈ 4-6万条记录

阶段二：增量监控（每日执行）
  └─ 每日固定时间抓取最新发布页
  └─ 与已有数据比对去重
  └─ 异常检测：价格空缺、格式变更、页面不可达告警
```

### 1.3 采集注意事项

- **分页规律**：该站按日期分页，URL规律性强，可通过日期参数直接定位
- **反爬策略**：政府站一般无严格反爬，建议控制请求频率（≥3秒间隔），设置UA
- **数据缺失**：周末/节假日可能无更新，属正常情况，需标记而非填充
- **格式变更监控**：定期检查页面结构是否调整，及时更新解析逻辑
- **增量去重**：以"日期+品名"组合为主键，避免重复入库

## 二、数据规范

### 2.1 核心价格表（flower_price_daily）

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| trade_date | DATE | 交易日期 | 2024-05-20 |
| category | VARCHAR(32) | 品类大类 | 玫瑰、百合、康乃馨… |
| variety | VARCHAR(64) | 具体品种 | 卡罗拉、粉红雪山… |
| color | VARCHAR(16) | 花色 | 红、粉、白、紫、黄… |
| grade | VARCHAR(8) | 等级 | A、B、C、D（如有） |
| stem_type | VARCHAR(16) | 单头/多头 | 单头、多头 |
| price_high | DECIMAL(6,2) | 最高价（元/枝或元/千克） | 5.60 |
| price_low | DECIMAL(6,2) | 最低价 | 0.30 |
| price_avg | DECIMAL(6,2) | 均价 | 1.85 |
| unit | VARCHAR(8) | 计价单位 | 元/枝、元/千克 |
| source | VARCHAR(32) | 数据来源 | 昆明市农业农村局 |
| created_at | DATETIME | 入库时间 | 2024-05-20 18:30:00 |

**主键**：`trade_date + category + variety + color + stem_type + grade`

### 2.2 存储目录结构

```
flower_price_db/
├── raw/                          # 原始采集数据（按月归档）
│   ├── 2023-01.csv
│   ├── 2023-02.csv
│   └── ...
├── processed/                    # 清洗后标准数据
│   └── flower_price_daily.csv    # 合并全量标准表
├── factors/                      # 因子数据（见第三节）
│   ├── weather_daily.csv
│   ├── holiday_events.csv
│   └── ...
└── logs/                         # 采集日志
    └── crawl_YYYYMMDD.log
```

### 2.3 数据清洗规则

| 规则 | 说明 |
|------|------|
| 品名标准化 | 统一品类名称：如"红玫瑰（单头）"拆分为 category=玫瑰, color=红, stem_type=单头 |
| 异常值处理 | 均价 < 0 或 > 50元/枝（玫瑰类）标记为疑似异常，人工复核 |
| 缺失日处理 | 周末/节假日无数据标记为 non_trading_day=1，不插值 |
| 单位统一 | 配花类（满天星等）按元/千克计，切花类按元/枝计，分表存储 |
| 去重 | 同一 trade_date + variety 组合只保留最新采集结果 |

## 三、价格波动因子体系

基于行业研究和实证分析，鲜花批发价格受 **6大因子群、18个具体因子** 驱动，按影响力度排序如下：

### 因子群一：节日需求因子 ⭐⭐⭐⭐⭐（影响最显著）

| 因子 | 变量名 | 类型 | 数据来源 | 说明 |
|------|--------|------|----------|------|
| 固定节日 | is_fixed_holiday | 布尔 | 节假日API | 情人节(2/14)、母亲节(5月第2周日)、七夕(农历)、教师节(9/10)、520(5/20) |
| 农历节日 | is_lunar_holiday | 布尔 | 节假日API | 春节、中秋、清明 — 影响祭祀用花(菊花)和年宵花需求 |
| 节前天数 | days_to_holiday | 整数 | 计算字段 | 距最近节日的天数，节前5-10天价格开始攀升，节前1-2天达峰 |
| 节日类型 | holiday_flower_type | 分类 | 预设映射 | 红色系=情人节、康乃馨=母亲节、菊花=清明节，不同节日拉动不同品类 |

> **实证**：情人节期间玫瑰批发均价可达平日8-10倍；520期间综合均价上涨25%+；节后3-5天价格回落30-60%

### 因子群二：气象因子 ⭐⭐⭐⭐⭐（影响供应端）

| 因子 | 变量名 | 类型 | 数据来源 | 说明 |
|------|--------|------|----------|------|
| 日均气温 | temp_avg | 连续 | 心知天气/和风天气API | 气温回升→出花量增加→价格下降；低温→花期延长→供应减少→价格上涨 |
| 降水量 | precipitation | 连续 | 同上 | 连续阴雨→品质下降→良品率降低→有效供应减少；暴雨/冰雹→大棚损毁→供应断崖 |
| 日照时数 | sunshine_hours | 连续 | 同上 | 日照不足→长日花卉延迟开花；极端多照→短日花卉出荷期偏移 |
| 极端天气 | is_extreme_weather | 布尔 | 同上 | 霜冻、台风、暴雨、冰雹 — 触发供应冲击，短期价格跳涨 |
| 产区天气滞后 | weather_lag_3d | 连续 | 计算字段 | 前3天气象数据的移动平均 — 花卉从采收到上市有2-3天滞后期 |

> **实证**：2023年春云南持续低温阴雨，玫瑰出花率下降18%，全国批发均价上涨37%；2026年520期间受前期低温降雨影响，优质花材上市时间后移，价格同比上涨25%+

**推荐气象数据源**：

| 数据源 | 历史覆盖 | 费用 | 适用场景 |
|--------|----------|------|----------|
| 心知天气 | 2018年至今（中国1km网格级） | 免费+付费 | **首选**，支持历史天气查询 |
| 和风天气 | 2018年至今 | 非商业免费 | 备选，数据质量好 |
| Visual Crossing | 50年历史 | 免费1000次/天 | 海外产区天气补充 |
| 高德天气API | 仅预报 | 免费 | 增量监控用 |

### 因子群三：供给量因子 ⭐⭐⭐⭐

| 因子 | 变量名 | 类型 | 数据来源 | 说明 |
|------|--------|------|----------|------|
| 当日供货量 | supply_volume | 连续 | KIFA月报/花拍中心数据 | 供货量增加→价格承压；减少→价格上行 |
| 成交率 | trade_rate | 连续 | 同上 | 成交率下降=供过于求信号；>95%为紧平衡 |
| 种植面积变化 | planting_area_yoy | 连续 | 云南省花卉产业报告（年度） | 面积扩增→中期供应增加→价格中枢下移 |

> **实证**：KIFA 2026年4月单头玫瑰供货8873万支，成交率94.25%，进入淡季均价仅0.59元/支

### 因子群四：成本因子 ⭐⭐⭐

| 因子 | 变量名 | 类型 | 数据来源 | 说明 |
|------|--------|------|----------|------|
| 原油价格 | crude_oil_price | 连续 | 上海期货交易所/阿里云API | 原油↑→温室加温成本↑→冬季出花量↓→价格上涨；运输成本↑ |
| 农资价格指数 | agri_input_index | 连续 | 国家统计局 | 化肥、农药、大棚膜等投入品价格 → 影响种植成本底线 |
| 冷链运费指数 | cold_chain_freight | 连续 | 顺丰冷链报告/行业数据 | 运费↑→终端涨价传导，产区批发价受终端需求萎缩反压 |

**推荐成本数据源**：

| 数据源 | 内容 | 费用 |
|--------|------|------|
| 上海期货交易所 | 原油期货(SC)日行情 | 免费 |
| 阿里云原油API | WTI/布伦特实时+历史 | 免费试用100次 |
| 国家统计局 | 农资价格指数 | 免费 |

### 因子群五：出口与外部需求因子 ⭐⭐⭐

| 因子 | 变量名 | 类型 | 数据来源 | 说明 |
|------|--------|------|----------|------|
| 出口量 | export_volume | 连续 | 昆明海关月报 | 出口分流→国内高品质供应减少→推高国内优质品价格 |
| 汇率 | cny_usd_rate | 连续 | 人民银行/外汇API | 人民币贬值→出口增加→国内供应收紧；进口花材成本↑ |

> **实证**：2026年1-4月云南鲜切花出口货值超8亿元，同比增长53.4%，出口分流导致国内高品质花材"一花难求"

### 因子群六：季节性与趋势因子 ⭐⭐⭐

| 因子 | 变量名 | 类型 | 数据来源 | 说明 |
|------|--------|------|----------|------|
| 月份 | month | 分类 | 日期字段 | 3-5月春季旺季(占35%)、6-8月淡季、9-11月秋季旺季、12-2月节日驱动 |
| 周内天数 | day_of_week | 分类 | 日期字段 | 周一至周五批发交易日，周末需求弱 |
| 年度趋势 | year_trend | 连续 | 计算字段 | 人均花卉消费年增14.2%，长期价格中枢缓升 |
| 消费升级 | daily_self_use_ratio | 连续 | 行业报告 | "悦己消费"占比提升，日常需求基数扩大，峰谷比收窄 |

> **实证**：春季(3-5月)占全年批发量35%，夏季(6-8月)仅占15-20%；"仪式感日常化"使日常消费占比从2019年的23%升至2023年的41%

## 四、因子优先级与实施路线

### 4.1 分期实施建议

| 阶段 | 因子 | 理由 |
|------|------|------|
| **一期（立即可做）** | 节日需求因子 + 季节性因子 | 数据内生于日期字段，零成本，解释力最强 |
| **二期（1-2周）** | 气象因子 | 接入心知天气API获取昆明历史天气，与价格表按日期JOIN |
| **三期（1个月）** | 供给量因子 + 成本因子 | 需定期抓取KIFA月报+原油期货数据，建立多源采集pipeline |
| **四期（按需）** | 出口因子 | 月度数据，来自海关公开统计，更新频率低但解释力强 |

### 4.2 因子影响力排序（定性评估）

```
节日需求 >>> 气象条件 >> 供给量 > 原油/成本 > 出口分流 > 季节性趋势
  (8-10x)    (2-3x)      (1.5-2x)   (1.2-1.5x)  (1.1-1.3x)  (基线)
```

### 4.3 推荐节假日数据源

| 数据源 | 覆盖 | 费用 | 说明 |
|--------|------|------|------|
| OneAPI节假日接口 | 2011年至今 | 免费，无需认证 | 含农历、调休、节假日类型 |
| NateScarlet/holiday-cn | 2017年至今 | 免费开源 | GitHub JSON数据，可自建API |
| Chinese Days | 2004-2026 | 免费 | 含农历节气、iCal订阅 |

## 五、数据关联架构

```
flower_price_daily (核心价格表)
    │
    ├── JOIN trade_date ──→ weather_daily (气象因子表)
    │                        temp_avg, precipitation, sunshine_hours,
    │                        is_extreme_weather, weather_lag_3d
    │
    ├── JOIN trade_date ──→ holiday_events (节日因子表)
    │                        is_fixed_holiday, is_lunar_holiday,
    │                        days_to_holiday, holiday_flower_type
    │
    ├── JOIN trade_date ──→ supply_daily (供给量因子表)
    │                        supply_volume, trade_rate
    │
    ├── JOIN trade_date ──→ cost_daily (成本因子表)
    │                        crude_oil_price, agri_input_index
    │
    └── JOIN month ──────→ export_monthly (出口因子表)
                             export_volume, cny_usd_rate
```

## 六、注意事项

1. **价格与因子的时间对齐**：花卉从采收到上市有2-3天滞后期，气象因子应使用3日滞后值
2. **品类差异化建模**：不同品类对因子的敏感度差异大（如玫瑰对节日极敏感，菊花对清明敏感），建议分品类建模
3. **节日互斥处理**：同一时段多个节日叠加时（如520+母亲节相邻），需解耦各节日效应
4. **异常值标注**：台风/冰雹等极端天气导致的价格跳涨属于不可重复事件，建模时考虑是否剔除
5. **数据时效声明**：本方案基于2026年6月的市场调研，行业结构和数据源可用性可能随时间变化
