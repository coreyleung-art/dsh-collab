## §1 这句话的三层意思（★ 逐层拆）

### 层 1 ·「候选」是怎么来的：三个前序候选，**两个已被官方证据打掉**

| 候选 | 打掉它的证据 | 证据强度 |
|---|---|---|
| 「7 类消息分级」 | **FIPA-ACL 2002 年就标准化了 performative 库** ⇒ 分类维度本身不新 | ⚠️ **官方 PDF 读取被拒，条数为二手**；★ 但**另有两条官方旁证**（AG-UI 该 commit 实测 26 项 `EventType` + A2A 操作集）⇒ 锚点 `:548` 明写「**不得作为「7 类分级不领先」的唯一依据**」 |
| 「黑板+邮箱双模」 | **A2A 把 Artifacts+`contextId`（黑板等价）与 push notification（邮箱等价）放在同一规范内** | ✅ **官方规范** |
| 「成本权重入选择器」 | ★ **未被打掉** | ⚠️ **阴性** |

★ **⇒ 3 − 2 = 1 ⇒「仅 1 项候选」。** ★ 这个「1」**不是**「发现了 1 项领先」，而是「**没被证伪的只剩 1 项**」。

### 层 2 ·「阴性证据」是什么：**「我没搜到等价物」**

★ 锚点自己给了**精确表述**（`:433` 逐字）：
> **「把通道权重写进消息类型→通道的选择器」在协议层本轮未发现等价物**

★ 并**按纪律标注了检索面**（`:433` 与 `:550` 逐字）：
> **检索面 = A2A 规范全文 · MCP 规范全文 · CWEP · BTUP · dca_theory · 通信效率综述**；**未系统检索** arXiv 全库 / IEEE-ACM / 企业私有规范

★★ **⇒ 「阴性证据」= 一次【检索面已声明】的【未命中】。** ★ 它**证明不了**「业界没有」；★ 它只证明「**在这个面里没找到**」。

### 层 3 ·「一票否决前提」：**「有表无数据」**

★ 锚点 `:433` 逐字：
> ★ **且该候选有一票否决前提**：CAHAC **尚无成本计量与归因落地**（§9.1 用 token、§9.2 用金额，换算靠 §9.2 `:423-431` 自己都标「**须校准**」）⇒ **权重选择器当前是「有表无数据」**。

★★ **⇒ 即使检索侧成立，这条也还不能记领先** —— 因为「权重选择器」在本机**没有数据喂它**。

## §2 为什么它是**保守结论**（四条理由，逐条）

| # | 保守的理由 | 依据 |
|---|---|---|
| **①** | ★ **阴性证据不能证否「存在」** —— 「未搜到 ≠ 不存在」（锚点 `:377` 逐字纪律：「**「未搜到」一律写作「本轮未发现」，不写作「业界没有」**」） | 锚点 `:377` |
| **②** | ★ **检索面不完整且已声明** —— 未检索 arXiv 全库 / IEEE-ACM / **企业私有规范**。★ **最后一项最要紧**：成本感知路由最可能出现在**企业内部实现**里，而那**恰恰不在检索面内** | 锚点 `:433`/`:550` |
| **③** | ★ **候选自身有前置缺口**（有表无数据）⇒ **它的"领先"目前无法演示**（不能跑给你看） | 锚点 `:433` |
| **④** | ★ **本仓有明文的「领先」门，且未裁前不得记** —— `:276` 逐字：「保持领先 L-1/L-2 … **投入顺序待用户裁；未裁前不得记领先**」；`W8.14`（`:1929`）逐字：「★ **证伪前不得在 v6 写「领先」结论**」 | 锚点 `:276` / `:1929` |

★★ **⇒ 一句话**：**「保守」不是语气软，是**四条独立的不可判**叠加后的必然措辞** —— 检索不全（②）· 阴性不可证否（①）· 候选不可演示（③）· 门未裁（④）。

★ ★ **口径诚实**：★★ **那三条的逐字原文，本件在锚点内未找到**（只在 `:276` 找到「未裁前不得记领先」）。★ **如实标：三条件按任务转述使用，未取到原文。**

## §3 ★ 要把它变成**可复跑的对照实验**，需要什么？

★ 本仓**已经有半张蓝图**：`W8.14`（`:1929` 逐字）：
> 产出**可证伪命题 + 检索词清单 + 检索面声明**，交第三方复检；★ **证伪前不得在 v6 写「领先」结论**

★ **⇒ 以下把它展开成一份可执行的实验设计**（★ 这是本件的**产出**，★ **不是对 W8.14 的替换**）。

### 3.1 需要一个**预注册的可证伪命题**（★ 现在没有）

★ 现在有的是一句**观察**（「本轮未发现等价物」）—— ★ **它不是命题，不可证伪**。
★ **缺的形态**（示例，★ 供起草方取舍，**不是本件替它定**）：
> **P1**：在**【面 F】**内，**不存在**任何**已发布的协议规范**同时满足
> ① 定义 **≥N 种消息类型**；② 在**类型→通道**的**选择**环节引入**成本/预算权重**；③ 该权重是**规范正文的一部分**（非实现细节）。
> **证伪条件**：在面 F 内**找到一条**满足 ①②③ 的规范 ⇒ **P1 假**。

★★ **关键**：命题必须**写得能被一条证据打死**。★ 现在这句话**打不死**（没说面、没说条数、没说"权重算不算实现细节"）。

### 3.2 需要**检索面 F 的显式枚举 + 每面的取数方式**

| 面 | 取数方式（可复跑） | 现测状态 |
|---|---|---|
| A2A 规范全文 | 取 `v1.0.0` 的 `specification.md`，grep 成本/预算关键词 | ★ 本次**未复跑**（见 §5 限制） |
| MCP 规范全文 | 取 `2026-07-28` 全部页面，grep 同上 | ★ 本次**未复跑** |
| CloudEvents | 同上 | ★ 本次**未复跑** |
| CWEP / BTUP / dca_theory / 通信效率综述 | ★ 锚点已列 URL | ★ 未复跑 |
| **RFC/IANA 登记表** | ★ **本件新增建议面** —— 成本/预算类字段若要"协议层"，最可能出现在**登记表**里 | ★ **锚点未列此面** |
| **企业私有规范** | ★ **锚点自陈"未系统检索"** | ★ **不可复跑**（无入口）⇒ ★ 须**显式标为「不可判」**，不得并入结论 |
| arXiv 全库 / IEEE-ACM | 需检索串 + 时点 | ★ 锚点自陈未做 |

### 3.3 需要**阴性对照（negative control）—— 即「已知存在的一条，必须被检索到」**

★★★ **这是本件最重要的一条建议**：
> ★ 现在的检索面**从未被验证过它有捕获能力**。★ 一个从未命中的检索，**无法区分**「业界没有」与「我的检索串不灵」。

★ **做法**：在同一面上检索一个**已知存在**的等价物（如 **A2A 的 Agent Card** 或 **MCP 的 `capabilities`**），★ **必须命中**；★ **不命中 ⇒ 该次检索作废**（不是「结论成立」）。
★ ★ **本仓已有这套写法的先例**：`qk-structure-mutation.py` 的 **M5「反向对照·应当绿」**（现测 `[exit=0]`，逐字「基线绿 · M1–M4 红 · **M5（反向对照）绿** ⇒ 判据既有判别力、又不恒红」）⇒ ★ **同一形态可以搬到检索上。**

### 3.4 需要**检索词清单 + 时点 + 退出码**

★ 现在缺**全部三件**。★ 可复跑形态示例：

```bash
# ★ 形态示例（本件给出，尚未在锚点上落地）
# 1) 拉规范全文（一次性，留 hash）
curl -sL <A2A v1.0.0 specification.md> -o /tmp/a2a.md && shasum -a 256 /tmp/a2a.md
# 2) 逐词检索（★ 词表本身要预注册，不得事后增补）
for w in "cost" "budget" "price" "quota" "unit price" "settlement" "billing" "token budget"; do
  printf "%-16s %s\n" "$w" "$(grep -ic "$w" /tmp/a2a.md)"
done
# 3) 阴性对照（★ 已知存在的项，必须命中）
grep -ic "agent card" /tmp/a2a.md      # ⇒ 必须 > 0，否则本次检索作废
echo "[exit=$?]"
```
★ **判据**：★ 阴性对照 `= 0` ⇒ **本次检索不可用**（**红**）；★ 阴性对照 `> 0` **且** 目标词全 `= 0` ⇒ **阴性证据成立**。

### 3.5 需要**清单**：「什么算满足」，且在检索**之前**定死

★ 即 §3.1 的 ①②③。★ **缺它 ⇒ 找到东西也不知道算不算命中**（★ 事后定标准 = 制造结论）。

### 3.6 需要**独立复检人**（★ 与 Q-O 是同一件事）

★ 锚点 `:550` 逐字：「须第三方复检，**见 W8.14**」；★ **而 W8.14 没有 verifier**。
★ 现测（Q-O）：登记表列的三个候选 **全部离线**；★ 但在线会话里**有**独立审查角色（见 01 篇 §Q-O）。
★★ **⇒ 3.1–3.5 全做完，只要没有第三方复检，这条仍然只能停在「本轮未发现」。**
