## 问题①：数字孪生需要什么硬件设备？

**核心结论**：数字孪生"物理工作台"硬件按四层配（感知采集/传输网关/计算建模/可视化+执行回写），门槛已极低。详见 `digital-twin-hardware-guide.md`。要点：
- **感知层**（最重要，无数据则 3D 模型是摆设）：温湿度(DHT22/BME280)、IMU 姿态(MPU6050)、视觉摄像头、力/电流等；ESP32+DHT22 全套 <50 元（教程实证）
- **3D 重建层**（把现实数字化）：消费级结构化光扫描（Revopoint/Creality，￥2800+）/ 摄影测量 / LiDAR（手机/PiLiDAR）/ 桌面转台；精度需求决定预算档（2800 消费级 vs 数万工业级差显著）
- **计算建模**：树莓派/ESP32（入门）、Unity/Blender/CesiumJS/Omniverse（引擎）；实时 3D+生成式推理需 GPU
- **执行回写/3D 打印**：完整物理工作台才需（电机驱动 + FDM/树脂打印机，拓竹可接生成式 3D 闭环）
- **组合成本档**：纯 3D 模拟 ￥0-2000 → 入门数字孪生 ￥200-1500 → +3D 重建 +￥2800-8000 → 完整工作台 ￥5000-2 万+

## 问题②：做 3D 打印/3D 设计智能体需要什么前提条件？

基于市场玩家 + 学术论文提炼，**做这类智能体的前提 = 五层基础设施**：

### 前提 1：模型层（智能体的"大脑"）
- **多模态 LLM/VLLM**：需能"看懂"CAD/几何/图像——CAD-Assistant 用工具增强 VLLM 做通用 CAD 求解（ICCV 2025）；ShapeCraft 用 LLM Agent 做结构化/纹理/交互 3D 建模（NeurIPS 2025）
- **空间推理能力**：Adam 团队自述需"为模型赋予正确的空间推理语境"（招 AI/工程人才）
- **生成式 3D 模型**（若走生成路线）：腾讯混元3D（文/图/草图→3D，3.0 精度×3）、Adam/Meshy 文本转 CAD

### 前提 2：工具链深度接入（智能体的"手脚"）——关键前提
- **必须扎进实际工具链**：Synera 低代码编排 **80+ CAD/CAE/CAM/PLM 工具**，代理当"数字工程劳动力"选工作流、无监督持续运转；其判断"代理必须扎进实际工具链(CAD/仿真/PLM)才有产出"（Gartner：86% 计划投生成式 AI 但仅 41% 原型进生产，断点=AI 与工程软件不连通）
- 工业案例已实证：NASA 用 Synera 代理一小时数百次设计迭代；宝马/现代/空客在用

### 前提 3：数据 / 知识图谱层（智能体的"记忆"）
- CAD 几何数据互操作 + 参数化
- **动态制造知识图谱**：AutoMEX（LLM+知识图谱材料挤出）、3DprintMIND（LLM+动态制造知识图谱做智能制造 AI-Agent）——用图谱给 agent 结构化领域知识

### 前提 4：物理验证闭环（智能体的"质检"）——设计与打印特有
- **物理在环**：Physics-in-the-Loop 混合 Agent 架构（AI 生成 CAD → 物理仿真验证 → 迭代）；CAD-Assistant 做工程验证
- 打印过程控制需传感器反馈：LLM-3D print（LLM 监控/控制 3D 打印，读打印过程数据纠偏）

### 前提 5：部署 / 交互形态（智能体落地的"边界"）
- **工业级 = 本地部署 + 数据不出域 + 合规**：Synera 本地 + TISAX Level 2（工程 IP 不离开客户基础设施）；这是工业客户前提
- **消费者级 = 云 API/低门槛**：混元3D API、Adam 订阅制；先爆量再进 B 端
- **交互**：非纯文本更优——Adam 融合"选中 3D 物体对话"；混元支持图/草图输入降低门槛

### 关键判断（对我方/用户）
1. 做"3D 设计智能体"最低可行 = **一个能读写 CAD/3D 文件的多模态 LLM agent + 参数化几何 API/工具 + 简单的物理/格式校验**（Adam 路径，消费者起家）。
2. 若想进"工业/打印闭环"，硬前提 = **工具链编排（CAD→CAM→打印准备）+ 数据不出域的本地部署 + 生成物验证**（Synera 已产品化，可参考其架构而非从零造）。
3. 纯"3D 打印控制智能体"较窄（LLM-3D print 监控打印），前提是**接入打印机/传感器反馈**。

## 落地建议（用户拟做"物理工作台 3D 模拟"）
- **硬件先行最小集**：ESP32/树莓派 + 传感器 + PC 跑 3D 引擎（Blender/Cesium）→ 先打通"数据→3D 呈现"
- **加 3D 重建**：若要把现实工作台数字化，配消费级扫描（Revopoint 类，先借/租试精度）
- **3D 设计智能体**：可基于开源 LLM + FreeCAD/OpenSCAD 参数化 API 起步（成本≈0），或接混元3D API 做生成式；工业级编排参考 Synera（暂不自研）
