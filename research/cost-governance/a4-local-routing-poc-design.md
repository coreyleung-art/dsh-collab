## 一、目标

验证 qwen3.5-2b 按 v1.1 置信度门控能消化多少场景、成本降多少——产出命中率/升级率/质量数据，支撑规则 v1.1→正式与 v1.2 学习型路由。

## 二、PoC 范围（5 类候选场景）

| 场景 | 输入 | 输出 | 风险级 |
|---|---|---|---|
| 意图/消息分类 | 短消息 | CAHAC 类型标签 | 低（可复核） |
| 关键词/标签提取 | 文本 | 关键词列表 | 低 |
| 短摘要（<500 字） | 长文本截取段 | 摘要 | 低-中 |
| 结构化提取（JSON 字段） | 消息/文档 | JSON | 中（需准） |
| 回复/文案草稿 | 场景上下文 | 草稿 | 中（需复核） |

## 三、测量协议

| 采集项 | 说明 |
|---|---|
| 本地结果 | qwen3.5-2b 输出 |
| 置信度 | Ollama logprobs 或自检 prompt（「你是否确定」） |
| 门控判定 | ≥0.9 采用 / 0.7-0.9 复核 / <0.7 升级云端 |
| 升级记录 | 低置信→云端 flash 结果 |
| 质量抽查 | 5% 本地结果云端对比（同任务） |
| 成本记录 | 本地 0 vs 云端对比（入每日回放） |

## 四、指标与验收（2 周）

| 指标 | 目标 |
|---|---|
| 本地命中率（高+中置信） | ≥50% |
| 升级率（低置信） | ≤30% |
| 质量抽查通过率（5% 云端对比） | ≥95% |
| 成本降幅（vs 纯云端同场景） | ≥40%（FrugalGPT 级联预期 30-50%） |

## 五、工具面与调用

- 模型：Ollama qwen3.5-2b（已装，Ollama 11434 本机）
- 调用：ollama run（bash）/ API 127.0.0.1:11434/api/generate
- 置信度：Ollama API options 返回 token 概率 或 自检 prompt 二段式
- 数据落点：token-monitor/local-routing/（PoC 日志+统计）

## 六、与体系衔接

| 体系 | 衔接 |

## 七、风险（J39 精简）

| 风险 | 概率×影响 | 对策 |
|---|---|---|
| qwen3.5-2b 能力不足 | 中×中 | 升级 L1（8b）或调阈值；分类类先跑 |
| 置信度不可靠 | 中×中 | 自检 prompt 兜底+抽查校准 |
| 质量降级 | 中×高 | 5% 云端抽查+复核门控（人在环） |
| 成本风险 | 低×低 | 本地零成本，升级云端受 quota 限制 |
