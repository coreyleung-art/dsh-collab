# 外卖商品订单 → ERP 导入方案 v1.0

> 2026-08-24 · 协调者 · 蓝图 2.5-3 数据打通核心（数据已就绪）
> 前置：commodityData 全量回溯完成（6 店 17,426 行 / 16,531 单 / 净额 ¥134 万）

## 一、目标
外卖商品订单数据（美团等平台）导入 ERP，形成数据唯一口径（蓝图 2.5 闭环）

## 二、数据流
```
外卖面板（8787）commodityData（17426行，已回溯）
  → 商品映射（外卖商品 → ERP product/variety）
  → ERP MCP（product.query 查重 / 导入写入）
  → 数据打通（订单/销售额入 ERP）
```

## 三、商品映射规则
| 外卖侧 | ERP 侧 | 方式 |
|---|---|---|
| 商品标题/规格 | product (SKU/UPC/名称) | product.query 匹配名称+规格 |
| 品类 | variety | 按品类映射（花束/礼盒/单枝） |
| 销量/销售额 | 订单数据 | salesOrder 导入或 erp.api_call |

## 四、执行步骤
1. 读取外卖 commodityData（4 店核心：初蘅2/客村6/江南西4/佛山7）
2. 用 product.query 查 ERP 现有商品，比对映射
3. 未匹配商品 → 建立映射表（外卖标题→ERP 商品 ID）
4. 订单/销售数据经 erp.api_call 或 salesOrder 导入
5. 对账：导入量 vs 外卖面板数据一致
