## 三、场景 → 模型映射（核心决策表）

| 场景 | 判定特征 | 模型 | 理由 |
|---|---|---|---|
| 意图路由/消息分类 | 短文本、可错、实时 | L0 | 零成本，够用 |
| 关键词提取/标签 | 结构化、可错 | L0 | 同上 |
| 短摘要（<500 字） | 低风险 | L0-L1 | 本地 |
| 长文档摘要（>8k） | 中等 | L1（超长先压缩） | 本地+压缩 |
| 回复/文案草稿 | 需复核 | L1-L2 | 质量敏感用 L2 |
| 结构化提取（JSON） | 需准 | L1-L2 | 本地优先，抽检 |
| 复杂推理/多轮对话 | 高要求 | L2 flash | 云端 |
| 日报/报告终稿 | 高质量 | L2 flash（错峰） | 正式产出 |
| 战略/财务分析 | 最高 | L3 pro（错峰） | 人主导 |
| 嵌入/OCR | 全量 | 本地 | 零成本 |

## 四、决策算法（伪代码）

    def route(task):
        if task.kind in ("embed", "ocr"): return local
        if task.context_len > 32k: task = compress(task)   # LLMLingua/Local-Splitter T2
        if task.quality == "low" or task.reviewable:       # 可错/人在环
            if task.context_len <= 8k: return L0 or L1
            return L1 (compress if needed)
        if task.deferrable and peak_hour(task): queue(off_peak)
        if task.complexity == "strategic": return L3 pro
        return L2 flash

## 五、质量门槛与回退（铁律）

1. 不可复核任务禁用本地（人在环是本地模型的使用前提）
2. 回退链：L0 失败/质量差 → L1 → L2（升级不降级）
3. 抽查：本地产出周抽 5% 云端对比（质量护栏）
4. 敏感数据：隐私/业务敏感 → 直接 L2+（本地可留，但禁止出域）

## 八、论文支撑（2026-08-19 调研入库）

| 规则依据 | 论文 | 核心发现 | 对我们规则的影响 |
|---|---|---|---|
| 本地路由节省 | **Local-Splitter**（arXiv 2604.12301，已入库全文 65 chunks） | 7 战术：本地路由+压缩省 45-79%（编辑/解释类） | 支撑 L0-L1 本地消化多数场景；>32k 先压缩 |
| 路由学习方法 | **RouteLLM**（arXiv 2406.18665，已入库） | 用偏好数据学习路由策略，在强模型与弱模型间动态选择，成本降低 | 规则 v1.0 为静态规则表；**升级方向=RouteLLM 式学习型路由**（A4 PoC 后可演进） |
| 级联降本 | **FrugalGPT**（arXiv 2305.05176，已入库） | LLM 级联（小→大，按置信度升级），成本大幅下降且性能不降 | 支撑回退链 L0→L1→L2 的「升级不降级」设计；可加置信度门控（本地低置信→升级云端） |
| 端云协作推理 | **Bridging On-Device and Cloud LLMs**（arXiv 2509.24050，已入库） | 本地路由+后训练统一方法论，端云协作推理 | 支撑「本地草稿+云端审」模式（Local-Splitter T4）与后训练微调方向 |
| 协作推理协议 | Collaborative Inference Protocols（arXiv 2511.07885，已入库） | 本地-云分割生成的协议框架 | 与 CAHAC 通道选择衔接的推理侧协议参考 |

**规则升级路线**：v1.0 静态规则表（当前）→ v1.1 置信度门控（FrugalGPT 级联启发）→ v1.2 学习型路由（RouteLLM 方法，需数据积累）。
- 监测：token-roi-review 日审 + 本地命中率统计（A4 PoC 加计数）
