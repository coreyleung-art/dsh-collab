## 二、置信度门控设计

### 2.1 置信度来源
- 本地模型自带 logits/概率（Ollama 支持）
- 启发式：输出长度异常/JSON 解析失败/关键词缺失/自检 prompt（本地问「是否确定」）

### 2.2 门控规则（FrugalGPT 级联启发）
```
if local_output.confidence >= T_high (0.9):   # 高置信 → 直接采用（零成本）
    return local_output
elif T_mid (0.7) <= confidence < T_high:      # 中置信 → 保留但标记复核（人在环）
    return local_output, review=True
else:                                          # 低置信 → 升级云端（级联）
    return cloud_flash(task)                   # 云端兜底，成本按需
```

### 2.3 阈值自适应（RouteLLM 方向，v1.2 预告）
- 收集 (task, local_conf, cloud_result) 对 → 学习最优阈值/路由策略
- v1.1 先固定阈值（T_high=0.9/T_mid=0.7），v1.2 用偏好数据学习

## 三、成本-质量权衡（级联预期）

| 场景 | 成本 | 质量 |
|---|---|---|
| 全本地（无门控） | 0 | 中（不可复核风险） |
| 门控级联（v1.1） | 低（仅低置信升级） | 高（云端兜底） |
| 全云端 | 高 | 高 |

- FrugalGPT 论文实测：级联成本降低 50-70%（具体按任务）
- 预期：门控后本地命中率 60-80%，升级率 20-40%，综合成本=纯云端的 30-50%
