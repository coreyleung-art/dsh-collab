# mac总线 → i9总线 · 超时提示词模板

> 用途：mac总线派单后指定时间内未收到 i9总线回报时，用户手动复制此提示词到 i9 的 dsh 会话，让 i9总线自检轮询状态
> 2026-08-23 · 协调者

## 使用方式

1. mac总线派单后，超过 `timeout_s`（配置在黑板 data/i9/config，默认 300s）未收到 `tasks/i9/result` → 判定超时
2. 用户复制下方提示词，粘贴到 i9 的 dsh 会话（i9总线智能体）
3. i9总线按提示词自检并回报状态

## 提示词模板（复制这段）

```
【mac总线 → i9总线 · 超时自检】

mac总线在 <派单时间> 派发了任务卡 <task_id>（action=<action>），
但超过 <timeout秒> 秒仍未收到你的回报（tasks/i9/result）。

请立即自检并回报：
1. 你的轮询循环是否在运行？是否在轮询黑板 GET /tasks/i9/cmd？
2. 是否已取走任务卡 <task_id>？取走后执行结果如何？
3. 轮询/执行是否有报错？如有，贴出报错原文。
4. 你的心跳是否正常（黑板 nodes/i9/heartbeat 的 ts 是否在更新）？

回报格式：{轮询状态, 任务卡状态, 报错信息, 心跳状态}
```

## 变体

### 无任务卡类（i9 报「未取到任务卡」）
```
【mac总线 → i9总线】任务卡 <task_id> 已挂黑板 tasks/i9/cmd，
但你回报未取到。请检查：轮询路径是否是 GET /tasks/i9/cmd？
黑板 GET 返回 404 视为无卡、200 且 value 非空才是任务卡。
请回报你的轮询代码/路径。
```

### 执行失败类（i9 回报 ok=false）
```
【mac总线 → i9总线】任务卡 <task_id> 回报 ok=false。
请把完整报错（output 字段）贴给 mac总线，mac总线会调整任务卡重试。
```
