## 一、定位

把体系能力（监察/告警/运营数据/知识检索）封装为 **MCP 服务器**，部署在**腾讯轻量云（公网域名）**，让**任何外部设备**（手机/其他电脑/第三方 agent）通过 MCP client 调用。

```
外部设备（MCP client）
  → https://你的域名/mcp（腾讯轻量云·TLS）
  → 云网关鉴权（SSE_TOKEN/API Key）→ 工具白名单过滤 → 审计/限流
  → 隧道（Tailscale/frp）回连本地 external-link-mcp :8910
  → 总线/智能体执行（监察/告警/知识/运营）
  → 结果回传外部设备
```

## 二、为什么选 MCP + 云

| 维度 | 判断 | 依据 |
|---|---|---|
| 协议 | MCP 已是 agent 工具标准（15,930+ 服务器/97M SDK 月下载） | 论文 P4 批次 + 调研 R1 |
| 云端 | 公网域名+固定入口，外部设备免 Tailscale | 腾讯轻量云 ¥50-100/月 |
| 本地执行 | 数据/凭据/写操作留在本地，云只做网关 | 安全（J45 数据出域护栏） |
| 商业化 | 订阅制出口（对标 Anysite/Composio $19-499/mo） | open-core-mcp-subscription-r1 |

## 四、安全五闸（上公网前提）

| # | 闸 | 实现 |
|---|---|---|
| 1 | TLS | 腾讯云免费证书（域名 HTTPS） |
| 2 | 鉴权 | SSE_TOKEN / API Key（作用域：只读子集） |
| 3 | 工具白名单 | 只暴露：监察查询/告警/运营报表/知识检索/差评数据（只读聚合）；**禁**：审批/删除/改价/凭据/写操作 |
| 4 | 审计 | 全量日志：调用方/工具/参数/时间（可回放，衔接监察体系） |
| 5 | 限流+计费 | 按调用限流；商业化走 x402 按调用（$0.01/次）或订阅档 |
