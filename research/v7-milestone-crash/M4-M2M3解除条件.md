### 1.3 本件给出的「真积压」可判定义（`RCP-6` 形，供 v7 采用）

> **定义候选**：`真积压` ≝ 满足下面**两条合取**的消息条数：
> ① `status == 'queued'`；**且** ② `now − time > 2 × QUEUE_TTL_MS` **或** `time` 缺失（**口径必须选一，不得两个都算**）。
> ★ 理由：`QUEUE_TTL_MS = 7 * 864e5`（`agent-bus/lib/index.js:84` 逐字实读），**只按 `queued` 计数会把「刚入队、正常在途」与「滞留过久、真积压」混为一谈** —— 后者才是 M2 关心的事。

```bash
python3 - <<'PY'
import json,os,time,collections
p=os.path.expanduser('~/.dsh/agent-bus.json'); d=json.load(open(p))
TTL=7*864e5; now=time.time()*1000
tot=q=stale=notime=0; ages=[]
for t in (d.get('threads') or []):
    for m in (t.get('messages') or []):
        tot+=1
        if m.get('status')!='queued': continue
        q+=1
        tm=m.get('time')
        if not tm: notime+=1; continue
        ages.append(now-tm)
        if now-tm > 2*TTL: stale+=1
print("消息总数(分母):",tot)
print("queued:",q,"其中 time 缺失:",notime)
print("真积压(queued 且 age>2×TTL):",stale)
if ages: print("queued 滞留天数 min/median/max:",round(min(ages)/864e5,2),round(sorted(ages)[len(ages)//2]/864e5,2),round(max(ages)/864e5,2))
print("★ 分母为 0 时本条必须报『不可判』，不得报 OK")
PY
```

| 元 | 内容 |
|---|---|
| **P** | `真积压 ≤ 10`，三态；分母 0 ⇒ **不可判** |
| **C** | 上面那段（**本件未执行** ⇒ 标 `未测`，★ 因为「真积压」的定义尚未获裁） |
| **D** | 分母 = **消息总数**（现测 33902）；**且必须同时报「`time` 缺失条数」**（缺失条不可默认为 0） |
| **N** | 造一条 `status='queued'` 且 `time` 推早 20 天的**影子副本**记录 ⇒ 计数**必须 ≥1**；★ **须在副本上做，不动在役 `agent-bus.json`** |
| **W** | 不适用（状态量） |

⇒ ★ **本件对 M2① 的最终记法：`不可判`**（判据无定义）。**M2 的解除条件 ① 必须先把定义落盘**。
