⇒ ★ **由此新增一条硬纪律（M1 篇 §4.2）**：**退出码必须在管道之前取。**

## 本件对 v7 的六条可执行推论

1. **`§7.9` 空节必须先填**（坑 → 门 → 谓词 三列映射表）—— **这是「25 类零复发」唯一的前置**，不填则该条**永远不可判**。
2. **未覆盖的坑必须具名列缺**，**不得默认为 0**（本项目纪律「空 ≠ 无」）。
3. **凡引用 v6.1 的「未做 / 未合 / 已修 / ❌」条目，一律先现测**（本件已推翻 7 处）；引用时**同时写「引用时刻」与「重跑时刻」**。
4. **`N-A` 不得计入「全绿」**；门工具的自述分母与自报汇总**必须对齐**（`gcr-gate` 现测：头 **11** vs 汇总 **8**）。
5. **PEND / `unverified` 必须反映到退出码** —— 否则「未验证」在下游一律读成「绿」（`beacon-check` 现测 `PEND 1 / exit 0`）。
6. **P28/P29 无 G-CR 门** ⇒ 这两族的复发判定**必须由 M5 篇给出的逐子项谓词承载**，**不得挂在「G-CR 门全绿」上**。
