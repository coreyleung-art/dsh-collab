# 经营主体三公司切割 + 补贴货款设计（2026-08-25）

> 核心：把「趣趣就来」单一主体拆分为品牌/运营/供应链三公司——风险隔离 + 资本化灵活 + 合规优化
> 关键决策：不承诺回购（保本红线），改为「补贴货款」（采购抵扣，风险评估报告明确建议的方向）
> 依据：商业模式文档双轮架构雏形 + 风险评估报告补贴建议 + 佛山协议单一主体问题

---

## 一、为什么拆三家（经营主体切割逻辑）

### 单一主体的风险（佛山协议已暴露）
```
现在：趣趣就来 = 品牌 + 运营 + 供应链 全在一个主体
问题1：品牌危机（食品安全/舆情）→ 全公司受牵连
问题2：供应链亏损（囤货/损耗）→ 品牌资产被拖累
问题3：资本化难（供应链要重资产，品牌要轻资产，混在一起估值模糊）
问题4：投资人签约主体单一（品牌授权+运营+供货一张合同，权责不清）
```

### 三公司切割结构
```
                   初蘅（实际控制人 / 资本平台）
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
    品牌公司             运营公司            供应链公司
   （品牌资产）        （运营能力）         （供货/物流）
        │                   │                   │
   收授权费 3-5万      收服务费 30%        赚供货差价 8-22%
   （轻资产·高毛利）   （轻资产·SaaS化）    （重资产·规模壁垒）
```

### 三公司各自角色

| 公司 | 资产 | 收入 | 资本化角色 | 风险特征 |
|---|---|---|---|---|
| **品牌公司** | 商标/VI/品牌理念/IP | 授权费 3-5 万/店 | 品牌溢价叙事（轻资产高毛利） | 品牌危机风险 |
| **运营公司** | SOP/培训/8787/数字化 | 运营服务费 30%（盈利后） | SaaS/效率叙事（可独立融资） | 模式被复制风险 |
| **供应链公司** | 四级采购/冷链/仓库/期货 | 供货差价 8-22% | 供应链霸权叙事（蜜雪逻辑） | 损耗/囤货风险 |

## 二、切割的好处（资本化 + 风险隔离）

### 1. 风险隔离
```
品牌危机 → 只影响品牌公司（供应链照常供货，运营照常服务）
供应链亏损（囤货砸价）→ 不拖累品牌资产
单一主体「一荣俱荣一损俱损」→ 三家各守一段
```

### 2. 资本化灵活（最重要的）
```
供应链公司：可独立融资（对标蜜雪/朴朴——「供应链霸权」叙事最强）
  → 投资人投供应链 = 投成本护城河
运营公司：可独立做 SaaS（对标 8787 产品化——「智能运营」叙事）
  → 投资人投运营 = 投效率引擎
品牌公司：可独立做品牌授权（对标特许经营——「情感资产」叙事）
  → 投资人投品牌 = 投溢价能力
= 三个公司三种估值逻辑，可分别对接不同资本
```

### 3. 并表选择（回应之前的问题）
```
品牌公司：轻资产 → 可并表（营收小但毛利高）
运营公司：SaaS 型 → 可并表（营收稳、毛利高）
供应链公司：重资产 → 战略选择并表（营收大）或不并表（控制权）
= 资本化时按叙事需要选择并表范围，不被单一主体锁死
```

### 4. 招商权责清晰
```
投资人跟谁签？
  品牌授权 → 品牌公司（商标使用权）
  运营服务 → 运营公司（SOP/培训/数字化）
  供货合同 → 供应链公司（采购/物流/损耗）
= 三份合同三个主体，权责边界清晰，合规（特许经营主体明确）
```

## 三、补贴货款设计（替代回购承诺）

### 为什么补贴货款 ≠ 回购（合规本质区别）

| 维度 | 承诺回购（❌） | 补贴货款（✅） |
|---|---|---|
| 本质 | 保本保息（投资回报承诺） | 采购优惠（真实经营激励） |
| 挂钩 | 投资本金/年限 | **真实进货量/经营表现** |
| 法律定性 | 借贷/保底→欺诈+非法集资风险 | 商业返利/供应链补贴（合法） |
| 现金流 | 或有负债炸弹（集中兑付） | 可控（按采购量计，上限明确） |
| 参照 | 嘉腾「满15月全额回购」 | 风险评估报告明确建议方向 |

### 补贴货款设计（三层）

```
第一层：老带新（口碑裂变）
  推荐奖 = 新店首批货款 × 3%（一次性，货款抵扣）
  持续奖 = 新店前 6 个月进货额 × 1.5%（按季，绑定存活）

第二层：经营补贴（扶持期）
  触发：连续 2 个季度净利润 < 1 万（收紧自 V1.0 的"任一季"）
  形式：采购货款抵扣（非现金）——亏损季进货时直接抵扣
  上限：年度累计不超过 3 万（可控）
  起算：明确"净利润 = 扣除运营服务费后的净额"（防双重损失）

第三层：供应链让利（规模激励）
  阶梯返点：月进货 ≥5 万下浮 3%；≥10 万下浮 5%（分档累进）
  = 越做越厚的采购优惠，绑供应链不绑承诺
```

### 补贴货款的合规要点
1. **挂钩真实进货**：补贴以「进货量/经营表现」为基数，不是投资本金
2. **货款抵扣非现金**：补贴以采购抵扣形式发放（风险评估报告建议）
3. **设上限**：年度 3 万封顶，多店可控
4. **明确计算口径**：净利润含服务费扣除（防争议）
5. **删除「最终解释权」**：改为「双方协商确定」（民法典 497 风险）
6. **不进合同承诺**：作为「扶持政策」非「保底条款」写入附件，表述为政策不承诺

## 四、三公司切割 × 补贴货款的协同

```
投资人视角：
  签品牌公司（授权费）→ 签运营公司（服务费 30%）
  → 签供应链公司（进货）→ 享受补贴货款（老带新+经营补贴+让利）
= 三份合同 + 三重补贴 = 清晰、合规、有安全感（但不保本）

资本化视角：
  供应链公司（蜜雪逻辑）→ 独立融资 → 重资产做厚
  运营公司（SaaS）→ 独立融资 → 8787 产品化
  品牌公司（授权）→ 品牌溢价 → 情感资产
= 三条资本线可分别推进，风险互不拖累
```

## 五、落地路径

### 阶段一（现在）：主体切割登记
- 趣趣就来 → 拆分为品牌/运营/供应链三家公司（或新设两家）
- 商标/VI 归品牌公司；SOP/8787 归运营公司；采购/冷链归供应链公司
- 佛山协议主体关系按新架构重新梳理（授权链清晰）

### 阶段二（招商期）：三合同 + 补贴政策
- 投资人签约：品牌授权协议（品牌公司）+ 运营服务协议（运营公司）+ 供货协议（供应链公司）
- 补贴政策：老带新 + 经营补贴 + 供应链让利（附件形式，非保底承诺）
- 合规：三主体各司其职，特许经营主体明确（品牌公司为特许人）

### 阶段三（资本化）：三线融资
- 供应链公司优先融资（对标朴朴/蜜雪叙事）
- 运营公司做 SaaS 独立估值
- 品牌公司做授权资产

## 六、风险与边界

1. **切割成本**：三家公司涉及注册/税务/关联交易合规——需专业财务税务顾问
2. **关联交易**：三公司之间的供货/服务/授权需按市场价结算（防税务/合规质疑）
3. **品牌公司特许人义务**：若走特许经营，品牌公司须满足「两店一年」+备案+披露
4. **补贴货款仍需谨慎**：补贴是「扶持政策」非「收益承诺」——表述上严格区分（「补贴」vs「保底」），且设上限
5. **与资本化并表协调**：三公司独立核算，资本化时按叙事选择并表范围（避免被单一主体锁死）

---

## 七、结论

```
三公司切割的价值：
  风险隔离（品牌/运营/供应链各守一段）
  + 资本化灵活（三线可分别融资，估值逻辑清晰）
  + 招商权责清晰（三合同三主体）
  + 合规优化（特许经营主体明确）

补贴货款的价值：
  替代回购（保本红线）→ 采购抵扣（风险评估建议方向）
  = 给合伙人「安全感」但不给「保本承诺」
  = 合规底线与招商吸引力兼得

核心一句话：
  「不承诺回购（保本），承诺补贴货款（经营激励）——
   三公司切割让补贴有主体、风险有隔离、资本有路径」
```
