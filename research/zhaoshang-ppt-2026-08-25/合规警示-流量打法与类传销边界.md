# 合规警示：流量/投流/私域运营与类传销的边界

> 警示来源：用户 2026-08-26 判断「流量/投流/私域运营，换个话就是类传销」
> 依据：区域代理裂变体系调研（传销红线清单）
> 用途：与嘉腾/任何招商平台合作前的合规自检

---

## 一、核心判断（用户警示）

> **「流量/投流/私域运营，换个话就是类传销。」**

不是所有流量打法都违法——但**以「发展门店/代理数量」为计酬依据的流量裂变，就是类传销**。
判定的生命线（两高一部〔2013〕37 号）：**报酬来自「发展人员数量」（人头）还是「商品实际销售」（流水）**。

## 二、为什么流量打法容易被穿透

| 流量打法表面话术 | 实质风险 |
|---|---|
| 「0 加盟费 / 永不抽佣 / 全额回购」 | 收入主体若来自「发展门店数」而非商品流转 → 变相入门费 |
| 「拉新裂变 / 推荐返佣 / 团队业绩」 | 直推奖结构（A 介绍 B 即拿钱）= 最典型传销计酬 |
| 「私域会员分级 / 发展下级」 | 层级计酬（30 人 + 3 级 = 刑事红线）|
| 「城市合伙人 / 区域代理快速扩张」 | 代理费只对应「发展资格」→ 变相入门费 |

## 三、我们（初蘅）的合规设计（不受影响）

```
✅ 收入锚定商品流转：供应链差价 + 货款补贴（按实际进货额）
✅ 招商佣金锚定「签约成功 + 完成首批进货/真实开店」（凭证据核销）
✅ 二级直接签初蘅（嘉腾转渠道服务商，不经手资格费）
✅ 不做收益承诺 / 不做回购
✅ 老带新以货款抵扣（首批货款 3% + 前 6 月进货 1.5%），非现金拉人头
```

## 四、与嘉腾合作的合规边界（重要修正）

**修正我此前的分析**：我之前把嘉腾的「流量/投流/私域运营」当作合作互补优势——**这是错误的**。
正确立场：

1. **不借鉴他们的流量裂变打法**——那是他们可能踩线的地方，不是我们要学的
2. **合作只锚定商品流转**——嘉腾负责「真实开店 + 真实进货」，我们按进货额给货款补贴；**绝不按「发展门店数量」计酬**
3. **警惕「0 加盟费/永不抽佣/全额回购」话术**——如果嘉腾的收入模型依赖人头，合作会把初蘅拖进类传销风险（品牌方知情参与同样追责）
4. **谈判立场**：我们做供应链与经营系统，嘉腾若想参与，就走「区域真实开店 + 货款补贴」路径——**不碰流量裂变**

## 五、红线清单（合作前自检）

- [ ] 嘉腾收入模型：是「商品流转差价」还是「发展代理数量」？
- [ ] 我们的计酬：是否锚定真实进货/销售流水？（是）
- [ ] 二级是否直接签初蘅？（是，嘉腾不经手资格费）
- [ ] 有无「直推奖 / 推荐返佣 / 按发展人数提成」？（无）
- [ ] 宣传材料是否含收益承诺？（无，统一管控）

## 六、结论

> **初蘅的合作模式天然合规（赚供应链钱不赚人头费）——这条底线不动。**
> 嘉腾的流量/投流/私域打法我们不借鉴、不背书、不参与；
> 合作只走「真实开店 + 真实进货 + 货款补贴」的合规路径。
