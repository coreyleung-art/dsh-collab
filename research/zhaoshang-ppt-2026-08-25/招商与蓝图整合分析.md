> 核心命题：招商不是孤立的市场动作，而是蓝图的「业务扩张线」——它既是蓝图的变现出口，也是数据飞轮的燃料来源。

## 二、核心洞察：招商 = 蓝图的「业务扩张线」

### 蓝图当前是「内生闭环」，招商让它变成「外生增长」

```
当前闭环（内生）：
  门店 → 数据 → 模型/工艺 → 降本增效 → 门店更赚
  （4 店自循环，增长慢）

招商之后（外生+内生飞轮）：
  更多门店 → 采购量↑ → 供应链差价↑（8-22%）
           → 数据量↑ → 模型更准（4.0 数据飞轮燃料）
           → 品牌授权费/服务费↑（每店 5 万 + 30% 分成）
           → 总部利润↑ → 投入技术 → 赋能更强 → 更多门店
  （鸣鸣很忙验证：2.2 万店，99% 收入来自供货）
```

**关键：招商给蓝图补上了「规模化数据源」**——4.0 数据飞轮（d4-3）和垂直模型训练（d4-2）缺的就是门店数量带来的数据多样性。10 店 → 100 店，每个门店都是数据采集点。

## 四、招商的蓝图化：建议新增 [business] 线

当前蓝图只有 digital + physical，**建议新增 business 扩张线**，让招商本身成为蓝图可跟踪的项目：

```
[business] 1.0 招商与扩张 (new)
  ├ b1-1 招商体系设计 [active]（本次任务：V3 内容版）
  │   ├ 分润制度（单店：授权费+30%分成；城市合伙人：代理费+区域抽成）
  │   ├ 合规修正（收益承诺/回购/竞业/备案）
  │   └ 招商 PPT/物料（基于 V2.0 升级）
  ├ b1-2 样板店验证 [todo]（五山店/天河店数据案例页）
  ├ b1-3 首批合伙人招募 [todo]（广州 3-5 家 → 多城）
  ├ b1-4 城市合伙人网络 [todo]（区域代理，考核开店数+存活率）
  └ b1-5 供应链规模化 [todo]（10 店后月采购 40 万+，差价 15-22%）
```

**与现有线的衔接**：
- b1-3（招募）→ 增加门店 → 反哺 d25-3（外卖→ERP 数据打通）和 d4-1（数据聚合）
- b1-5（供应链）→ physical 2.0 标准化（流水线需要订单量支撑）
- 每个门店上线 = digital 2.5 ERP 的一个新租户（多租户隔离 schema 已有设计）

## 五、分润制度 × 蓝图能力的三层设计

结合之前分析（调研报告公式）和 V2.0 三重收益，整合为三层：

**第一层：单店授权店主（V2.0 已有，合规修正）**
| 项目 | 数值 | 依据 |
|---|---|---|
| 品牌授权费 | 3-5 万/店（一次性，3-5 年） | V2.0 4.2；调研：授权费前置 |
| 运营服务费 | 月净利 30%，连续盈利 6 个月起收，亏损月不收 | V2.0 3.4；百果园利润抽成逻辑 |
| 供应链供货 | 结算价含差价 8-22% | 商业模式文档 2.3；鸣鸣模式 |
| 参投分红 | 合伙人按持股比例（≤70%）季度分红 | V2.0 3.4 |
| 阶梯返点（新增） | 月进货额 ≥5 万下浮 3%，≥10 万下浮 5% | 调研公式①，激励走总部供应链 |
| 老带新（新增） | 推荐奖=首批货款 3% + 新店前 6 个月进货额 1.5% | 调研公式②，鸣鸣 60% 老带新 |

**第二层：城市合伙人（新增，回应「两者」）**
| 项目 | 数值 | 依据 |
|---|---|---|
| 区域代理费 | 一次性 3-15 万（按城市等级） | 调研公式③（低于行业 5-30 万） |
| 区域管理抽成 | 辖区内门店流水 × 0.5% | 调研：行业 0.5-1%，总部已收服务费故取轻 |
| 考核门槛 | 年开店数达标 + 门店 12 个月存活率 ≥85% | 调研公式③，绑定质量 |
| 权限边界 | 招商权+门店管理权（非定价/品牌权） | 「合伙只分收益，不分权力」 |

**第三层：供应链利润（真正的规模化引擎）**
```
总部收入 = 授权费 + 服务费（30% 利润）+ 供货差价（8-22%）
蓝图中 4.0 数据飞轮 → 采购预测更准 → 差价率向 22% 上限靠拢
```

## 六、合规修正（对齐风险评估 + 行业红线）

| V2.0 条款 | 问题 | 修正 |
|---|---|---|
| 收益三档（年化 45-80%） | 保证性收益承诺 | 删乐观档，改用 5 月真实数据+区间参考+风险提示 |
| 回购（连续 6 月亏损→本金+8%） | 保本保息承诺 | 门槛提至 12 个月+亏超 50%，取消固定年化，付款期延长 |
| 兜底（季度净利<1 万补足） | 持续资金流出 | 改采购货款抵扣形式，连续两季度触发，年度上限 3 万 |
| 竞业（无对价/违约金高） | 可执行性存疑 | 加补偿金（限制期分红 30%），违约金调至投资额 1 倍，按店型差异化 |
| 「参投自营非加盟」 | 实质三特征可能穿透 | 律师确认是否备案/披露/冷静期 |
| 五权控制 | 可能被认定实际经营者 | 明确定位为建议/审核/监督权，重大事项股东会决议 |

## 七、结论

1. **招商是蓝图的缺失一环**——技术/工艺线已扎实，缺业务扩张线承接变现，招商正好补上
2. **分润三层设计完整**：单店（V2.0 修正）+ 城市合伙人（新增）+ 供应链（规模引擎）
3. **招商反哺蓝图**：每店 = ERP 租户 + 数据采集点 + 采购量贡献，直接喂 4.0 数据飞轮
4. **建议将招商登记为蓝图 [business] 1.0 线**，与 digital/physical 并列跟踪
