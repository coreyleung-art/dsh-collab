# 第一部分：愿景（我们从哪里来，到哪里去）

## 1.1 愿景一句话

> **「让每一家门店，都成为智能花店网络的一个节点——数据驱动、工艺标准化、可持续复制的生命美学生意。」**

初蘅不是一家花店连锁——是鲜花「情感消费品类」的供应链重构者。
用 AI + 双蓝图（digital/physical）替老板做专业事，用供应链霸权 + 运营霸权建立品类壁垒。

## 1.2 目标（我们要建成什么）

```
2026 H2  地基期：数据+感知跑通（ERP 打通 / 端侧模型 / 感知闭环）
2027     验证期：AI 决策闭环 + 单城密度（AI 运营助手上线）
2028     复制期：供应链规模化 + 数据飞轮（单店复制 / 无人值守单环节）
2029-30  霸权期：自动化 + 垂直模型（花店界的麦当劳）
5-8 年   终局：自动化工厂 / 资本化
```

## 1.3 为什么是现在（三叠窗口）

```
天时：AI 成熟——第一次能标准化鲜花（视觉 99.75% / 预测 98% / 减损 30-50%）
地利：即时零售爆发（闪购鲜花 +15.7%）
人和：42 万家夫妻店 26% 在死（存量整合窗口）
```

# 第三部分：双霸权（实现愿景的引擎）

## 3.1 供应链霸权（蜜雪式变体）

- 四级采购（云南空运/陆运 → 岭南 → 临采）+ 冷链 + 期货锁价
- **损耗 30%+ 压到 10%**（冷链已降至 3% 以下）
- 供应链差价 8-22%（对标蜜雪 97.6% 供货收入）

## 3.2 运营霸权（麦当劳式 AI 版）

- 8787 面板：多店实时（订单/告警/客户/分析全自动化）
- 通岗 SOP：3-5 天上岗（不依赖花艺师）
- 节日期货 SOP：23 节日窗口（预测→锁价→调价→履约）
- 视觉模型 flower-yolo 99.75% + 传感器 + AI 运营助手（蓝图）

## 3.3 双霸权协同飞轮

```
供应链霸权（成本低）→ 运营霸权（效率高）→ 数据飞轮（模型更准）
→ 损耗更低 → 成本更低 → 门店更赚 → 更多门店
```

# 第五部分：合作模式（一起走向愿景）

## 5.1 合作模式矩阵（三形态，按对方能力/意愿匹配）

| 形态 | 结构 | 适合对象 | 深度 |
|---|---|---|---|
| **A. 门店财务投资**（拼盘）| 投资单店/多店组合，品牌运营 | 个人财务投资者 | 浅（出资）|
| **B. 授权合作店主**（经营）| 门店自主经营+品牌赋能 | 想开店经营者 | 中（经营）|
| **C. 区域合伙人**（渠道）| 区域招商+督导+供应链 | 有区域资源的团队 | 深（区域）|

## 5.2 单店参数（A/B 共用，基准可谈）

| 参数 | 基准 | 弹性 |
|---|---|---|
| 门店分级 | 社区 10 万 / 标准 15 万 / 旗舰 20 万（带冷库）| 按店型 |
| 品牌授权费 | 3-5 万/店（一次性）| 按店型/区域 |
| 运营服务费 | 月净利 30%（盈利 6 个月起收，亏损月不收）| 可谈 |
| 参投分红 | 按持股比例季度分红（品牌占股 20-30% 不控股）| 按出资 |
| 区域保护 | 商圈/行政区保护 | 按密度 |

## 5.3 区域合伙人（C 形态）——承诺开店量 → 增量货款补贴

**核心模型**：区域合伙人承诺年开店量，按「实际进货额」给予货款补贴返回——报酬锚定真实商品流转（合规），不是人头费。

**为什么这个设计**：
1. **合规**：补贴基数 = 辖区门店实际进货额，不是授权费/人头（蜜雪 94% 收入来自供货、行业年度返利按销量）
2. **绑供应链**：补贴以货款抵扣发放 → 持续从初蘅进货 → 供应链利润留给自己（防套现）
3. **激励对齐**：开店量→进货量→补贴，每推一家店都真实转化为供应链流水

### 补贴模型（基准可谈）
| 承诺开店量（首年）| 增量货款补贴率 | 结算方式 |
|---|---|---|
| 3-5 家（试点）| 首批货款 3% + 前 6 月进货 1.5% | 货款抵扣 |
| 10 家 | 年度进货额返利 3-5% | 按季度结算 |
| 20 家 | 年度进货额返利 5-8% | 按季度结算 |

**双向绑定**：未达标降档 / 达标升级 / 存活率 ≥85% 考核

### 行业案例参考（调研验证）
| 品牌 | 做法 | 门槛 | 启示 |
|---|---|---|---|
| 蜜雪冰城（5 万店）| 无区域代理，品牌直管加盟 | 开店投资 21 万起 | 供应链为王，不靠人头 |
| 鸣鸣很忙（3 万店）| 免加盟费，直管门店 | 0 加盟费 | 赚供应链钱（毛利 11.5% 全来自价差）|
| 一点点 | 市级代理制 | 市级约 200 万 | 高门槛=重资产准入 |
| 白酒行业 | 省/市/县三级 | 40/20/10 万首单 | 代理费=首批货款门槛 |

## 5.4 合规红线（无商量）

- ❌ 不做回购/保本承诺（欺诈+非法集资+广告法三重风险）
- ❌ 二级不经手资格费（直接签初蘅，防传销）
- ❌ 不承诺收益/回本（话术统一管控）
- ❌ 投资款不碰资金池（进单店项目公司账户）
- ✅ 替代安全感：真实数据 + 区域保护 + 退出机制

# 第六部分：资本化（愿景的终局价值）

## 6.1 双路径

### 路径 A：独立上市（参照蜜雪/遇见小面）
- 供应链叙事（蜜雪式）+ 标准化（遇见小面式）
- 时间：5-8 年（对齐蓝图终局）

### 路径 B：被整合（参照朴朴/零食有鸣）
- 做厚：供应链/密度/数据/会员
- 估值预期：0.3-0.5x PS，窗口约 2027-2028

## 6.2 源文件弹药（可复验）

- **蜜雪**：收入 335.6 亿 / 净利 59.27 亿 / 59,823 店 / 加盟费仅 2.4% / 闭店率 4.2%
- **遇见小面**：同店 -4.2% / 客单价 31.3→27.7（以价换量铁证）
- **即时零售并购**：估值 0.2-0.5x PS / 巨头买密度+供应链+数据

## 6.3 资本化关键决策

- **参投自营不并表**：品牌占股 20-30% 不控股——绑定叙事 + 不背重资产报表
- **不做回购承诺**：安全感来自真实数据+区域保护+退出机制
