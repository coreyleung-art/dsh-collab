> 用途：招商展示「智能运营能力」的典型案例
> 核心叙事：七夕大促的打法策略（数据预测→备货锁价→阶梯调价→履约监控）由 AI 智能体驱动
> 注意：用户口径「只有大促打对，之前亏」→ 案例定位为「大促方法论 + 数据实证」，不承诺日常盈利

## 一、案例叙事框架

### 为什么选大促做案例？
- 鲜花行业 45%+ 销售额来自节日（行业数据）
- 大促是「打法」的分水岭：**打对 = 单店日销峰值 5-10 倍、打错 = 亏损**
- 初蘅的差异化 = 用数据/AI 把「靠经验赌节日」变成「靠模型赢节日」

### 大促打法五步（AI 智能体驱动）

```
1. 数据预测：历史订单 + 平台趋势 → 预估节日单量/SKU 结构
2. 备货锁价：提前 7-15 天云南锁价锁量（KIFA 指数锚定）
3. 阶梯调价：节前分档定价（溢价 30%-300%），AI 动态调价
4. 补贴策略：平台补贴 + 商家补贴组合，冲单量换排名
5. 履约监控：实时订单/库存/配送监控，爆单不崩

```

### 数据实证（2026-08-05 天河店大促日）
| 指标 | 数值 | 说明 |
|---|---|---|
| 订单数 | 34 单 | 单日 |
| 商品件数 | 516 件 | 含 33 朵大束 |
| 净销售额 | ¥2,249 | 顾客实付 |
| 平台+商家补贴 | ¥7,571 | 补贴是净销 3.4 倍——冲量策略 |
| 主推款 | 33朵粉玫瑰 | 429 支，占总量 83% |
| 价格带 | 60-100 元 | 主战场（24/36 单） |

**洞察**：大促日的商业模式 = 「高补贴冲单量 → 平台排名/流量加权 → 转化自然流量」，净利靠供应链差价（低价囤货）而非终端加价。

### 合规红线（必须遵守）
- ❌ 不写「月入 X 万」「回本 X 个月」——补贴数字是成本不是利润
- ✅ 写「单日订单量/件数/结构」——事实数据
- ✅ 写「打法方法论」——能力展示
- ⚠️ 补贴 7571 是**投入**，不展示为收入（避免误导）
