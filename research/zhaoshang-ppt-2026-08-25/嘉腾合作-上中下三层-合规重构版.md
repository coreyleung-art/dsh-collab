# 嘉腾合作 · 上中下三层框架（合规重构版）

> 用途：明天与嘉腾团队洽谈的最终方案
> 依据：区域代理裂变体系调研（158 行，法规+10 案例）+ 嘉腾合作框架方案 + 特许经营合规调研
> 核心：你的三层直觉方向对，但「上层」必须重构——否则踩传销红线

---

## 一、你的三层逻辑（保留骨架，重构机制）

```
上：嘉腾做总代，收区域代理费，发展二级代理（裂变）
中：嘉腾帮初蘅招区域代理
下：嘉腾帮初蘅招门店财务投资人（投资拼盘）
```

**核心结论**：三层都可行，但「上层」如果设计成「嘉腾收二级代理费+按人头提成」，就构成传销三要素（入门费+拉人头+层级计酬），刑事风险最高。**必须重构为「二级直接与初蘅签约，嘉腾转渠道服务商」**。

---

## 二、合规重构后的三层（最终版）

### 上层：区域代理网络（重构后）

```
❌ 原设计（危险）：嘉腾收代理费 → 嘉腾按发展二级数量提成 → 传销定性
✅ 重构后（安全）：二级代理直接与初蘅签约 → 嘉腾拿服务佣金+销量返利
```

**结构**：
| 环节 | 谁 | 角色 | 收益 |
|---|---|---|---|
| 特许人/供货方 | **初蘅** | 唯一主体（两店一年+备案+披露） | 授权费+供货价差+服务费 |
| 渠道服务商 | **嘉腾** | 招商撮合+区域协调+督导 | 招商佣金+区域销量返利+管理服务费 |
| 区域代理 | **直接与初蘅签约** | 区域经营+进货 | 区域独家+供货价差+年度返利 |
| 门店 | 加盟或投资 | 零售 | 利润 |

**关键点**：
1. 二级代理**直接与初蘅签约**（初蘅才是特许人）——嘉腾不经手代理费，切断人头链条
2. 嘉腾收益 = **招商服务佣金（按签约+首批进货结算）+ 区域销量返利（按真实流水）+ 管理服务费**
3. 每层报酬都锚定**商品/服务流转**，不是发展人数

### 中层：嘉腾帮招区域代理（低风险，规范即可）

- 本质 = **招商居间服务合同**（合法）
- 佣金锚定「签约成功 + 完成首批进货」，凭证据核销
- 嘉腾对招商对象做资质尽调（防批量拉人头）
- 宣传材料过法务，禁止收益承诺

### 下层：门店财务投资人（投资拼盘）（非法集资红线）

- 多人出资拼店 = 合伙/股权投资 → 必须：**非公开 + 真实股权登记 + 零回报承诺 + 不碰资金池**
- 单店合伙企业 ≤50 人；或单店公司制
- 纯财务投资人：只做股权投资，不参与经营（走股权投资路径）
- 若同时是经营者：走加盟路径（信息披露+冷静期+合同≥3 年）
- 初蘅只收货款/授权费，不碰投资款；嘉腾只居间撮合，投资款进单店项目公司账户

## 三、分润结构（五层利润池 · 全部锚定商品流转）

```
初蘅毛利 = Σ(出厂价×终端销量) + 区域授权费 + 服务费
嘉腾毛利 = (总代供货价−出厂价)×区域销量 + 年度返利 + 招商服务佣金*
区域代理毛利 = (门店供货价−总代供货价)×进货量 + 年度返利
门店毛利 = (零售价−进货价)×销量 − 房租 − 人工 − 损耗
```
> `*`招商服务佣金 = 按「成功签约并完成首批进货」结算，**严禁按被发展人数计酬**

### 参数区间（行业参考）

| 参数 | 行业惯例 | 建议值 |
|---|---|---|
| 区域授权费 | 城市级 5-50 万（一点点市代 200 万） | 广州/佛山 10-30 万 |
| 首批货款门槛 | 白酒：县 10 万/市 20 万/省 40 万 | 区域代理 10-20 万（与铺货量匹配） |
| 供货价差 | 快消 15-30% | 初蘅供应链差价 8-22% |
| 年度返利 | 白酒 5-8% | 5%（按年销量阶梯） |
| 招商佣金 | 加盟费 30%（中介惯例） | 授权费 30% |
| 区域保护 | 蜜雪 1000m/鸣鸣 500m | 按行政区/商圈 |

## 四、传销红线清单（明天谈判前必读）

### 绝对禁止（触犯即刑事）
1. **直推奖**：A 介绍 B 加入，A 立即从 B 的费用中拿固定比例——最典型传销
2. **入门费**：费用只对应「发展资格」而非真实对价；代理费畸高/首单货款远超铺货量
3. **层级计酬**：上下线关系+上线抽下线业绩。刑事门槛=30 人以上+层级 3 级+按人头计酬（「两级以内安全」是误区）
4. **收益承诺**：「稳赚不赔」「年化 XX%」——特许经营广告还禁止宣传被特许人收益
5. **非法集资**：公开宣传+承诺回报+向不特定对象吸资
6. **无授权再特许**：嘉腾未经初蘅书面同意不得转让特许权/发展二级（条例 18 条）

### 合规姿态（三层成立前提）
```
① 每层报酬锚定商品/服务流转
② 「资格费」与「货款/服务对价」清晰拆分、可审计
③ 层级 ≤2 级代理（品牌方→区域代理→门店），不按人头计酬
④ 特许经营资质先行（两店一年/备案/信息披露）
```

## 五、谈判要点（明天用）

### 开场定位（更新版）
```
「初蘅和嘉腾的合作分三层：嘉腾帮我们建区域代理网络（上层）、帮我们招区域代理（中层）、帮我们对接门店投资人（下层）。每一层嘉腾都有收益，而且越做越厚——但为了长期安全，二级代理直接和初蘅签约，嘉腾做区域渠道服务商，拿招商佣金+销量返利+管理服务费。」
```

### 关键谈判点
1. **招商佣金**：授权费 30%（市场惯例）——嘉腾每促成一家签约+首批进货，结算一次
2. **销量返利**：区域年度流水 5%（行业惯例）——绑定长期，嘉腾会帮门店活好
3. **管理服务费**：区域代理的服务包（培训/督导/协调）——按实际服务计
4. **合规红线明示**：不承诺收益、二级直接签初蘅、投资款不碰资金池——这既是保护初蘅也是保护嘉腾
5. **首期试点**：广州/佛山 3-5 家，跑通再扩

### 给嘉腾的算账（为什么这个方案对他们好）
- 不承担特许人义务（备案/披露/两店一年都是初蘅的事）
- 招商佣金即时兑现（每单 30%）
- 销量返利持续（区域流水 5%）
- 无传销风险（不碰人头费）
- 复用他们的门店资源+投资客资源
