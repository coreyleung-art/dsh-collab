### C3.2 版权与合规要点

- 中国《生成式人工智能服务管理暂行办法》要求 **AI 生成内容显著标注**；公众号/知乎对 AI 生成内容有平台规则，发布时按平台要求标注。
- **Midjourney**：付费订阅用户对产出拥有商用权利（按官方条款与营收门槛），免费试用图不可商用。
- **通义万相/即梦/可灵**：按各平台服务条款授权，商用前确认；企业级批量商用优先走阿里云 API 合同口径。
- **本地 SD**：自建模型可控性最高，但模型许可证（SD1.5/SDXL 宽松类 vs SD3.5 Community License）要分别核对。
- **落地**：首期配图 = 通义万相 API 或即梦免费档（人工出图）→ 固化 3-5 套「封面/正文配图 prompt 模板」入 templates/；批量/脱敏场景走本地 SD。

### C5.2 风险与边界

- **平台风控**：微信对非官方自动化发布风控趋严；矩阵分发工具多为「模拟点击/自动填充」而非原生接口，封号风险由账号承担。
- **账号安全**：第三方工具扫码/授权登录有撞库、数据泄露风险；**主账号密码/令牌绝不托管给无来源小工具**（延续管线 v1「未审核不发布+外链凭据」原则）。
- **结论**：首期（公众号+知乎各 1 个账号）**不上任何矩阵工具**；C5 整类 P2，等用户决策扩平台/扩账号再立项，届时先小号试水（蚁小二免费档）+ 指纹浏览器隔离。

## 局限与待验证

1. **价格高频变动**：扣子/即梦/可灵/剪映/蚁小二等价格均为 2026-08-17 时点信息（部分为活动价），使用前以官网实时报价为准；本报告未逐一核价。
2. **公众号自动发布接口权限**：草稿箱/群发 API 需认证服务号或开发者权限，**个人订阅号拿不到**——「全自动发布」不可行，落地为「自动生成草稿+人工审核发布」（与管线 v1 硬性审核一致，反而是安全垫）。

4. **Midjourney 商用条款**：按订阅档位与营收门槛区分，正式商用前需读官方 Terms。
5. **矩阵工具价格**：Kuaizi/WeMedia 等企业级报价需销售咨询，未获取公开报价。
6. **可灵/即梦生成视频的商用授权细节**：以官方服务条款为准，发布前逐平台确认。
