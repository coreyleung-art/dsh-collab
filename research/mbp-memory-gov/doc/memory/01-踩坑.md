## 五、2026-08-28 mbp-bus 实战沉淀（DSH 插件/黑板/运维/协作）

### 5.1 DSH 插件工程机制
1. **symlink 插件的依赖解析坑**：插件经 profile node_modules symlink 加载时，Node 按**真实路径**解析 bare import（preserveSymlinks=false）——宿主/运行时 node_modules **不在解析链上**。插件必须自带 node_modules 或正确声明 dependencies/peerDeps。实战：dsh-plugin-openchronicle import `@deepseek-ai/dsh-tools` 失败 → ERR_MODULE_NOT_FOUND 崩整个 dsh server
2. **defineTool API 版本不兼容**：旧版签名 `defineTool({name, description, parameters, handler})`；rc.6 要求 `execute(args, exec)` + **必填 `output:{schema, render}`**（无 output → `TypeError: Cannot read properties of undefined (reading 'render')`）。升级 API 时全量核对工具定义字段
3. **cordis.patch.yml 必须顶层 YAML 数组**：全注释文件解析为空 → `must be a top-level YAML array` 报错。禁用插件用 `[]`（合法空数组），并留 `.bak` 备份
4. **新插件先测试 profile 验证**再注入生产 profile；注入前检查 package.json dependencies 完整性
5. **central-inbox 旧版缺陷**：findCentralAgent 无 boot 重试 + handleEvent 无动态补查 → 启动时 `agentBus.list()` 为空且 CENTRAL_AGENT 未设则**永不解析**（日志「注入 ?」）→ 事件到达也不注入。新版需：5s 重试 + handleEvent 动态补查 + 自回声过滤（`value.from===NODE_ID` 跳过）

### 5.2 黑板协议要点
6. **键 = URL 路径去前导 `/`**：写 `PUT /<key>`（body=扁平 value，服务器自动赋 ISO ts）；读单键 `GET /<key>`；全量 `GET /notes` 过大易截断（>2.8MB）
7. **PUT body 用扁平 value**：嵌套 `{"value": {...}}` 会被服务器双重包裹（value.value）；mac-mini 早期也踩过（空值问题）
8. **自回声缺口**：`value.from===NODE_ID` 是精确匹配——`mbp-coord`/`mbp-bus` 不命中 `mbp` → 协调者写入统一用 `from=mbp` 或改前缀/集合匹配
9. **命名空间规范**：跨设备可见内容写 `notes/collab/` 或 `notes/<node>/`；`notes/session-xxx/` 不在事件桥监听前缀（notes/mbp/、notes/collab/、tasks/mbp/、nodes/mbp/heartbeat、notes/i9/*mbp*）→ 不会被自动消费

### 5.3 运维/系统
10. **launchd stdout 无界写日志 = 磁盘满炸弹**：node-bridge stdout → mbp-agent.log 涨到 **21GB** 占满数据卷（100%）。防护：`mbp-log-guard.sh` + LaunchAgent 每 5 分钟截断 >100MB（com.dsh.mbp.log-guard，runs 160+ 实证）；launchctl bootstrap 在沙箱需提权（danger-full-access）
11. **/opt/homebrew/bin 不在默认 PATH**（PATH=/usr/bin:/bin:/usr/sbin:/sbin）：node/npm/pnpm/lark-cli 都在这——用绝对路径或 `export PATH=/opt/homebrew/bin:$PATH`；lark-cli 认证已就绪（bot=GM大总管、user=梁振宇，im 权限齐）
12. **SSH 排查 mac-mini**：`ssh coreyleung@100.120.203.20` 密钥直连可用；CLD 崩溃恢复流程 = 定位根因 → 非破坏修复 → `pkill` 残留 + `open /Applications/CLD.app` → 双窗口验证稳定

### 5.4 协作/流程
13. **agent_send v2.3**：内容落黑板 + 只发「看黑板 <key>」指针；纯确认不回；旧版本滞后会话用**最终指令**终止循环（"此话题关闭，不再回复"）
14. **会话管理**：agent_wake resume 可恢复持久化会话（session.jsonl.zstd）；登记用 agent_profile（role/abilities/resources）；分工章程挂 `notes/collab/mbp-session-registry`
15. **恢复探针回报**：verify-mbp-ack 键版本递增回报；黑板单键 GET 高效
16. **零轮询协议 v1 实证**：写黑板→事件桥 SSE→central-inbox 注入可维持多轮对话（3 轮 ping-pong 27s/30s/15s）
17. **CLD 每次启动弹系统浏览器**：CLD(Electron 壳) spawn `dsh web --port 0` 未带 `--no-open`，dsh-web-app 默认 `openBrowser:true` → 每次启动在默认浏览器弹 Harness 网页。**修复**：web profile 用户 patch 层覆盖 `web-runtime` 条目的 `config.openBrowser: false`（`~/.dsh/profiles/web/cordis.patch.yml`，备份 .bak-openbrowser）；CLD 自身 BrowserWindow 不受影响。patch 语法：`{id: <entry-id>, config: {...}}` 覆盖 bundle 层配置（insert/override/disable 三类）
