# 调研子代理模板（source-trust 自动评级接入 · v1.0）

> 数据调查员 4787d717 · 2026-08-31 · 用途：所有调研子代理产出需经 source-trust 信源可信度评级

## 使用方式
派发调研子代理时，在 prompt 末尾附加以下段落：

---
**【信源评级要求（必须执行）】**
1. 报告「证据来源」节的所有 URL，用本机工具评级：
   `dsh-tools source-trust <url>`（S/A/B/C + 得分）或 `--check <摘要文本>`（内容特征/传播特征）
2. 评级结果写入报告「来源可信度」节（每来源：URL + 评级 + 得分 + 依据）
3. C 级/低分来源不得作为结论依据（仅作线索，标注"低可信"）
4. 关键结论数字必须 ≥2 个独立 A/S 级来源，否则标注"单源待验证"
---

## 评级判定标准（source-trust 三维度）
| 维度 | 规则 | 输出 |
|------|------|------|
| 来源信誉 | S 官方/A 聚合/B 二手/C 低质 | grade + 得分 |
| 内容特征 | 噪音词 18 + AI 腔 8（句法指纹） | content_score（越低越可疑） |
| 传播特征 | 转载/镜像/聚合/付费墙/预印本/官方 | spread signals |

## 执行检查（调研子代理交付前）
- [ ] 证据来源全部评级
- [ ] C 级来源已标注"低可信/仅线索"
- [ ] 关键数字 ≥2 独立来源（否则标"单源待验证"）
- [ ] 结论基于 A/S 级来源
