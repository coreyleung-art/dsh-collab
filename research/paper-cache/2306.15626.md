# [2306.15626] LeanDojo: Theorem Proving with Retrieval-Augmented Language Models

- arXiv: https://arxiv.org/abs/2306.15626

## Abstract

Abstract:We introduce LeanDojo: an open, AI-first research environment for theorem proving in the Lean proof assistant, along with LeanDojo Benchmark, a large-scale dataset of formal statements extracted from real-world Lean projects. LeanDojo provides toolkits for retrieving premises from the library, interacting with the proof environment, and reproducing state-of-the-art machine learning methods for theorem proving. Our retrieval-augmented language model (ReProver) achieves state-of-the-art on LeanDojo Benchmark, and we show that premise retrieval is a key bottleneck for theorem proving with LLMs: ReProver outperforms GPT-4 on the benchmark despite using a much smaller model, which highlights the importance of retrieval in theorem proving. LeanDojo is publicly released, with a Python toolkit, reproducible data, and a web interface.
