# [2403.14064] Lean4Lean: Verifying a Typechecker for Lean, in Lean

- arXiv: https://arxiv.org/abs/2403.14064

## Abstract

Abstract:We present a verified typechecker for a substantial fragment of the Lean 4 dependent type theory, implemented and verified entirely within Lean 4 itself. The verification covers the core typechecking algorithm — the trusted kernel that all proofs in Lean ultimately rely on — demonstrating that a typechecker for the theory can be proved correct inside the theory itself. This self-verification (bootstrapping) result strengthens the case for the soundness of Lean's trusted computing base: the kernel's correctness is itself machine-checked in Lean.
