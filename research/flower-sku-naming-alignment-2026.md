# 采购命名对齐调研：花材 SKU 规范基础（ERP 物品库 + 采购平台命名对齐）

> 调研日期：2026-08-30 · 调研人：数据调查员（子代理）
> 目标：为花店 10 店矩阵 SKU 规范制定提供基础——调研鲜切花行业命名惯例与花伍批发 / 阿里巴巴 1688 / 淘宝三平台的商品命名方式，产出多平台命名对齐方案，支撑 ERP 物品库命名与采购平台商品名映射。
> 方法：web_search 9 次（中英双语、拍卖标准/行业惯例/平台规则/实际商品页多信源）+ 关键页面全文抓取 6 组，交叉验证后成文。

---

## 结论（SKU 字段结构草案）

**核心结论：国内鲜切花无全国统一官方分级标准，行业实际通行「品种 + 颜色 + 等级 + 枝长 + 每扎支数 + 单位」六要素命名，等级体系以昆明花拍（KIFA）A/B/C/D/E 为事实基准但各批发商/平台微调；三平台（花伍/1688/淘宝）商品名都覆盖同一套要素，差异仅在「结构化字段 vs 标题文本」的呈现方式与 B 端/C 端词汇侧重。**

由此得出 SKU 规范设计原则：

1. **等级与枝长解耦存储**：不同批发商对同一等级的长度区间定义有差异（A 级 60-80cm 或 ≥70cm 并存），SKU 必须同时存 `grade` 与 `stem_length_cm` 两个独立字段，采购匹配时按 (品种+等级+规格) 而非单看等级。
2. **品种 canonical 化 + 别名表**：以拍卖/行业品种名为标准名（卡罗拉、戴安娜、蜜桃雪山…），把「红玫瑰」「红玫卡罗拉」等俗名/平台词维护进别名表，避免一花多名导致重复建 SKU。
3. **平台呈现差异不影响底层结构**：B2B（花伍/1688）用结构化字段+等级驱动，B2C（淘宝）用场景词+卖点驱动；ERP 物品库只存结构化字段，标题/卖点作为平台模板在发布层生成。
4. **单位归一**：采购基本单位统一为「扎」（玫瑰类 20 枝/扎、百合 10 枝/扎为行业高频惯例），保留 `pack_qty`（每扎支数）与 `weight_kg`（估重，运费核算用）字段。
5. **一 SKU 多供应商**：同一逻辑 SKU 挂多个供应商采购映射（平台+商品名关键词），价格按供应商独立记录。

**草案字段（详见 §SKU 规范草案）**：`sku_code / flower_variety(标准品种名) / variety_alias(别名) / category(类目) / head_type(头型) / color(颜色) / grade(等级) / stem_length_cm(枝长) / pack_qty(每扎支数) / unit(单位) / weight_kg(估重) / origin(产地) / supplier_refs(平台映射) / retail_sku(零售关联)`。

## 花材命名惯例（品种 / 等级 / 规格 / 单位）

### 1. 等级体系（交叉验证一致）

- **无全国统一官方鲜切花分级标准**；行业实际通行 A/B/C/D/E 五级（部分批发商再加 O 级等外），源自昆明斗南/花拍体系（[花礼网等级区分](https://www.hua.com/huayu/20303.html)、[花比三家-等级标准](https://www.huaxianpai.com/about/17)）。
- **KIFA 官方标准**：2013 年昆明国际花卉拍卖交易中心发布《鲜切花拍卖产品质量等级》第 1 部分通用要求 / 第 2 部分单头月季 / 第 3 部分非洲菊 / 第 4 部分单头香石竹四项标准（[云南网报道](http://culture.yunnan.cn/system/2021/11/26/031788663.shtml)）；2021-11 公布「鲜切花电商产品质量等级」企业标准，加强采后处理/病虫害/瓶插期评级、放宽枝长要求，已用于 KIFA 与盒马鲜生等电商供应链。
- **评级维度**：整体感、花头饱满度/开放度、花色（焦边/变色）、枝干（粗细/挺直/弯颈）、叶片（均匀/光泽/褪绿）、病虫害/药害/机械损伤缺陷比例。
- **玫瑰枝长区间（不同来源有差异，按品种特性浮动）**：

| 等级 | 花礼网口径 | 花比三家口径 | 缺陷比例红线 |
|------|-----------|-------------|-------------|
| A | 花茎 ≥70cm，无弯颈 | 60-80cm（按品种） | ≤5% |
| B | 50-70cm，允许轻微弯曲 | 55-70cm | ≤10% |
| C | ≥40cm（卡罗拉/黑魔术/影星/老香槟/水蜜桃 ≥60cm） | ≥40cm | ≤20% |
| D | ≥35cm（同上品种 ≥50cm） | 低于 C | ≤30% |
| E | ≥30cm（同上品种 ≥41cm），等外级 | 花头中小、枝条 40cm 左右 | — |

> 注：多头玫瑰按 1 头以上计多头，断头属正常；AB 级需茎基部 10-15cm 去叶去刺（[花比三家](https://www.huaxianpai.com/about/17)）。百合按花苞长度评级（A 主花苞 8-10cm、B 7-8cm、C ≥7cm）且与成熟度无关。

### 2. 品种命名惯例

- **品种名 + 俗名并存**，批发价格表常见「品种(俗名/颜色)」写法：卡罗拉(红玫瑰)、黑魔术(黑玫)、白玫瑰(坦尼克)、粉玫瑰(艳粉)、蜜桃雪山(香槟色)、戴安娜(粉色)、海洋之迷(浅紫)、芬得拉(乳白)（[昆明种花人鲜花批发网实测价格表](http://www.xhpfw.com/search/)）。
- **头型前缀**：单头 / 2头 / 3头 / 多头（西伯利亚2头/3头/多头、索邦单头/2头/3头/多头、梯伯2头/3头），用于百合、康乃馨、部分玫瑰。
- **颜色**：品种决定基准色，但同品种存在色系变体（爱莎 粉红边、诱惑 花边），需独立颜色字段。

### 3. 规格 / 单位惯例（批发网实测字段结构）

昆明种花人鲜花批发网价格表（真实采集，字段完整）列结构为：**花卉名称 | 颜色 | 单位 | 估重 | 枝长 | 等级 | 价格（按等级梯度）**，实例：

## 三平台命名结构对比表

| 维度 | 花伍批发（B2B，花店进货） | 阿里巴巴 1688（B2B） | 淘宝（B2C） |
|------|--------------------------|---------------------|------------|
| 平台定位 | 鲜花批发/花店货源 App（云南花伍科技，年交易近 8 亿、日销 10 万扎） | 综合 B2B 批发市场，鲜花类目含云南/斗南基地直发商家 | B2C 零售，鲜花类目属「鲜花园艺」行业 |
| 商品命名形态 | 结构化字段为主：品种+颜色+等级+规格（枝长/每扎支数）+产地；等级 A/B/C 明示 | 标题（30字/60字符）+ 类目属性字段双轨；标题=核心产品词+等级+规格+产地+服务词 | 标题（30字/60字符）场景词驱动：场景+品种+数量+卖点+配送服务；等级信息弱化（多用「高品质/大花头」） |
| 标题/命名要素 | 品种名（含俗名）、颜色、等级、枝长、每扎支数、单位、价格档 | 核心词（品种）+ 规格 + 等级 + 产地（云南/昆明/斗南）+ 服务词（一件代发/基地直发/包邮） | 场景词（表白/生日/七夕/同城配送）+ 品种 + 支数 + 成品形态（花束/花盒）+ 卖点 |
| 典型命名实例 | 卡罗拉(红玫瑰) 红 A级 45-90CM 20枝/扎（批发表格式） | 「红玫卡罗拉鲜花一件代发昆明基地直发」（[黄页88采集](http://wap.huangye88.com/shop5417n82hc4966/product_16066178.html)）；批发站标题如「云南鲜花 玫瑰花 卡罗拉 20枝/扎 鲜花直发」 | 「鲜花速递 玫瑰花束 20枝 表白生日礼物 同城配送」类 |
| 平台规则要点 | 无公开命名规则文档；遵循行业惯例（推断） | 标题限 30 字（汉字 2 字符/英文数字 1 字符）；禁关键词堆砌、禁多品类混排、禁错别字/拼音作弊、标题须与商品属性一致（[1688标题规范](http://www.fywlcn.com/mobile/show-565.html)） | 鲜花园艺有专门行业管理规范，2024-02-01 / 04-01 类目调整生效（[类目调整通知](https://www.yuque.com/xgz5ze/gdzlhw/ryzc6df02ptdecvt)）；标题禁极限词/违禁词、须与主图详情一致；商品信息合规性约束（[淘宝官方课堂](https://jianghu.taobao.com/detail/58626050)） |
| 等级表达 | 明示（A/B/C 分档报价） | 明示（A级/B级 常见于标题与属性） | 弱化（B2C 信任语境，等级争议大，转用「高品质」等描述） |
| 对 SKU 的意义 | 字段可直接映射 ERP（品种/颜色/等级/枝长/每扎/单位全齐） | 标题需解析出品种+等级+规格词；属性字段若可得则结构化 | 标题需剥离场景词/卖点词后提取品种+数量；等级不可靠 |

**三平台共性**：底层要素集一致 = 品种 + 颜色 + 等级 + 规格（枝长）+ 数量（每扎支数）+ 单位；差异只在结构化程度（B2B 强 / B2C 弱）与词汇侧重（B 端采购词 vs C 端场景词）。

## 命名对齐映射规则

### 1. 一花多名 → 别名归一（核心规则）

同一花材在三平台的叫法差异 → 全部归一到 canonical 品种名 + 别名表：

| Canonical 品种名 | 花伍/批发别名 | 1688 标题词 | 淘宝标题词 |
|-----------------|--------------|------------|-----------|
| 卡罗拉 | 红玫瑰、卡罗拉(红玫瑰) | 卡罗拉红玫瑰、红玫卡罗拉 | 红玫瑰、玫瑰花 |
| 坦尼克 | 白玫瑰、白玫瑰(坦尼克) | 坦尼克白玫瑰、白玫瑰 | 白玫瑰 |
| 芬得拉 | 乳白玫瑰、芬得拉 | 芬得拉 | 白玫瑰/奶白玫瑰 |
| 艳粉 | 粉玫瑰、粉玫瑰(艳粉) | 艳粉玫瑰、粉玫瑰 | 粉玫瑰 |
| 戴安娜 | 粉色玫瑰、戴安娜 | 戴安娜玫瑰 | 粉玫瑰 |
| 蜜桃雪山 | 香槟色玫瑰、蜜桃雪山 | 蜜桃雪山 | 香槟玫瑰 |
| 黑魔术 | 黑玫、黑魔术(黑玫) | 黑魔术黑玫瑰 | 黑玫瑰 |
| 海洋之歌 | 紫玫瑰、海洋之歌 | 海洋之歌 | 紫玫瑰 |
| 西伯利亚 | 百合-西伯利亚2/3头/多头 | 西伯利亚百合 | 白百合 |

规则：**颜色词/俗名词不建新 SKU**，只进别名表；品种名（含头型后缀）才是 SKU 唯一键。反向：采购平台商品名 → 先剥离平台噪声词（1688：批发/直发/一件代发/包邮/基地；淘宝：速递/礼物/表白/生日/同城配送/花束/花盒）→ 再查别名表 → 命中品种。

### 2. 等级对齐

- ERP 枚举：`A / B / C / D / E / O(等外) / EC(电商级)`，其中电商级（KIFA 2021 电商标准）单列。
- 因来源间等级定义微调，**同一 SKU 采购不同供应商时允许 grade 相同但 stem_length_cm 不同**（如 A 级 60-80cm vs ≥70cm），采购匹配条件 = `flower_variety + head_type + grade + stem_length_cm 区间 + pack_qty`。
- 淘宝 C 端「高品质/大花头」类描述不可映射等级 → 标 `grade=UNKNOWN`，采购询价时人工确认。

### 3. 规格/单位归一

| 平台表达 | 归一字段 |
|---------|---------|
| 20枝/扎、20支/扎、20支 | pack_qty=20, unit=扎 |
| 10枝/扎（百合/非洲菊） | pack_qty=10, unit=扎 |
| 1枝/扎（绣球） | pack_qty=1, unit=扎 |
| 若干枝/扎、一把 | pack_qty=NULL, unit=把 |
| 公斤/斤计价（草花） | unit=公斤，pack_qty 不适用 |
| 45-90CM、40-80CM、50公分左右 | stem_length_cm 存区间 [40,80] |

### 4. 零售成品关联

B2C 成品（花束/花盒）是组合品，不直接映射单一花材 SKU；ERP 设 `retail_sku` 关联到花材 SKU 清单（BOM），采购需求由零售计划反推花材采购量。

## SKU 规范草案（字段 + 示例）

### 字段结构（可落 ERP 物品库）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| sku_code | string(20) | 层级编码，唯一 | RO-CAR-S-A-60-20Z |
| flower_variety | string | 标准品种名（canonical） | 卡罗拉 |
| variety_alias | string | 别名表（逗号分隔，采购匹配用） | 红玫瑰,红玫卡罗拉 |
| category | enum | 类目：玫瑰/百合/康乃馨/非洲菊/绣球/洋桔梗/配花/配叶/草花 | 玫瑰 |
| head_type | enum | 头型：S(单头)/M(多头)/2H/3H/NA | S |
| color | string | 标准色板色名 | 红 |
| grade | enum | A/B/C/D/E/O/EC/UNKNOWN | A |
| stem_length_cm | string | 枝长区间 | 40-60 |
| pack_qty | int | 每扎支数 | 20 |
| unit | enum | 扎/支/束/公斤/把 | 扎 |
| weight_kg | decimal | 估重 kg/扎（运费核算） | 1.2 |
| origin | string | 产地 | 云南斗南 |
| supplier_refs | json | 平台映射：[{platform, supplier, title_keywords, url, price_tier}] | 见下 |
| retail_sku | string | 零售成品 SKU（BOM 关联，可空） | BQ-ROS20 |

### 编码规则

`{类目2位}-{品种3-4位}-{头型1位}-{等级1位}-{枝长档2位}-{数量}{单位1位}`

- 类目：RO=玫瑰 LY=百合 KN=康乃馨 FJ=非洲菊 XQ=绣球 YJ=洋桔梗 PH=配花 PY=配叶 CH=草花
- 品种码：品种名拼音/英文缩写（CAR=卡罗拉、TNK=坦尼克、FDL=芬得拉、YY=艳粉、DAN=戴安娜、MTXS=蜜桃雪山、HMS=黑魔术、HYZG=海洋之歌）
- 枝长档：40=40-60cm、60=60-80cm、80=≥80cm、XX=不定
- 单位：Z=扎、ZHI=支、KG=公斤、BA=把

## 不可得标注

1. **花伍平台内部商品字段结构**：无公开 API/开发者文档/命名规范，App 内商品字段（是否强制等级、是否含产地属性等）不可得 → 命名惯例按「其 B2B 花店货源定位 + 行业批发表共性」推断，落地前需在 App 内实测 10-20 个商品页验证字段集。
2. **淘宝/天猫鲜花园艺行业管理规范全文**：语雀类目调整通知为 SPA 无法抓取正文，仅获类目调整时间线；具体条款需商家后台登录查看 → 标注待补。
3. **1688/淘宝鲜花类目完整属性字典**：类目属性（品种/等级/规格是否必填、枚举值列表）未获取 → 建议对接平台类目 API 或抓取属性页补充。
4. **KIFA 官网新闻页抓取失败**（fetch failed），电商等级标准细节以云南网报道为准，标准全文需向 KIFA 索取。
5. **等级标准不一致性本身**（花礼网 A≥70cm vs 花比三家 A 60-80cm）：非笔误而是行业现实——不同批发商对同一等级长度定义不同，已通过「等级/枝长解耦存储」在 SKU 设计中规避。
6. **每扎支数与枝长高频值**基于单一批发网（种花人）实测，样本覆盖 100+ 花材但来自一个商家；多商家交叉样本建议后续从花伍/1688 各采集 50+ 商品页补充验证。
