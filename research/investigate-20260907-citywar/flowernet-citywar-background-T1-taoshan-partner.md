## 一、制度存在性结论（真/伪/查无）

**「城市合伙人」作为淘宝闪购/淘宝买菜官方制度名：公开面查无——但实体制度真实存在，官方称谓是「城市经营伙伴 / 城市合作商 / 城代」。结论：「真·存在，但名称与形态与内部妙记不符」。**

| 维度 | 公开面证据 |
|---|---|
| 官方制度实体 | ✅ **存在**。淘宝闪购运营主体为拉扎斯系（饿了么），官方商户协议定义「部分区域的城市合作商」，附件六《城市合作商商户服务与责任清单（适用于城市合作区域商户）》专列其市场开发 / 商户入驻 / 配送等 14 项职责 |
| 峰会与生态 | ✅ **存在**。2026-05 杭州「淘宝闪购城市经营伙伴峰会」（上线一周年，「重构」主题），CEO 雷雁群、城市经营伙伴业务中心负责人黄辉出席；宣布合作模式「从行政地理边界划分，发展至城市、高校、乡镇等多生态模式」 |
| 官方系统 | ✅ **存在**。「城盟」系统 = 为城市经营伙伴打造的专属 AI 智能体（2026-06 起赋能数据洞察 / 智能调度 / 营销算法等产品工具）；另有服务商 AI 工作台「闪购助手」（四层架构） |
| 官方招聘 | ✅ **存在**。饿了么官方人才网（talent.ele.me）在招「淘宝闪购-城代业务经理」（新疆 / 江西等）——「城代」是平台侧管理该体系的正式岗位术语 |
| 制度谱系 | 饿了么 2015「找 1000 个城市代理」→ 2023「饿了么城市经营伙伴峰会」→ 2025-2026 淘宝闪购沿用。「城市合伙人」一词系本地生活行业通用渠道称谓（美团点评 2016 亦用过），**非淘闪官方文档用语** |
| 淘宝买菜 / 淘菜菜 | ❌ **查无城市合伙人制**。公开形态为社区团购团长制 + 网格仓 / 配送站加盟 + 地推自营 + 产地仓（云南交投产地仓等），无「城市合伙人」层级 |
| ⚠️ 重大风险信号 | 湖南日报 2025-11-12 报道：60 余商家被以「入驻淘宝闪购」名义收取「招商费/保证金」骗走超 140 万元（涉鑫智达、湖南即时京选、长沙即时优选等公司，鑫智达已列经营异常）；**饿了么商家中心 2025 年 9 月官方声明「淘宝闪购从未以线下收款形式向个人收取入驻费、代运营费」**。即：以「淘闪招商会 / 城市合伙人名额」名义线下收钱的公开记录里，全部是诈骗与第三方冒名 |

## 二、公开资质清单（若查到）

官方只公开到「服务商准入」层面，**城市经营伙伴 / 城市合作商的具体资金门槛未公开**：

**服务商准入（《淘宝闪购服务商管理规范》2025V1，官方）**
1. 【独立法人】经工商注册登记成立且存续、具备一定注册资本的合法法人主体
2. 【运营经验】具备相关行业 O2O 平台代运营经验
3. 【服务能力】配备与服务商户数量匹配的服务人员，建立较全面的信息系统
4. 【无清退记录】主体及关联公司无被淘宝闪购平台清退的记录
5. 【其他】特定类型 / 行业商户的服务商另设单独准入标准
6. 保证金：「服务商在入驻时，或为特定行业商户提供运营服务时，应当根据淘宝闪购要求缴纳一定金额的服务保证金……具体保证金缴纳标准以各行业规定为准」

**城市合作商**：官方协议仅列职责义务（市场开发、商户资质搜集审核、签约指导、信息公示核查、价格检查、培训、商业推广、营销活动、代运营、区域配送、费用收取等 14 项），**无任何注册资本 / 存款 / 流水 / 社保数字公开**。

| 妙记（内部） | 公开面 | 判定 |
|---|---|---|
| 制度名「城市合伙人」 | 官方称「城市经营伙伴 / 城市合作商 / 城代」 | 名称不符，实体对应物存在 |
| 实缴资本 200 万 | 查无官方出处；服务商规范仅「具备一定注册资本」 | **查无** |
| 存款 400 万 | 查无任何公开来源 | **查无** |
| 流水 800 万 | 查无任何公开来源 | **查无** |
| 社保要求 | 查无（仅要求「人员配置与服务商户数匹配」，无社保数字） | **查无** |
| 花颜选频道 | 三轮多查询检索零命中 | **查无公开对应物** |
| 甄选仓（每城名额 / 60 名额） | 查无淘宝体系对应；行业存在「闪电仓」（仓店一体模式，非此名） | **查无**，警惕与「闪电仓」混淆 |
| 官方平台内真实存在频道 | 「全能超市」频道（官方商户协议附件七：闪购自营运营的频道页，商品圈选展示 + 智能购物车同品替换） | 存在，疑似招商话术「移花接木」的对象 |

**综合判定**：资质四件套（实缴 200 万 / 存款 400 万 / 流水 800 万 / 社保）+「甄选仓 60 名额」的卖点结构，与湖南日报曝光的骗局话术特征（名额有限、现场签约、保证金变服务费）高度同构；也可能是平台 BD 线下定向招商的非公开门槛。**公开面零证据，无法确认为官方公开制度**——按「无证据即存疑」处理：citywar 蓝图不得把该数字当官方事实引用，需先做内部实证（原始妙记信源 / 平台 BD 口径）。

## 五、招商费诈骗风险（重点警示）

**官方媒体实锤报道 + 平台官方声明，构成对「淘闪城市合伙人/招商名额」类线下收费的高危定性。**

- 湖南日报 2025-11-12《警惕诈骗新套路——入驻"淘宝闪购"交"招商费"》：长沙雷先生被「湖南鑫智达供应链有限公司」以淘闪线下招商名义收 2.28 万「保证金」（合同写为运营服务费）；已有 60 余人同鑫智达 / 湖南即时京选 / 长沙即时优选签订类似合同，金额超 140 万元。骗局套路：营销电话邀约「招商会」→ 主讲 PPT 打「万能的淘宝」旗号 →「名额有限 / 现场签约」制造紧迫 → 保证金变相转「招商费 / 服务费」。鑫智达已因未在登记住所经营且失联被芙蓉区市监局列入经营异常名录。
- 饿了么商家中心 2025 年 9 月发文：「淘宝闪购」从未以线下收款形式向个人收取入驻费、代运营费等。
- 行业对照：IT 之家 2025-04 报道美团声明「有偿入驻 / 加盟美团闪购」等活动均为诈骗——「城市合伙人 / 加盟名额」收费是即时零售行业高发诈骗模板，平台官方均不公开售名额。
- 官方协议亦明文禁止：服务商「不得使任何第三方误认为服务商与淘宝闪购之间存在任何雇用、代理、合资关系」；城市合作商「不得以任何名义向商户及用户收取平台规则以外的费用」。
