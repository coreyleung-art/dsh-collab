## A 类：内容技巧（怎么写）

### A1 标题公式（P0：悬念缺口/数字承诺/痛点人群/对比反差/组合拳）
10 条公式：悬念缺口/数字承诺/痛点人群/身份反差/时间反转/对比反差/热点借势/承诺确定/符号借势/组合拳——详见 A 报告（各带示例与字段）。

### A2 开篇钩子（P0：故事钩/数据钩/提问钩）
7 种：故事/冲突/数据/提问/承诺/断言/场景；知乎盐选「第一人称+300 字爆炸点+黄金三步法」实测高适配。

### A3 结构模板（P0：清单式/干货论证式/问答式）
5 式：清单（公众号专题）/故事/干货论证（知乎长文）/对比/问答（知乎原生）——与管线「母稿/平台稿」设计对齐。

### A4 平台调性（7 平台对比）
公众号 1000-3000 字/标题 13-20 字；知乎 2000-4000 字问题导向；小红书 ≤1500 字/标题 ≤20 字前 10 字放关键词；B站/抖音/视频号三期视频平台 P2。

### A5 情绪触发（5 机制+边界）
共鸣/好奇/爽点/焦虑/归属感怎么用；附微信标题党 5 类红线（混淆官方/煽动蛊惑/夸大误导/公众人物负面/对抗）——与「不虚构+脱敏」安全垫一致。

## B 类：发布工具（怎么发）

### B1 多平台分发（P1：OpenWrite 首期）
OpenWrite（免费/Markdown/公众号+知乎）适配最高；蚁小二/易媒免费档备选（注意第三方授权风控）；爱发狗无可靠近期源不采信。

### B2 定时发布（P0：公众号官方定时群发）
公众号官方定时零成本零风险；知乎无官方定时；最佳时段经验值：公众号晚 20-22、知乎午 12-13/晚 20-23（需自测校准）。

### B3 数据回收（P0：官方后台周度台账）
公众号/知乎/小红书个人创作者均无开箱导出 API → P0 官方后台手动周度台账 reports/metrics-log.md；新榜/灰豚 P1-P2。

### B4 CMS（P0：本地 Markdown+Git+Notion/飞书）
管线已有 drafts/ 目录 + Git 版本管理；Notion/飞书作检索层；WP/Ghost P2（与图文场景错配）。

## C 类：AI 插件/自动化（怎么自动化）

### C1 内容生成 Agent（P0：扣子+Dify 双轨）
扣子（已接 coze-bridge；按积分消耗决定留档，免费/进阶先跑原型）+ 本地 Dify（数据可控）双轨；公众号个人订阅号无发布 API → 自动生成草稿+人工审核发布（与管线硬性审核一致）；OpenClaw/n8n P1。

### C2 热点抓取自动选题（P0：今日热榜 API）
DailyHotApi/tophub-api（免费开源，Vercel+RSS）→ 每日定时 → LLM 过滤 → topic-backlog；RSSHub P1；百度指数无官方 API P2。

### C3 AI 配图（P0：通义万相 ~0.14 元/张）
通义万相 API + 即梦免费积分；本地 SD（PC-i9 4060Ti 实测可跑）免费兜底 P1；Midjourney P2（成本/商用条款）。

### C4 视频生成（P2：二期参考）
剪映 SVIP（活动约 16.8 元/月）最顺手起步；可灵/即梦为能力标杆。

### C5 账号矩阵（P2：首期单账号不需要）
二期扩矩阵：蚁小二免费档 + 指纹浏览器（AdsPower/比特）最小授权试水；主账号密码不托管。
