## WF-1 · CLD/dsh 底层安全改动流（核心）

```
① guard backup <target>          备份（最后 2 个 good 态滚动）
② guard check-writable <target>  不可写门禁（红线即停）
③ guard version-check            确认目标版本（依赖改动时）
④ 在 /tmp 沙箱副本验证            语法/解析/补丁效果
⑤ 落真                           实际修改
⑥ guard review <target>          物理审查（语法/权限/链接/加载）
⑦ 重启 + 实测                     dump-config EXIT0 + web 200 + 点会话 + 历史加载
⑧ send-repair-report 报告         留痕
```
**产出**：guard/tools/guard（已实现 backup/check-writable/version-check/sandbox/review）

## WF-2 · 依赖一致性修复（pnpm 事故恢复）

```

⑥ 系统化清理：全部 @deepseek-ai 旧包
```

## WF-3 · 品牌插件套壳

```
① 建 ~/dsh-plugin-<name>/：package.json + cordis.patch.yml + lib/{index,client}.js
   - package.json 需 dsh.bundle.patch + dsh.client（含 inject+platform web）
   - exports 用 {default: ...} 条件对象
   - host index.js：空 apply（export {apply}）
   - client.js：__ModuleLoader__.load({factory}) 格式
② 注册 slot：priority:-1 shadowing（sidebar.brand.mark/name, hero.brand.mark）
③ 组件返回 React.createElement（勿手写 {type,props}）
④ 接入 profile：package.json deps link + bundles 追加 + node_modules symlink
⑤ 重启验证：蓝点替换 = shadowing 生效
⑥ 填真实设计（SVG viewBox 自适应 size 24/34）
```
**参考**：dsh-plugin-my-brand（已在 Mac mini 验证运行）

## WF-4 · 远程故障诊断

```
① mDNS 发现 + SSH 免密（dns-sd -B _ssh._tcp → ssh）
② 看日志：~/.cld/logs/dsh-web.log（boot 段/exit-trace/GC）
③ renderer 错误：--enable-logging=stderr 重启抓 console
④ doctor 会话数：判断数据层健康
⑤ 进程/端口/内存：ps/lsof/vm_stat
⑥ 版本对比：profile vs runtime @deepseek-ai
```
