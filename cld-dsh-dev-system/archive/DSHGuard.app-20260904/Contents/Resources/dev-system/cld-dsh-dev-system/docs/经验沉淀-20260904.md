## 一、OOM 崩溃链（6 次 SIGABRT）

### 现象
CLD 反复 `JavaScript heap out of memory`，启动 3-13 分钟崩溃。

### 根因（三层叠加）
1. **dsh 侧**：打开会话 = 整文件 zstd 解压 + 全量事件驻留（137MB 会话 → 数 GB）
2. **CLD 壳侧**：看门狗只看主进程退出 → 子进程 OOM 被记 clean exit（信号失真）
3. **环境侧**：auto-index 每日 04:30 全量重建 ChromaDB 吃 4-13GB

### 关键认知（纠正了 2 个错误假设）
| 假设 | 真相 | 证据 |
|---|---|---|
| NODE_OPTIONS 扩堆有效 | **无效**——Electron packaged 白名单仅放行 HTTP 选项 | 官方文档 + GC 恒 4001MB |
| 62261 稳定=堆扩容生效 | 假象——那段时间没人开多会话 | 回查 GC 也是 4001MB |

### 正确方向
- 帧索引（会话历史可分页，磁盘扩内存）——用户模型落地
- Electron crashReporter + 内存采样接入
- auto-index 改流式/限内存

### 教训
**不要靠"调参扩堆"解决内存问题**——先确认官方限制（NODE_OPTIONS 白名单），再找架构解法。

## 二、pnpm 破坏事故（最痛的一次）

### 现象
想用 `dsh plugin add` 正规安装 my-brand → pnpm 重写 profile 依赖树 → 连环故障：dsh-gov schema 崩溃 → knowledge-tools 误装 → reference pending → 会话列表空 → 历史加载失败。

### 根因
**pnpm 把大量旧版 @deepseek-ai peer 包（rc.6/rc.7）装进 profile node_modules，遮蔽了 runtime 的正确版本（rc.2）**。profile 解析优先就近 → 全部用了错误版本。

### 破坏清单（按发现顺序）
1. gov 加到 bundles（本不该在）→ schema.required 崩溃
2. knowledge-tools/office/gate 误装
3. file-reference remote 桥接断 → reference pending
4. client-runtime rc.6 → abbreviateHomePath undefined → sidebar 崩 → 会话空
5. dsh-session rc.7 → 历史加载 .parse undefined

### 修复模式（验证有效）
**移除 profile 里 @deepseek-ai 旧包 → 解析回落到 runtime rc.2**（`.bak-*` 保留可回滚）。逐个移 + 重启验证，最后系统性清。

### 教训（最高优先）
1. **改 profile 依赖永远先备份 package.json + pnpm-lock + node_modules 清单**
2. **优先用 dsh plugin 官方命令，但理解它会重写整个依赖树**
3. **改完必须 dump-config + 重启 + 会话/历史实测**，不是只看 boot 通过
4. **@deepseek-ai 包版本以 runtime 为准，profile 不应自装遮蔽版本**

## 三、品牌套壳（成功）

### 过程
禁 ui-brand-official → fallback "DSH Local Build" → 改 priority:-1 shadowing → client.js 格式踩坑（ESM export → __ModuleLoader__.load）→ React 元素踩坑（{type,props} → createElement）→ 成功蓝点替换鲸鱼。

### 关键技术点
1. **禁用触发 fallback**（sidebar 渲染 "DSH Local Build"）→ 必须 shadowing（priority:-1 < 官方 0）
2. **client 插件必须 `__ModuleLoader__.load({factory})` 格式**（非 ESM export）
3. **client 组件必须返回合法 React 元素**（React.createElement，非手写对象）——否则 slot 崩连带界面
4. **尺寸自适应**：SVG + viewBox，宿主传 size 24/34 自动缩放
5. **hero 文案**（hero.headline/preview）是 locale key 非 slot → 只能 CSS 或改 locale

### 教训
**client 插件是浏览器环境**——格式/React 契约与 host 完全不同，先做最小探针（改 document）验证 apply 执行，再上完整逻辑。

## 四、界面修复链（会话消失 → 恢复）

### 现象
会话列表空 / 历史加载失败。

### 根因
全是 pnpm 装错的 @deepseek-ai 旧包：
- client-runtime rc.6 → abbreviateHomePath undefined → sidebar workspaces 崩
- dsh-session rc.7 → history .parse undefined

### 修复
移除 profile 旧包 → 回落 runtime rc.2 → 逐个验证。

### 教训
**界面"什么都不显示"时先看 renderer console（--enable-logging=stderr）**——比猜快得多。

## 五、方法论沉淀

### 高效诊断手段
1. `--enable-logging=stderr` 抓 renderer console（浏览器端错误）
2. `dump-config` 验证 loader 树
3. doctor 会话健康数字
4. 版本对比（profile vs runtime）
5. mDNS + SSH 远程运维

### 高效验证手段
1. 最小探针（改 document 背景/title）确认 apply 执行
2. 逐个移除变量（二分）定位根因
3. 每次改动重启实测（非只看 boot）
