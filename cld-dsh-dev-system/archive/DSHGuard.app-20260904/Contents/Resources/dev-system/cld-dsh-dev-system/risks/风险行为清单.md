## 🔴 P0 · 高危（曾致系统性故障）

| # | 危险行为 | 实证后果 | 正确做法 |
|---|---|---|---|
| R1 | 直接跑 `pnpm install/add` 改 profile 依赖 | 重写依赖树，旧版 @deepseek-ai 遮蔽 runtime，连环崩（gov/reference/会话全挂） | 先备份 package.json+lock+node_modules 清单；理解会全量重装；改后 dump-config+重启+实测 |
| R2 | 手改 profile node_modules 或 package.json bundles | 误加/误删（gate/office/knowledge-tools 教训） | 只经 link 源改，bundles 改动走 diff 对比备份 |
| R3 | 用 NODE_OPTIONS 扩 CLD 堆 | 无效（Electron packaged 白名单），浪费排查时间 | 认官方限制，走帧索引/行为约束 |
| R4 | 禁用品牌插件想隐藏 logo | 触发 fallback "DSH Local Build" | 用 priority shadowing 替换 |
| R5 | client 插件用 ESM export | `loaded without registering __ModuleLoader__` | 用 `__ModuleLoader__.load({factory})` |
| R6 | client 组件返回手写 `{type,props}` | React error #31，slot 崩连带界面（会话消失） | 用 React.createElement / JSX |
| R7 | 改 runtime 官方包（@deepseek-ai/*） | API 漂移（schema DSL），改一个崩一串 | 视为升级，走完整五道闸；优先版本对齐 |
