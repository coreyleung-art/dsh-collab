# 考古治理闭环 · 方法论 v1（Arch-Act-Loop）

> mbp-ops · 2026-09-05 · 规则级方法论（与《修复规范-Lean逻辑版-v2》配套）
> 一句话：**让每一次修复/新问题都沉淀为可考古、可守护、可回归的资产，形成越治越好的正循环。**
> 工具：labforge archaeology / guard_archaeology / labforge regress / archaeology-watch（6h 主动循环）

---

## 〇、闭环全景（Arch-Act-Loop）

```
① 考古（主动循环 6h）
   扫描历史修复报告 → 按 6 大根因模式 M1-M6 归类 → 守护面缺口判定
② 评估
   每条发现带解决方案(remediation) + Lean4 门(leanGate)
③ 落地（Lean4 门把关）
   方案执行前 guard-gate/guard_compliance 五道闸 → safe_edit 才允许改
④ 守护固化
   方案落地 → 建 labforge 实验卡（断言回收标准）→ regress 纳入回归面
⑤ 沉淀
   结果自动落黑板 + 向量化(guard-recall) + 本方法论回写
⑥ 再考古
   6h 后新问题自动判定：落入已知模式(有守护) or 新缺口(触发②补方案)
```

**Lean 语义**：这个环是一个**良基递归**——每轮要么发现已被守护（termination），要么暴露新缺口并补方案（progress），不会无限空转。

## 三、纪律（对每次迭代强制）

1. **新问题必考古**：遇到未归类问题 → `labforge archaeology` 判定落入 M1-M6 或新缺口
2. **新缺口必补方案**：缺口 → remediation + leanGate 明确 → 建卡守护
3. **动生产必过门**：guard-gate/guard_compliance 五道闸（与修复规范 Lean 版一致）
4. **修完必守护**：每修复 → labforge 卡 → regress 纳面
5. **沉淀义务**：考古快照/修复报告/方法论更新 → 黑板 + 向量化（不沉淀 = 白修）

## 五、回滚与边界
