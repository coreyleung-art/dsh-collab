# GC/RSS 回缩落地设计 v1（2026-09-06）

## 三层架构(解耦)
1. 观察器: cld-monitor 加 dsh_rss 采样(消除盲区) + RSS>3GB 写 GC 许可
2. GC执行器: dsh 内注入(--require gc-timer-v2), 许可+空闲才 GC(非无脑定时)
3. 审计: gc-audit.jsonl 记录 前RSS/后RSS/耗时

## 空闲判据(实测可行)
会话文件 15s 无写入 = 空闲(fsync 落盘 mtime 硬信号)
推理中会话持续写→不触发 GC

## 部署分阶段
S1 观察(先) → S2 注入(env) → S3 调优(7天观察)
每阶段可回滚

## 验收
RSS 回缩≤1.5GB / 会话不丢(189) / GC≤300ms / 7天0事故
