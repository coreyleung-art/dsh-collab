# GC 逻辑门 guard-gc-gate（2026-09-06）

## 是什么
把 GC/内存治理操作的安全前提形式化为 Lean 门(六命题机械检查)
任何 GC 操作前: guard-gc-gate check → 全过才允许

## 六前提(实测全过 ✅)
G1 会话落盘(fsync+rollback) ✅ / G2 无GC误删回调(FR=0) ✅
G3 会话强引用(Map) ✅ / G4 阻塞预算300ms ✅
G5 仅空闲触发 ✅ / G6 RSS阈值3GB ✅

## 价值
1. GC 方案不再是"自觉安全" → 机械强制六前提
2. 防未来内存治理改动忘查安全前提
3. 会话不丢有代码级证明(落盘+强引用+无回调)
