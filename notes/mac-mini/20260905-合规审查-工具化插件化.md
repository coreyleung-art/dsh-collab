# 合规审查过程 dsh 工具化/插件化（2026-09-05）

## 扩展 dsh-plugin-guard (v0.2→v0.3)
生产插件(dsh-plugin-guard, 行id guard) 新增 2 工具:

### guard_compliance — 一键 Lean4 合规审查编排
输入: target(路径) + topic(P0主题) + operation
自动串: P2 红线 → P0 官方预查 → P1 备份 → P4 沙箱确认 → P5 有界 → pre-mortem
输出: 五道闸矩阵 + safe_edit 判定(全过=允许执行/任一不过=拒绝)
受限区写操作(如 P2-3 的 cordis.patch.yml)前调用

### guard_premortem — pre-mortem 反例模板(Q0-Q4)
动手改底层前必答: Q0官方文档锚点/Q1什么会崩/Q2什么丢会话/Q3哪项C先报警/Q4回滚点
输出作答记录 + complete 判定
