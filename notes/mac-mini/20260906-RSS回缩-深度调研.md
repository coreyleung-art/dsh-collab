# Node/Electron RSS 回缩深度调研（2026-09-06）

## 核心发现
1. V8 "不愿把内存还给 OS"是设计使然(非bug) — V2EX 共识
2. **Electron shared V8 cage**: 所有进程共享~4GB heap(dyad 实测)
   → dsh 3.6GB 逼近 cage 硬顶; 8.4GB max-old-space 可能未真正作用于 cage
3. 主动GC可行: --expose-gc 放行 + 完整GC 39ms + --require 注入成功(本地全验证)
4. jemalloc 无效(业界反馈); 重启最彻底但中断

## 方案结论
方案A(定时完整GC) = 业界共识+本地验证最优 → RSS 3.6GB 可回缩~1GB
但需先确认 cage 假设(查 dsh heap_limit 是否 4GB 硬顶)
根治需评估禁用 cage(如 --no-pointer-compression, 查 Node 版本支持)
