# mac-mini 弹网页 · 完整根因与解决（2026-09-06）

## 现象
重启/启动 CLD 后跟随弹出默认浏览器网页

## 根因（两层）
1. **非正常启动路径无 --no-open**：
   - v0.6.1 main.js 399 行已硬编码 `--no-open`（GUI 正常路径）
   - 但 auto-relaunch plist（旧, 已卸载）的参数**无 --no-open**
   - 某些启动方式（plist/残留）绕过 main.js 399 行 → dsh 收不到 no-open → 弹窗
2. **孤儿实例叠加**：81555(旧) 与 7460 并存加剧混乱

## 解决
1. 杀孤儿实例 → 单实例
2. GUI 干净启动(open -a CLD) → 8297 带 --no-open → 无弹窗 ✅
3. cld-monitor 加多实例守护
4. auto-relaunch plist 移备份区

## 验证
- GUI 启动实例 8297: 命令行含 --no-open ✅
- dsh-web.log 无 opening（URL 后直接 doctor 191）✅
- 用户确认: 当前不弹了 ✅

## 经验
- CLD 弹浏览器 = dsh 没收到 --no-open 的信号
- 正常 GUI 启动 = main.js 399 行保证带 no-open
- 非 GUI 启动路径(plist 等) 需自己带 no-open
- 排查法: ps 看进程命令行有无 no-open + dsh-web.log 有无 opening
