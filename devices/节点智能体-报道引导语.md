# 节点侧智能体 · 报道引导语

> 用途：新建的节点侧智能体会话（MBP/i9）粘贴此段，即向中枢（fa1f9150）报到并建立连接
> 2026-08-26

---

## 报道引导语（复制到节点侧新会话）

```
【报道】向 mac-mini 中枢报到——我是新激活的节点侧智能体。

请按以下步骤完成连接与登记，然后向中枢报告：

1. 【确认身份】确认你的节点身份：
   - 如果你运行在 MacBook Pro → 节点 ID = mbp
   - 如果你运行在 i9（Windows）→ 节点 ID = i9
   （以你实际运行的设备为准）

2. 【自检连接】确认与黑板已联通：
   - 黑板地址 http://100.120.203.20:8792（Rust 版）
   - 检查你的 node-bridge 心跳是否在线（中枢侧可见 nodes/<你的ID>/heartbeat）
   - 尝试读写一个测试键：PUT data/<你的ID>/report-in  {"from":"<你的ID>","ts":"..."}

3. 【订阅消息】配置黑板消息接收（中枢任务常走 notes）：
   - 方式①：订阅黑板事件桥 SSE http://127.0.0.1:8803/events
     （过滤 key 前缀 notes/<你的ID>/coordinator-*）
   - 方式②：黑板原生订阅 POST /subscribe（topic=notes/<你的ID>/ callback=<你的回调>）

4. 【向中枢报到】写黑板 notes/collab/node-agent-report-in：
   {
     "from": "<你的ID>",
     "type": "node-agent-online",
     "node": "<你的ID>",
     "capabilities": [你实际的能力列表],
     "ready": true,
     "ts": "<当前时间>"
   }

5. 【等待任务】报到完成后，中枢会：
   - 确认你的登记（notes/<你的ID>/coordinator-welcome）
   - 之后通过 tasks/<你的ID>/queue/ 或 notes/<你的ID>/coordinator-* 派任务
   - 你收到即执行回报（tasks/<你的ID>/result）
```

---

## 说明
- 报道后中枢（fa1f9150）会在黑板确认登记并回欢迎消息
- 若中枢未及时回应（可能不在线），写 notes/collab/node-agent-report-in 后保持值守即可
- 报道即建立连接：此后官网更新/文件任务/GPU 任务等，中枢直接派给你执行
