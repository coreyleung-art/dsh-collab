# 决策：本机（mac-mini）不再本地运行视觉模型

> 日期：2026-08-27 · 起因：测试 LM Studio glm-4.6v-flash 视觉模型导致设备死机重启

## 决策
**mac-mini 上禁止本地运行任何视觉/多模态模型**（LM Studio 加载视觉模型、跑 VLM 推理等）。

## 原因
- 本机内存有限（25GB），视觉模型推理（glm-4.6v-flash 等）内存压力过大 → 系统死机重启
- 视觉推理收益 vs 稳定性风险不成比例
- 已实测：LM Studio 加载 glm-4.6v-flash → 设备崩溃（load 44+ 后重启）

## 替代路径（视觉需求怎么办）
1. **订单商品推断粗标注**（零依赖）：从 IM 会话/order_sales 匹配商品名 → 花材品类推断（学习智能体已提议，立即可行）
2. **云端视觉 API**（如需精标）：用已有 DeepSeek key 或接入其他视觉云 API（成本可控、不占本地资源）
3. **i9 侧**（如有视觉需求）：i9 是 Windows + GPU，可评估 ollama 视觉模型（qwen2.5-vl 等），但需 i9 确认内存/显存
4. **OCR**：tesseract 可用（仅文字场景，花束照片无效）

## 约束生效范围
- 本会话 + 所有协作智能体（learning/运营/HR 等）：本机不跑视觉模型
- 视觉需求统一走「粗标注优先 + 云端备选」
