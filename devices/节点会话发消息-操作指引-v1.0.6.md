# 节点侧会话 · 发消息给中枢（outbox 机制）

> 版本：v1.0.6（2026-08-26）· 配套 node-bridge outbox 线程
> 解决：MBP/i9 侧 DSH 会话没有 HTTP 工具，怎么把消息发给 mac-mini 中枢？

---

## 一句话

**写本地文件 `~/.dsh/outbox/<topic>.json` = 发消息给中枢。**
node-bridge 的 outbox 线程（2s 轮询）自动把它 PUT 到黑板 `notes/<node>/<topic>`，中枢即可读到。

## 操作步骤（节点侧会话）

### 发消息（你要给中枢发什么）
```
1. 打开终端（或你有文件工具的会话）
2. 写文件：
   echo '{"from":"<你的节点ID>","subject":"<主题>","content":"<内容>"}' > ~/.dsh/outbox/<topic>.json
   （Windows 用 %USERPROFILE%\.dsh\outbox\<topic>.json）
3. 等 2 秒 → node-bridge 自动转发到黑板 notes/<node>/<topic>
4. 本地文件自动删除（转发成功）
```

### 主题命名建议
```
report-<事项>    → 汇报（如 report-website-update）
reply-<原主题>   → 回复中枢某条消息（如 reply-coordinator-test）
status          → 状态上报
request-<事项>  → 请求（如 request-help）
```

### 消息内容格式（JSON 对象）
```json
{
  "from": "mbp",          // 或 i9（你的节点 ID）
  "to": "coordinator",    // 发给中枢
  "subject": "消息主题",
  "content": "消息正文（可长文本）",
  "ts": "2026-08-26T02:55:00"
}
```
（纯文本也可以——node-bridge 会自动包成 {"content": "..."}）

## 收消息（中枢 → 你）

中枢写 `notes/<node>/coordinator-*` → node-bridge notes 线程读到打日志 → 你的会话订阅黑板事件桥（http://127.0.0.1:8803/events）实时收到。

## 验证

```
发消息后：访问黑板 http://100.120.203.20:8792/notes/<node>/<topic>
  应看到你发的 from/content
中枢侧：轮询 notes/ 会读到你的消息
```
