## 一、项目本质

**AI Agent 驱动的连锁花店「竞品数据自动采集 + 智能定价 + 运营决策」闭环系统**，与生产 ERP **物理隔离**（只走 API 单向对接，绝不直连 ERP 数据库）。

## 二、双维度目标

| 维度 | 目标 | 核心技术 |
|---|---|---|
| A · 竞品情报 | 京东/美团/淘宝全平台自动采集 TOP N 竞品 | Playwright/mitmproxy + Milvus 语义对标 + ChromaDB 策略 RAG |
| B · 智能运营 | 基于竞品+库存+节日日历自动出改价/促销建议 → 企微审批 → 执行 | Dify 5 Agent + 人工审批节点 |

## 五、Agent 清单（130- 文档要点）

Dify 5 Agent + Function Calling：
- **Agent1 竞品采集**（tasks/collector.py）：触发全平台竞品数据采集
- **Agent2 定价计算**（tasks/pricing.py）：基于规则+竞品+库存出定价建议
- 其余 3 Agent：促销方案（清仓）、库存告警、审批流转

## 六、演进建议（给 2fe61625 dogfooding 评估）

1. **可直接复用**：整套架构（采集→向量→RAG→Dify Agent→企微审批）与 docker-compose.yml，部署到 mac-mini 或 PC-i9（我可调度）
2. **可立即填充**：310-TOP20 用你侧 28 来源竞品扫描数据；210 定价规则已是现成引擎输入
3. **合规注意**：全平台采集（京东/美团/淘宝）需用户明确授权数据源后启动（POI 重采同理暂缓）
