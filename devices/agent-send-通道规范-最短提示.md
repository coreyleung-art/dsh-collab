# agent_send 通道规范 v2.1：最短提示 + 看黑板（所有智能体统一）

> 版本：v2.1 · 2026-08-27 · 升级：**对中枢同样适用**（含智能体→中枢的消息）
> 核心：非紧急通道 agent_send **只发最短提示**，内容写黑板让对方看（bb-read 本地摘要）

## 一、适用范围（关键升级）

**本规范对 ALL 智能体生效，双向适用：**
- 智能体 → 智能体：非紧急只发最短提示
- **智能体 → 中枢（fa1f9150）：同样只发最短提示**——内容写黑板 notes/mac-mini/，再发「看黑板 <key>」提醒
- **中枢 → 智能体：同样只发最短提示**——内容写黑板 notes/<角色>/，再发「看黑板 <key>」

**为什么对中枢也适用**：中枢会话上下文同样珍贵（今天 de7b29de 回报 500 字全文、4787d717 回报全文——都插入了我的上下文）。规范面前人人平等。

## 二、判定标准

| 通道类型 | 判定 | 发什么 | token |
|---|---|---|---|
| **紧急** | 需对方立即行动/决策 | 全文（≤200 字要点） | ~300 |
| **非紧急** | 状态更新/通知/待办提醒/巡检回报 | **最短提示**：看黑板 <key> | ~15 |
| **纯确认** | 对方只是确认收到 | **不回**（防确认循环） | 0 |

## 三、最短提示模板（双向）

```
看黑板 <key>（一句话提示）
```

示例（智能体→中枢）：
- 看黑板 notes/mac-mini/de7b29de-采集回报（10店恢复+京东2店登录失效+看门狗待查）
- 看黑板 data/recovery/4787d717-progress（178篇落链+3待办按需）

示例（中枢→智能体）：
- 看黑板 notes/i9/coordinator-task-34OCR（任务包就绪）
- 看黑板 data/qa/pending-20260827（9项挂起待办）

## 四、内容获取（bb-read 本地摘要）

收到「看黑板 <key>」：
```bash
dsh-tools bb-read <key>          # 摘要 ~30 token 零成本
dsh-tools bb-read --full <key>   # 需要全文才用
```

## 五、配套机制（已有）

- bb-sub 订阅器：事件驱动落盘 inbox/bb/<角色>.jsonl（主动可见）
- 黑板回报：notes/mac-mini/（中枢消费）· notes/<角色>/（对方消费）
- agent_send 仅作唤醒提醒，不承载内容

## 六、收益

- token：全文 1200 → 45（省 97.5%）——**中枢上下文同样受益**
- 可追溯：内容在黑板上（HLC 时间轴+审计）
- 防刷屏：纯确认不回
- 统一：所有智能体一套规范，无特权

## 七、执行监督

- 中枢自查：非紧急一律最短提示（之前违反的已改正）
- 各角色自查：回报写黑板 + 最短提示唤醒
- 发现违规（全文 agent_send 非紧急）→ 提醒按规范重发

## 八、版本

- v1.0：最小上下文模式（bb-read）
- v2.0：正式规范（判定标准+最短提示+纯确认不回）
- v2.1：**双向适用（含对中枢）**——智能体→中枢同样最短提示

## 九、v2.2 升级：强制规则 + 门禁（2026-08-27）

**「写黑板 + 短提醒」从建议升级为强制规则（门禁检测）：**

### 强制规则（违反=违规）
1. **回报/通知/待办提醒 → 内容必须写黑板**（notes/mac-mini/ 或 notes/<角色>/ 或 data/<域>/）
2. **agent_send 只发最短提示**：`看黑板 <key>`（≤50 字）
3. 纯确认不回（防刷屏）
4. 紧急（≤200 字含 urgent 标记）例外

### 门禁判定（agent-send-gate.py）
- **违规** = agent_send 文本 >50 字 且 不含「看黑板」且 非 urgent 且 非广播
- **合规** = 短提示 / 含看黑板 / urgent 标记 / 广播
- 违规 → 记录黑板 data/audit/agentsend-violations.jsonl + 提醒违规方

### 运行
- 手动：python3 ~/dsh-collab/scripts/agent-send-gate.py --once
- 常驻：--interval 300（每 5 分钟扫）

### 为什么强制
- de7b29de 看门狗修复回报（500 字全文未落黑板）暴露：建议式规范对部分角色无效
- 强制后：内容必有黑板记录（可追溯/审计），agent_send 只做唤醒（省 token）
