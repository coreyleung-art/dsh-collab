# 星台图片溯源调研工作流 v1（用户定案 2026-09-04）

> 触发：用户通过星台发图片（截图/照片）→ 星桥识别内容 → 溯源调研 → 回收结果
> 执行：星桥（识别+派单）→ 数据调查员 4787d717（调研）→ 星桥（回收给用户）
> 目标：把「发图—识别—溯源—完整信息」固化为可复跑工作流，不丢不散

## 一、流程五步

```
[用户发图] → [1 星桥视觉读图] → [2 提取溯源线索] → [3 派单数据调查员] → [4 调研] → [5 回收给用户]
```

### Step 1：星桥视觉读图（图已存 ~/sb-mobile/uploads/<ts>.<ext>）
- 用 LM Studio `zai-org/glm-4.6v-flash` 视觉读图（实测可用；content 空时取 reasoning_content）
- 输出：主体内容 + 文字（标题/作者/平台/时长/标签）+ 场景 + 颜色

### Step 2：提取溯源线索（判据）
| 线索类型 | 特征 | 例 |
|---|---|---|
| 平台 | App 名称/界面特征/URL | 「AI 前沿」(WOFRONTIER) |
| 标题 | 文章/视频大标题 | 「智能体的版本管理 多个智能体共享记忆」 |
| 频道/合集 | 来源账号/系列 | AI·ONTOLOGY 系列 4 集 |
| 元数据 | 时长/日期/标签 | 04:15 / SIGNAL·ATLAS·RUST +888/DAY |
| 截图特征 | 视频播放按钮/时间线/评论 | — |

### Step 3：派单数据调查员（R031 黑板通道）
- 写 `data/investigate/<topic>-<ts>` 卡：图 id + 读图结果 + 溯源问题
- 或 agent_send 短引（≤50 字）：「看黑板 data/investigate/xxx」

### Step 4：调研内容
- 溯源：标题/主题全网检索 → 找原文章/原视频/原作者（平台、URL、发布时间）
- 深挖：该主题的完整信息/核心观点/与我们项目的关联（如 comm-server 多智能体协作）
- 产出：结构化报告（来源链接 + 摘要 + 要点 + 可借鉴点）

### Step 5：回收给用户（星台回复）
- 写 `notes/mac-mini/mobile-reply/latest-main`（text=调研结论摘要 + 链接）
- 完整报告可落盘 `~/dsh-collab/research/<topic>-<date>.md` 备查

## 二、SOP 要点
- 图片本地留档：`~/sb-mobile/uploads/`（不删，溯源依据）
- 每张图一单，单据含图 id（ts 可回查）
- 调研超时：数据调查员 30 分钟无回报 → 星桥催
- 用户可指定调研重点（如「这个理念跟我们智能体网络的关系」）
