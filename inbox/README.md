# 📥 外链收件箱（inbox）

> 用户/外部资料的**零等待快路径**：把文件放到本目录，外链通讯员扫描后路由给对应会话。

## 使用方式

- **用户**：直接把文件（PDF/DOCX/XLSX/图片/文本等）拖入本目录即可
- **外链通讯员**：定期扫描本目录，识别文件后按类型路由：
  - 活动公司/财务资料 → 用户洞察（session-2fe61625）
  - 经营/运营数据 → 运营（session-aa528267）
  - 客户咨询材料 → 客服（session-b193c782）
  - 其他 → 由外链通讯员判断路由

## 约定

- 处理完成的文件移动到 `processed/` 子目录（保留溯源），不需要的放入 `trash/`
- 敏感文件注意：本目录为共享目录，凭据/密钥类文件**不要**放这里（凭据只存本机 0600 私有配置）
- 与企微通道（P0 转发式）双路并行：本目录无需等企微凭据即可用
