# 价格波动测算报告（锚定定价 + 大促库存动态抬价策略验证）

> 学习：a3bc8cba · 2026-08-23 · 数据源：order_sales（17,673 行 / 4 店 / 8 个月）
> 验证策略：原价=锚定价（心理参照）→ 折扣价=日常竞争收单价 → 大促按库存动态抬升回原价

## 一、策略模型（用户设定，数据验证）

```
原价（锚定）─高─→ 折扣价（日常竞争收单）─大促─→ 一级级抬升回原价
   ¥282-403        ¥70-90（折扣率 27-29%）     峰值 ¥120-129（38-47%）
```

## 二、锚定折扣结构（全店 8 个月）

| 指标 | 值 |
|---|---|
| 商品级平均折扣率（实付/原价） | **29.3%** |
| 订单级平均折扣率 | 29.3% |
| 常见折扣率区间（样本集中） | **20-33%**（大量样本在 20-31%）|
| 原价/实付倍数 | **约 3.4 倍**（¥282 原价 vs ¥74 实付）|

**锚定效应**：原价约为成交价的 3.4 倍——心理参照强烈（顾客看到"¥282 打 2.6 折"的锚定感）。

## 三、日常 vs 大促 价格对比（核心验证）

| 时段 | 平均折扣率 | 均实付 | 样本 |
|---|---|---|---|
| **日常** | **28.2%** | ¥70-80 | 15,891 |
| **大促日**（七夕/520/214/38） | **39.7%** | ¥120-129 | 1,782 |

**结论**：大促折扣率比日常高 **11.5 个百分点**——**大促确实抬价**（折扣收窄 11.5pp = 提价约 40% 幅度），验证"向原价回归"策略。

## 八、策略有效性评估

### 有效（数据支持）
1. **大促抬价不降量**：8/19 折扣率 47% 但实付 ¥76,895（日常 6-8 倍）——高价高量并存
2. **爆款稀缺定价极致**：KT猫系列 65.9% 折扣率仍 103 行（日常 4 倍）——锚定心理生效
3. **阶梯节奏**：前 1-2 天日常价蓄客 → 大促当天抬价收割 → 次日回落
4. **日常竞争价稳定**：28% 左右保持竞争力（商圈收单）

### 优化空间
1. **峰值后回落略慢**：8/23-24 仍在 30-32%（未完全回 28%）——可加快回落
2. **非爆款抬价有限**：全店峰值 47.4% vs 爆款 65.9%——普通款大促抬价空间小，可差异化
3. **补贴黑洞商品**（心跳不止补贴 294k/实付 2.2k）在大促策略外需单独治理

## 九、可复用测算工具（运营参考）

```sql
-- 任意日期段折扣率（验证抬价）
SELECT date, ROUND(AVG(net_sales*100.0/gross_sales),1) disc_pct,
  ROUND(SUM(net_sales),0) net FROM order_sales
  WHERE date BETWEEN '开始' AND '结束' GROUP BY date ORDER BY date;

-- 爆款商品大促抬价
SELECT date, ROUND(AVG(net_sales*100.0/gross_sales),1) disc
  FROM order_sales WHERE product_name LIKE '%关键词%' AND date BETWEEN ... GROUP BY date;
```
