## 〇、这是什么

**一套把"拍脑袋决策"变成"可复现推演"的方法 + 工具 + 记录模板**。它解决：给定一个目标（市场地位/资本化/股权/架构/里程碑），**如何诚实地穷举可能 → 倒推路径 → 排序价值 → 说清资本与赢法**，而不是拍脑袋给结论。

**三层封装**：①**方法**（四步）②**工具**（wargame-sim 引擎）③**记录**（全记录模板）。

---

## 一、四步方法（核心）

| 步 | 做什么 | 输出 |
|---|---|---|
| **①第一性穷举** | 抛开已知，从"价值链哪一环能被卡住"穷举**可能的地位/路径/打法** | `<主题>-FIRSTPRINCIPLE-ENUMERATION.md` |
| **②反向推演** | 从**终点倒推**前置条件（资格/数据/战绩/能力/资本）→ 分阶段路径 → 分水岭 | `<主题>-WIN-PATH.md` |
| **③价值再评估** | 用**统一 6 维**打分排序 → S/A/B/C 分档 | `<主题>-POSITION-RANKING.md` |
| **④资本与赢法** | 资本介入（工具/金额/稀释/退出锚）+ 赢的杠杆 + 次序 + 纪律 | `<主题>-CAPITAL-WINPATH.md` |

**引擎命令**：`enumerate` / `reverse` / `value` / `capital` / `run`（整套引导）/ `lean4-check`（约束门自检）。

## 二、6 维框架（打分口径 · 固定）

| 维度 | 权重 | 问的是 |
|---|---|---|
| 护城河深度 | 30% | 别人能不能复制/替代 |
| 天花板 | 20% | 做到极致有多大 |
| 可进入性 | 15% | 我们现在能不能进/进多深 |
| 资本化效率 | 15% | 需多少资本/能用杠杆快上吗 |
| 现金流健康 | 10% | 能不能自转/要不要烧钱 |
| 风险 | 10% | 政策/市场/执行确定性（越低=越安全） |

**分档**：S≥7.0 / A≥6.2 / B≥5.5 / C<5.5。**打分 0-10**，可调（重点看排序逻辑，非绝对分）。

## 四、三种跑法（★关键）

| 跑法 | 做什么 | 价值 |
|---|---|---|
| **①反向跑** | 从终点倒推前置条件 + 分阶段 + 分水岭 | 定"要去哪、要什么前置" |
| **②空跑（无数据）** | 抽象基线排序 | 给"抽象框架基线" |
| **③数据跑（注入真实数据）** | 用真实数据重跑 | **全员加分 + 纠正抽象误判** |

**★ 三跑的真正价值**：**看真实数据把哪些"以为最优"纠正成"真正最优"**（花联网范例：IP线"女性向IP"数据跑反超；底座线"数据报告"升位）。**不是走流程，是数据校正判断。**

## 六、应用流程（新项目怎么套）

```
第1步  定主题与终点（如"某行业X的市场地位"/"公司资本化"）
第2步  跑①第一性穷举 → 列出 ≥5 种地位/路径
第3步  跑②反向推演 → 从终点倒推前置条件+分阶段+分水岭
第4步  跑③价值再评估（6维打分）→ S/A/B/C 分档
第5步  跑④资本与赢法 → 资本介入+杠杆+次序+纪律
第6步  ★按 9 类逐类跑（战略/组合拳/资本/股权/架构/里程碑/能力人/业务线）
第7步  ★对关键类跑"三跑"（反向→空跑→数据跑）→ 看数据校正
第8步  输出：全记录文档（按九类）+ 关键结论★ + 落链索引
第9步  诚实红线自查（4 条）→ 定稿
```

## 七、诚实红线（模板的灵魂 · 4 条）

1. **测算 ≠ 验证**：凡会议口径/模型外推标"测算/待定"；只有真实财务/订单回填才标"已验证"。
2. **文档冲突要标出**：不同版本数字打架必须点明，不假装一致。
3. **来源不明要标注**：无公开信源数字标"待考证/需补信源"。
4. **资产归属要核实**："牌/资源"在不在自己名下——不核实就推演会自欺。

**引擎自带**：`--lean4-check` 实证约束门（违规路径被拒）。
