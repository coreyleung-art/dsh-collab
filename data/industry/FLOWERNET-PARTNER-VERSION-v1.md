## 〇、一句话说清这份文件的立场

**这份文件不对任何一方有利**。它的目的是让**每一方在看同一张表**：你拿什么、担什么、坐什么位子、每次可以怎么选。**把规则讲清楚，把数字留给各方谈。**

**三条总原则（对各方一律）**：
1. **出资 = 权益**（按出资比例）；
2. **资源 = 作价**（按评估，不按喜好）；
3. **贡献 = 激励**（按里程碑，不按资历）。

## 一之补、为什么种子轮就要 1000 万（出资方必问）

> 完整推导见 `FLOWERNET-WHY-1000W-v1.md`。这里给结论与要点。

**一句话**：**1000 万不是"我们想要 1000 万"，而是"把成都样板做实 + 数据底座地基打好 + 把人搭起来，最少需要 1000 万"**——**自下而上算出来的，不是自上而下定的**。

### （1）1000 万买的是四样东西
1. **买"跑正单店经济模型"**（A 成都样板 300 万）——没有它，后面所有复制都是空中楼阁（投资人第一个看的就是"单店能不能赚钱"）；
2. **买"数据底座的入场资格"**（B 端口 80 + 合规 50 = 130 万）——端口是技术地基、合规是法律地基，**两样必须一次性建立**；合规一旦出事是灭顶（个保法顶格 5% 营业额或 5000 万，且双罚）；
3. **买"效率杠杆的发动机"**（C AI 工具 50 + **F 能力层 200**）——人效 6-8→15-20 家靠它；**没有 FDE 就没有封装，没有封装落店就要派人（成本线性、不可扩展）**；
4. **买"第二盈利点 + 落地必需 + 架构地基 + 风险准备金"**（D IP 150 + E 供应链 70 + H 硬件 32 + I 云 23.5 + G 机动 44.5）。

### （2）为什么不能更少（砍任何一类都会断链）
| 如果砍掉 | 会发生什么 |
|---|---|
| 砍 A（成都样板） | 跑不正单店单位经济 → 拿不到下一轮 → **整条链断在起点** |
| 砍 B（端口+合规） | 没有数据 → 数据底座终局不成立；**合规漏洞=灭顶** |
| 砍 F（能力层） | 没人做封装 → **落店只能派人** → 成本线性、不可扩展 |
| 砍 H5（设计师双环境） | 设计 AI 军团的效率被硬件卡住 → 拖慢整条链 |
| 砍 G（双牌确权） | **最大结构性风险无任何对冲**（牌照不在名下、一年一签） |
| 砍 D（IP 首场） | 失去第二盈利点 → 只靠代运营（抽成率平台定 8-10 点、无定价权） |
| 砍 I（云） | 架构地基不存在 → 数据无法汇聚、多城协同做不了 |

**一句话**：**这九类里没有一类是"锦上添花"，每一类都对应一个"不买就会断链"的环节。**

### （3）为什么不该更多（说 1000 万也要说清"不该更多"）
1. **种子阶段的任务是"验证"不是"扩张"**——要证明的是"单店能赚钱 + 数据能采到 + 人能搭起来"，不是"开多少家店"；**钱多了会诱发超前扩张，反而埋雷**。
2. **不确定性下的纪律**：平台授权一年一签、单位经济尚未真实财务验证——**多拿钱 = 多承诺 = 多风险**，这是对出资方负责。
3. **资本纪律**："能现金流自转就不融资；**每轮只干一轮的事**"。
4. **不稀释**：种子出让 15-20%（测算）、估值约 6000 万；拿更多钱要么多稀释、要么抬高估值承诺，都不利后续轮次。

### （4）1000 万花完必须达到什么（出资方的"验收清单"）
① 单店单位经济跑正（**从测算→验证**，第一道分水岭）② 数据端口 P1 稳定运行（订单 43 列 + IM + 评价）③ 合规清单 100% 成文 + 个人信息隔离到位 ④ **采集器封装完成**（新店部署不需工程师到店）⑤ 能力层三层分工搭起来 ⑥ 设计师生产级双环境就位 ⑦ 成都样板 SOP 可复制 ⑧ **达到 Pre-A 的融资条件**。

**换句话说**：**1000 万买到的是"从'测算'跨到'验证'的资格"**——跨过去，Pre-A 才有得谈；跨不过去，后面所有轮次都不成立。

### （5）钱的来源与"一笔钱三重回报"
- **来源**：种子 1000 万来自**自己人/股东借资**（不占外部轮次、不引入外部投资人、不产生额外稀释）。
- **纪律**：**出钱只出在"卡位"上**（数据端口、合规、双牌确权、能力层、硬件刚需）；能借力/回血的都不出钱（平台发薪 BD、新签与返佣回血、算力向投资人租赁、城市仓合作方出资、IP 零成本授权）。
- **三重回报**：① 跑正单店单位经济（**得现金流**）② 采到单店数据（**得底座原料**）③ 换到平台资格与战功（**得平台绑定**）。

## 二、梁振宇及其主体（你自己）

### 2.1 你拿到什么
1. **51% 投票权，且前三轮融资不被稀释**——通过四道防线实现：① **双层有限合伙**（你做 GP 控制上层、出资方做 LP 只出钱）② **AB 股**（同股不同权，1 股 = 10 票；中国《公司法》第 65 条允许有限公司章程约定、第 144 条允许股份公司发行特殊表决权股）③ **章程锁定表决权 + 关键事项一票否决** ④ **期权池放顶层、按里程碑解锁**（不干扰控制权）。
2. **出资额可由背后 LP 解决**——你个人不必为 51% 的出资全额掏现金；LP 出钱、拿收益、不干预经营，控制权仍在你的 GP 身份上。
3. **里程碑期权（两轨激励）**：**规模轨**（把公司做大：5 城 / 10 城 / 30 城 / 数据底座建成 / 垂类第一）+ **资本轨**（创造价值：A 轮估值达标 / 2030 上市市值）。**资本轨给更强的激励**（因为经营达标是"做好本职"，估值达标才是"真正创造价值"）。
4. **经营控制权**：董事会主导经营决策；GP 身份 + 章程锁定保证方向不被资本绑架。

### 2.2 你担什么
1. **业绩对赌**——里程碑未达，你要受约束（期权不解锁、可能的调整）。**这是你自己给自己上的锁，也是让出资方敢进来的前提。**
2. **回购义务（公司层）**——注意：**所有回购与补偿义务都放在公司层面，你个人不兜底**（遵循现行司法裁判口径）。**这一条对你至关重要，务必在协议里写死。**
3. **低薪 + 高压力**——你的现金薪酬低（主要回报靠期权），但要承担"设计 AI 军团 + 拿资格 + 跑战绩 + 融资"的全部压力。
4. **个人时间被工程细节拖住的风险**——如果你不找 1-2 名 FDE 把设计落地，你会被封装、部署、运维这些琐事吃掉做战略的时间。**所以"招 FDE"是你的刚需，不是可选项。**

### 2.3 你在各轮的选项
| 轮次 | 你可能的选项 | 得 / 失 |
|---|---|---|
| 种子 | 自己出资 / 让背后 LP 出资 / 混合 | LP 出资：你少占用自有现金，但要让出经济收益；自己出资：收益全归你，但现金压力大 |
| Pre-A / A | 保持 51% 不动（靠 AB 股 + GP 分层） / 部分稀释经济权益（不动投票权） | 前者最稳；后者能多融资但收益让渡更多 |
| B / Pre-IPO | 期权池扩容（激励团队） / 引入战略投资（如平台系资本） | 前者留人；后者换资源但可能带来治理复杂性 |
| 上市前 | 保持控制 / 逐步退出（如部分老股转让） | 前者继续做大；后者提前变现但失去增长 |

## 三、背后出资方（LP）

### 3.1 你拿到什么
1. **安全退出的底线**：**保底回购（本金 + 年化 8%）**——万一公司没做起来，你仍能拿回本金加约定收益。
2. **优先清算**：公司退出（上市/并购/清算）时，你**先拿回本金 + 门槛收益**，再参与剩余分配。
3. **上行分享**：公司做大了，你按约定比例分享估值增长（不是只拿固定收益）。
4. **每轮退出权**：每轮融资后，你有权按当时估值**部分或全部退出**。
5. **反稀释**：若后续轮次估值下调，你有股份补偿（加权平均，不用最严苛的完全棘轮）。
6. **业绩对赌**：里程碑未达，你可要求回购或补偿。

### 3.2 你担什么 / 你要接受什么
1. **不干预经营**——你是 LP（有限合伙人），**只出钱、拿收益，不参与管理决策**。这是这个结构的前提，也是梁振宇接受你进来的条件。
2. **收益有上限的风险**——如果公司大获成功，你的收益按约定比例分配（不是无限）。
3. **回购义务在公司层**——即公司回购你，**梁振宇个人不为你兜底**；所以你的安全底线依赖"公司有资产/有现金流"，不是依赖梁振宇个人信用。**这一点你必须在谈判时看清。**
4. **期限**——回购/退出通常有约定时点或触发条件，不会无限期挂着。

### 3.3 你在各轮的选项
| 轮次 | 你可能的选项 | 得 / 失 |
|---|---|---|
| 种子 | 出资（换 LP 份额） / 不出资 | 出资：拿到安全退出 + 上行；不出资：错过整个头寸 |
| Pre-A / A | **跟投**（同轮同权） / **不跟投**（保持比例但被稀释） / **部分退出**（行使每轮退出权） | 跟投：保住比例；不跟投：被稀释；部分退出：落袋为安但失去后续上行 |
| B / Pre-IPO | **全部退出**（估值高点套现） / **部分退出** / **继续持有** | 全部退出：锁定收益、放弃上市溢价；持有：赌上市 |
| 上市后 | 解禁后择机退出 | 按市场价 |

**给你的建议（不作为承诺）**：如果你要的是**安全 + 适度上行**，那么"种子轮进 + 每轮部分退出 + Pre-IPO 前退出大部分"是常见路径；如果你要**博上市溢价**，则持有到 IPO 后解禁。

## 四、橙果（现金出资 + 全国牌照）

### 4.1 你拿到什么
1. **现金部分的回报**：与出资方同等的经济待遇（按出资比例）、优先清算、保底回购。
2. **牌照/流量权的作价对价**：你带来的**全国鲜花类目服务商资格（淘宝闪购）与流量权**要**单独作价**，换取对应的股权/权益（**现金和牌照两块分开计价，不混同**）。
3. **董事席位 + 清单式否决**：你作为资源方股东，进董事席位，并对**关键事项（清单式）有否决权**——这是对你"带来核心资质"的对价保护。
4. **公司层面的确定性**：你的牌照一旦投入，公司在相当长时期内依赖它，因此你的谈判位置是强的一方。

### 4.2 你担什么 / 你要接受什么
1. **牌照持续有效的责任**——这是你的核心义务：**如果牌照未稳定、被平台收回、或到期未续，你要承担补偿责任**（让渡股份 / 回购 / 现金补偿）。
2. **资源作价的风险**——**如果牌照的实际价值/稳定性低于当初作价，你要回吐**（股份调整）。
3. **必要时调整投票权/股份**——如果牌照层面出现不利情况，可能触发**权益调整**（把部分投票权/股份让渡给合资公司或梁振宇），以保证公司和其他方不被拖累。
4. **平台政策的不可控性**——**平台授权一年一签**，这是你和公司共同面对的外部风险；正因为如此，条款要设计成"风险共担"，而不是"全压在你身上"。

### 4.3 你在各轮的选项
| 轮次 | 你可能的选项 | 得 / 失 |
|---|---|---|
| 种子 | **牌照作价入股**（换股权） / **牌照授权（收授权费，不入股）** | 入股：分享公司成长但承担牌照风险条款；收授权费：现金流确定但不分享成长 |
| Pre-A / A | **跟投保住比例** / **不跟投** / **追加牌照资源换更多权益** | 跟投：保比例；追加资源：可谈更高权益但要担更多作价对赌 |
| B / Pre-IPO | **保持** / **部分退出** / **引入同体系资源方** | 退出：锁定；保持：分享上市溢价 |
| 平台政策变化时 | **谈判续约** / **切换主体** / **触发权益调整条款** | 续约成功：地位不变；触发调整：承担补偿但保住合作 |

## 五、声通（城市合伙人牌照）

### 5.1 你拿到什么
1. **牌照作价对价**：城市合伙人牌照（**商家运营管理权 · 主导活动**）按实际授权计价，换取对应权益。
2. **与橙果"牌照部分"同等待遇**：牌照保障对赌 + 作价对赌，规则一致（不因体量大小而被区别对待）。
3. **按约定参与治理**：董事席位 / 清单式否决（按协议约定）。
4. **每城主体按实际授权计价**——**因为合规原因，每个城市的城市合伙人可能由不同主体持有**，所以计价与权益按**实际授权**逐城落地（不是"一刀切"）。

### 5.2 你担什么 / 你要接受什么
1. **牌照授权链的稳定性责任**——授权断裂/未续，触发补偿条款。
2. **每城主体的合规安排**——要配合"全国一层 + 城市网络一层"的结构（城市这层是**运营权**，不是地域牌照）。
3. **作价对赌**——牌照价值若低于作价，需调整。

### 5.3 你在各轮的选项
与橙果的"牌照部分"一致：**入股 / 授权 / 跟投 / 部分退出 / 触发调整条款**（见第四节表格）。

## 六、团队（含 AI 团队）

- **拿到**：期权池（按里程碑解锁），与梁振宇同规则（里程碑预设、透明、可测）。
- **担什么**：交付成果；里程碑未达则期权不解锁。

### 八之补：资本出资 vs 牌照资源，保护应该对等吗？（对等性检验·必读）

> 完整版见 `FLOWERNET-EQUIVALENCE-CHECK-v1.md`。这是谈判中最容易起争议的一点，必须说清。

**问题**：牌照方有「清单式否决」（且清单上含牌照相关内容），资本出资方只有经济性保护——**这两者应该对等吗？**

**答案**：**要对等的不是「权力大小」，而是「风险与保护的匹配」**——因为**资本和牌照是两类性质完全不同的投入**：**钱是可替代的，牌照是不可替代的**。

### （1）先分清「两种对等」（否则越谈越乱）
| 理解 | 含义 | 是否成立 |
|---|---|---|
| **理解 A：金额对等** | 我出多少金额，就该拿多少权力（出资 1000 万 vs 牌照作价 1000 万，权力应一样） | **不成立**——权力不是按金额分配，而是按**风险性质**分配 |
| **理解 B：风险-保护对等** | 谁承担什么风险，谁就获得对应保护（**形式可不同，但匹配度要对等**） | **成立，这正是我们的设计原则** |

### （2）两类投入的性质完全不同（全部差异的根源）
| 维度 | 资本出资（LP） | 牌照资源（橙果/声通） |
|---|---|---|
| 投入什么 | 钱 | 平台资格/流量权/城市运营权 |
| **可替代性** | **高**——谁的钱都是钱 | **低**——平台给的、一年一签、别人复制不了 |
| **风险性质** | 资金安全（钱能不能拿回来） | 资源被处置或贬值（会不会被转让/质押/改行/收回） |
| **对经营的要求** | **不需要参与经营** | **需要防止资源被处置** |
| **退出方式** | 回购/转让/上市解禁 | **无法「回购牌照」**——只能作价调整/权益调整/合作终止 |

**所以保护形式必然不同**：资本 → **经济性保护**（保底回购/优先清算/反稀释/退出权）；牌照 → **治理性保护（清单式否决）+ 经济性保护**（作价对赌/权益调整）。**这不是厚此薄彼，而是对症下药。**

### （3）必须对等的四件事（谈判逐条检查）
1. **作价的公允性**——资本按公允估值入股（同轮同价）；**牌照也要有公允的作价方法与依据**（评估方法/可比交易/收益法）。⚠️ **这是最容易出问题的地方：牌照作价虚高 = 资源方用虚高的东西换走真实股权，是对资本方的不对等。**
2. **风险-保护匹配**——资本有资金风险→给经济性保护；牌照有资源风险→给治理性+经济性保护。**不是谁多谁少，而是「是否对症」。**
3. **权利-义务对称**——资本拿保护就要**放弃干预权**；牌照方拿保护就要**担资源维持责任**（牌照出问题要补偿/让渡/回吐）。**没有只拿保护不担义务的一方。**
4. **退出路径存在**——资本有回购/转让/解禁；牌照没有「回购」，但必须有**作价调整/权益调整/合作终止**。**不是形式相同，而是都有一条走得通的路。**

### （4）不该对等的两处（且为什么）
| 问 | 答 |
|---|---|
| **资本为什么不给治理权？** | **因为钱不需要被保护**——钱的风险是「能不能拿回来」，是经济性问题，用回购/清算/反稀释解决就够了。**如果给资本治理权，就变成「出钱就要控制权」，那才是不对等**（钱可替代，不该换走经营控制） |
| **牌照方为什么要给治理权？** | **因为资源需要被保护**——牌照风险是「会不会被公司单方面处置」（转让/质押/改行），这是**公司行为问题**，**经济性条款防不住「公司把牌照卖掉」，只有治理性条款（否决权）能防** |
| **会不会「既要对价、又要控制」？** | **只要清单严格限定在「与牌照相关的事项」，就不是**——**作价对价 = 买它的资源**（交易）；**清单式否决 = 防止资源被单方面处置**（保护）。**「对价 + 保护」不是「双重索取」** |

### （5）两种真正的不对等（必须防）
| 情形 | 表现 | 怎么防 |
|---|---|---|
| **① 牌照方清单泛化** | 把**日常经营**（开城/关店/定价/活动/人事）也放进否决清单 | 变成「既要经济对价、又要经营控制」→ **清单严格限定在牌照相关事项，日常经营一律不进清单** |
| **② 资本方索要治理权** | 出资方要求董事席位/一票否决/参与经营 | 变成「出钱要控制」→ **资本不进经营层、不给否决权；只给信息权 + 经济性保护** |

### （6）一句话回答
> **对等的不是「权力一样大」，而是「谁担什么风险，谁就拿到对应的保护；谁拿了保护，谁就担对应的义务」。**
> **用同一把尺子（金额）去量两类不同的投入（可替代的钱 vs 不可替代的牌照），才是真正的不对等。**

**九项对等性检验表**（完整版见 `FLOWERNET-EQUIVALENCE-CHECK-v1.md` 第五节）：定价公允 / 风险-保护匹配 / 权利-义务对称 / 退出路径存在 / 否决范围受限 / 否决权有期限与联动 / 义务公司层 / 信息权 / 不自我交易——**九项全打勾 = 对等成立**。

### 九之补：「清单式否决」到底是什么（重要术语·必读）

> 完整版见 `FLOWERNET-VETO-EXPLAINED-v1.md`。

**一句话定义**：「清单式否决」= 一方**只对"协议里明确列举的少数事项"拥有否决权；清单之外的一切事项，它不能否决**。**关键在"清单"两个字**——权力被限定在一张纸上。

**它不是什么**：**不是"什么事它都能否"**（那叫"**一票全否**"，会让公司决策瘫痪，我们**不用**）。

**为什么这么设计（双方的折中）**：
- **对资源方（橙果/声通）**：你把**核心资源**（牌照/流量权/运营权）投进公司，如果公司把牌照转让了、质押了、或者改行不做鲜花了，你的投入就白费了——所以你需要**一张"安全清单"**；
- **对梁振宇**：如果把否决权无限制给出去，**公司任何经营决策都可能被卡死**，梁振宇也就失去了经营控制；
- **折中**：**清单内 → 资源方能否决（保护核心利益）；清单外 → 资源方不能干预（保证经营效率）**。

**建议清单上有什么（保护资源方核心利益）**：① 处分核心牌照/资质（转让、质押、许可）② 变更主营业务 ③ 清算/解散/合并/分立 ④ 增发导致资源方持股跌破约定线 ⑤ 重大资产处置 ⑥ 变更牌照使用主体或授权链 ⑦ 与牌照相关的重大合规变动 ⑧ 改变利润分配/退出安排。
**共同特征**：**都与"资源方的核心投入"直接相关，而与日常经营无关。**

**清单上不该有什么（保证经营效率）**：日常经营决策（开城/关店/定价/活动排期）、预算内支出、人事招聘与考核、一般业务合作、产品与技术选型、合规范围内的常规数据处理。
**判断标准**：**"这件事会不会实质影响资源方投入的价值？"**——会，进清单；不会，不进清单。

**与相近概念的区别**：**一票全否**（力度最强，会让决策瘫痪，**不用**）｜**清单式否决**（力度适中，保护核心利益但不卡日常经营，**用**）｜**董事席位**（席位是"参与"，否决是"拦下"，两者不同）｜**梁振宇一票否决**（梁振宇**也有自己的清单**，保护方向不被绑架）。

**⚠️ 注意对称性**：梁振宇也是"清单式否决"——**这不是双重标准，而是对称**：梁振宇用清单保护"公司方向不被资本绑架"，资源方用清单保护"核心资源不被处置"。**双方都是"有限的否决权"，不是"无限的否决权"。**

**三个必须写清的技术细节（谈判时务必确认）**：
1. **逐项表决**还是打包同意（建议逐项，否则一次打包同意可能掩盖某项不利安排）；
2. **时限与失效**——**否决权不是永久的**：常见设计是上市后失效（公开市场治理通常不允许特殊否决权保留）或资源方退出后失效；
3. **与"资源出问题"联动**——**否决权的对价是"它带来的资源"**；如果资源方自己的牌照未稳定/被收回/到期未续，它的否决权应**同步调整**（须与"牌照保障对赌 + 权益调整"条款配套写）。

## 十一、一句话总结各方的位置

- **梁振宇**：拿控制权，担里程碑。**"我要方向不被绑架，所以我给自己上锁（对赌）。"**
