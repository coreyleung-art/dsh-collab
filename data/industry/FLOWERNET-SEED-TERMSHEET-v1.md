## 三、核心权利条款（出资方）

| 条款 | 要点 |
|---|---|
| **保底回购** | 触发（到期未上市 / 里程碑未达 / 重大不利变化）时，出资方有权要求**按本金 + 年化 8%** 回购其权益 |
| **优先清算** | 公司退出（上市/并购/清算）时，出资方**先拿回本金 + 门槛收益**，再参与剩余分配 |
| **反稀释** | 后续轮次估值下调时给予股份补偿，采用**加权平均**（不用最严苛的完全棘轮） |
| **每轮退出权** | 每轮融资完成后，出资方有权按当时估值**部分或全部退出** |
| **业绩对赌** | 里程碑未达时，出资方可要求回购或补偿 |
| **信息权** | 定期获取经营报表（范围与频率【待确认】） |
| **不干预经营** | **出资方不进经营层、不参与日常决策**（这是获得上述保护的前提） |

## 四、治理与义务

| 项 | 条款 |
|---|---|
| **表决权** | 梁振宇经双层有限合伙 GP 身份控制 **51% 表决权**，**前三轮不稀释**（AB 股 + 章程锁定 + 一票否决 + 顶层期权池） |
| **董事会** | 梁振宇主导经营决策；橙果/声通进董事席位（按约定） |
| **★ 回购义务主体** | **所有回购与补偿义务在公司层面，梁振宇个人不兜底** |
| **资金监管** | 建议：专款专用台账 + 季度对账 + 超支预警 |
| **合规红线** | 只采**商家经营数据**、严格隔离个人信息（PII）；违反适用《个人信息保护法》顶格处罚 |
