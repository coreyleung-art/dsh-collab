# 花联网（内部暂命名）· 淘宝闪购业务说明与规划简报

## 一、我们是谁、与别的服务商有什么不同

**四个不同点（这是我们与其他服务商的差别）**：

| # | 差异点 | 具体做法 | 对平台的价值 |
|---|---|---|---|
| **1** | **不卷价格，卷商品** | **给商家注入定价权**：用 IP 联名把「一束可被比价的红玫瑰」变成「有品牌与情感价值的专属款」 | **不靠降价抢单，靠把商品卖出价值**——商家有毛利、平台有含金量、消费者有理由 |
| **2** | **会做商品，不只是贴标** | **鲜花 × IP 商品设计能力**：IP 标签化 → 载体化（定制包材/专属花束/公仔/礼盒）→ 场景化 → 系列化 | **给类目带来有溢价的产品线**，而不只是一次促销活动 |
| **3** | **会造节，不只等节** | **首场 IP 应援月定在 11 月淡季**（不是借节日的势），此后**每年 ≥2 场落在非自然节日窗口** | **在需求最低的窗口造出新增消费**——这才是造节两个字的意义，而且可以按窗口对比验证 |
| **4** | **会铺渠道，不只是等人上门** | **帮花店完成线上迁移**：按片区、商圈、品类结构识别目标，用具体的经营方案去谈，签约之后才是真正的交付 | **减少类目供给缺口**——平台缺的不是规则，是愿意把店真正做好的商家 |

我们的工作，最终都落到平台自己的四个指标上：

| # | 指标 | 我方怎么推动 | 可核验方式 |
|---|---|---|---|

**这四个指标就是我们的工作纲。**

## 三、我们的差异化打法

### 3.1 鲜花 × IP：给商家定价权，不打价格战

**先说清楚我们的打法与别人有什么不同。**

鲜花这个类目现在有一个根本问题：**商品是同质的**。一束红玫瑰，A 店和 B 店没有区别，消费者只比价格。结果是商家陷入**降价内卷**——今天你便宜两块，明天我便宜三块，**最后谁都没有毛利，谁都没有能力把品质做好**。这不是商家不努力，是**商品本身没有给商家留出定价的空间**。

**我们的 IP 打法，本质是给商家注入定价权。**

当一束花不再只是「红玫瑰」，而是**「某个角色的应援花」——它的定价逻辑就变了：消费者买的不是花，是对角色的情感**。这时候商家卖的是**有品牌、有故事、有专属设计的商品**，而不是一束可以被比价的白牌花。**同样的花材，因为 IP 的加持，商家有了定价空间。**

**这件事对三方的价值是不同的，但方向一致：**

| 对象 | 我们的做法 | 带来的结果 |
|---|---|---|
| **① 帮助商家** | 用 IP 联名给商品注入品牌与情感价值，让商家卖的是**专属款而不是白牌款** | **商家有了定价权 → 有了毛利 → 有了生存能力**。有毛利的商家才愿意投入把品质、服务、履约做好；不内卷的商家才愿意长期留在平台 |
| **② 帮助平台** | 把鲜花类目从**「价格战红海」引导到「有溢价的健康类目」** | **GMV 的含金量提升**（不是靠补贴堆出来的低价成交）；**商家留存改善**（活得下去的商家不会流失）；**类目心智升级**（消费者来买「设计过的花」，不只是「便宜的花」） |
| **③ 让新消费者进来** | 用 IP 应援把**平台外的粉丝群体**带来——他们不是「来比价的人」，而是「来买角色周边的人」 | **带来的是新增注册与新增消费**，不是从别处搬来的存量。粉丝的购买动机是情感，**对价格的敏感度低**，愿意为设计付溢价 |

**一句话概括这条路：我们不做「帮商家降价抢单」的生意，做「帮商家把商品卖出价值」的生意。** 这是我们认为鲜花类目能长期健康的关键，也是我们与其他服务商最不一样的地方。

**怎么把这件事落到淘宝闪购的运营里（而不是停留在概念上）**：

1. **商品端**——把 IP 变成可上架、可履约、可复购的鲜花商品（见下文四个层次）；
2. **活动端**——以 IP 应援月造节，在非节日时段创造消费理由，并整体组织在管商家参与；
3. **商家端**——培训与陈列标准同步，让商家知道「为什么要卖这款、怎么卖、卖给谁」；
4. **治理端**——正版化前置：商家与 **IP 权利方或其代理方直签独立电子授权合同**，一货一物防串货，**保护愿意投入的商家不被低价盗版冲击**（这是定价权能否守住的物理前提）。

**为什么这件事只有懂鲜花的人能做**：IP 联名在各行各业都在做，但**鲜花是最难联名的品类之一**——花是有生命的，花期只有几天，节日需求是平日的几十倍，同城即时配送还要求 30 分钟到 1 小时送达。**把 IP 做成一个能卖、能履约、能复购的鲜花商品，是一件需要品类纵深才能做成的事。** 这正是我们的能力所在。

**我们的商品 IP 结合能力，分四个层次：**

| 层次 | 做什么 | 创造性的体现 |
|---|---|---|
| **一 · IP 标签化** | 给热销现货叠 IP 标签（小阿狸案例：平台选中红玫瑰款，参与门店全部可打「小阿狸同款」） | **零新增 SKU**，用最快的路径验证 IP 的带货力 |
| **二 · IP 载体化** | 把 IP 落到实物载体上：**定制包材、专属花束、公仔、卡片、礼盒** | **不是贴标，是重新设计一件商品**——从花的品种、配色、包装到赠品，按 IP 的气质重新组合 |
| **三 · IP 场景化** | 为 IP 设计**专属购买场景**：应援、庆生、告白、纪念日 | **从「卖花」变成「卖一次表达」**——商品不再是花，是粉丝对角色的情感载体 |
| **四 · IP 系列化** | 同一 IP 做**系列款**，跨节点持续迭代 | **把一个爆款变成一条产品线**，形成可复购的商品结构 |

**创造性体现在三个地方**：

1. **造节而不是等节**。鲜花消费被二十几个自然节日框死，非节日就是淡季。我们做的是**造出新的消费理由**——「为我的角色买一束花」，购买动机是情感，与情人节无关。**首场就定在 11 月淡季**：在双旦做活动，做出来的是节日本来就有的需求；**只有在淡季做出来，才能证明 IP 真能造出新的消费理由**。这也是把平台外已有的粉丝消费，移植到平台内完成。

2. **应援月，不是应援日**。不做单日脉冲，做「**预告 → 应援期 → 返场**」的 **30 天量级周期**——用持续曝光培养消费习惯，把一次活动变成一个节日。**单日做的是 GMV 峰值，30 天做的是习惯。**

3. **一套可复用的造节方法**。不是碰运气做一个爆款，而是把方法沉淀成 SOP：**IP 筛选 → 载体设计 → 商家报名 → 资材铺货 → 培训陈列 → 活动执行 → 治理联动 → 复盘**。这个方法可以反复用在不同的 IP、不同的节点、不同的城市。

**IP 矩阵的组合能力**：头部筛选 **1 个配合度高的 IP 打透做案例**（「求不来只能吸引」，不浪费精力）；腰部按人群画像做矩阵覆盖更广；尾部培育自有。以**双向评价**为基础（商家配合度 × IP 配合度），匹配不上就不硬推——**宁少勿假**。

**城市落地：成都整体上 + 快闪**。成都淘闪鲜花类目现有 **700-800 家存量商家**（其中有效动销 **750 家**，均有真实订单），可整体组织进活动；线下配合大屏与中庭快闪，**把线上活动做成城市事件**——让一次联名不只是手机里的一个 banner，而是这座城市能看见的事。

**正版化是前置条件，而授权必须来自权利方本身。**

**授权的唯一合法来源是 IP 权利方（或其授权代理方）**——商家参加活动前，必须与该权利方或其代理方**直接签署独立的电子授权合同**，授权才生效。服务商不代替权利方授权，也不代替权利方担责。链路是：

```
IP 权利方（或授权代理方）
   │  独立电子授权合同（直签，一份一签）
   ▼
参与活动的商家  ←── 我方只做三件事：组织报名 / 送审监修 / 核对授权文件
```

**我方在授权链上的三个动作**：① **组织报名**——把愿意参与的商家组织起来；② **送审监修**——把商品设计（包材、花束、礼盒）送 IP 方监修，通过才可生产；③ **核对授权文件**——**报名商家须持有与权利方/代理方直签的电子合同编号，无编号不进入活动**。

**正版锁**：**一货一物**——授权带数量限制，采购多少包材卖多少束，杜绝超卖与串货；**不买指定资材包，物理上做不出正版款**，这是把「正版」从口号变成门槛。非授权渠道采购即为盗版，**按平台规则举报、链接下架，我方主动配合**。

**一个前提要说清**：首场活动启动前，**必须完成 IP 权利方（或代理方）的授权链路签约**；若届时授权链未落地，我方**不启动该场联名活动**——不拿未授权的活动去试探平台的容忍度。

**可交付**：一次可复制的造节 SOP、活动中实际使用的**商品设计（包材/花束/礼盒）方案**、活动期商家参与率与资材渗透率、以及新增注册与跨平台迁入的数据复盘。

## 四、如何从其他平台带来增量：一套可复制的打法

**这件事的本质**：平台间的商家数量差距（淘宝闪购鲜花商家约 **5 万家** vs 同类平台公开披露 **超 20 万家**）不是自然形成的，是**靠人力逐个谈出来的**。这套打法分四步，每一步都有可核验的产出。

**第一步：识别——找到「值得搬」的店。** 不盲目扫街。按片区、商圈、品类结构筛出三类目标：① 有线下真实动销（不是空壳店）；② 在别处经营但线上运营薄弱（有需求、缺能力）；③ 店址在配送半径内（能保障履约体验）。**选商三条标准写死，避免为冲量签空壳店。**

**第二步：触达——用他们听得懂的方式谈。** 两个通道并行：**骑手建联**（覆盖密度高、单人触达量大）+ **专职商务上线**（讲清上架、资质、活动的完整路径）。每家店的材料是一次**具体的经营方案**（这个商圈卖什么、价格带怎么定、活动怎么报），不是一张招商传单。

**第三步：迁移——把「搬过来」变成「活起来」。** 签约只是开始。**口径写死：新签且 30 天内完成首次动销，不以签约数计功。** 承接硬线是**首周问题解决率 ≥90%**——上架、改价、活动报名、客服工具接入，每一步都有表单、有时限，避免「签完就没人管」。

**第四步：留存——把迁移沉淀成增量。** 迁入后 30 天的动销率、复购率、单店产出按月过账。**只做前三步，GMV 会随流失回落**——拉新是「店的数量」，单店产出是「店的厚度」，两者必须同时报。

**增量的两个来源**：
- **商家迁移**——帮花店完成线上迁移，带来的是**现成的经营能力与货盘**；
- **用户迁移**——通过 IP 矩阵的应援与活动，把平台外的粉丝与鲜花消费者带进来**首次注册下单**。

**可核验产出**：跨平台迁入商家数、迁入后 30 天动销率、新注册用户数与首单来源、以及分新老商家的 GMV 拆分。

**IP 应援月节奏**：**第一场定在 11 月——这是鲜花真正的淡季**（国庆后、双 11 后、双旦前，全年需求最低的窗口之一），不是借任何自然节日的势。

| 类型 | 排期 | 报什么数 |
|---|---|---|
| **造节**（**首场 = 11 月淡季**，此后**每年 ≥2 场落在非自然节日窗口**） | 11 月（首场）· 3 月 · 7 月 等淡季窗口 | 该窗口 vs **前 4 周同店 GMV 增幅**、新增注册数、复购率 |
| **借节**（承认是叠加，不是造节） | 双旦 · 情人节 · 母亲节 · 七夕 | IP 款 GMV 占比、IP 款 vs 白牌款**同店增幅差** |

**为什么首场要放在淡季**：在双旦做活动，做出来的是**节日本来就有的需求**；只有在淡季做出来，才能证明 **IP 真能造出新的消费理由**。**首场选 11 月，就是要把这件事一次验证清楚。**

## 五、我们想要什么（城市 / 片区 / 全国 × 活动 / 流量入口）

**这是「我们想要什么」，不是「我们要求什么」。** 每一项都写明：**我们要什么**（具体位置/权限/时效）、**打算用它做什么**、**对平台的价值**（从平台自己的指标说）。

**我们不要资源前置条件**——不写「平台先给、我方再做」。这些诉求是**希望与平台共同商定的事项**，供会上逐项讨论。

**另有一项不占用任何资源位的请求**：希望平台把**考核口径与支持政策书面化**，并建立**按月经营复盘**机制——这不需要资源，只需要口径清楚。
