# 沙盘推演标准化工具 v1 —— 战略推演方法（沉淀）

> 明鉴 · 2026-09-10 · 把我们刚跑完的几轮战略推演过程（第一性模拟 → 反向推演 → 价值再评估 → 资本介入与赢法）提取成一套**可复用的沙盘推演标准化工具**。
> 这套工具解决一个问题：**给定一个目标（如"成为行业数据底座"/某个市场地位），如何诚实地穷举可能、倒推路径、排序价值、说清资本与赢法**——而不是拍脑袋给个结论。
> 输出层标准 = 我方 BP 标准的**红杉/F君十大核心模块**（价值主张/痛点/方案/市场/模式/增长/竞争/团队/财务/亮点），每个推演动作都要能产出可落到这十模块的结论。

---

## 〇、这套工具是什么

它是一套**四步沙盘推演方法论**（对应我们刚做的几轮，见姊妹篇 FLOWERNET-*-WIN-PATH / CURRENT-STATE / POSITION-*）：

```
第一步 第一性模拟  →  抛开已知要素，从0穷举"可能成为什么市场地位/可能路径"
第二步 反向推演    →  从目标(终点)倒推"要达成必须做到什么状态/拿到什么"
第三步 价值再评估  →  把穷举的选项按同一套维度打分排序，选出最优
第四步 资本与赢法  →  说清资本怎么介入、用哪些杠杆不烧钱也要赢
→ 输出落到十大模块，作为可展示/可融资/可执行的结论
```

---

## 一、第一步 · 第一性模拟（穷举可能性）

**问题**：如果完全不了解背景，只从"市场上有 X、我要在某位置成为不可替代"出发，有哪些可能？

**做法**：
1. 定义价值链（如 产地→批发→花材商→零售→消费者），标出每一环"谁能卡住/谁来提供"。
2. 穷举所有**市场地位**（不是"怎么赚钱"，而是"卡住哪一环、用什么方式"）。
3. 每种地位写清：是什么 / 凭什么 / 难度。
4. 穷举**资本化工具谱系**（用哪种工具匹配哪种地位）。

**产出**：`<主题>-FIRSTPRINCIPLE-ENUMERATION.md`（如 FLOWERNET-FIRSTPRINCIPLE-ENUMERATION.md 的 10 种地位）。

**落到十大模块**：价值主张（我能卡哪一环）、痛点（那一环没人做/做不好）、方案（我怎么卡）。

---

## 二、第二步 · 反向推演（从终点倒推）

**问题**：目标是"成为 XX"（如垂类第一/数据底座），要达成它，必须做到什么状态、拿到什么资源？

**做法**：
1. 明确终点（如 平台难换的行业数据底座 / 垂类第一）。
2. 反向拆：达到终点需要的**前置条件**（资格/数据/战绩/能力/资本）。
3. 把前置条件反推成**分阶段路径**（第1年做什么→第2年→…），每阶段标注"拿到什么/验证什么"。
4. 找到**分水岭/守门动作**（赢下哪一关才能上台阶）。

**产出**：`<主题>-WIN-PATH.md`（如 FLOWERNET-WIN-PATH-v1 的 4 阶段 + 三关分水岭）。

**落到十大模块**：市场（从宏观格局到切入）、增长（阶段路径）、模式（每阶段怎么赚钱）。

---

## 三、第三步 · 价值再评估（同维度打分排序）

**问题**：穷举出的所有选项，哪个最值得优先？

**做法**：
1. 定**统一评估维度**（默认 6 维，可调）：
   - 护城河深度（别人能不能复制替代）30%
   - 天花板（做到极致多大）20%
   - 可进入性（我们现在能不能进/进多深）15%
   - 资本化效率（需多少资本/能用杠杆快上吗）15%
   - 现金流健康（能不能自转/要不要烧钱）10%
   - 风险（政策/市场/执行确定性，越低分=风险越低）10%
2. 每维度 0-10 打分 → 加权得总分。
3. 排序 + 分档（S/A/B/C）。
4. **再灌入现状现实**（已跑通什么/资产是什么/数字是测算还是验证），看排序在现实下是否要**降档/升档**。

**产出**：`<主题>-POSITION-RANKING.md`（如 FLOWERNET-POSITION-RANKING + 现状分析 §结构性再分析）。

**落到十大模块**：竞争（相对优势/护城河）、亮点（为什么是我们）。

---

## 四、第四步 · 资本介入与赢法（怎么赢，不烧钱）

**问题**：选定后，资本怎么介入？怎么用杠杆、不烧钱也要赢？怎么为总战略供血？

**做法**：
1. **资本介入**：按阶段匹配资本工具（自有现金流/种子/VC/银行/并购/可转债/对赌/IP/供应链金融/资源作价/ESOP/财团…），写金额/进场时点/稀释/退出锚。
2. **赢的杠杆（空手套白狼）**：列出"用别人的钱/资源/流量"的项——平台发薪/平台返佣/牌照复用/算力复用/IP零授权/伙伴出资。
3. **赢的次序**：先做现金底盘 → 再建护城河 → 再外溢，每级赢下的钱和战绩=下一级门票。
4. **纪律**：能现金流自转就不融；借了就要证明能力；只干一轮的事。

**产出**：`<主题>-CAPITAL-WINPATH`（并入 WIN-PATH 与现状分析）。

**落到十大模块**：财务（现金流/融资节奏）、团队（51%控盘/对赌）、亮点。

## 五、诚实性红线（这套工具的灵魂）

沙盘推演最容易变"自嗨"。四条红线必须遵守：
1. **区分测算 vs 验证**：凡是会议口径/模型外推，标"测算/目标值待定"；只有真实财务/订单回填的才标"已验证"。**不得把拍脑袋阈值冒充已达标。**
2. **文档冲突要标出**：不同版本数字打架（如 A 轮金额、回本周期、种子是否已融）必须点明，不能假装一致。
3. **来源不明要标注**：无公开信源的数字（如 15% 份额分母、IP 32 资产 262 亿$）标"待考证/需补信源"，不用它做融资叙事。
4. **资产归属要核实**："牌是不是自己的""资源是不是背靠"——在不在自己名下决定地位牢不牢，不核实就推演会推到自欺。
