②b IP 选型与落地策略（完整打法）

IP 核心策略：以"IP 粉丝红利"为平台创造外部新增用户，而非争夺存量。通过与 IP 授权方零成本合作（授权金靠物料赚回），用 IP 专属花束将女性向高狂热粉丝引至平台，实现新注册用户增长、高客单 GMV、无消费习惯用户迁移三重新增——这是平台最需要的增量价值，也是我方差异化的核心。
方向不变：女性向 × 高狂热（我们直觉上认定的高价值客群）——具体符合这一象限的 IP 候选（可直接点名追踪）：恋与制作人、光与夜之恋、原神、第五人格（游戏/乙女向，女性粉丝高狂热）、泡泡玛特 LABUBU、Jellycat（潮玩/谷子，女性 70% 客群、88.6% 愿付溢价）、以及乙女/二次元系 IP。以下为市场数据佐证：

不学美团的原因（风险规避）: 美团同类活动选"中性低狂热"头部IP（迪士尼）规避风险，结果销售压力倒逼商家刷单，最终引发法律纠纷。我方策略是避开"低狂热必须靠营销拉动"的陷阱，只选"高狂热、粉丝自发消费"的 IP——这样 IP 粉丝本身有购买意愿，不需要平台/商家刷单支撑，从源头规避了平台最大的合规风险，同时让 IP 消费成为平台可持续的新增 GMV 来源。

① 为什么做 IP（战略价值）

IP 粉丝是平台增量用户（非存量转化）——通过 IP 专属消费把圈外粉丝引到平台，同时带动高客单 GMV，是帮平台实现"外部新增+高客单"双增量的差异化打法。

② 人群切割（选型坐标）

按"性别×狂热程度"二维切割：横轴男→女、纵轴冷→热。只选右上角（女性向×高狂热）——她们价格敏感度极低、自发高消费；排除左半（男性向/中性）和下半（低狂热），因为这几类无法用自发购买支撑，只能靠营销拉动。

③ 为什么这样选（商业逻辑）

高狂热粉丝自发消费、无刷单压力；高客单（1588/888/288 三档）粉丝愿意为 IP 付溢价。对平台而言，这是"真实新增用户+高客单 GMV"，而非靠补贴/刷单制造的虚增——正是平台考核最想要的增量。

④ 差异化：为何不效仿美团

美团同类活动选中性低狂热头部 IP（迪士尼）求稳，结果销售压力倒逼商家刷单，最终引发法律纠纷。我方策略是选高狂热、粉丝自发消费的 IP，从源头避免"必须靠营销/刷单才能成单"的陷阱——既规避合规风险，也让 IP 消费成为平台可持续的新增 GMV。
