# 花联网 · 启动资金与各轮计划

> ⚠️ **全文金额均为"测算"**（待真实报价与财务回填）；公司**尚未注册**；**声通的城市合伙人牌照是"授权"来的**（授权链风险须核查）。

---

## 甲、启动资金 1000 万元详细计划（不是融资轮）

### 甲一、性质说明

#### 1. 这 1000 万是"股东出资"，不是"融资轮"

**这 1000 万元是公司成立时的启动资金，由股东按约定出资。它不是"公司向外部投资人融资"，因此它没有估值、没有出让比例、没有投后估值。**


- **公司层面只有两个股东**：**梁振宇及其实控主体公司 51% + 橙果 49%**；
- **没有"声通"这个股东**——声通是**橙果的股东**，它把城市合伙人牌照**通过法律文书授权给橙果**，这块牌照算作**橙果资源入股的一部分**；

一句话：**公司层面不引入外部投资人**。既然公司层面没有外部投资人，"出让多少股份给投资人""投后估值多少""投资人清算时先拿多少"这些条款在启动阶段**根本不存在适用对象**。

#### 2. 为什么这么安排

| 角度 | 说明 |
|---|---|
| **最直接** | 合资公司成立时，启动资金由股东按约定出资，是**最简单、最省摩擦**的方式——一次谈清出资额与出资方式，不引入公司层面的估值与条款谈判 |
| **不锁死后续轮次** | **若在公司层面引入外部投资人，就会带出估值**。启动阶段就把估值定下来，等于**在"什么都还没验证"的时候先给公司标了一个价**——后面每一轮都要围绕这个价解释，反而抬高后续融资难度 |
| **条款干净** | 融资轮必然带优先清算、反稀释、回购、董事会席位等条款。启动阶段引入这些条款，是**用治理权换一笔本来可以由股东自己解决的钱**，不划算 |
| **风险性质不同** | 这 1000 万干的是"验证"（单店经济能不能跑正、数据能不能采到、人能不能搭起来）。**验证的钱由股东认，验证的成果才拿到外部轮次去定价**——这是"先自己做实、再对外定价"的顺序 |

#### 3. 与"融资轮"的对照（一眼看清差别）

| 维度 | **启动资金 1000 万（本节的甲）** | **后续轮次（Pre-A / A / B / Pre-IPO，见乙）** |
|---|---|---|
| 钱的性质 | **股东出资** | **公司向外部投资人融资** |
| 有没有估值 | **没有**（不涉及估值） | **有**（每轮都有投后估值与估值依据） |
| 有没有出让比例 | **没有**（股东按约定出资，不涉及向外出让） | **有**（各轮 1.5%-20% 不等，见乙部） |
| 出资/投资人 | 梁振宇及其实控主体公司 51% + 橙果 49% | 天使／早期机构 → VC → 成长基金 → PE |
| 清算优先 | 不适用 | 有（1x 起，逐轮变化） |
| 回购/对赌 | **无外部投资人回购**；只有**对橙果的资源对赌**（橙果承诺的资源失效 → 让渡股份／回购／现金补偿） | 有（公司层面回购权、上市对赌） |
| 这笔钱要买到什么 | **"从测算跨到验证"的资格** | 复制、规模化、产品化、上市 |

**一句话口径（全文不得写错）**：
**1000 万 = 股东出资 = 公司启动资金；没有估值、没有出让比例、没有"投后 6000 万"。真正有估值与出让的是 Pre-A / A 轮 / B 轮 / Pre-IPO。**

### 甲二、为什么需要 1000 万（自下而上推导）

**先说清结论**：1000 万不是"我们想要 1000 万"，而是**把成都样板做实 + 把数据底座的地基打好 + 把人搭起来，最少需要 1000 万**——它是**自下而上算出来的，不是自上而下定的**。

#### 甲二一、不能更少：砍掉任何一类都会断链

| 如果砍掉 | 会发生什么（断链路径） |
|---|---|
| **砍 A（成都样板 300 万）** | **单店单位经济跑不正** → 后面所有复制都是空中楼阁；平台与下一轮投资人看的第一个硬指标就是"单店能不能赚钱" → 链条断在起点 |
| **砍 B（数据底座 130 万）** | 没有数据来源 → **"数据底座"这个终局不成立**；更危险的是**合规漏洞 = 灭顶**（个人信息保护法顶格可罚 5% 营业额或 5000 万元，且对公司与责任人双罚） |
| **砍 F（能力层 200 万）** | **没有 前置服务工程师（Forward Deployed Engineer，既懂业务、又能把需求落成能跑系统的工程师）就没有"封装"**；没有封装 → **每开一家新店都要派工程师到店（巡场部署）** → 成本线性、不可扩展 → 永远到不了几百家店的规模 |
| **砍 H5（设计师双环境工作站 17 万）** | 设计师（即梁振宇本人，见 F 类三层分工）没有生产级环境 → **"设计 AI 军团"这件事被硬件卡住** → 拖慢整条链（而这本是全场最高杠杆的工作；家用级机器实测跑不动） |
| **砍 G（双牌确权 40 万）** | **本项目最大的结构性风险没有任何对冲**——两张牌照都不在公司自己名下、平台授权一年一签，**授权链一旦断裂，前面全部投入归零** |
| **砍 D（IP 首场 150 万）** | 失去第二盈利点 → 只剩代运营（**抽成率由平台定，8-10 个点，我们没有定价权**）→ 单位经济更脆弱 |
| **砍 E（供应链 70 万）** | 区仓（区域仓储，供资材耗材并采花材成本数据）缺位 → 供货差价收入与"花材成本"这一类底座原料都拿不到 |
| **砍 I（云资源 23.5 万/年）** | 架构地基不存在（本来是"**中央上云 + 采集落店 + 算力按需租赁**"）→ 数据无法汇聚 → 管理面、多城协同都做不了 |
| **砍 C（AI 提效工具 50 万）** | 人效停在 6-8 店/人（**实测**：现在一个人一天只能有效管 6-8 家花店，教师节等峰值掉到 2-3 家）→ 规模一上去人力就压垮单位经济 |

**一句话**：这九类里**没有一类是"锦上添花"**，每一类都对应一个"不买就会断链"的环节。

#### 甲二二、不该更多：为什么不是 2000 万

1. **启动阶段的任务是"验证"，不是"扩张"。** 这个阶段要证明的是"**单店能赚钱 + 数据能采到 + 人能搭起来**"，不是"开多少家店"。钱多了会诱发**超前扩张**（还没验证就开第二城、第三城），反而埋雷。
2. **多要钱 = 多承诺。** 平台授权一年一签、单位经济尚未用真实财务验证——在这种不确定性下多拿钱，等于对出资方多承诺。
3. **每轮只干一轮的事。** 启动阶段干启动阶段的事（验证），Pre-A 才干 Pre-A 的事（第二城复制）。

### 甲五、出资安排（股东出资）

#### 5.1 谁出资、出什么

| 出资方 | 股比 | 出什么 | 状态 |
|---|---|---|---|
| **梁振宇及其实控主体公司** | **51%** | 现金出资（**金额待各方协议确认**） | 待确认 |
| **橙果**（广州橙果供应链科技） | **49%** | ① **现金** ② **全国鲜花类目服务商资格／流量权**（橙果自己持有，作价入股）③ **城市合伙人牌照**（**声通通过法律文书授权给橙果** → 算橙果资源入股的一部分，作价入股） | 三者各占多少【待各方协议确认】 |

**四条必须写清的结构事实**：

1. **公司层面只有两个股东**：梁振宇及其实控主体公司（51%）+ 橙果（49%）。**没有"声通"这个股东，也没有"外部外部投资人"这个股东**。
2. **声通在橙果内部**：声通是**橙果的股东**，它通过**法律文书授权**把城市合伙人牌照给橙果；**这块牌照算橙果资源入股的一部分**。
3. **由此，公司只有一个资源交易对手 = 橙果**：公司**不需要单独跟声通签对赌**；对赌/保障条款**只需对橙果写一份**，覆盖"橙果自己持有的 + 声通授权来的"**全部资源**——**牌照出问题，由橙果对合资公司负责**。
4. **⚠️ 一处必须写进计划书的风险**：**声通的牌照是"授权"来的，不是橙果自己持有的**——授权期限多长？能不能续？能不能被单方撤回？**若授权链断裂，橙果承诺的第三块资源就失效。** 这正是预算 G1（双牌确权 40 万）要核查的核心事项，并在对赌条款中写明：**授权链失效 = 橙果的补偿责任（让渡股份／回购／现金补偿）**。

## 乙、后续各轮融资计划（Pre-A / A 轮 / B 轮 / Pre-IPO）

### 乙一、先说清：为什么"启动资金"与"后续轮次"必须用两套口径

- **启动资金（甲）**：**股东出资**，没有估值、没有出让比例——因为公司层面没有外部投资人。
- **后续轮次（乙）**：**公司向外部投资人融资**，**有融资额、有出让比例、有投后估值**，并逐轮引入机构条款。

**投后估值**（解释：投资人投钱进来之后，公司整体值多少钱）= 融资额 ÷ 出让比例。**本文各轮的出让比例均按此式反推，与投后估值严格自洽。**例如融资 3000 万、出让 15%，投后估值即 2 亿。

| **启动出资**（不是融资轮） | **1000 万（股东出资）** | **—（无）** | **—（无）** | **无（股东出资不涉及估值）** | 现在 |
| **Pre-A** | **2000-3000 万** | **10-20%** | 约 **1.5-2 亿** | 里程碑链（单店经济**真实验证** + 第二城） | 单店单位经济跑正 + 第二城可持续 |
| **A 轮** | **3000-3700 万** | **6-12%** | 约 **3-5 亿** | 里程碑链 + **PS（市销率）**参照 | 跨城份额形成底座雏形 + AI 收入爬向 30% |

> · A 轮：3000-3700 万 ÷ 3-5 亿 = **6-12%**
> · B 轮：5000 万-1 亿 ÷ 17-22 亿 = **2.5-6%**
> · Pre-IPO：1-2 亿 ÷ 52-67 亿 = **1.5-4%**
>

### 乙六、估值方法与阶段对应（理解整条链的钥匙）

**不同阶段用不同的估值方法，而"方法切换"本身就是估值跃升的重要原因。**

| 阶段 | 主要估值方法 | 为什么用这个方法 | 倍数参考（测算） |
|---|---|---|---|
| **启动出资** | **无估值** | 股东出资，不面向外部投资人，**不涉及估值** | — |
| **Pre-A** | **里程碑链**（验证 → 复制） | 仍无稳定收入，但"单店经济已被真实验证"，可用"验证后的同类早期项目"作参照 | — |
| **A 轮** | **PS（市销率）** 为主 | 开始有可观察的规模化收入（GMV → 抽成收入），VC 用 PS 定价 | PS **5-10 倍** |
| **B 轮** | **★从 PS 切到 PE（市盈率）** | 10 城满配产生**真实净利润**，且 AI 收入占比 ≥30%，市场愿意用 PE 定价 | PE **25 倍** |
| **Pre-IPO** | **PE 25 倍** 维持 | 盈利规模继续扩大，倍数维持 | PE **25 倍** |

**一句话**：**前两轮涨的是"风险降低"（从没验证到验证、从 1 城到多城）；A→B 涨的是"方法切换"（从收入故事切到利润故事）；B→Pre-IPO 涨的是"盈利线性放大"。**

### 乙七、四个估值跃升的依据

| 跃升 | 从 → 到 | 倍数 | **核心依据（一句话）** | 量化锚点 | **反向风险（达不到会怎样）** |
|---|---|---|---|---|---|
| **启动 → Pre-A** | 启动阶段（资源重置成本参照约 5000-7000 万）→ **1.5-2 亿** | **2.5-3.3 倍** | **风险性质变化**：单店经济从"测算"到"已验证" | 1 → 2 城；商家 750 → 约 1500；月净利从 0 到为正 | **验证不了 → Pre-A 不成立**（投资人不会为未验证的模型付钱） |
| **Pre-A → A 轮** | 1.5-2 亿 → **3-5 亿** | **2-2.5 倍** | **从服务到产品**：多城规模化 + AI 工具产品化（**首次可用 PS 定价**） | 2 → 5-10 城；月 GMV 4000 万 → 1-2 亿 | **产品化失败 → 退回服务型定价（1.5-2.5 亿）** |
| **A 轮 → B 轮 ★（最大一跳）** | 3-5 亿 → **17-22 亿** | **4-5.5 倍** | **方法切换（PS→PE）+ 真实利润 + AI 收入 ≥30%**（三者缺一不可） | 10 城满配；**年净 0.7-0.9 亿**；**AI 收入 ≥30%**；月净约 1200 万 | **AI 收入 <30% → 25 倍撑不住 → 腰斩到 7-13.5 亿**（按 10-15 倍算） |
| **B 轮 → Pre-IPO** | 17-22 亿 → **52-67 亿** | **约 3 倍** | **盈利线性放大 3 倍 + 倍数维持 25 倍 + 垂类第一** | 10 → 30 城（3 倍）；年净 0.7-0.9 亿 → **2.1-2.7 亿**（3 倍） | 30 城达不到／市场情绪差／AI 占比下滑 → **估值降到 21-40 亿** |
| **IPO** | 52-67 亿 → 二级市场定价 | — | 上市后由市场定价 | — | 破发风险 |

**四个跃升的性质不同**：

1. **启动 → Pre-A**：涨的是「**风险降低**」（最高风险 → 中等风险）——**最硬的一跳**，不依赖新假设，只依赖"把已做到的事再做一遍"。
2. **Pre-A → A 轮**：涨的是「**从服务到产品**」（产品型公司的 PS 显著高于服务型）。
3. **A 轮 → B 轮**：涨的是「**方法切换**」（PS 5-10 倍 → PE 25 倍）——**这是 4-5.5 倍跃升的主要来源**。
4. **B 轮 → Pre-IPO**：涨的是「**盈利线性放大**」（3 倍利润 × 相同倍数）——**最可预测的一跳**。

**⚠️ 两个必须准备好的回答**：

1. **"B 轮凭什么一步涨 4-5 倍？"**——答案必须是"**10 城满配的真实盈利规模 + AI 收入结构的变化 + 数据资产化**"三者同时成立；**若 AI 收入占比达不到 30%，25 倍市盈率撑不住**（可能只给 10-15 倍，估值腰斩到 7-13.5 亿）。
2. **"25 倍市盈率是不是太高？"**——**对代运营/平台类公司偏高**，必须靠"AI 收入 ≥30% + 数据底座资产化"的溢价；否则按 10-15 倍算，30 城估值只有 21-40 亿。

### 乙八、每一步的反向风险（汇总）

| 轮次 | 最可能出问题的地方 | 后果 |
|---|---|---|
| **启动阶段** | 单店经济验证不了；授权链断裂；合规出漏洞 | Pre-A 不成立／牌照资源失效／前期投入不再适用 |
| **Pre-A** | 只验证了单店、第二城复制不了 | 估值可能只到 **8000 万-1 亿**（而非 1.5-2 亿）——因为"复制能力"没被证明 |
| **A 轮** | 城市复制不达预期（只到 5 城）；AI 工具产品化失败；中台没建成 | 估值落到 **2-3 亿**，或退回服务型定价 **1.5-2.5 亿**，并失去数据资产加成 |
| **B 轮** | **AI 收入 <30%**；10 城满配达不到（月净不足 1200 万）；底座没产品化；B 轮拿不到钱 | **估值腰斩到 7-13.5 亿**；分母变小估值下降；失去资产化溢价；**扩张节奏后移（但 30 城仍可靠回血滚动）** |
| **Pre-IPO** | 30 城达不到；港股市场情绪差；AI 占比下滑；上市窗口关闭 | 估值降到 **21-40 亿**；发行估值受压；**走并购退出（倍数通常低于 IPO）** |

**诚实提醒**：这套链是**"论证框架"，不是"已实现的业绩"**——公司尚未注册、单位经济未验证；**链上每一步都要靠里程碑兑现，不是时间到了就自动上涨**。而且**"分母"（净利润）我们能控，"倍数"（市场情绪与可比估值）我们控不了**——所以要做的是**把利润做实、把 AI 收入结构做出来**，倍数交给市场。

### 乙九、梁振宇控制权在各轮的保障

| 轮次 | 控制权安排 |
|---|---|
| **启动（股东出资）** | **梁振宇及其实控主体公司直接持股 51%**——股东层面就是多数，不需要任何额外结构 |
| **Pre-A** | 51% 表决权**不动**（章程锁定关键事项）；投资人为观察员或 1 席董事 |
| **A 轮** | **51% 是谈判红线**；同步可用 AB 股（同股不同权，梁振宇的每股有更多投票权）+ 章程锁定 + 关键事项一票否决 |
| **B 轮** | **仍保 51% 表决权**；董事会可能扩到 3-5 席，梁振宇占多数 |
| **Pre-IPO** | 转为**符合交易所规则的 AB 股／特殊表决权**（⚠️ **部分否决权与特殊权利须在上市前失效**） |

**法律依据（中国）**：《公司法》允许有限责任公司通过**章程约定**表决权与分红不按出资比例，也允许符合条件的股份公司**发行特殊表决权股**——这是"51% + AB 股"能站住的法律基础（具体条款以律师意见为准）。

### 乙十、核心纪律（贯穿所有轮次）

> **外部资本只补到 10 城满配（累计约 5000 万），剩下 20 城靠 10 城每月约 1200 万经营净现金流滚动——不为扩张牺牲股权比例。**

**六条纪律**：

1. **出钱只出在"卡位"上**：数据端口、合规、数据底座、能力层（前置服务工程师）、硬件刚需。
2. **能借力/回血的都不出钱**：平台给 BD 发薪、平台新签激励与返佣回血、算力向投资方租赁、城市仓由合作方出资、IP 授权零成本。
3. **每轮只干一轮的事**：Pre-A 只做第二城、A 轮只做多城与中台、B 轮只满配 10 城、Pre-IPO 只冲 30 城。
4. **能力层三层分工每轮不变**：梁振宇 = 智能体设计师（本人）→ 前置服务工程师 = 工程落地 → 智能体 = 执行；**钱压在"把设计落地"，不压在"招设计师"**。
5. **对赌只对橙果写一份**：覆盖橙果承诺的全部资源（现金 + 全国牌照/流量权 + 城市合伙人牌照，**含声通授权来的那份**）。
6. **所有金额为测算**：待真实报价与财务回填替换。

## 丙、跨轮次条款演变

### 丙一、一张表看清条款怎么变

| 条款 | **启动（股东出资）** | **Pre-A** | **A 轮** | **B 轮** | **Pre-IPO** |
|---|---|---|---|---|---|
| **投资人类型** | **无外部投资人**（梁振宇及其实控主体公司 + 橙果） | 天使／早期机构（可能含产业方） | VC 机构（可能引平台系战略） | 成长基金／产业资本 | PE／战略投资人（含基石） |
| **优先清算** | **不适用**（股东出资不构成"投资"，无清算优先） | **1x** | **1x 非参与型** | **1x** | **可能低于 1x**（临近上市） |
| **董事会席位** | 按章程约定【待确认】 | 观察员／1 席（按金额定） | 1 席 | **1-2 席** | 按上市治理规范 |
| **否决权** | 章程约定的关键事项（保护 49% 股东）【待确认】 | 少量清单 | 清单式 | 清单式（更全） | **上市后失效** |
| **领售权／拖售权** | **不适用** | 可能 | **有** | **有** | **有** |
| **优先购买权** | 股东间转让按章程（《公司法》默认其他股东有优先购买权） | **有** | **有** | **有** | **有** |
| **上市对赌** | **无**（对橙果的是"资源对赌"，不是上市对赌） | 无 | 可能 | **有**（时间／估值） | **有**（明确） |
| **梁振宇控制权** | **51% 直接持股**（股东层面多数） | **51% 保住** | **51% 保住（红线）** | **51% 保住** | 转为符合交易所规则的 **AB 股** |
| **回购义务** | **无外部投资人回购**；仅**对橙果的资源对赌**可触发让渡股份／回购／现金补偿 | **公司层**（义务主体是公司） | **公司层** | **公司层** | **公司层** |

**读表要点**：

- **启动出资那一列几乎全是"不适用"**——这**正是本修正的核心**：启动阶段不引入投资条款，因为没有外部投资人。
- **从 Pre-A 开始，"越来越严"**：优先清算、反稀释、领售权、董事会席位、上市对赌逐轮加码；到 Pre-IPO 又因"一切为上市让路"而**特殊权利开始退出**（部分否决权上市前失效）。
- **梁振宇的 51% 是关键事项的底线**；到 Pre-IPO 转为 AB 股（且须符合交易所规则）。

### 丙二、贯穿前后段的两条铁律

2. **融资阶段：回购与补偿义务的承担主体是公司**；对赌保障条款**只需对橙果写一份**（覆盖其全部承诺资源，含声通授权部分）；**梁振宇控制权（51% / 未来的 AB 股）是谈判红线**。

## 丁、术语表（首次出现即解释）

| 术语 | 解释 |
|---|---|
| **即时零售** | 手机上买、30 分钟-1 小时送到家（如美团闪购、淘宝闪购） |
| **平台服务商／代运营** | 帮平台运营某个品类的第三方公司 |
| **双牌** | ①全国鲜花类目服务商资格（全国流量权）②城市合伙人牌照（商家运营管理权，可主导活动） |
| **股东出资** | 股东按约定把资金投入公司，换取股权；**不是"向投资人融资"，不涉及估值与出让比例** |
| **投后估值** | 投资人投钱进来之后，公司整体值多少钱 = 融资额 ÷ 出让比例 |
| **GMV** | 交易总额 |
| **抽成率** | 平台从每笔交易中给服务商的分成比例（当前 8-10 个点，由平台定） |
| **数据端口／数据底座** | 采集单店数据的技术通道／沉淀成的行业级数据资产 |
| **前置服务工程师** | 既懂业务、又能把需求落成能跑系统的工程师（Forward Deployed Engineer） |
| **工具接口协议** | 把 AI 工具封装成标准接口以便被不同客户端调用的协议（相当于"工具的 USB 口"） |
| **SOP** | 标准作业程序（把做法写成可复制的步骤） |
| **PS（市销率）** | 估值 ÷ 收入，用于有收入但利润尚不稳定的阶段 |
| **PE（市盈率）** | 估值 ÷ 净利润，用于有真实利润的阶段 |
| **优先清算（1x）** | 公司清算或被并购时，投资人先按 1 倍本金拿回，再参与剩余分配 |
| **反稀释（加权平均）** | 后续以更低价格融资时，早期投资人的股份数被上调，以少摊薄 |
| **领售权／拖售权** | 多数股东决定整体出售公司时，可强制小股东一起卖 |
| **共同出售权** | 大股东卖股时，小股东有权按比例一起卖 |
| **上市对赌** | 约定"什么时候上市、达到什么估值"，未达成触发补偿或回购 |
| **AB 股（同股不同权）** | 梁振宇持有的每股有更多投票权，用于在稀释股权后仍保住控制权 |
| **法律文书授权** | 声通通过正式法律文件把牌照使用权授予橙果（**授权链的稳定性是本项目最大风险点**） |
| **对赌** | 约定的条件（业绩/资源），未达标触发回购或补偿 |
| **测算 vs 实测** | 推算估计（未验证） vs 真实业务跑出来的数据（本文实测项已标注） |
