# 花联网 · 股权设计 v1（中国法律结构 + 投票权 + GP/LP + AB股 + CEO里程碑）

> 明鉴 · 2026-09-10 · 基于投资计划（种子→Pre-A→A轮→30城→2030港股IPO）做股权设计，结合中国境内法律框架。引擎 `wargame-sim.py value` 对股权结构方案排序（S/A/B/C）。法律依据：公司法2023（类别股/同股不同权）、合伙企业法（GP/LP）、港交所同股不同权(WVR)。⚠️ 本文为设计框架，落地以专业律师最终出具为准。

---

## 〇、股权设计目标（4 个）

1. **控制**：梁振宇 51% 投票权，前 3 轮不被稀释；且**越做越大、控制权越强**（随业绩/里程碑解锁）。
2. **融资**：按计划融资（种子1000万→Pre-A→A轮→30城回血→2030 IPO），不因融资丧失控制。
3. **激励**：CEO/核心团队期权绑定业绩里程碑（Musk 式），打得越狠拿得越多。
4. **公平**：过程公正（独立董事会定薪、透明里程碑、分档归属、信息披露、不自我交易、再确认机制）。

## 一、中国境内法律框架（哪些工具可用）

| 工具 | 法律依据 | 说明 |
|---|---|---|
| **有限公司·同股不同权** | 公司法 §65 | 股东会**按出资比例行使表决权，但公司章程另有约定除外** → **有限公司可在章程约定梁振宇更高表决权（AB股）**，境内最直接的"同股不同权"。 |
| **股份公司·类别股** | 公司法 2023 §144 | **股份有限公司可发行类别股**，含"**每一股的表决权数多于或少于普通股的股份**"（特殊表决权股）、优先股、劣后股、转让受限股等。→ 股份公司也能做 AB 股（类别股）。 |
| **有限合伙 GP/LP** | 合伙企业法 | **GP（普通合伙人）执行事务、承担无限连带责任；LP（有限合伙人）只出资、不执行事务、以出资额为限**。→ GP 控制，LP 拿钱无控制——**"钱权分离"的标准工具**。 |
| **港股同股不同权(WVR)** | 港交所 | 创新产业公司可**同股不同权**（加权投票权，最高 10:1），**审批门槛已大幅降低**（制度升级）。→ 为 2030 港股 IPO 预留 AB 股/WVR 通道。 |
| **科创板特别表决权** | 证监会/交易所 | 符合条件企业可设**表决权差异安排**（境内上市可选）。 |

> ⚠️ 红线：**有限公司的"同股不同权"靠章程约定**（§65 除外条款），**股份公司的"类别股"需符合 §144 类别股规定**；上市后同股不同权受交易所/WVR 限制；涉境外（VIE/红筹/37号文）更复杂。**落地须律师按其实际持股与章程出具。**

## 二、推荐股权架构（引擎排序：双主体 + GP/LP + AB股 + 持股平台）

> 引擎结论：**S 档 = GP/LP分层(7.7)、双主体结构(7.4)、开曼+WVR(7.3)、境内AB股/类别股(7.2)**。推荐**双层境内架构 + 未来开曼 WVR 接 IPO**：

```
层① 经营控制层 —— 梁振宇(梁振宇)任 GP + 控股股东，51% 投票权(AB股/GP)
层② 资金平台层 —— 财务投资方(LP)，只出钱拿收益，不进控制(外部资本只进这层)
层③ 资源方股东层 —— 橙果(持牌)：董事席位 + 清单式否决(资源作价入股)
层④ 业务子公司层 —— 各业务(代运营/IP/数据/工具)，谁强谁操盘(有限合伙或子公司)
└─ 员工持股平台(有限合伙/期权池) —— 绑定 CEO+核心团队(Musk 式里程碑期权)
```

**具体怎么搭**：
1. **主体**：境内**有限责任公司**（控股）+ 各业务**有限合伙/子公司**（谁强谁操盘）。
2. **梁振宇控制**：① 有限公司章程约定 AB 股（梁振宇 1 股=10 票，§65）；或 ② 梁振宇任**控股有限合伙的 GP**。
3. **资方(个人资方/机构)**：做 **LP**（只出钱拿收益，无控制）——这样**你 51% 出资不用靠资方持股实现**，资方给钱、你拿控制。
4. **橙果**：做**资源方股东层**（董事席位+清单式否决），其**全国鲜花服务商牌照作价入股**。
5. **员工持股平台**：有限合伙承接期权池，CEO+核心团队按里程碑解锁。
6. **为 IPO**：未来**红筹/开曼控股 + WVR(同股不同权 10:1)** 接 2030 港股（港交所 WVR 门槛已降低）。

## 三、投票权怎么实现（GP/LP + AB股 + 章程锁定）

**组合拳**（引擎排序 S 档全用）：
1. **AB 股 / 超级投票权**：梁振宇 1 股 = 10 票（有限公司章程 §65 或股份公司类别股 §144）。**持股比例可低于 51%，但投票权 ≥51%。**
2. **GP/LP 分层**：梁振宇任 GP（执行事务+控制），外部资本=LP（只进资金平台层，不碰控制）。**与 AB 股叠加，双重锁定。**
3. **章程表决权锁定**：章程写死"创始股东表决权 ≥51%"（表决权与分红权分离约定）。
4. **梁振宇一票否决 + 董事会控制**：增资/稀释/清算/出售/预算等关键事项，梁振宇一票否决。
5. **期权池放顶层控股、以里程碑解锁**（Musk 式），与 51% 控盘身份物理隔离。
6. **反稀释（加权平均）+ 优先认缴（pro-rata）**：每轮梁振宇有权跟投；不跟投才摊薄，投票权靠 AB 股/章程保护。
7. **双主体**：控股公司/有限合伙持有 51% 表决权，梁振宇控制该主体（控股结构转移控制权到梁振宇手中）。

> **结论**：前 3 轮（种子/Pre-A/A轮）靠 **AB 股 + GP 分层 + 章程锁定 + 一票否决**，**持股比例可被稀释，51% 投票权不被稀释**；且随 CEO 里程碑期权解锁，**控制权逐年增强**。

## 四、CEO 里程碑期权怎么设计（Musk-适配，境内可行）

**总设计**：0 现金底薪打法 + **股权绑定业绩里程碑**，分档归属（cliff + tranche），董事会（独立委员会）定薪，客观市场基准，信息披露。

**里程碑两轨**（对应投资计划）：
| 轨 | 里程碑（例子） | 解锁档 |
|---|---|---|
| **经营轨** | ①成都样板单城单位经济为正（毛利160-200万/月、回本8-10月）②人效 6-8→15-20店/人、IM回复率60→90% ③数据接入 750→1200+、合规100% ④IP首场 溢价≥30%/自发消费≥60% ⑤5城/10城/30城 复制 | 每达成一档解锁一批期权 |
| **估值轨** | Pre-A 估值达标、A轮估值达标、2030港股IPO（市值达 SaaS 3-4x PS + AI收入≥30%） | 估值/市值里程碑 |

**设计要点（公平）**：
- **分档归属+行权价格**：每档期权设行权价（按归属时估值），达成里程碑才解锁（不靠时间），行权后**限售**（锁定期）。
- **独立董事会定薪 + 非自我交易**：薪酬/期权由独立董事/薪酬委员会定，梁振宇**不自己定自己**的薪酬（Musk 2018 方案被推翻的教训——程序不公/自我交易）。披露+股东大会确认+**再确认机制**（若被判不公可重新批准）。
- **客观基准**：市值/营收/人效/数据接入都是可测第三方/经营数据，不是主观。
- **过程公平**：预设透明里程碑、平等对待小股东、防稀释保护、信息透明。
- **合规红线**：境内期权激励（员工持股平台/ESOP）需符合**公司法/证券法/税务机关**（股权激励个税、递延纳税）、**外汇（37号文，若境外）**、上市前**期权池占比**（通常 10-20%，上市后摊薄）。

## 五、合到一起（一句话架构）

> **境内有限责任公司（控股·梁振宇AB股§65）为轴**：梁振宇（GP+AB股 1股=10票）任经营控制层 → **财务资方=LP**（只出钱拿收益·无控制，钱权分离）→ **橙果=资源方股东层**（持牌作价+董事+清单式否决）→ **员工持股平台（有限合伙·期权池）**绑 CEO+核心团队（Musk式里程碑期权·经营轨+估值轨）。**前 3 轮不稀释梁振宇 51% 投票权**（AB股+GP分层+章程锁定+一票否决+反稀释+优先认缴），**CEO 期权随业绩里程碑解锁、控制权越做越强**。为 2030 港股 IPO 预留**红筹/开曼控股 + WVR** 通道。⚠️ 落地以专业律师出具为准（尤其章程、类别股、ESOP、37号文、港股权）。

## 六、补充：橙果=三方资方 + 牌照分块结构（引擎补充 · 2026-09-10）

> 用户补充关键信息，修订 §二/§五 的"橙果=纯资源方"框架：**① 橙果本身由三方资方组成，应出钱（不只是牌照作价）**；**② 牌照分块——一块在橙果（淘宝闪购全国鲜花类目服务商），另一块在声通的其他子公司**。所以架构要同时处理「橙果（三方资方·现金出资+牌照1）」与「声通子公司（牌照2）」两个**不同的贡献方**。

### 6.1 引擎排序（补充信息后 · S/A/B/C）
| 档 | 结构 | 分 |
|---|---|---|
| **S** | **双主体：控股公司（你的AB股）+ 橙果/声通以"牌照+现金"分层进入**（橙果=资金LP+牌照1资源；声通子公司=牌照2资源股东层） | **7.6** |
| **S** | 橙果（三方资方·现金出资+牌照1）做财务+资源双股东；声通子公司（牌照2）做资源股东；你 GP+AB股控 51% | 7.55 |
| **S** | 橙果=LP（现金+牌照1作价）；声通子公司=资源作价（LP）；你=GP（51%·AB股） | 7.55 |
| **S** | 牌照（橙果1+声通子公司1）作价入股+现金分成两种贡献；你以 GP+AB股+一票否决锁定控制 | 7.25 |
| **S** | 橙果+声通子公司（两牌照方）共同持股；你靠 AB股（1股=10票）保持投票≥51% | 7.05 |

### 6.2 推荐结构（引擎最优 · 双主体 + 分层进入）
```
层① 经营控制层 —— 你(梁振宇)：控股公司(有限责任公司)·AB股(1股=10票)+GP → 51%投票权
层② 资金平台层 —— 财务资方(含个人资方/机构)：LP，只出钱拿收益，无控制
层③ 资源方股东层 —— 橙果(三方资方组成·现金出资+持牌照1=淘闪全国服务商)：董事席位+清单式否决
                    + 声通其他子公司(持牌照2=成都城市合伙人/另一块)：资源作价入股(董事/清单式否决按约定)
层④ 业务子公司层 —— 各业务(代运营/IP/数据/工具)谁强谁操盘(有限合伙/子公司)
└─ 员工持股平台(有限合伙·期权池) = CEO+核心团队(Musk式里程碑期权)
```

### 6.3 关键拆分（为什么这么设计）
1. **橙果=「现金出资 + 牌照1」双重贡献**（三方资方要出钱）：橙果不是纯"挂牌作价"，而是**进资金平台层(LP)出一部分钱** + **牌照1作价进资源方股东层**。回报也对应双重（资金收益 + 资源作价收益）。
2. **声通子公司=「牌照2」资源贡献**（另一块牌照在它）：声通子公司以**牌照2作价**进资源方股东层（董事+清单式否决），**主要是资源贡献，可不强制现金出资**（牌照已值钱），或按约定少量出资。
3. **你的控制**：仍靠**AB股(1股=10票)+GP分层+章程锁定+一票否决**，前3轮51%投票权不稀释。橙果/声通子公司持股比例可高，但**投票权被你锁定**。
4. **双主体**：控股公司(你AB股)持有51%表决权 → 你控制控股公司 → 控股公司控制经营主体。橙果/声通以**牌照+现金分层进入**，**钱、牌照、控制三件事分开**。
5. **双牌合一**：因为牌照分在橙果和声通子公司两块，**架构里把两块牌照都作价进来**（橙果的淘闪全国服务商 + 声通子公司的成都城市合伙人/另一块），**合作后双牌合一**放在合资公司/控股层，避免"牌照分散在两家、合作名存实亡"。

### 6.4 一句话修订
> 不再把橙果当"纯挂牌资源方"——**橙果是三方资方组成、要出钱 + 持牌照1**；**声通其他子公司持牌照2**。推荐**双主体结构**：控股公司(你AB股/51%投票权) + 橙果(资金LP + 牌照1资源) + 声通子公司(牌照2资源)分层进入 + 员工持股平台(期权池)。**钱(橙果/各方出资)、牌照(橙果1+声通2)、控制(你AB股/GP)三件事在架构里分开设计、清晰归位**，且**两块牌照整合到合资层，双牌合一**。

## 七、再补充：全国牌照/流量权（橙果）+ 城市合伙人网络（每城不同主体）

> 用户再补充关键信息：**① 全国牌照-流量权在橙果**（核心资产）；**② 城市合伙人牌照在声通子公司或控制公司**，且**因合规所需，每个城市可能由不同的子公司获得城市合伙人**（每城主体不一定相同）。所以这是"**全国盘子 + 城市网络**"两层，不是单一城市合伙人实体。

### 7.1 引擎排序（全国+城市网络 · S/A/B/C）
| 档 | 结构 | 分 |
|---|---|---|
| **S** | **全国合资控股(你AB股+橙果流量权) + 每城城市合伙人为独立主体(网络加盟式,合规每城不同)** | **7.45** |
| **S** | 全国+城市两层均持牌：橙果全国流量权 + 声通系城市网络，合资公司为统一操盘中枢(你AB股51%) | 7.3 |
| **S** | 橙果=全国流量权主资产；声通系=每城城市合伙人(不同子公司)；你=全国+城市操盘方 | 7.15 |
| **S** | 全国层=你控(AB股)+橙果(流量权作价)；城市层=每城公司，但城市合伙人主体随城随合规变化，合资以协议锁定 | 7.15 |
| **A** | 城市合伙人由声通系不同子公司持有，合资公司以授权/分成绑定每城(非持股) | 6.6 |

### 7.2 推荐结构（引擎最优 7.45 · 全国合资控股 + 城市网络加盟式）

```
【全国层 · 合资控股】(统一操盘中枢)
  你(梁振宇) = 控股公司·AB股(1股=10票)+GP → 51%投票权，全国操盘
  橙果 = 全国牌照/流量权(核心资产)·作价/资源进股东层 · 董事+清单式否决
  财务资方(含个人资方) = LP(资金平台层·只出钱拿收益)

【城市层 · 每城独立主体(网络加盟式)】
  城市1 = 某声通系子公司A(或控制公司) 持城市合伙人牌照(合规)
  城市2 = 某声通系子公司B(或控制公司) 持城市合伙人牌照(合规·主体不同)
  城市N = 每城依合规由不同主体获得城市合伙人牌照
  └─ 合资公司以「授权/分成/协议」绑定每城(非逐城持股，或按城设子公司/合伙)

【横跨】员工持股平台(有限合伙·期权池) = CEO+核心团队(Musk式里程碑期权)
```

### 7.3 关键点（全国+城市 两层怎么控）
1. **全国流量权(橙果) = 最硬资产**：橙果的"全国牌照/流量权"是全国盘子的**锚**。橙果作价/资源进股东层，但**投票权归你(AB股)**——橙果出流量权，你锁控制。
2. **城市合伙人 = 每城不同主体(网络加盟)**：因合规，每城城市合伙人可能由**不同声通子公司/控制公司**获得（主体不同）。所以**城市层是"网络/加盟"结构**——合资公司**不逐城持股，而是以授权/分成/协议绑定每城**，或按城设子公司/合伙（谁强谁操盘/当地合规）。
3. **统一操盘中枢**：合资公司(你 AB股51%)是**全国+城市的统一操盘中枢**——全国盘子在合资，城市盘子通过授权/协议挂到合资下。**你控中间(全国+城市网络的整合者)**。
4. **合规驱动的主体变化**：每城主体随合规变(不同子公司)，所以**架构别把它当固定单实体**，要设计成"全国统一 + 城市适配"的**可扩展网格**（新城市开新主体/新合伙/新授权，可复制）。
5. **对投资的含义**：城市扩张(5城/10城/30城)不是"开分公司"，而是"**每城按合规设主体/授权 + 绑定到全国合资(你控) + 复用全国流量权(橙果)**"——**全国盘子你控、城市盘子可复制、橙果流量权做锚**。

### 7.4 一句话修订
> **全国层**：合资控股(你AB股51%·GP) + 橙果(全国牌照/流量权·作价进股东层) + 财务资方(LP·资金)；**城市层**：每城按合规由**不同声通系子公司/控制公司**获得城市合伙人牌照，合资以**授权/分成/协议**绑定(不逐城持股，或按城设公司/合伙)，形成**可复制的城市网络**；**你=全国+城市统一操盘中枢(AB股/GP控51%)**，橙果=全国流量权做锚。**牌照结构=全国盘子(橙果流量权) + 城市网络(每城不同主体)，两层都绕不开你(你AB股/GP)+橙果(流量权)。** ⚠️ 每城合规主体与具体授权/持股，落地以专业律师出具为准。

### 7.5 重要澄清：城市合伙人牌照 = 商家运营管理权（主导活动）
> 用户确认：**城市合伙人牌照掌握的是"商家运营管理权（主导活动）"**，不是传统意义的"某城市品牌/地域牌照"。这直接把城市层从"被动资产"正名为"**主动运营权**"：
- **城市合伙人牌照 = 授权主导**该城**商家的营销/运营/活动**（帮商家做增量、做活动、拉 GMV）——这正是我们整个业务的**运营引擎**。
- **价值链完整化**：全国流量权(橙果)=触达用户/流量入口 → 城市运营权(城市合伙人·主导活动)=主导商家运营/活动·产生 GMV/增量 → 平台/商家受益。
- **架构含义**：城市层是"**运营权**"而非"地域牌照"——每城一个运营权点（主导该城商家活动）；你=全国流量权(橙果)×城市运营权(城市合伙人)的**整合者/增量操盘中枢**。**运营是价值引擎，流量权是入口，城市运营权是产出。**
- **对模型**：与"帮平台做增量/运营"定位完全一致——平台(淘闪)需要城市合伙人，正因它要的是**能把商家活动/运营做起来、拉增量的操盘手**。
