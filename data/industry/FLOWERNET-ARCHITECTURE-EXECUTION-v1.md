## 〇、为什么架构线优先（引擎 8.0 第一）

- **架构线 = 执行的地基**：它把战略/业务线条/预算**全部落到"能跑"的地面**。
- **架构线（8.0）> 战略线（7.9）**——**"能跑出来"比"想清楚"更值钱**；战略已足够，**当下瓶颈在"架构能否落地"**。
- **目标架构**：**分布式采集落店（真实IP+指纹）+ 中央云（数据/管理中枢）+ 算力租赁 + 三层分工（梁振宇设计/FDE落地/智能体执行）+ 双/三环境**。

## 一、分层落地清单（5 层 · 做什么/交付物/验收/周期）

### L1 · 采集层（分布式落店）★★关键约束
| 项 | 内容 |
|---|---|
| 做什么 | 每店/每城 **标准化采集机**（Chrome 实例·独立 profile+CDP·真实门店IP+设备指纹）；**双OS（Mac/Win）**；**不做中央化采集**（机房登录=风控高危） |
| 交付物 | ①采集器标准包（Docker/一键部署/自更新/远程运维）②双OS 支持 ③门店采集机清单（每店/每城） |
| Owner | **FDE（工程落地）**——封装；梁振宇（设计）；门店人员/远程（部署） |
| 验收 | 采集器**一键部署成功**（不用工程师到店）；真实IP+指纹通过平台风控；多账号隔离（不同OS/指纹） |
| 周期 | 种子期（1-3 月） |
| 对应预算 | H1 采集机 8万（种子）→ 各轮 +16/+60/+150/+500万（随店） |

### L2 · 中央层（数据 + 管理中枢）
| 项 | 内容 |
|---|---|
| 做什么 | **云中央服务器 = 数据聚合 + 管理面**（面板/告警/报表单点）；**≤30店/1城不自建**（用云）；**缺"采集"，只做聚合与管理** |
| 交付物 | ①云中央服务器（16核/64G/1TB 档·50店规格）②数据聚合管道（10机→1库）③管理面板/告警/报表 |
| Owner | FDE + 数据/合规专员 |
| 验收 | 数据从各店采集机**汇聚到 1 库**（订单43列/IM/评价）；管理面单点可见；备份/审计一致 |
| 周期 | 种子期（1-3 月） |
| 对应预算 | I1 云中央服务器 6万/年 + I2 云数据库/存储 4万/年 |

## 二、关键前置（合规 · 必须先做）

| 前置 | 内容 | 红线 |
|---|---|---|
| **数据合规** | 只采**商家经营数据**；严格**隔离 PII**（收货人手机号/地址） | 碰 PII = 个保法顶格 5%/5000万双罚 |
| **封装前置** | 采集器封装（Docker/一键部署/自更新/远程运维）**先做**——否则每店派人（巡场 5.2 C 不可扩展） | 封装差 → 落店成本爆炸 |
| **风控前置** | 采集**必须留店真实IP+指纹**；**严禁中央化机房登录** | 中央化采集 = 5.45 C（风控高危） |
| **牌照合规** | 全国流量权（橙果）+ 城市合伙人（声通子公司·每城不同主体）授权链确权 | 授权链以律师为准 |

## 四、执行顺序（建议）

```
第1步  环境就绪（设计师双环境 Mac+Windows）—— 你的"设计台"先到位（H5）
第2步  三层分工立起来（梁振宇设计 + FDE 落地 + 智能体执行）
第3步  FDE 封装采集器（Docker/一键部署/自更新/远程运维）—— 一次建造的杠杆
第4步  采集落店（分布式·真实IP+指纹·双OS）—— 验证风控通过
第5步  中央云汇聚（数据+管理中枢·≤30店不自建）
第6步  算力租赁接入（投资方算力）
第7步  合规前置贯穿（只采商家数据·隔离PII）
```

**核心顺序逻辑**：**先"设计台"（环境）→ 再"设计师+FDE"（能力层）→ 再"封装"（杠杆）→ 再"落店"（采集）→ 再"汇聚"（中央）→ 再"算力"（租赁）**。**合规贯穿全程。**

---

## 五、风险与红线

1. **中央化采集 = 风控高危（5.45 C）**——**绝对不做**；采集必须分布式落店。
2. **巡场部署 = 不可扩展（5.2 C）**——必须靠**封装**实现"一次建造、多处部署"。
3. **PII 隔离 = 硬红线**——只采商家经营数据，碰收货人手机号=个保法顶格罚。
4. **内存墙**——按实测 **2.0 GB/店** 配（不是标称 500MB）；**解=分布式（分散）+轻量化（API/MCP优先）**，不是配更大机器。
5. **自建硬件中心**——**≤30店/1城不自建**（临界 40-50店/跨3城）；**算力=租赁**。
6. **⚠️ 金额测算（R1）**——待真实报价/财务回填。
