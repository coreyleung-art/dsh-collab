# design-05 · IP 联名造节方案（IP 授权贸易线闭环 × 双旦部署）

> 明鉴 v3 · 2026-09-09 · 基于 09-08 淘闪城市站原文（split-obcnwjk9：01/02/03/05/09/10 章）与深挖 §2.2–2.4 编制。
> 口径：**淘闪=淘宝闪购**（阿里本地生活系），联名活动**发起方=淘宝闪购**；我方双角色=全国鲜花服务商（广州橙果，91440101MA5D19KY33）+成都城市合伙人（中恒天仰，91110108327275954W，ESP 中标）；「双旦」=圣诞+元旦。
> 配套 supply 蓝图 ip-license/acquire 主线与 citywar 城市战打法。

## 一、背景与依据

成都淘闪盘约 700–800 存量商家、有效动销 750、我方 15% 份额（深挖 §2.1）。存量见顶，增量只来自：①他平台鲜花用户迁入淘闪；②无消费需求者被 IP 群体经济（"无脑粉"）带成新注册（01 章）。IP 是把同款逻辑放大为"平台牵头、全国报名、我司控资材授权"的造节工具。

## 二、小阿狸案例复盘：明星同款=已验证捷径

**案例事实**（05 章，平台方原话）：小阿狸活动平台**选中红玫瑰款**，参与门店**全部可打「小阿狸同款」**——本质不是新造 SKU，而是给热销现货叠 IP 标签，"在类目与流量切线里做文章"；同逻辑可打泡泡玛特/原神/王者同款。

**四条结论**：①**爆款现货×IP 标签=零新增 SKU**，供应链零风险；②**全门店可上=覆盖面优先**，全城铺量对冲单店转化不确定；③**款在 IP 前**：先有 IP 定向，再有包材/公仔等载体的供给选择，再抓商家上活动，三层整体推（05 章）；④同款（平台选款+门店打标）是 IP 联名（平台发起+报名+指定资材+监修）的**商家教育与流量位样本**。

## 三、"应援月"造节框架：打破 27/23 个节日框架

- **打破节日框架**：鲜花被 27（一说 23）个节日框死、等节卖花；IP 造节不靠自然节日——"为我的老公（乙女角色）买一束 IP 花"，购买理由是粉丝情感（03 章），把粉丝既有消费习惯**移植到淘闪**完成。
- **应援月非一天**：二次元活动做"应援月"（预告→应援期→返场），用 30 天量级培养习惯换取 GMV 与新注册，而非单日脉冲。
- **IP 矩阵而非单一 IP**（03/02 章）：头部筛 1 个意愿度/配合度高者打透打案例（"求不来只能吸引"，不浪费精力）；腰部做矩阵服务最广画像；尾部自培收编。配**双向评分撮合**（商家配合度×IP 配合度），我方赚撮合+资材差价。
- **画像切蛋糕**：向平台要存量消费画像，按人群切开对号喂 IP（02 章）；**优先游戏/乙女 IP**（粉丝最忠诚）；泡泡玛特市场授权部门只关注 GOGO 全球授权，不作第一波（02 章）。

## 四、淘宝闪购牵头的协作模式

- **发起邀约**：以淘闪为发起方邀约**全国花店**报名（03 章）。权限在平台鲜花类目总负责人侧：全局商家信、活动 banner、花严选专栏上/下插 IP 联名位、指挥 BD（20 PD 新签+10 BD 运营）宣传、门店定档升档（青铜→铂金/钻石）（01 章、深挖 §2.2）。
- **三个解决路径**（02 章）：①类目路径——我司已服务鲜花商家全上活动；②城市路径——成都 750 家花店整体上（配快闪）；③全国路径——与阿里总部谈。执行序：先①②打案例再谈③。
- **报名即授权**：报名=签**电子协议**（主协议下分授权），通过即正版可售；授权带数量限制——**一货一物**，买多少包材卖多少束（09/10 章）。
- **平台治理配合**：平台不下场指定供应商，但"指定做正版"——非授权渠道采购=盗版→举报→链接下架→关店自修（09 章）；我方发起活动即主动风控第一步，后台可查虚拟门店与"报名未采购"（10 章）。

## 六、地推打法：成都=自己地盘才投

商场大屏、中庭快闪只在城市合伙人覆盖的**成都（自己地盘）**投放，其他城市不投（03/09 章）。场景：消费者持 IP 联名花拍摄传播（合影/应援打卡），快闪点线下反哺线上报名转化；成本归成都盘、与全国活动 GMV 分离核算。

## 七、IP 授权贸易线闭环落地（10/09 章、深挖 §2.4）

1. **正版锁=定制包材**：包材定制并送 IP 监修——**不买资材包，理论上不可能有正版花束**；授权金实体化在耗材上，经包材销售回收（09 章）。
2. **完整授权链**：IP 监修 → **IP 指定工厂生产（例：喜得利）** → **IP 指定贸易公司销售**（10 章）；平台只治站内正版，线下靠"无包材=无正版"物理锁。
3. **IP 聚合平台**：拢进多 IP（IP 公司**下挂**不外挂），服务门店家族设计与联动元素（深挖 §2.4）。
4. **自建管道=贸易线逻辑**：IP 方要求全渠道可售（阿里/淘宝/京东）——我方获授权后自建销售网络作定向 IP 授权入口，管道自用优先、不限制销售对象（狂热粉 DIY 也要买得到包材，10 章）；贸易公司兼作电商：阿里巴巴上架/自建站均可，**有授权即通，全国发货**。
5. **审计闭环**：以"报名未采购"名单核包材采购量 vs 报单量，堵"报名不买、外购盗版"（10 章）。

## 八、里程碑

M1（09 底）方案+四件事过平台审、IP 池 20+；M2（10 底）头部 IP 意向+授权链签约、首样过监修；M3（11 底）报名页上线、资材包 60% 到仓、地推点位锁定；M4（12 中）双旦全量上线+快闪执行；M5（01 中）复盘+评分库 v1+下节点 IP 排期。

2. 首个头部 IP 候选与谈判窗口（泡泡玛特仅长期撩拨）。

4. 工厂档期产能（旺季排产提前锁）；一货一物防伪等级（是否溯源码）。
