# rule-judge L2 业务断言库设计（rj2-1）

> 明鉴 v2 · 2026-09-02T00:16:59 · 原理：把『对不对』交给确定性裁判层（Lean 思想）

## 六大断言类
| 类别 | 示例 | 来源 |
|------|------|------|
| 成本红线 | 人力成本≤28% / 花材成本≤40% | 画像/SOP/妙记 |
| 库存上限 | 预售锁单≤80%产能 / SKU 库存红线 | 大促三失衡 |
| 毛利率 | ≥35% / 折扣率∈[0.5,0.9] | 定价决策 |
| 节日定价 | 系数 1.5-2.0 / 客单价≤2x | 节日日历化 |
| 产能约束 | 超时单≤36 / 接单≤产能 | 七夕教训 |
| 合规 | 报价≥成本 / 花材单价预警 | 基础+画像 |

## 架构
- 格式：JSON 断言（name/expr/category/source/severity/active）
- 引擎：规则编译（Policy Compiler）
- 流程：AI 提议→L1 schema（已落地）→L2 断言→不过打回+原因→通过放行
- 灰度：新断言影子模式→回测误杀率→硬阻断（rj2-3 switch OFF）
