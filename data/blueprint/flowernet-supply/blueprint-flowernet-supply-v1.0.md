## 一、主线(重梳)

- **trade**：贸易线 — 给代运营/加盟商家 B 端供货, **聚焦资材/耗材/包材**(供给侧分散无全国品牌=可整合空白; 花材红海不碰); 高耗材消耗路线支撑加盟扩张
- **ip-license**：IP 授权线 — IP 授权**贸易线闭环**(09-08会议实证): 定制包材=正版锁(不买资材包无正版) → IP指定工厂生产(如喜得利) → IP指定贸易公司销售 → 自建销售网络 → **IP聚合平台**(IP公司下挂未来主体, 不能外挂); 面向花店生态 IP 配件标准化供货(公开无玩家=空白); IP 第一候选=初蘅自有品牌 + 外部IP(张庭鹤/小阿狸等二次元)
- **lock**：锁店线 — 供应链控店: 联营/加盟靠"运营+供应链锁店", 供应链利润锁住门店关系(核心盈利支点); ⚠️须配差异化货盘+价格波动对冲(宜花/花加前车之鉴)
- **acquire**：获客线 — IP 专有花束(配件来自 ip-license): 帮城市合伙人区域获代运营商家→外部流量; 他平台无授权商家有需求→消费者迁移导流当地淘闪
- **ops**：运营线 — 履约/库存/账务(子公司独立核算, 对公)
- **warehouse**：区仓线 — 每区一个细仓(服务本品牌8-10店+周边ABCD商家); 鲜花前置仓=垂直细分仓(25㎡三匹机/库存低/无需冷链/全平台可发to B)——BD一鱼三吃(供应链客户+淘闪上新+硬件软件)
