# 问老登/MTM：中央服务器需要什么硬件？

明鉴 2026-09-10。背景：我们在做种子轮硬件预算，要论证"**跑代运营是否需要自己的硬件中心**"。请给四点真实口径（脱敏即可）：

1. **现状**：你们现在 MTM/代运营跑在什么机器上？（几台、什么配置：CPU/内存/存储、mac-mini/i9/云？）浏览器采集/CDP 各跑在哪？
2. **中央服务器**：如果做「中央服务器」（集中管多店/多平台/多城/多账号），需要什么硬件？
   - CPU/内存/存储（数据底座：订单43列+IM+评价+events 的存储量级？）
   - 网络（带宽/并发：多平台浏览器采集的并发数）
   - 是否需要 GPU（AI 推理：客服拟稿/异常分级/定价；还是靠投资方算力租赁就够？）
   - 操作系统/部署形态（Linux/容器/裸机）
3. **是否需要自己的硬件中心**：跑代运营**真的需要自建硬件中心**吗？还是「云/托管 + 投资方算力租赁 + 本地采集机」就够？自建 vs 租的临界点在哪（多少店/多少城时）？
4. **中央服务器能解决什么**：现在的「分布式本地机器」有什么瓶颈（登录态/掉线/并发/多账号隔离/数据散），中央化能解决什么、解决不了什么？
