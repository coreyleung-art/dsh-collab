# 越秀采购成本率深挖报告 v2（含代运营三阶段分析）

> 更新时间：2026-06-11 | 数据范围：2025年12月 - 2026年5月

## 一、核心结论

**越秀采购率高的原因是双重打击：自运营期花材浪费严重 + 花千束期平台抽成暴增。配送费不是主因。**

| 根因 | 占采购率差异的贡献 | 说明 |
|------|-------------------|------|
| **分母效应（营收不足）** | ~60% | 日均单量仅18.5单 vs 天河28.1单，营收低44% |
| **自运营期花材浪费** | ~25% | 12-1月每单花材¥77，是天河同期¥32的2.4倍 |
| **花千束期配送费暴增** | ~15% | 2-4月平台配送费占营收17.7%，远超天河11.4% |
| **配送费绝对值差异** | ~0% | 每单配送费越秀¥11.5 < 天河¥11.9，不是原因 |

## 二、配送费对比：不是主因

| 指标 | 天河(12-5月) | 越秀(12-5月) | 差额 |
|------|-------------|-------------|------|
| 平台配送费占营收 | 11.4% | 12.7% | +1.3% |
| 每单平台配送费 | ¥11.9 | ¥11.5 | -¥0.5 |
| 物流配送占营收 | 3.6% | 3.1% | -0.6% |
| 每单物流配送 | ¥3.8 | ¥2.8 | -¥1.0 |

越秀每单配送费反而比天河低。占营收比率高1.3%纯粹是分母（营收）低导致的。

## 三、越秀代运营三阶段分析

### 阶段1：自运营（12月-1月）

| 指标 | 数值 | 对标天河同期 |
|------|------|-------------|
| 日均单量 | 6.2单 | 18.0单 |
| 采购率 | 74.7% | 44.3% |
| 花材占营收 | 49.2% | 26.9% |
| 每单花材 | ¥77.0 | ¥32.0 |
| 每单包材 | ¥11.2 | ¥4.4 |
| 每单其他 | ¥24.8 | ¥13.0 |
| 平台配送费占营收 | 10.5% | 11.5% |

**问题**：日均仅6.2单，花材每单¥77是天河同期¥32的2.4倍。原因：
- 自运营经验不足，花材损耗/浪费严重
- 单量太少，固定花材消耗无法摊薄
- 开业初期商品结构不成熟，大量采购试错（"其他"类每单¥24.8）

### 阶段2：花千束代运营（2月-4月）

| 指标 | 数值 | 对标天河同期 |
|------|------|-------------|
| 日均单量 | 21.0单 | 20.6单 |
| 采购率 | 53.0% | 42.3% |
| 花材占营收 | 40.0% | 25.4% |
| 每单花材 | ¥28.7 | ¥26.7 |
| 每单包材 | ¥2.1 | ¥3.0 |
| 每单其他 | ¥5.6 | ¥7.4 |
| **平台配送费占营收** | **17.7%** | **12.2%** |

**问题变化**：花千束把单量拉起来了（日均21单），每单花材成本也从¥77降到¥28.7，但暴露了新问题：
- **平台配送费占比暴增至17.7%**：代运营猛推线上单，配送费占比远超天河12.2%
- 花千束推太多新品，非花材物料采购增加（花艺资材¥2,716，包括大量喷漆/丝带/玩偶/抱抱桶等装饰品）
- 但从每单角度看，花千束期间的花材成本（¥28.7）已接近天河（¥26.7），**采购绝对效率在改善**

### 阶段3：新策略代运营（5月）

| 指标 | 数值 | 对标天河5月 |
|------|------|-------------|
| 日均单量 | 35.5单 | 50.7单 |
| 采购率 | 45.0% | 45.6% |
| 花材占营收 | 32.9% | 33.1% |
| 每单花材 | ¥33.1 | ¥29.0 |
| 每单包材 | ¥2.5 | ¥3.1 |
| 平台配送费占营收 | 7.6% | 10.5% |

**关键突破**：
- 5月采购率45.0% ≈ 天河5月45.6%，**已经追平**
- 花材占营收32.9% ≈ 天河33.1%，**完全一致**
- 平台配送费占比7.6% 甚至低于天河5月的10.5%（私域占比提升的结果）
- 新策略下代运营只负责线上操作和市场调研，商品结构由自己控制

## 四、天河代运营前后对比（参照）

| 指标 | 旧代运营(12-3月) | 新代运营(4-5月) | 变化 |
|------|-----------------|----------------|------|
| 采购率 | 44.3% | 36.8% | -7.5% |
| 花材占营收 | 26.9% | 25.8% | -1.1% |

天河换新代运营后，采购率从44.3%降到36.8%，主要改善来自每单花材降¥8.4和"其他"类降¥7.3。

## 五、越秀采购"其他"类深挖

v2登记表中"其他"类占比：

| 月份 | 越秀其他占采购 | 天河其他占采购 |
|------|--------------|--------------|
| 12月 | 25.4% | 19.9% |
| 1月 | 16.9% | 28.4% |
| 2月 | 14.2% | 33.3% |
| 3月 | 14.1% | 15.3% |
| 4月 | 16.1% | 21.4% |
| 5月 | 17.9% | 15.2% |

"其他"类主要包括：
- **绿植盆栽**（蝴蝶兰等，不算"鲜切花材"前缀）
- **永生花材**（干花等）
- **鲜切叶材**（配草/配叶，不算"鲜切花材"前缀）
- **花艺资材**（喷漆/丝带/玩偶/抱抱桶/贺卡等装饰品）
- **无前缀商品**（如透明醒花筒、玩偶挂件等）
- **水果**（苹果、草莓等花束搭配物）

花千束期间花艺资材采购明细（2-4月合计¥2,716）：
- 大量喷色剂（马卡龙蔷薇粉/薄雾紫/碎冰蓝等）¥707
- 玩偶配件（kt猫眼镜/珍珠链/爱心卡片夹等）¥433
- 抱抱桶花器（套四无盖圆形桶）¥274
- 花泥¥440
- 玻璃纸/防尘袋/丝带等包装辅助¥397
- 硬卡纸包花纸（新品色系）¥134

**但"其他"类不是越秀采购率高的主因**——越秀每单"其他"¥8.5 vs 天河¥9.2，越秀反而更低。

## 六、行动建议

### 短期（6月验证）
1. **继续5月策略**：采购率45%已是合理水平，6月若维持即确认策略有效
2. **关注每单花材**：5月¥33.1仍高于天河¥29.0，继续优化花材用量
3. **私域建设**：5月配送费占比7.6%的突破来自私域，继续加大

### 中期（Q3）
4. **日均单量目标35+**：单量到日均35单后，采购率自然降到45%以下
5. **商品结构标准化**：限制代运营推新品频率，避免花千束式物料浪费
6. **供应链集约**：同供应链采购已无优化空间，重点在门店端消耗管控

### 关键观察指标
- 越秀6月采购率是否≤45%（5月水平）
- 越秀日均单量是否≥35单
- 越秀私域营收占比是否持续提升
