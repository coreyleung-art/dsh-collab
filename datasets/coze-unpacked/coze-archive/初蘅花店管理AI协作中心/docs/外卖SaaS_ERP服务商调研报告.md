# 美团外卖集成SaaS ERP服务商调研报告

## 一、调研背景与目标

### 1.1 用户需求概述
- **用户场景**：4家鲜花连锁门店（禅城/华师/越秀/天河），位于广州佛山地区
- **核心痛点**：无法直接自研接入美团外卖开放平台（需30家门店门槛）
- **目标**：寻找第三方SaaS服务商作为中间层，将美团外卖数据拉取后对接到自研ERP系统

### 1.2 调研范围
1. **重点调研**：麦芽田（用户指定）
2. **对比调研**：银豹、客如云、有赞、哗啦啦、美团经营管家、乐外卖、快跑者

---

## 二、结论先行——推荐排序

| 优先级 | 服务商 | 推荐理由 | 适配度 |
|--------|--------|----------|--------|
| ⭐⭐⭐⭐⭐ | **麦芽田** | 专注鲜花/闪购行业，支持A4彩打/贺卡打印，完美适配鲜花品类，数据聚合能力强 | 非常匹配 |
| ⭐⭐⭐⭐ | **有赞连锁** | 美团外卖官方授权对接，支持ERP数据回传，品牌连锁管理完善 | 匹配 |
| ⭐⭐⭐⭐ | **银豹收银** | 支持美团外卖对接，鲜花行业适配，多门店管理，API数据导出 | 匹配 |
| ⭐⭐⭐ | **客如云** | 聚合外卖功能完善，多平台对接能力强，但餐饮为主，鲜花适配一般 | 部分匹配 |
| ⭐⭐⭐ | **哗啦啦** | 餐饮行业深度覆盖，外卖聚合能力强，但行业适配偏向餐饮 | 部分匹配 |
| ⭐⭐ | **美团经营管家** | 官方工具，数据最全，但功能封闭，数据回传受限 | 备选 |

**最佳推荐**：**麦芽田 + 自研ERP数据对接方案**

## 三、重点调研对象：麦芽田

### 3.1 产品定位

麦芽田是一款**专注订单管理的技术服务商**，定位为"全渠道外卖订单管理SaaS平台"，专为外卖自配送商户提供订单全链路的SaaS服务。

**据麦芽田官网（https://www.maiyatian.com/）：**
> 麦芽田-全渠道外卖订单管理SaaS平台，助力提升同城订单管理便捷高效

**据华军软件园产品介绍：**
> 麦芽田是外卖商户全渠道订单管理SaaS平台，2017年上线，聚合美团/饿了么等多平台订单，一键对接70+配送商，提供智能发单、数据报表、库存管理，适配鲜花/蛋糕/餐饮/生鲜等自配送商家。

### 3.2 核心功能

| 功能模块 | 具体能力 |
|----------|----------|
| **全渠道订单聚合** | 美团外卖、淘宝闪购、饿了么、京东到家、有赞、微盟、美团团购、抖音等 |
| **一键配送发单** | 支持70+配送平台比价发单（达达、闪送、顺丰同城、美团众包等） |
| **智能比价发单** | 支持价格/时效/骑手评分自动派单，保底发单，自动加小费规则 |
| **多场景打印** | 小票打印、分单打印、A4彩色打印、贺卡打印（**鲜花行业专属**） |
| **多门店管理** | 品牌服务：支持总部统一配置、分店独立运营 |
| **数据魔方** | 全方位数据整理分析，营业额/订单量/客单价/热销商品分析 |
| **库存管理** | 动态实时库存管控，支持库存不足自动暂停接单 |
| **客服聚合** | 整合多平台客服消息，统一回复，工单管理 |

### 3.3 鲜花行业适配分析（重点）

**麦芽田对鲜花行业有深度适配，这是其核心优势：**

1. **行业解决方案专属**：官网明确标注"浪漫鲜花"作为六大行业解决方案之一

2. **鲜花专属功能**：
   - A4彩色打印（鲜花贺卡、花语卡）
   - 贺卡打印（订单附带手写贺卡内容）
   - 甄选花材管理（库存与商品关联）
   - 节日高峰解决方案（情人节/七夕等）

3. **客户案例**：
   > **鼎卉鲜花**："鲜花礼品行业最大的痛点就是保鲜难、物流慢，而麦芽田的甄选花材和库存管理极大的帮助我们商家解决了这类难题。"

4. **多门店就近分单**：
   > "以对接美团、淘宝闪购为主的线上外卖店铺，在不限制门店数量的同时，可以根据顾客的实际取货位置自动选择就近门店进行分单配送，节省时间、节省配送费用。"

### 3.4 对接方式

**据麦芽田功能演示（https://www.maiyatian.com/help.html）：**

|----------|------|------|


### 3.6 数据开放性评估

**关键问题：麦芽田能否将数据回传给自研ERP？**

| 能力 | 支持情况 | 说明 |
|------|----------|------|
| 订单数据导出 | ✅ 支持 | 报表中心支持订单明细导出 |
| API开放 | ⚠️ 未明确 | 未查到公开API文档，需联系商务 |
| Webhook回调 | ⚠️ 未明确 | 建议联系确认 |
| 财务数据 | ✅ 支持 | 账单报表、成本核算 |
| 配送数据 | ✅ 支持 | 配送轨迹、费用明细 |

**结论**：麦芽田数据以SaaS平台使用为主，**未查到公开的API开放接口**。如需对接自研ERP，建议：
1. 联系麦芽田商务确认是否有企业版API
2. 使用报表导出功能+定时任务同步
3. 或考虑数据中转方案

## 六、针对用户4家鲜花门店的选型建议

### 6.1 最佳方案：麦芽田 + 数据中转方案

**方案架构**：
```
美团外卖/饿了么 → 麦芽田（订单聚合） → 数据导出 → 自研ERP
```

**具体实施建议**：

1. **麦芽田作为主订单入口**
   - 授权绑定4家门店的美团外卖/淘宝闪购/饿了么
   - 使用麦芽田统一处理订单聚合、分单打印、配送调度
   - 鲜花专属功能：A4贺卡打印、贺卡内容打印

2. **数据回传自研ERP的三种方式**
   - **方式一**：麦芽田企业版API（联系商务确认是否有）
   - **方式二**：定时任务抓取报表数据（CSV/Excel导出）
   - **方式三**：数据中台方案（麦芽田 → 中间层 → 自研ERP）

3. **年度成本**：
   - 麦芽田服务费：约 5,000-8,500元/年
   - 数据对接开发：一次性约 5,000-10,000元（自研或外包）

### 6.2 备选方案：银豹收银 + 有赞云

**适用场景**：如果麦芽田无法提供API，可考虑此方案

**方案特点**：
- 银豹收银：作为收银/订单基础
- 有赞云：作为外卖聚合层+数据API开放层
- 自研ERP：通过有赞云API对接数据

**优点**：有赞云有公开API，支持ERP对接
**缺点**：鲜花行业适配不如麦芽田

## 七、风险提示与注意事项

### 7.1 麦芽田风险点

1. **系统稳定性**：有用户反馈系统偶发故障，建议商务谈判时确认SLA

3. **融资情况**：未查到公开融资信息，公司规模中等

   - 联系麦芽田商务获取正式报价单

   - 4店连锁能否争取折扣
   - 能否获取API开放接口文档
   - 是否支持数据导出频率定制
