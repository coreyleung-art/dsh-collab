## 五、越秀店专项诊断——为什么一直亏损？

越秀店6个月经营期(12月~5月)每月亏损，核心原因：

### 1. 采购成本率畸高（54.3% vs 天河40.9%）

差额13个百分点，意味着同等营收下越秀每月多亏：
- 按月均营收¥50,081计算：(54.3%-40.9%)×50,081 = **¥6,711/月**
- 可能原因：
  - 规模不够，采购量小导致单位成本高
  - 采购"其他"类占比高（含未标注花材）
  - 售价偏低（需对比天河同品类定价）

### 2. 营收不足，规模效应无法释放

- 月均¥50,081仅为平衡线¥55,271的91%
- 6个月中仅2个月(3月、5月)营收超过平衡线
- 1月仅¥21,486——不到平衡线一半

### 3. 人力成本刚性+高占比（29%）

- 最低月也要¥5,677，正常月¥11,000-16,000
- 占营收29%，高于天河的20.6%
- 反映出营收不够养活现有人力配置

### 4. 刷单投流效率偏低

- 投流¥5,553/月(11.1%)，但营收增长不稳定
- 天河投流¥6,669/月(7.5%)带来¥88,395营收，ROI更高

## 七、方法论说明

### 盈亏平衡计算公式

```
盈亏平衡营收 = 月固定成本 ÷ 贡献边际率

贡献边际率 = 1 - 变动成本率
变动成本率 = 采购成本率 + 平台配送率 + 渠道返点率 (+ 刷单投流实际费率 + 推广费率)
```

### 刷单投流调整逻辑

根据Corey确认：刷单投流费用中约80%为本金，本金会通过平台结算回流到现金流中。因此：
- **实际刷单成本 ≈ 记录金额的20%**（即服务费+平台扣点）
- 场景B采用此调整，更接近真实经营状况
- 场景A（全额计入）为保守估计，场景C（完全剔除）为乐观估计

### 数据局限

1. 越秀6月人力和费用数据为0（不完整月），暂不计入分析
2. 天河2025-08/09采购异常低(¥7-8K vs 后期¥25-38K)，可能为开业初期采购模式不同，已从分析月份中剔除
3. 江南西仅1个月数据，盈亏平衡线可靠性有限
4. 采购"其他"类占比20-30%，可能含未标注花材，影响采购成本率准确性
