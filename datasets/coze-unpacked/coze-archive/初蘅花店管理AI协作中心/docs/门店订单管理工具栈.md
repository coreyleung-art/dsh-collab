# 门店订单管理工具栈

> 更新时间：2026-06-07

## 工具架构

```
线上订单流入
    │
    ├──→ 麦芽田（主力）
    │     ├── 真实订单管理（美团/饿了么/京东到家等10+平台聚合）
    │     ├── A4彩色大订单纸质打印
    │     ├── 小票打印
    │     ├── 贺卡打印
    │     ├── 配送管理
    │     └── 已开通年度会员
    │
    └──→ 花集通（补充）
          ├── 补单管理
          ├── 虚拟AI配送路径回传
          └── 补充麦芽田无法覆盖的板块
```

## 工具分工

| 功能 | 麦芽田 | 花集通 |
|------|--------|--------|
| 真实订单管理 | ✅ 主力 | ❌ |
| 补单管理 | ❌ | ✅ 主力 |
| A4彩色打印 | ✅ | ❌ |
| 小票打印 | ✅ | ❌ |
| 贺卡打印 | ✅ | ❌ |
| 配送管理 | ✅ | ✅（虚拟路径） |
| AI配送路径回传 | ❌ | ✅ |
| 多平台聚合 | ✅ 10+平台 | ❌ |
| 会员状态 | 年度会员 | — |

## ERP对接规划

- 麦芽田提供开放API，可对接自研ERP拉取订单数据
- 花集通需确认是否有API能力（待调研）
- 目标：统一数据入口 → 自研ERP销售数据端
