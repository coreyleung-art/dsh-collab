# M05 门店编制与岗位标准

**版本**：v1.0  
**生效日期**：2026-04-23  
**适用范围**：守白鲜花店（广州地区）

---

## 第一章 门店编制标准

### 第一条 编制原则

1. **运营核心原则**：编制配置以线上运营效率、无损订单交付目标为核心导向；
2. **适配经营原则**：以线上订单量、运营时段需求、低客单价盈利特性及私域转化目标为核心依据；
3. **精简高效原则**：在保障正常运营的前提下，控制人力成本，避免冗余编制；
4. **弹性调整原则**：针对大促节日、订单激增等特殊场景，灵活配置临时人力。

### 第二条 基础编制配置

| 线上日均订单量 | 编制配置 |
|--------------|---------|
| ≤50单 | 店长1名 + 店员2名 |
| 51-100单 | 店长1名 + 助理店长1名 + 店员3名 |
| ＞100单 | 店长1名 + 助理店长1名 + 店员4-5名 |

### 第三条 弹性编制配置

1. **触发场景**：大促节日、线上平台活动、突发订单激增（单日订单超日常30%）；
2. **配置标准**：在基础编制基础上，临时增设1-2名弹性人员（含临时聘任花艺师、兼职客服/打包员）；
3. **薪酬标准**：
   - 兼职客服/打包员：15元/小时；
   - 临时聘任花艺师：按具体项目具体合作模式核算。

### 第四条 编制调整规则

1. 每月根据上月数据综合评估是否调整基础编制；
2. 大促节日前7天确认弹性人员需求并完成招募，提前3天公示临时排班表；
3. 连续1个月低于对应编制阈值且指标稳定达标时，可缩减店员编制，优先保留1年以上、考核优秀的员工。

## 第二章 岗位执行标准

### 第一节 店长

**核心职责**：运营统筹、人力应急保障、团队管理、成本与库存、供应链协同、客户管理、外协管理、6S管理统筹、合规管理。

**任职要求**：仅限内部提拔，1年以上门店工作经验。

**考核要点**：
- 季度营业利润达标（≥10,000元），私域利润贡献占比≥30%；
- 无损交付指标：1分钟回复率≥90%、返图率100%、履约率≥90%；
- 私域转化核心指标达成；
- 美团外卖综合评分≥8.0；
- 花材损耗率≤5%。

### 第二节 助理店长

**核心职责**：协助运营、客服管理、订单管控、排班协助、物料管理、供应链协同协助、外协协助、临时统筹、6S管理协助。

**任职要求**：仅限内部提拔，熟悉全部基础岗位工作。

**考核要点**：
- 1分钟回复率≥90%、返图率100%、履约率≥99%；
- 协助完成月度销售目标与私域转化目标；
- 无重大订单失误，私域客户满意度≥90%。

### 第三节 店员

**核心职责**：客服响应、订单处理、花材养护、售后配合、外协配合、日常运维、6S执行。

**任职要求**：有无经验均可，基本沟通表达能力。

**考核要点**：
- 月度全勤；
- 无损交付指标达成；
- 无重大订单制作失误；
- 花材损耗率个人操作单月≥3%需担责；
- 6S执行达标。

### 第四节 试岗人员

**试岗周期**：3个自然日。

**核心职责**：基础学习、协助工作、适应观察。

**试岗结果**：
- 合格：次日正式进入试用期；
- 不合格：当日告知，试岗薪酬120元/天，不满3天不发放。

### 第五节 试用期店员

**试用期**：3个月，考核合格可提前转正。

**核心职责**：学习适应、协助工作、培训参与、遵守制度。

**考核要点**：月度考核合格、考勤合规、积极参与培训。

## 第三章 临时聘任花艺师

### 合作形式

非全日制临时聘任，无劳动关系，双方签订临时合作协议。

### 薪酬核算

| 工作类型 | 计费方式 |
|---------|---------|
| 设计打板 | 按单付费 |
| 外出授课 | 按次/按时付费（含交通补贴） |
| 花壳生产 | 计件付费 |
| 大促支援 | 时薪付费 + 100元/人专项补贴 |
