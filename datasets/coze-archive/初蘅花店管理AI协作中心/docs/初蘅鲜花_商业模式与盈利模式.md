**更新日期：2026-06-22**

## 一、整体架构：两条盈利线

初蘅鲜花的商业本质是**「供应链公司 + 品牌管理公司」双轮驱动**，两套盈利逻辑各自独立、互相放大：

```
                    初蘅鲜花（实际控制人：梁振宇/Corey）
                              │
            ┌─────────────────┼─────────────────┐
            │                                   │
     供应链公司                              品牌管理公司
   （趣趣就来）                            （趣趣就来，同一主体）
            │                                   │
    赚的是「采购差价」                    赚的是「品牌溢价」
    + 供应链效率收益                      + 运营服务分成
            │                                   │
    ┌───┬───┬───┐                    ┌───┬───┬───┬───┐
    天河 越秀 江南西 佛山               天河 越秀 江南西 佛山
    (欣趣)(全萃)(新馨)(注册中)          (欣趣)(全萃)(新馨)(注册中)
```

**核心洞察**：门店是两个盈利模型的交汇点——供应链通过门店走量，品牌通过门店变现。门店不直接赚大钱，门店是管道。

## 二、供应链商业模式与盈利模式

### 2.1 商业模式：集中采购 + 统一配送

| 维度 | 描述 |
|------|------|
| **角色** | 趣趣就来作为「鲜花供应链公司」，统一为所有门店集中采购花材、包材、耗材 |
| **核心逻辑** | 门店不单独采购，所有采购需求汇总至趣趣就来，由其对接产地/批发市场，再配送至各门店 |
| **法律基础** | 《品牌授权与运营服务协议》第一章1.4条：门店须使用甲方（趣趣就来）的「货品采购渠道」和「物流配送体系」 |
| **规模效应** | 4店（未来6-10店）合并采购量→议价能力→采购成本持续下降 |

### 2.2 四级缓冲供应链架构

```
Level 1: 产地源头（云南）
  → 拍手直采，绕过所有中间环节，获得最前端价格
  → 产地直采降低采购成本15-30%

Level 2: 云南前置仓
  → 节日大促前1-2周锁定花材，囤货+分拣+预冷
  → 仅S级节日（520/七夕/情人节/母亲节）激活

Level 3: 岭南花卉市场前置仓
  → 日常采购主渠道，1-2小时可达门店
  → 节日时承接云南发运，二次分拣后配送

Level 4: 门店冷库
  → 4店各配装配式保鲜冷库
  → 终端蓄水，保证销售不断货
```

### 2.3 供应链盈利模型

**盈利来源 = 采购差价 + 供应链效率收益**

| 盈利项 | 机制 | 金额测算 |
|--------|------|---------|
| **采购差价** | 门店按「结算价」向趣趣就来支付采购款，结算价与产地实际采购价之间的差额 | 产地直采比批发市场低15-30%，门店按接近批发市场价结算，差价归供应链 |
| **规模议价收益** | 4店合并采购量→获得更低产地价→但门店结算价不变 | 门店越多，采购量越大，差价越厚 |
| **库存调度收益** | 统一库存管理→门店间调拨花材→减少损耗→降低实际成本 | 行业损耗5-15%，集中调度可压至5%以下 |
| **包材集中采购** | 1688/阿里巴巴批量采购包材/资材→门店按标价结算 | 批量采购价约为零售价的50-60% |
| **物流集约收益** | 岭南→多店统一配送→单次配送成本分摊 | 对比每店单独采购运输，节约20-40% |

|------|----------|--------|---------|

| 越秀 | ¥45,021 | 42.0% | ¥107,180 |

> 四店合计月采购额超¥12万，已达批发议价起步线。未来6-10店时月采购额可达¥18-30万，进入大客户议价区间。

### 2.4 供应链盈利能力测算

| 场景 | 门店数 | 月采购总额 | 供应链差价率 | 月供应链利润 |
|------|--------|----------|------------|------------|
| 当前 | 3店 | ¥123K | 8-12% | ¥10K-15K |
| +佛山 | 4店 | ¥165K | 10-15% | ¥16K-25K |

## 三、品牌商业模式与盈利模式

### 3.1 商业模式：品牌授权 + 运营服务

| 维度 | 描述 |
|------|------|
| **角色** | 趣趣就来作为「品牌管理公司」，向门店授权初蘅品牌使用权+提供全套运营支持 |
| **核心逻辑** | 门店独立经营、自负盈亏，品牌方不承担门店经营风险，通过授权费+服务分成获取收益 |
| **法律基础** | 《品牌授权与运营服务协议》完整约定 |
| **风险隔离** | 门店亏损不影响品牌方收入结构（授权费已收，服务费亏损月不收） |

### 3.2 品牌授权内容

| 授权资产 | 具体内容 |
|----------|---------|
| **商标权** | 初蘅文字商标+图形商标+系列注册商标 |
| **VI系统** | 品牌标志/标准色/标准字体/店铺装修方案/包装设计方案/宣传物料模板 |
| **标准化管理体系** | 运营管理手册/产品SOP/服务标准/培训体系/质量管理 |
| **供应链管理系统** | 供应商准入/采购渠道/物流体系/库存管理 |
| **数字化系统** | 管理系统账号+权限/营销推广方案/门店陈列设计 |

### 3.3 品牌盈利模型

**盈利来源 = 品牌授权费（一次性）+ 品牌运营服务费（持续性）**

#### 3.3.1 品牌授权费（一次性收入）

### 3.4 品牌盈利的关键杠杆

| 杠杆 | 机制 | 效果 |

| **门店盈利能力** | 门店利润越高→30%基数越大 | 品牌方利益与门店利益完全一致 |
| **淡季不收费** | 亏损月不收服务费→品牌方有动力帮门店过冬 | 天然激励品牌方输出运营能力 |
| **品牌溢价** | 初蘅品牌越强→门店定价权越大→利润越厚→服务费越高 | 飞轮效应 |

## 四、两条盈利线的协同效应

### 4.1 协同机制

```
品牌授权 → 吸引更多门店加入
    ↓
门店数量增加 → 采购量增加
    ↓
供应链规模效应 → 采购成本下降 → 门店利润上升
    ↓
门店利润上升 → 品牌运营服务费增加
    ↓
品牌收入增加 → 品牌投入增加 → 品牌力更强 → 吸引更多门店
    ↺ 循环
```

**核心飞轮**：门店越多→采购越便宜→门店越赚钱→品牌分成越多→品牌越强→更多门店加入

### 4.2 两条线的收入结构对比

| 收入类型 | 供应链线 | 品牌线 |
|---------|---------|--------|
| **收入性质** | 采购差价（交易型） | 授权费+分成（权益型） |
| **收入弹性** | 随采购量线性增长 | 随门店数和盈利能力非线性增长 |
| **风险特征** | 采购量波动风险 | 门店亏损零收入风险 |
| **启动门槛** | 已有3店采购规模 | 已有品牌授权协议 |
| **规模上限** | 取决于区域采购半径 | 取决于品牌辐射力 |
| **边际成本** | 递减（集中采购/物流） | 极低（授权/培训边际成本≈0） |

### 4.3 合计盈利测算

| 场景 | 门店数 | 供应链月利 | 品牌月利（服务费） | 品牌年利（授权费） | 合计年利润 |
|------|--------|----------|---------------|---------------|----------|
| 当前 | 3店 | ¥10K-15K | ¥5K-8K | ¥0（已开店） | ¥180K-276K |
| +佛山 | 4店 | ¥16K-25K | ¥7K-12K | ¥50K | ¥348K-484K |
| 规模化 | 6店 | ¥30K-45K | ¥12K-20K | ¥150K | ¥666K-960K |
| 成熟期 | 10店 | ¥60K-88K | ¥25K-40K | ¥350K | ¥1,370K-1,986K |

> **10店成熟期，品牌管理公司年利润可达137-199万元。**

## 五、门店视角：如何赚钱

门店是两个盈利模型的交汇点，但门店本身也有独立的盈利逻辑：

### 5.1 门店盈利公式

```
门店净利润 = 营业收入 - COGS（花材+包材+耗材） - 人力成本 - 运营费用 - 品牌运营服务费（30%净利润）
```

### 5.2 门店利润驱动因素

| 驱动因素 | 控制方 | 机制 |
|---------|--------|------|
| **客单价** | 门店+品牌 | 品牌溢价→定价权→高客单 |
| **单量** | 门店+平台 | 即时零售多平台入驻+刷单投流+私域 |
| **采购率** | 供应链 | 供应链集中采购→低采购率→高毛利 |
| **人力效率** | 门店+品牌 | 通岗运营+流水线作业→人效最大化 |
| **固定成本** | 门店 | 选址策略→社区前置仓吃掉临街溢价 |

### 5.3 三店5月实际利润数据

| 门店 | 营收 | COGS率 | 人力率 | 费用率 | 净利润率 |
|------|------|--------|--------|--------|---------|
| 天河 | ¥137,629 | 36.9% | 24.9% | 27.2% | 11.0% |
| 越秀 | ¥107,180 | 36.5% | 27.2% | 27.7% | 8.6% |
| 江南西 | ¥45,955 | 35.0% | 32.7% | 31.8% | 0.4% |

> 三店均已过盈亏平衡线（5月），但利润率差异显著。天河体量最大利润最厚，江南西低固定成本是最大优势。

## 六、与行业对比：为什么初蘅的模型更优

| 维度 | 传统花店 | 初蘅模型 | 差异来源 |
|------|---------|---------|---------|
| **采购** | 零散批发，单店采购 | 集中采购，4店合一 | 规模议价→低15-30% |
| **选址** | 临街旺铺，高租金 | 社区前置仓，低租金 | 吃掉临街溢价50-70% |
| **人力** | 花艺师，月薪6-8K | 通岗运营，月薪3-4K | 制造业逻辑替代手艺人 |
| **工艺** | 全手工，单束30-40min | 花泥插花+流水线，8-11min | 标准化SOP替代经验 |
| **获客** | 坐等客来 | 即时零售+刷单投流+私域 | 主动获客替代被动等待 |
| **管理** | 老板盯店 | AI系统+数字化决策 | 1人管理多店 |
| **品牌** | 无品牌，靠口碑 | 初蘅统一品牌，授权+分成 | 品牌溢价→定价权 |

### 成本结构对比

| 成本项 | 传统花店占比 | 初蘅占比 | 节省 |
|--------|------------|---------|------|
| 房租 | 20-30% | 5-8% | 前置仓替代临街 |
| 人力 | 30-40% | 25-33% | 通岗+流水线 |
| 采购 | 35-45% | 35-43% | 产地直采对冲 |
| **合计** | 85-115% | 65-84% | **综合低15-30%** |

## 七、增长路径：从3店到行业基础设施

### 阶段一（当前-6个月）：验证模型

- 3店→4店（+佛山）
- 供应链差价验证：月均¥10-15K
- 品牌服务费验证：全年¥50-80K
- AI系统自用验证（库存Bot/财务Agent/培训系统）

### 阶段二（6-18个月）：规模化

- 4店→6-8店
- 供应链月利¥30-45K + 品牌月利¥12-20K
- 花店AI运营管家SaaS化→行业产品
- 品牌力从「初蘅」延伸到「花店行业AI基础设施」

### 阶段三（18-36个月）：平台化

- 10+店 + 加盟店
- 供应链平台开放→服务非初蘅花店
- AI管家SaaS → ¥299/店/月 × N家店
- 品牌管理公司独立运营

**终局**：初蘅不是一家花店，是一家**通过花店验证供应链和品牌模型，再用AI工具把这个模型复制给行业**的公司。

## 八、风险提示

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 门店持续亏损→品牌服务费归零 | 品牌线无收入 | 供应链差价兜底；AI运营能力输出帮门店过冬 |
| 供应链差价过薄→门店采购意愿下降 | 供应链线收入萎缩 | 差价率控制在8-15%，门店仍有明显成本优势 |
| 品牌授权协议执行不到位 | 法律风险 | 协议已约定违约金+暂停授权条款 |
| 门店独立采购绕过供应链 | 供应链规模效应瓦解 | 协议约定须使用品牌采购渠道+品质管控 |
| 品牌力不足以支撑30%分成 | 门店觉得不值 | AI运营系统+数字化管理+培训体系=硬服务 |
