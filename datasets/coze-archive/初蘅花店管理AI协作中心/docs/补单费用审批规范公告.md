# 关于规范补单费用审批提交流程的通知

**致：全体门店**

**生效日期：即日起**

---

近期财务核查发现，补单费用审批单存在填写不规范、信息缺失、与其他费用混报等问题，导致对账困难、数据归属不清。为保障财务数据准确性，现对补单费用审批流程作如下规范：

## 一、提交内容要求

每笔补单审批**必须写明与补单团队对账的完整明细**，包括：

- 补单日期
- 补单单量
- 好评数量（如有）
- 本金金额
- 服务费计算（单价×单量）
- 好评费计算（如有）
- 合计金额

## 二、独立提交，不得混报

补单费用**必须单独提交审批**，不得与餐饮、交通、办公等其他费用项目合并在同一笔审批单中。

混合提报的审批单将被驳回。

## 三、统一格式

所有补单费用按以下格式填写：

> **日期：X单 + X好评（本金¥X + 服务费X单×¥X + 好评X单×¥X = ¥合计）**

**示例：**

> 4/27：23单 + 2好评（本金¥1,509.86 + 服务费23×¥11 + 好评2×¥5 = ¥1,772.06）

多日补单可合并提交，但**每日明细需逐行列示**，例如：

> 5/11：6单 + 0好评（本金¥510.53 + 服务费6×¥11 = ¥576.53）
> 5/12：13单 + 1好评（本金¥1,093.78 + 服务费13×¥11 + 好评1×¥5 = ¥1,241.78）

## 四、驳回规则

以下情况审批将被驳回，需修改后重新提交：

1. **未写明单量和好评数**——仅填金额无明细的
2. **补单与其他费用混报**——同一审批单中包含补单以外项目的
3. **格式不符合规范**——未按上述统一格式填写的

## 五、常见问题

**Q：一天内多批补单怎么填？**
A：按日合并，写明当日总单量和好评数即可。

**Q：补单团队费率调整了怎么办？**
A：按实际对账费率填写，服务费和好评费单价以实际发生为准。

**Q：跨月补单怎么归属？**
A：费用归属月份按补单实际发生日期填写，不要按提交日期归属。
