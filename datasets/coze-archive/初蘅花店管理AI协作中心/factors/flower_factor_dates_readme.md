# 鲜花花材批发价格 — 因子日期数据集说明

## 概述

本数据集覆盖 **2023-01-01 ~ 2028-12-31** 共2192天的逐日因子标注，对应规范文档中的**因子群一（节日需求因子 ⭐⭐⭐⭐⭐）**和**因子群六（季节性与趋势因子 ⭐⭐⭐）**，另补充了**鲜花销售大促/行业旺季标记**。

## 文件位置

- 项目路径：`/factors/flower_factor_dates.csv`
- 编码：UTF-8 with BOM
- 行数：2192行（含表头）

## 关键设计说明

1. **节前效应模型**：根据行业实证，节前1-2天价格达峰(effect=5)，3-5天快速攀升(4)，6-10天开始上涨(3)，11-15天预热(2)，16-20天微弱影响(1)
2. **节后效应模型**：节后1天效应=4，逐天衰减，5天后归零
3. **多节日叠加**：如2024年春节(2/10)与情人节(2/14)仅隔4天，数据集同时标注两个节日的效应
4. **行业备货期**：KIFA数据显示520备货期为5月6-20日，母亲节备货期为节前10天，情人节备货期为2月4-13日等
5. **季节性批发量**：春季占全年35%（3-5月），夏季15-20%（6-8月），秋季20%（9-11月），冬季30%（12-2月含节日驱动）
6. **年度趋势**：价格中枢年增约3.5%，悦己消费占比从2023年41%增至2028年56%

## 数据使用建议

- 与 `flower_price_daily` 核心价格表通过 `trade_date` 字段JOIN
- 建模时优先使用 `pre_holiday_effect` + `holiday_max_strength` 作为节日因子
- 品类差异化建模：玫瑰对情人节/七夕极敏感，菊花对清明敏感，康乃馨对母亲节敏感
- 同一时段多节日叠加时需解耦各节日效应

## 数据来源

- 农历日期：zhdate库（精确农历-公历转换）
- 清明节气：天文历精确日期
- 节日花材关联：六朵花鲜花网、花店营销方案、中国花卉协会报告
- 批发量季节分布：2023全国花卉产销形势分析报告、KIFA月报
- 悦己消费占比：行业调研数据（2019年23%→2023年41%趋势外推）
